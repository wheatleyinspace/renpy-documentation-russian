iOS

Ren'Py поддерживает создание приложений iOS, работающих на устройствах iPhone и iPad. Поскольку для создания приложений iOS требуются программы, разработанные Apple (например, IDE Xcode), сборка приложений iOS возможна только на компьютерах под управлением macOS.

Обязательное уведомление о лицензиях

Некоторые библиотеки, используемые Ren'Py на iOS, распространяются на условиях лицензии GNU Lesser General Public License (LGPL). Для распространения приложений Ren'Py вам необходимо соблюдать условия этой лицензии. Мы полагаем, что включения следующего текста в описание вашего приложения будет достаточно, однако для полной уверенности проконсультируйтесь с юристом.

This program contains free software licensed under a number of licenses, including the GNU Lesser General Public License. A complete list of software is available at https://www.renpy.org/l/license/.

Текущее состояние разработки

Поддержка iOS в Ren'Py постоянно развивается. Хотя на движке уже выпускались игры в Apple App Store, стандартный графический интерфейс Ren'Py не полностью соответствует рекомендациям Apple (Human Interface Guidelines) и потребует адаптации.

Пожалуйста, сообщайте разработчикам Ren'Py о результатах прохождения модерации вашей игры в App Store.

Отличия платформы

Платформа iOS во многом похожа на Android, но имеет существенные отличия от платформ с управлением мышью. Все отличия платформы Android в полной мере применимы и к iOS.

Список видеоформатов, поддерживаемых iOS, доступен в документации Apple.

Тестирование и эмуляция

Для тестирования Ren'Py поддерживает два режима эмуляции iOS. Доступ к ним осуществляется через раздел «iOS» в лаунчере. Оба режима симулируют работу сенсорного экрана: события передаются в игру только при зажатой кнопке мыши.

iPhone

Эмулирует интерфейс смартфона iPhone.

Tablet

Эмулирует планшет iPad.

Хотя эти эмуляторы удобны для быстрой проверки проекта, настоятельно рекомендуется тестировать игру на реальных устройствах. Эмуляторы не учитывают эргономические факторы, такие как реальный физический размер пальцев пользователя на компактном экране.

Сборка пакета

Сборка игры Ren'Py для iOS в настоящее время представляет собой более сложный процесс по сравнению с другими платформами. Предполагается, что у вас есть опыт разработки приложений для iOS или вы можете следовать официальным руководствам Apple.

Подготовка к работе

Перед упаковкой игры Ren'Py необходимо подготовить компьютер Mac для сборки приложений iOS. Это включает установку Xcode на Mac, регистрацию в программе Apple Developer Program и создание профиля подготовки (provisioning profile), позволяющего запускать приложения на вашем устройстве iOS.

В официальном руководстве Apple App Distribution Quick Start подробно объясняется вся процедура настройки. Мы рекомендуем ознакомиться с ним и даже собрать одно из тестовых шаблонных приложений Xcode перед переходом к проектам Ren'Py.

Создание проекта Xcode

Первым шагом в создании приложения iOS является генерация проекта Xcode. Для этого выберите пункт «Create Xcode Project» (Создать проект Xcode) в меню iOS лаунчера Ren'Py.

Имя проекта Xcode выбирается автоматически на основе названия игры в лаунчере. Настройки проекта кастомизируются на основе этого имени, но могут быть изменены непосредственно в Xcode.

Проекты Xcode, созданные таким образом, привязаны к конкретной версии Ren'Py. После обновления Ren'Py необходимо создать новый проект Xcode для вашей игры и заново применить пользовательские настройки.

Сборка проекта

После того как проект создан в Ren'Py, его можно открыть в Xcode, выбрав пункт «Launch Xcode» в лаунчере. Когда проект открыт в Xcode, его можно собрать и установить на устройство iOS.

Обновление проекта

Пункт «Update Xcode Project» копирует последнюю версию файлов вашего проекта Ren'Py в проект Xcode. Это используется при изменении файлов сценария и ресурсов игры, но не подходит в случае обновления самого Ren'Py.

Настройка

Большинство настроек выполняется внутри проекта Xcode. Например, иконка приложения, стартовые изображения и ориентация экрана настраиваются в Xcode.

Экран запуска (Launch Storyboard)

При запуске приложения отображается раскадровка запуска (Launch Storyboard, настроенная в проекте Xcode вне Ren'Py), пока Ren'Py подготавливает и выводит интерфейс игры.

После завершения инициализации Ren'Py либо возобновляет текущую сессию игры, либо запускает заставку (splashscreen) и главное меню.

Генерация иконок

Для упрощения процесса разработки Ren'Py умеет автоматически генерировать набор иконок iOS из файла изображения.

ios-icon.png

Если этот файл присутствует в проекте, он автоматически масштабируется до различных разрешений PNG, необходимых для иконки iOS.

Pyobjus

На платформах iOS и macOS доступна библиотека Pyobjus, позволяющая опытным разработчикам вызывать функции системных библиотек Objective-C из Python.
