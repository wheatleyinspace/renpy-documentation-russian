Конфигурационные переменные

Конфигурационные переменные управляют поведением внутренней реализации Ren'Py, позволяя настраивать движок множеством способов: от самых распространенных (например, изменение размера экрана) до специфических (добавление новых типов архивных файлов).

Реализация Ren'Py исходит из предположения, что после инициализации системы GUI конфигурационные переменные больше не изменяются. Изменение конфигурационных переменных вне блоков init может привести к неопределенному поведению. Конфигурационные переменные не сохраняются в данных сохранений.

Большинство конфигурационных переменных легко задать с помощью оператора define:

define config.rollback_enabled = False

Переменные-словари и списки можно заполнять с помощью define или в блоке init python:

define config.preload_fonts += ["OrthodoxHerbertarian.ttf"]
define config.adjust_attributes["eileen"] = eileen_adjust_function

init python hide:
    def inter_cbk():
        # неудачный пример колбэка
        renpy.notify("Взаимодействие!")

    config.interact_callbacks.append(inter_cbk)

Информация о проекте

define config.name = ""

Строка, задающая имя игры. Она включается в отчеты об ошибках (traceback) и другие файлы логов, помогая определить версию используемой игры.

define config.version = ""

Строка, задающая версию игры. Она включается в отчеты об ошибках (traceback) и другие файлы логов, помогая определить версию используемой игры.

define config.window_icon = None

Если не None, задает имя файла изображения значка для главного окна игры. Это не влияет на значки исполняемых файлов Windows и приложений Mac, так как они управляются разделом Специальные файлы.

define config.window_title = None

Статическая часть заголовка окна с игрой Ren'Py. Переменная _window_subtitle добавляется к ней для получения полного заголовка окна.

Если None (по умолчанию), используется значение config.name.

Режим авточтения

define config.afm_bonus = 25

Количество бонусных символов, добавляемых к каждой строке текста при работе режима авточтения (Auto-Forward Mode).

define config.afm_callback = None

Если не None, функция Python, вызываемая для проверки безопасности автопрокрутки вперед. Если None, используется внутренняя функция для отключения авточтения во время воспроизведения голоса (если только переменная preferences.wait_voice не установлена в False).

define config.afm_characters = 250

Количество символов в строке, необходимое для того, чтобы задержка, указанная в настройках авточтения, действовала в полном объеме.

define config.afm_voice_delay = .5

Количество секунд после завершения воспроизведения голосового файла, по истечении которых авточтение может перейти к следующему тексту.

Функции обратного вызова (колбэки)

Принимают функции, вызываемые при возникновении определенных событий. Это не единственные колбэки — функции для конкретных систем описаны в соответствующих разделах документации.

Колбэки можно регистрировать с помощью функции renpy.callback() — декоратора Python, который автоматически добавляет функцию в соответствующий список колбэков на основе имени функции (автоматически преобразуемого во множественное число). Например:

@renpy.callback
def start_callback():
    import time
    global actual_start_time
    actual_start_time = time.time()
define config.after_default_callbacks = [ ... ]

Список функций, вызываемых (без аргументов) при обработке операторов default. Операторы default выполняются после этапа инициализации, но до запуска игры; при загрузке сохранения; после отката; перед запуском lint; а также при других обстоятельствах.

Как и сам оператор default, эти колбэки являются отличным местом для добавления в игру данных, которые еще не существуют, но необходимы.

Этот колбэк также выполняется между фазой инициализации и стартом игры, поэтому может использоваться для инициализации структур, необходимых при начале игры.

define config.after_init_callbacks = [ ... ]

Список функций, вызываемых (без аргументов) в самом конце фазы инициализации, до того как игра начнет свое нормальное выполнение в первый раз. Они запускаются после config.after_default_callbacks, поэтому здесь можно настраивать колбэки, требующие доступа к данным операторов default (разница в том, что этот список вызывается только один раз, тогда как config.after_default_callbacks вызывается также после отката и загрузки сохранения).

Рекомендуемое использование — настройка других колбэков, которым нужен доступ к данным по умолчанию. Другие действия могут не сработать — это выполняется после того момента, когда большинство переменных конфигурации уже не должно изменяться, но до реального запуска игры.

define config.context_callbacks = [ ]

Колбэки, вызываемые без аргументов при переходе Ren'Py в новый контекст (например, при старте игры, входе в главное меню или меню игры, либо при запуске повтора сцены).

define config.interact_callbacks = [ ... ]

Список функций, вызываемых (без аргументов) при запуске или перезапуске взаимодействия.

define config.label_callbacks = [ ]

Список колбэков, вызываемых при переходе к метке (label). Вызываются с двумя аргументами: имя метки и логическое значение (True, если метка была достигнута через jump, call или создание нового контекста, и False в противном случае).

define config.periodic_callbacks = [ ... ]

Список функций, вызываемых без аргументов с частотой примерно 20 Гц.

define config.python_callbacks = [ ... ]

Список функций, вызываемых без аргументов при выполнении блока Python вне фазы инициализации.

Возможный вариант использования — ограничение значения переменной определенным диапазоном при каждом ее изменении.

Функции могут вызываться во время запуска Ren'Py до непосредственного старта игры и потенциально до того, как переменные, от которых зависит функция, будут инициализированы. Функции должны учитывать это, например, с помощью проверки hasattr(store, 'varname').

define config.python_exit_callbacks = [ ]

Список функций, вызываемых перед завершением работы Ren'Py и выходом в операционную систему. Предназначен для деинициализации модулей Python.

Большая часть систем Ren'Py деинициализируется до вызова этих функций, поэтому использовать функции Ren'Py внутри этих колбэков небезопасно.

define config.scene_callbacks = [ ... ]

Список функций, вызываемых при выполнении оператора scene или функции renpy.scene(). Функции вызываются с единственным аргументом — именем слоя, на котором выполняется оператор scene. Функции вызываются после очистки слоя, но до добавления нового изображения, если оно указано.

Ren'Py может вызывать renpy.scene для собственных нужд, поэтому рекомендуется проверять имя слоя перед выполнением действий.

define config.start_callbacks = [ ... ]

Список функций обратного вызова, вызываемых без аргументов после фазы инициализации, но до старта игры (включая splashscreen). Предназначен для использования библиотеками и фреймворками для инициализации сохраняемых переменных.

Значение по умолчанию включает колбэки, которые Ren'Py использует внутри движка для реализации таких возможностей, как nvl-режим. Новые колбэки можно добавлять в этот список, но существующие удалять не следует.

define config.start_interact_callbacks = [ ... ]

Список функций, вызываемых (без аргументов) при старте взаимодействия. Эти колбэки не вызываются при перезапуске взаимодействия.

define config.statement_callbacks = [ ... ]

Список функций, вызываемых при выполнении оператора. Обычно вызываются с именем выполняемого оператора. Существуют специальные имена операторов:

"say"

Обычные операторы say.

"say-nvl"

Операторы say в режиме NVL.

"say-bubble"

Операторы say в режиме речевых пузырей (bubble).

"say-centered"

Операторы say с персонажем centered.

"menu"

Обычные операторы меню.

"menu-nvl"

Операторы меню в режиме NVL.

"menu-with-caption"

Операторы меню с подписью.

"menu-nvl-with-caption"

Операторы меню с подписью в режиме NVL.

В этом списке есть стандартный колбэк, используемый для реализации работы window auto.

define config.with_callback = None

Если не None, функция, вызываемая при выполнении оператора with. Эта функция может отвечать за отображение временных элементов на экране во время перехода. Функция вызывается с двумя аргументами: выполняемый переход и переход, с которым он спарен. Второй аргумент равен None, за исключением неявного перехода None, порожденного строчным оператором with (в этом случае это встроенный переход). Функция должна возвращать объект перехода, который может совпадать или не совпадать с переданным аргументом.

Персонажи и диалоги

define config.all_character_callbacks = [ ... ]

Список колбэков, вызываемых для всех персонажей. Этот список добавляется перед списком колбэков конкретного персонажа. В начало списка Ren'Py помещает собственные колбэки.

define config.character_callback = None

Значение по умолчанию для параметра callback класса Character.

define config.character_id_prefixes = [ ... ]

Задает список префиксов свойств стиля, которые можно передавать объекту Character(). При указании стиля с одним из этих префиксов он применяется к отображаемому объекту с этим префиксом в качестве ID.

Например, стандартный GUI добавляет сюда префикс "namebox". Когда персонажу передается свойство namebox_background, оно задает background на отображаемом объекте экрана say с id "namebox".

define config.say_allow_dismiss = None

Если не None, функция, вызываемая без аргументов при попытке игрока пропустить оператор say. Если функция возвращает True, пропуск разрешается, иначе клик игнорируется.

define config.say_arguments_callback = None

Если не None, функция, принимающая говорящего персонажа, позиционные и именованные аргументы. Вызывается при каждом выполнении оператора say, даже если оператор явно не передает аргументов. Аргументы всегда включают параметр interact, а также любые другие, указанные в операторе say.

Функция должна возвращать пару: кортеж позиционных аргументов (почти всегда пустой) и словарь именованных аргументов (почти всегда содержащий хотя бы interact). Они заменят аргументы, переданные в оператор.

Например:

def say_arguments_callback(who, interact=True, color="#fff"):
    return (), { "interact" : interact, "what_color" : color }

config.say_arguments_callback = say_arguments_callback
define config.say_sustain_callbacks = [ ... ]

Список функций, вызываемых без аргументов перед вторым и последующими взаимодействиями, вызванными строкой диалога с паузами внутри. Используется для непрерывного звучания голоса во время пауз.

Меню выбора

define config.auto_choice_delay = None

Если не None, задает задержку в секундах, на которую Ren'Py делает паузу в игровом меню выбора перед тем, как автоматически выбрать случайный вариант. В релизных играх эта переменная обычно равна None, но указание числа позволяет запускать автоматические демонстрации игр без участия человека.

define config.menu_arguments_callback = None

Если не None, функция, принимающая позиционные и/или именованные аргументы. Вызывается при каждом выполнении оператора menu с аргументами этого оператора.

Должна возвращать пару: кортеж позиционных аргументов (почти всегда пустой) и словарь именованных аргументов.

define config.menu_include_disabled = False

Если True, варианты выбора, отключенные условием оператора if, отображаются как неактивные кнопки.

define config.menu_window_subtitle = ""

Переменной _window_subtitle присваивается это значение при входе в главное или игровое меню.

define config.narrator_menu = True

Если True, текст повествования внутри меню отображается с помощью персонажа narrator. В противном случае текст отображается в виде заголовков (подписей) внутри самого меню.

Отображение

define config.adjust_view_size = None

Если не None, функция, принимающая два аргумента: ширину и высоту физического окна. Она должна возвращать кортеж с шириной и высотой области просмотра OpenGL — части экрана, на которую Ren'Py выводит изображение.

Может использоваться для ограничения размеров окна. Например, следующий код разрешает только целочисленные масштабы исходного разрешения экрана:

init python:

    def force_integer_multiplier(width, height):
        multiplier = min(width / config.screen_width, height / config.screen_height)
        multiplier = max(int(multiplier), 1)
        return (multiplier * config.screen_width, multiplier * config.screen_height)

    config.adjust_view_size = force_integer_multiplier
define config.automatic_oversampling = 4

Максимальный уровень автоматической избыточной дискретизации, используемый Ren'Py. Если None, автоматическая избыточная выборка отключена.

define config.display_start_callbacks = [ ]

Курсор мыши

define config.mouse = None

Управляет пользовательскими курсорами мыши. Если None, используется системный курсор мыши.

В противном случае задается словарь кадров анимации для различных состояний курсора. Ключи, используемые стандартной библиотекой: default, say, with, menu, prompt, imagemap, button, pause, mainmenu и gamemenu. Ключ default должен присутствовать всегда, так как он используется при отсутствии более конкретного ключа. Ключи могут иметь префикс pressed_ для обозначения вида курсора при зажатой кнопке мыши.

Каждое значение в словаре представляет собой список кортежей (image, xoffset, yoffset), задающих кадры анимации:

image

Изображение курсора. Максимальный размер зависит от оборудования: 32x32 гарантированно работает везде, 64x64 — на большинстве систем.

xoffset

Смещение активной точки (hotspot) курсора от левого края.

yoffset

Смещение активной точки (hotspot) курсора от верхнего края.

Кадры сменяются с частотой 20 Гц, анимация зацикливается. Подробнее см. Пользовательские курсоры мыши.

define config.mouse_displayable = None

Если не None, отображаемый объект или вызываемый объект, возвращающий отображаемый объект (или None).

Если задан отображаемый объект, системный курсор мыши скрывается, а этот объект отображается поверх всего остального. Объект отвечает за позиционирование и отрисовку курсора (например, MouseDisplayable()). Подробнее см. Пользовательские курсоры мыши.

define config.mouse_focus_clickthrough = False

Если True, клик, приводящий к получению окном фокуса, обрабатывается как обычный клик. Если False, такой клик игнорируется.

define config.mouse_hide_time = 30

Курсор мыши скрывается после указанного количества секунд бездействия. Рекомендуется устанавливать значение больше времени чтения одного экрана диалога, чтобы курсор не исчезал между кликами.

Если None, курсор мыши никогда не скрывается.
