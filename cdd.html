Пользовательские отображаемые объекты (CDD)

Самый сложный, но и самый мощный способ настройки поведения Ren'Py — это использование пользовательских отображаемых объектов (creator-defined displayables, CDD). Пользовательский отображаемый объект может принимать произвольные события pygame. Он также может рендерить другие отображаемые объекты и размещать их в любых координатах экрана. Это делает его идеальным инструментом для создания 2D-мини-игр, функционал которых невозможно реализовать стандартными инструментами Ren'Py. (См. также раздел спрайты, где описан более высокоуровневый способ реализации многих схожих задач.)

Пользовательские отображаемые объекты программируются исключительно на Python, поэтому перед началом их создания рекомендуется обладать уверенными навыками объектно-ориентированного программирования на Python.

Пример

Вот пример пользовательского отображаемого объекта. Этот объект рендерит свой дочерний элемент с прозрачностью (альфа-каналом), которая зависит от расстояния между указателем мыши и центром дочернего элемента.

init python:

    import math

    class Appearing(renpy.Displayable):

        def __init__(self, child, opaque_distance, transparent_distance, **kwargs):

            # Передаём дополнительные свойства конструктору renpy.Displayable.
            super(Appearing, self).__init__(**kwargs)

            # Дочерний элемент.
            self.child = renpy.displayable(child)

            # Расстояние, на котором дочерний элемент станет полностью непрозрачным,
            # и на котором он станет полностью прозрачным. Первое значение должно быть
            # меньше второго.
            self.opaque_distance = opaque_distance
            self.transparent_distance = transparent_distance

            # Альфа-канал дочернего элемента.
            self.alpha = 0.0

            # Размеры нашего объекта и дочернего элемента.
            self.width = 0
            self.height = 0

        def render(self, width, height, st, at):

            # Создаём трансформацию, которая может изменять альфа-канал
            # дочернего элемента.
            t = Transform(child=self.child, alpha=self.alpha)

            # Создаём render из дочернего элемента.
            child_render = renpy.render(t, width, height, st, at)

            # Получаем размер дочернего элемента.
            self.width, self.height = child_render.get_size()

            # Создаём объект render, который мы вернём.
            render = renpy.Render(self.width, self.height)

            # Отрисовываем (blit) render дочернего элемента на нашем render.
            render.blit(child_render, (0, 0))

            # Возвращаем render.
            return render

        def event(self, ev, x, y, st):

            # Вычисляем расстояние между центром этого отображаемого объекта и
            # указателем мыши. Координаты мыши передаются в x и y относительно
            # верхнего левого угла отображаемого объекта.
            distance = math.hypot(x - (self.width / 2), y - (self.height / 2))

            # На основе расстояния вычисляем значение прозрачности alpha.
            if distance <= self.opaque_distance:
                alpha = 1.0
            elif distance >= self.transparent_distance:
                alpha = 0.0
            else:
                alpha = 1.0 - 1.0 * (distance - self.opaque_distance) / (self.transparent_distance - self.opaque_distance)

            # Если прозрачность изменилась, инициируем событие перерисовки.
            if alpha != self.alpha:
                self.alpha = alpha
                renpy.redraw(self, 0)

            # Передаём событие дочернему элементу.
            return self.child.event(ev, x, y, st)

        def visit(self):
            return [ self.child ]

Чтобы использовать созданный пользовательский отображаемый объект, мы можем создать его экземпляр и добавить этот экземпляр на экран.

screen alpha_magic:
    add Appearing("logo.png", 100, 200):
        xalign 0.5
        yalign 0.5

label start:
    show screen alpha_magic

    "Can you find the logo?"

    return

renpy.Displayable

Пользовательский отображаемый объект создаётся путём наследования от класса renpy.Displayable. Пользовательский объект должен переопределить метод render и при необходимости может переопределять другие методы.

Отображаемый объект должен поддерживать сериализацию через pickle, что означает, что он не может содержать ссылки на объекты, не поддерживающие pickle. В частности, объекты Render нельзя сохранять в полях пользовательского отображаемого объекта.

Поскольку предполагается переопределение методов класса отображаемого объекта, мы приводим их с параметром self.

class renpy.Displayable

Базовый класс для пользовательских отображаемых объектов.

__init__(**properties)

Подкласс может переопределить конструктор, возможно, добавляя новые параметры. В этом случае он должен передать все неизвестные именованные аргументы конструктору renpy.Displayable с помощью вызова:

super(MyDisplayable, self).__init__(**properties)
render(self, width, height, st, at)

Подклассы обязаны переопределить этот метод и вернуть объект renpy.Render. Объект render определяет то, что (если вообще что-либо) будет показано на экране.

width, height

Объём пространства, доступного этому отображаемому объекту, в пикселях.

st

Число с плавающей запятой (float), временная шкала показа (shown timebase) в секундах. Она начинается с момента первого появления этого отображаемого объекта на экране.

at

Число с плавающей запятой (float), временная шкала анимации (animation timebase) в секундах. Она начинается с момента показа изображения с тем же тегом без его скрытия. (Когда отображаемый объект показывается без тега, это значение совпадает с st.)

Метод render вызывается при первом отображении объекта. Он может вызываться повторно, если для этого объекта вызвана функция renpy.redraw().

event(self, ev, x, y, st)

Метод event вызывается для передачи события pygame пользовательскому отображаемому объекту. Если метод event возвращает значение, отличное от None, это значение возвращается как результат взаимодействия. Если метод event возвращает None, событие передаётся дальше другим отображаемым объектам.

Чтобы проигнорировать событие без возврата None, вызовите исключение renpy.IgnoreEvent.

Метод event существует и у других отображаемых объектов, что позволяет пользовательскому объекту передавать событие дальше по цепочке.

ev

Объект события pygame.

x, y

Координаты x и y события относительно верхнего левого угла отображаемого объекта. Их следует предпочитать информации о позиции, находящейся в объектах событий pygame.

st

Число с плавающей запятой (float), временная шкала показа в секундах.

Событие генерируется в начале каждого взаимодействия, а функция renpy.timeout() может использоваться для принудительного вызова следующего события.

per_interact(self)

Этот метод вызывается в начале каждого взаимодействия. Его можно использовать для запуска перерисовки, и его практически наверняка следует использовать для перерисовки, если объект участвует в откате.

visit(self)

Если у отображаемого объекта есть дочерние отображаемые объекты, этот метод следует переопределить так, чтобы он возвращал список этих дочерних объектов. Это гарантирует, что методы per_interact этих дочерних объектов будут вызваны, а также позволяет предсказывать изображения (predicting), используемые дочерними элементами.

place(self, dest, x, y, width, height, surf, main=True)

Размещает render (который должен принадлежать этому отображаемому объекту) внутри ограничивающей области. Возвращает кортеж (x, y), определяющий координаты, в которых был размещён объект.

dest

Если не None, surf будет отрисован (blitted) в dest по вычисленным координатам.

x, y, width, height

Ограничивающая область.

surf

Объект render для размещения.

main

Передаётся в Render.blit().

renpy.Render

Пользовательские отображаемые объекты работают с объектами renpy.Render. Объекты Render возвращаются при вызове функции renpy.render() для отображаемого объекта. Пользовательский отображаемый объект должен создавать объект Render путём вызова renpy.Render из своего метода render.

Поскольку объект render не предназначен для создания подклассов, мы опустим неявный параметр self.

class renpy.Render(width, height)

Создаёт новый объект Render.

width, height

Ширина и высота объекта render в пикселях.

blit(source, pos, main=True)

Отрисовывает другой объект render внутри этого объекта render.

source

Объект render для отрисовки.

pos

Позиция отрисовки. Это кортеж (x, y), где координаты заданы в пикселях относительно верхнего левого угла целевого объекта render.

main

Параметр, передаваемый только по имени. Если True, source будет отображаться в инспекторе стилей.

place(d, x=0, y=0, width=None, height=None, st=None, at=None, render=None, main=True)

Рендерит отображаемый объект d и помещает его в прямоугольник, определённый x, y, width и height, используя стандартный алгоритм размещения Ren'Py. Возвращает кортеж (x, y) с координатами размещения отображаемого объекта. Позиция вычисляется путём вызова метода Displayable.place().

x, y, width, height

Прямоугольник для размещения. Если width или height равны None, используются ширина и высота данного объекта render соответственно.

st, at

Время, передаваемое в Render. Если None, по умолчанию используются значения времени, переданные в вызывающий этот метод метод render.

render

Если не None, используется это значение вместо повторного рендеринга d.

main

Аналогично параметру в .blit().

canvas()

Возвращает объект холста (canvas). Объект холста содержит методы, соответствующие функциям модуля pygame.draw, с опущенным первым параметром (поверхностью).

В Ren'Py функции arc и ellipse не реализованы.

У объектов canvas также есть метод get_surface(), возвращающий поверхность pygame Surface, лежащую в основе холста.

get_size()

Возвращает кортеж (width, height), определяющий размеры этого объекта render.

subsurface(rect)

Возвращает объект render, представляющий собой прямоугольную область, вырезанную из данного объекта render.

rect

Кортеж (x, y, width, height).

zoom(xzoom, yzoom)

Задаёт коэффициент масштабирования дочерних элементов этого отображаемого объекта по горизонтальной и вертикальной осям. Масштабируются только дочерние элементы — ширина, высота и координаты blit не масштабируются.

Следующие атрибуты и методы используются только тогда, когда включён модельный рендеринг:

mesh

Это поле включает модельный рендеринг для данного Render.

Если установлено в True:

  • Все дочерние элементы этого отображаемого объекта рендерятся в текстуры.

  • К данному отображаемому объекту привязывается сетка (mesh) по размеру первого дочернего элемента.

  • Создаётся модель с сеткой, шейдерами, uniform-переменными и свойствами, связанными с этим Render.

Затем модель отрисовывается за одну операцию.

add_shader(shader)

Указывает использовать шейдерную часть shader при отрисовке этого Render или его дочерних элементов. Часть должна быть строкой либо строкой, начинающейся с "-", чтобы предотвратить отрисовку шейдера.

add_uniform(name, value)

Присваивает uniform-переменной name значение value при отрисовке этого Render или его дочерних элементов.

add_property(name, value)

Присваивает свойству GL name значение value при отрисовке этого Render или одного из его дочерних элементов.

Вспомогательные функции и классы

renpy.displayable(d: DisplayableLike, scope: dict[str, Any] | None = None) → Displayable

Принимает d, который может быть отображаемым объектом или строкой. Если это строка, она преобразуется в отображаемый объект по обычным правилам.

renpy.end_interaction(value)

Если value не None, немедленно завершает текущее взаимодействие, в результате чего взаимодействие возвращает value. Если value равно None, ничего не делает.

Может вызываться изнутри методов render и event пользовательских отображаемых объектов.

renpy.is_pixel_opaque(d, width, height, st, at, x, y)

Возвращает, является ли пиксель в позиции (x, y) непрозрачным, когда этот отображаемый объект отрисован с помощью renpy.render(d, width, height, st, at).

renpy.load_image(im) → 'renpy.display.render.Render'

Загружает манипулятор изображения im с использованием кэша изображений и возвращает объект render.

renpy.load_rgba(data: bytes, size: tuple[int, int]) → Any

Загружает графические данные data в текстуру размера size и возвращает её.

data

Объект bytes, содержащий данные изображения в формате RGBA8888.

renpy.load_surface(im) → Surface

Загружает манипулятор изображения im с использованием кэша изображений и возвращает pygame Surface.

renpy.map_event(ev, keysym)

Возвращает True, если событие pygame ev соответствует keysym.

keysym

Одно из следующих значений:

  • Имя привязки клавиши в config.keymap.

  • Символ клавиши (keysym), как описано в разделе Настройка привязок клавиш.

  • Список, содержащий один или несколько символов клавиш (keysyms).

renpy.render(d, width, height, /, st, at)

Вызывает отрисовку отображаемого объекта и возвращает объект renpy.Render.

d

Отображаемый объект для отрисовки.

width, height

Ширина и высота, доступные отображаемому объекту для отрисовки.

st, at

Временные шкалы показа (shown) и анимации (animation).

Объекты Render, возвращаемые этой функцией, могут кэшироваться, и их не следует изменять после получения.

renpy.timeout(seconds)

Вызывает генерацию события до истечения seconds секунд. Это гарантирует, что метод event пользовательского отображаемого объекта будет вызван.

renpy.redraw(d, when)

Вызывает перерисовку отображаемого объекта d (вызов метода render) по истечении when секунд. Отображаемый объект может быть перерисован и раньше этого времени (например, при перерисовке дочернего элемента); в этом случае отложенная перерисовка отменяется.

exception renpy.IgnoreEvent

Исключение, вызов которого заставляет Ren'Py проигнорировать событие. Чтобы вызвать его внутри метода event, напишите:

raise renpy.IgnoreEvent()
