Ввод текста

С некоторыми ограничениями Ren'Py может запрашивать у пользователя ввод небольшого фрагмента текста. Этот запрос выполняется с помощью функции renpy.input(), возвращающей введённый текст, который затем можно сохранить в переменной или обработать.

В операционной системе Linux ввод текста ограничен языками, не требующими поддержки методов ввода (IME). Большинство европейских языков работают штатно, однако китайский, японский и корейский языки могут не поддерживаться.

Функция renpy.input объявляется следующим образом:

renpy.input(default='', allow=None, exclude='{}', length=None, pixel_width=None, screen='input', mask=None, copypaste=True, multiline=False, **kwargs)

Выводит окно с запросом на ввод текста от игрока и возвращает введённый текст.

prompt

Строка с текстом подсказки (приглашения к вводу), отображаемая игроку.

default

Строка с начальным текстом, который игрок может отредактировать.

allow

Если не None, строка со списком символов, разрешённых для ввода.

exclude

Если не None, символы из этой строки запрещены для ввода.

length

Если не None, целое число, задающее максимальную длину строки в символах.

pixel_width

Если не None, ширина вводимого текста ограничивается этим количеством пикселей в используемом шрифте.

screen

Имя экрана, обрабатывающего ввод. По умолчанию используется экран input.

mask

Если не None, односимвольная строка, заменяющая введённые символы на экране (например, для скрытия пароля).

copypaste

Если True, разрешено копирование и вставка текста в поле ввода.

multiline

Если True, разрешён перевод курсора на новую строку (многострочный ввод).

Если config.disable_input равно True, функция сразу возвращает default.

Именованные аргументы с префиксом show_ передаются экрану со снятым префиксом.

Из-за ограничений вспомогательных библиотек на Android и веб-платформе функция ограничена символами латинского алфавита.

В играх результат функции renpy.input часто подвергается дополнительной обработке стандартными методами строк Python. Например, следующий код запрашивает имя игрока, удаляет начальные и конечные пробелы, подставляет имя по умолчанию при пустом вводе и выводит результат в диалоге:

define pov = Character("[povname]")

python:
    povname = renpy.input("Как вас зовут?", length=32)
    povname = povname.strip()

    if not povname:
         povname = "Пат Смит"

pov "Меня зовут [povname]!"

В этом примере длина вводимой строки ограничена 32 символами. Важно протестировать игру с длинными именами, чтобы убедиться, что они не нарушают верстку интерфейса. В то же время слишком короткие поля могут помешать игроку ввести желаемое имя.

Методы ввода (IME)

Когда редактор метода ввода (IME) передаёт вводимый текст (композицию), Ren'Py отрисовывает его внутри отображаемого объекта ввода. На платформах, где библиотека SDL передаёт события списка кандидатов, Ren'Py самостоятельно выводит список вариантов вместо использования стандартного окна операционной системы. Это позволяет видеть список кандидатов даже в полноэкранном режиме игры.

События кандидатов поддерживаются в Windows. Бэкенды Linux IBus и Fcitx в SDL в настоящее время не передают эти события и не подавляют системное окно кандидатов, продолжая использовать системный интерфейс. Установка переменной окружения SDL_IME_IMPLEMENTED_UI не включает поддержку событий на неподдерживаемых бэкендах.

Когда события кандидатов поступают, список отображается экраном _ime_candidates, который Ren'Py автоматически показывает и скрывает. Экран размещается рядом с вводимым текстом и настраивается через стили:

_ime_candidates_frame

Фрейм (рамка), содержащий список кандидатов.

_ime_candidates_box

Контейнер box, содержащий элементы списка кандидатов.

_ime_candidates_item_frame, _ime_candidates_selected_item_frame

Рамки вокруг невыбранного и выбранного кандидата соответственно.

_ime_candidates_text, _ime_candidates_selected_text

Текст невыбранного и выбранного кандидата.

Пример настройки стилей:

style _ime_candidates_frame:
    background "#202040e0"

style _ime_candidates_selected_text:
    color "#ffff00"
