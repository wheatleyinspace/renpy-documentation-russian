Многослойные картинки

Когда набор спрайтов персонажа достигает определённого уровня сложности, явное объявление каждой возможной комбинации становится крайне неудобным. Например, персонаж с 4 нарядами, 4 причёсками и 6 эмоциями даёт уже 96 возможных комбинаций. Создание отдельных статических картинок для каждой комбинации потребовало бы огромного дискового пространства и времени разработчика.

Для решения этой задачи в Ren'Py предусмотрен способ создания изображений, состоящих из нескольких спрайтов, упорядоченных по слоям. (В данном контексте слои аналогичны слоям в графических редакторах, таких как Photoshop или GIMP, и отличаются от глобальных экранных слоёв Ren'Py). Элементы этих слоёв можно выбирать с помощью атрибутов, передаваемых изображению, или условий, вычисляемых во время выполнения игры.

Такие изображения объявляются с помощью оператора layeredimage на специализированном языке разметки. Объект LayeredImage() представляет собой его Python-эквивалент; он не является отображаемым объектом, но может быть присвоен в операторе image и использоваться аналогично.

В нижней части этой страницы приведены практические рекомендации и примеры использования.

Определение многослойных картинок

Язык определения многослойных картинок состоит всего из нескольких операторов для объявления слоёв. Ниже приведён пример, который демонстрирует синтаксис layeredimage:

layeredimage augustina:
    zoom 1.4
    at recolor_transform

    always:
        "augustina_base"

    attribute base2 default

    group outfit:
        attribute dress default:
            "augustina_dress"
        attribute uniform
        attribute psychedelic:
            image:
                "augustina_dress"
                matrixcolor TintMatrix("#f00")
                linear 1 matrixcolor TintMatrix("#0f0")
                linear 1 matrixcolor TintMatrix("#00f")
                repeat

    group face auto:
        pos (100, 100)
        attribute neutral default

label start:
    show augustina # отображает платье (dress) и нейтральное выражение (neutral)
    aug "Мне нравится это платье."

    show augustina happy # авто-определено в группе auto
    aug "Но что мне нравится ещё больше..."

    show augustina uniform -happy # uniform заменяет dress, neutral заменяет happy
    aug "Так это эта униформа!"

Оператор Layeredimage

Оператор layeredimage начинает объявление слоистого изображения. Он является частью скриптового языка Ren'Py и выполняется на этапе инициализации. Как и оператор image ATL, он принимает имя изображения и открывает блок, хотя содержимое этого блока существенно отличается. Имя изображения может содержать пробелы, как и любое другое имя изображения в Ren'Py.

Внутри блока размещаются операторы, описанные ниже, а также следующие необязательные свойства:

image_format

Если изображение задано строкой, имя изображения подставляется в image_format для формирования пути к файлу изображения. Например, шаблон "sprites/eileen/{image}.png" будет искать картинку в подкаталоге sprites. (Это не используется группами auto, которые ищут уже объявленные изображения, а не файлы на диске).

format_function

Функция, используемая вместо layeredimage.format_function() для форматирования информации об изображении в отображаемый объект на этапе инициализации.

attribute_function

Функция или вызываемый объект для тонкой настройки итогового набора отображаемых атрибутов. Она вызывается с набором атрибутов, переданных изображению, и должна возвращать набор атрибутов, используемых для выбора слоёв. С её помощью можно описывать сложные зависимости между атрибутами или выбирать атрибуты случайным образом. См. раздел Процесс выбора атрибутов для отображения для получения дополнительной информации.

at

Трансформация или список трансформаций, применяемых ко всему многослойному изображению. Также может использоваться в форме at transform: с последующим блоком ATL для определения трансформации ATL по месту.

свойства трансформации

Если указаны, используются для конструирования трансформации, применяемой к отображаемому объекту.

offer_screen

Если равно True, многослойное изображение размещает и масштабирует дочерние элементы с переменным размером так, как будто ему выделена область, равная всему экрану игры. Если False, размещение производится с учётом фактически доступной области (которая, например, меньше внутри hbox), из-за чего отображение может различаться в зависимости от контекста.

Если None (по умолчанию), используется значение переменной config.layeredimage_offer_screen, которая по умолчанию равна True.

Always

Оператор always объявляет изображение, которое всегда отображается в составе layeredimage и не привязано к конкретному атрибуту. Ему должен быть передан отображаемый объект, а также могут быть переданы свойства. И то, и другое может располагаться на одной строке или внутри блока. Отображаемый объект можно объявить с помощью ключевого слова image: и блока ATL, аналогично оператору image ATL.

Оператор always принимает следующие свойства:

when

Выражение Выражение When в круглых скобках. Если указано, слой отображается только тогда, когда набор атрибутов layeredimage удовлетворяет выражению when.

свойства трансформации

Если указаны, используются для конструирования трансформации, применяемой к отображаемому объекту.

at

Трансформация или список трансформаций, применяемых к переданному отображаемому объекту. Также допускается форма at transform: с блоком ATL.

If

Оператор if (или конструкция if-elif-else) позволяет задать одно или несколько условий, вычисляемых во время выполнения игры. Каждое условие связано с отображаемым объектом; показывается слой первого истинного условия. Если ни одно условие не истинно, отображается слой ветки else (если он задан).

Пример оператора if:

if glasses == "evil":
    "augustina_glasses_evil"
elif glasses == "normal":
    "augustina_glasses"
elif glasses == "funky":
    "augustina_glasses_clown"
else:
    "augustina_nose_mark"

Каждой ветке должен быть назначен отображаемый объект (включая синтаксис image: с блоком ATL). Также можно передать свойства:

when

Выражение Выражение When в круглых скобках. Слой отображается только при выполнении выражения.

свойства трансформации

Если указаны, используются для создания трансформации отображаемого объекта.

at

Трансформация или список трансформаций, применяемых к отображаемому объекту.

Оператор if преобразуется в ConditionSwitch() во время выполнения оператора layeredimage.

layeredimage.predict_all = None

Задаёт значение параметра predict_all для переключателей ConditionSwitch, создаваемых операторами if в layeredimage.

Если predict_all не равно True, следует избегать изменения условий оператора if в момент, когда многослойное изображение уже отображается или готово к показу, так как это вызовет неоптимизированную загрузку изображения без предсказания. Параметр предназначен для опций кастомизации персонажа, которые меняются редко.

Attribute

Оператор attribute добавляет отображаемый объект, который становится частью результирующего изображения при вызове соответствующего атрибута. Например, в предыдущем примере вызов show augustina dress приведёт к показу слоя "augustina_dress" в составе изображения "augustina".

Клауза attribute принимает имя атрибута (одно слово, компонент имени изображения, см. Элементы инструкций). Она также может принимать два ключевых слова. Ключевое слово default указывает, что атрибут должен присутствовать по умолчанию, если не вызван другой атрибут из той же группы. Ключевое слово null предотвращает привязку отображаемого объекта к этой клаузе, что полезно для служебного учёта и построения условного отображения с помощью when, attribute_function, config.adjust_attributes или config.default_attribute_callbacks.

Одно и то же имя атрибута можно использовать в нескольких клаузах attribute (а также в автоматически определяемых атрибутах групп auto), при этом все соответствующие отображаемые объекты будут показаны одновременно (свойство when позволяет это скорректировать).

Отображаемый объект можно передать явно (в том числе синтаксисом image:). Если объект не указан, он формируется автоматически из имени layeredimage, группы (если есть), варианта группы или атрибута (если есть) и имени атрибута. Подробнее см. раздел шаблон.

Оператор attribute принимает следующие свойства:

when

Выражение Выражение When в круглых скобках. Слой отображается только при выполнении выражения.

свойства трансформации

Используются для создания трансформации слоя.

at

Трансформация или список трансформаций для слоя.

variant

Слово, добавляемое к имени атрибута через символ подчёркивания при поиске файла изображения. Допустимо только для атрибутов без явно заданного отображаемого объекта, не находящихся в группе с вариантом.

Проверка клаузы when основана на списке атрибутов результирующего изображения, как описано здесь, но не изменяет этот список.

layeredimage eileen:
    attribute a
    attribute b default when not a
    attribute c default when not b

В этом примере атрибуты b и c всегда входят в список атрибутов (из-за клаузы default). При вызове show eileen a атрибут a отобразится, а атрибут b — нет из-за свойства when. Но даже не будучи отображённым, атрибут b остаётся частью списка атрибутов, поэтому атрибут c также не отобразится.

Group

Оператор group объединяет атрибуты вместе, делая их взаимоисключающими. Когда атрибуты a и b находятся в одной группе, одновременное их указание (например, show eileen a b) является ошибкой, за исключением групп типа multiple. Вызов атрибута a скроет атрибут b, и наоборот. При этом несколько строк attribute могут иметь одинаковое имя даже внутри одной группы — в этом случае они рассматриваются как один атрибут, состоящий из нескольких спрайтов.

Оператор group принимает имя. Имя используется главным образом для генерации имён файлов изображений по умолчанию.

Имя группы multiple зарезервировано: оно делает группу множественной (неисключающей). В этом случае к атрибутам внутри блока не применяется правило взаимоисключения. Это полезно для автоматического объявления нескольких неисключающих атрибутов через auto или применения общих свойств к группе атрибутов сразу. Это конфликтует с ключевым словом default для атрибутов группы. Группы multiple считаются безымянными.

За именем может следовать ключевое слово auto. Если оно указано, Ren'Py после явных объявлений атрибутов просканирует список изображений на совпадение с шаблоном группы (см. ниже). Любые найденные изображения добавляются в группу как атрибуты.

Свойства, переданные группе, наследуются её атрибутами, если только не переопределены внутри самого атрибута. Два свойства специфичны для групп:

variant

Аналогично свойству variant оператора attribute, за исключением того, что оно не может быть передано одновременно и группе, и атрибуту внутри неё. Задаёт строку-вариант для автоматической генерации имён изображений без явных отображаемых объектов и поиска в группах auto.

prefix

Префикс, соединяемый знаком подчёркивания с именами атрибутов. Если указан префикс leftarm, то для строки attribute hip отображение будет вызываться командой show eileen leftarm_hip.

Атрибут также может входить в состав нескольких групп, и в этом случае он становится несовместимым со всеми атрибутами всех этих групп. Это удобно, например, для наряда dress, который должен скрывать и верхнюю одежду, и брюки:

layeredimage eileen:
    attribute base default
    group bottom:
        attribute jeans default
        attribute dress null
    group top:
        attribute shirt default
        attribute dress

Когда в одном layeredimage определено несколько блоков group с одинаковым именем, они считаются частями одной группы. Например:

layeredimage eileen sitting:
    attribute base default
    group arms variant behind:
        attribute on_hips
        attribute on_knees
        attribute mixed
    attribute table default
    group arms variant infront:
        attribute on_table default
        attribute holding_margarita
        attribute mixed

В этом примере файл eileen_sitting_arms_behind_mixed.png будет содержать левую руку позади стола, а eileen_sitting_arms_infront_mixed.png — правую руку на столе. При вызове show eileen sitting mixed оба изображения будут показаны одновременно — соответственно за столом и перед столом. В этом примере атрибут on_hips несовместим с атрибутом on_table, так как они принадлежат одной группе arms.

Выражение When

Выражение when задаёт логическое условие, зависящее от набора атрибутов, активных в данный момент на многослойном изображении.

Оно состоит из одного или нескольких имён атрибутов, разделённых ключевыми словами "and" и "or", и при необходимости инвертированных с помощью "not". Для задания приоритета можно использовать скобки.

Пример:

always:
    "eileen_red_dress"
    when b and not c
    # изображение показывается, когда активен атрибут b и не активен атрибут c

if var:
    "eileen_blue_ribbon"
    when not (a or b)
    # изображение показывается, когда переменная var истинна
    # и ни атрибут a, ни атрибут b не активны

attribute a:
    "eileen_a"
    when b or e
    # изображение показывается, когда активен атрибут a
    # и одновременно активен хотя бы один из атрибутов b или e

Устаревшие свойства

Следующие свойства операторов always, if и attribute считаются устаревшими, но могут встречаться в старых проектах:

if_all

Строка или список имён атрибутов. Слой отображается только при наличии всех указанных атрибутов.

if_any

Строка или список имён атрибутов. Слой отображается при наличии хотя бы одного из указанных атрибутов.

if_not

Строка или список имён атрибутов. Слой отображается, если ни один из указанных атрибутов не активен.

Для перехода на синтаксис when конструкцию:

if_any ["a", "b"]
if_all ["c", "d"]
if_not ["e", "f"]

можно заменить на более лаконичное выражение:

when (a or b) and c and d and not (e or f)

Шаблон имён и функция форматирования

Шаблон, используемый для поиска изображений по атрибутам при отсутствии явного отображаемого объекта, состоит из следующих частей:

  • Имя layeredimage с заменой пробелов на знаки подчёркивания.

  • Имя группы (если группа не является multiple).

  • Имя варианта (variant), если оно задано.

  • Имя атрибута.

Все части соединяются символом подчёркивания. Например, для layeredimage с именем "augustina work" и группы "eyes" шаблон будет соответствовать изображениям augustina_work_eyes_атрибут. С вариантом blue шаблон будет выглядеть как augustina_work_eyes_blue_атрибут. В примере:

layeredimage augustina work:
    group eyes variant blue:
        attribute closed

Атрибут связывается с изображением "augustina_work_eyes_blue_closed". Это имя может разрешаться в файл augustina_work_eyes_blue_closed.png или в изображение, объявленное через оператор image.

Всё поведение поиска по шаблону можно переопределить с помощью функции format_function. Функция layeredimage.format_function() используется по умолчанию.

layeredimage.format_function(what, name, group, variant, attribute, image, image_format, **kwargs)

Вызывается для форматирования информации об атрибуте или условии в отображаемый объект. Разработчик может переопределить эту функцию, однако новая функция должна игнорировать неизвестные именованные аргументы (kwargs).

what

Строка с описанием форматируемого элемента, используемая для формирования понятных сообщений об ошибках.

name

Имя layeredimage.

group

Группа атрибута, или None, если группа не указана или элемент является частью условия.

variant

Аргумент варианта группы, или None, если он не указан.

attribute

Сам атрибут.

image

Отображаемый объект или строка.

image_format

Аргумент image_format объекта LayeredImage.

Если image равно None, то name, group (если не None), variant (если не None) и attribute объединяются знаками подчёркивания для создания строки image.

Если image — строка и image_format не равен None, image форматируется в строку шаблона для получения итогового отображаемого объекта.

Например, если name равно "eileen", group — "expression", а attribute — "happy", image будет установлено в "eileen_expression_happy". Если image_format равен "images/{image}.png", Ren'Py найдёт итоговый файл "images/eileen_expression_happy.png". Однако заметим, что это же изображение было бы найдено и без явного аргумента format.

Обратите внимание: переданная функция format_function не влияет на поиск изображений в группах auto — группы auto всегда используют стандартный шаблон поиска, описанный выше.

Проксирование многослойных картинок

Иногда бывает полезно использовать одно и то же многослойное изображение в нескольких местах (например, для применения отдельной трансформации или использования в качестве бокового изображения).

Класс LayeredImageProxy() создаёт прокси-объект, дублирующий многослойное изображение. Например:

image dupe = LayeredImageProxy("augustina")

создаёт дубликат изображения, отображаемый независимо. Класс также принимает аргумент трансформации, что удобно для позиционирования бокового изображения:

image side augustina = LayeredImageProxy("augustina", Transform(crop=(0, 0, 362, 362), xoffset=-80))

Разница между прямым Transform и LayeredImageProxy:

image sepia_augustina_one = Transform("augustina", matrixcolor=SepiaMatrix())
image sepia_augustina_two = LayeredImageProxy("augustina", Transform(matrixcolor=SepiaMatrix()))

sepia_augustina_one будет сепией исходной версии без учёта последующих атрибутов. Напротив, sepia_augustina_two принимает любые атрибуты, передаваемые образу "augustina", и применяет эффект сепии к результирующему сочетанию слоёв. Если вы напишете:

show augustina happy eyes_blue dress

то команда:

show sepia_augustina_one happy eyes_blue dress
# не сработает, так как Transform не принимает атрибуты

show sepia_augustina_two happy eyes_blue dress
# сработает корректно и покажет сепию "augustina happy eyes_blue dress"
class LayeredImageProxy(name, transform=None)

Объект, ведущий себя как изображение, который перенаправляет передаваемые ему атрибуты в другое многослойное изображение.

name

Строка, задающая имя целевого многослойного изображения (layeredimage) для проксирования.

transform

Если указано, трансформация или список трансформаций, применяемых к изображению после его проксирования.

Процесс выбора атрибутов для отображения

Несколько факторов определяют, что именно выводится на экран при выполнении оператора show. В этом разделе показан жизненный цикл набора атрибутов:

  • Оператор show передаёт начальный набор атрибутов вслед за тегом изображения.

  • Если для тега задана функция config.adjust_attributes, она вызывается и может вернуть другой набор атрибутов, заменяющий исходный.

  • Если задана функция config.default_attribute_callbacks и условия её срабатывания выполнены, она вызывается и может добавить атрибуты.

Эти первые этапы не специфичны для многослойных изображений. На их основе Ren'Py определяет, какое именно изображение (обычное, layeredimage, Live2D...) будет показано.

  • Затем переданные атрибуты объединяются с атрибутами layeredimage, отбрасывая ранее показанные несовместимые атрибуты. На этом этапе обнаруживаются неизвестные атрибуты и вызываются ошибки. Если ошибок нет, новый набор фиксируется Ren'Py как связанный с тегом. Правила несовместимости внутри обычных групп применяются здесь, но клаузы when на этом этапе ещё не проверяются.

  • Если задана функция attribute_function, она вызывается с текущим набором атрибутов и может вернуть скорректированный набор.

  • Этот набор окончательно проверяется на все ограничения несовместимости layeredimage, включая клаузы when. Оставшиеся активными атрибуты выводятся на экран.

Советы и рекомендации

Используйте подчёркивания в именах файлов.

По умолчанию в layeredimage фрагменты имён соединяются символами подчёркивания. Использование пробелов в именах файлов может привести к конфликтам, когда отдельный спрайт будет ошибочно показан вместо всего слоистого изображения (например, пара парящих в воздухе глаз).

Обрезать прозрачные поля слоёв вручную не требуется.

Ren'Py автоматически обрезает прозрачные пиксели по границам непрозрачной области перед загрузкой в видеопамять. Ручная обрезка слоёв практически не даёт выигрыша в производительности.

Многослойные изображения не должны зависеть от переменных, меняющихся во время игры (кроме if).

Все выражения в блоке layeredimage (за исключением условий if) вычисляются один раз на этапе инициализации (при определении изображения).

Выбор синтаксиса:

  • Если спрайт должен быть виден всегда, используйте always или attribute x default.

  • Если спрайт выбирается передаваемыми атрибутами при показе (например, show eileen happy), используйте оператор attribute внутри или вне блока group.

  • Если отображение зависит от переменной Python, используйте оператор if.

  • Если отображение зависит и от переменной, и от атрибутов, объявите все варианты как атрибуты и используйте функцию config.adjust_attributes.

Примеры

Шаблон имён и группы auto

Пусть в папке images/ есть файлы:

francis_base.png
francis_face_neutral.png
francis_face_angry.png
francis_face_happy.png
francis_face_very_happy.png
francis_face annoyed.png
francis_supersad.png

И следующий код:

layeredimage francis:
    attribute base default
    group face auto:
        attribute neutral default
    attribute supersad image:
        "#00c3"
        xysize (100, 100)

Многослойное изображение francis объявит атрибут по умолчанию base и свяжет его с файлом "francis_base" по шаблону.

В группе face явный атрибут neutral связывается с "francis_face_neutral". Затем группа face auto находит файлы "francis_face_angry", "francis_face_happy" и "francis_face_very_happy", автоматически создавая атрибуты angry, happy и very_happy. Файл "francis_face annoyed" проигнорирован, так как содержит пробел вместо подчёркивания.

Атрибут supersad объявлен с явным отображаемым объектом. Использование групп auto и шаблона сокращает объём кода в несколько раз.

Динамика в атрибутах

Пример выбора атрибутов в зависимости от переменных:

layeredimage eileen:
    attribute base default
    group outfit auto
    group ribbon prefix ribbon:
        attribute red
        attribute blue

default eileen_ribbon_color = "red"

init python:
    def eileen_adjuster(names):
        atts = set(names[1:])
        if "ribbon" in atts:
            atts.remove("ribbon")
            atts.add("ribbon_" + eileen_ribbon_color)
        return names[0], *atts

define config.adjust_attributes["eileen"] = eileen_adjuster

Учёт групп в выражении when

Клауза when не принимает имя группы напрямую, но можно добавить фиктивный атрибут по умолчанию null:

layeredimage eliza:
    attribute head_and_hair default
    group top auto
    group headtop prefix headtop:
        attribute notop null default
        attribute hat
        attribute cap
    attribute hair_patch when notop

Здесь прядь волос hair_patch отобразится поверх одежды только тогда, когда на персонаже нет головного убора.
