Отображение изображений

Визуальная составляющая — ключевой аспект визуальных новелл, давший название всему жанру. В Ren'Py есть четыре основные инструкции для управления показом изображений, а также модель, определяющая порядок их отрисовки. Это делает вывод графики простым, наглядным и удобным для создания визуальных новелл и сюжетных игр.

Четыре инструкции для работы с изображениями:

  • image — объявляет новое изображение.

  • show — отображает изображение на слое.

  • scene — очищает слой и при необходимости отображает на нём изображение.

  • hide — скрывает изображение со слоя.

Поскольку резкая смена изображений может восприниматься неприятно, в Ren'Py предусмотрена инструкция with, позволяющая применять эффекты переходов при смене сцены.

Большинство (если не все) инструкций, перечисленных на этой странице, проверяются статическим анализатором Инструмент Lint, чего нельзя сказать об их аналогах на Python.

Основные понятия

Изображение

Изображение — это объект, который может быть выведен на экран с помощью инструкции show. Изображение состоит из имени и отображаемого объекта (displayable). Когда изображение выводится на слой, связанный с ним отображаемый объект отрисовывается на этом слое.

Имя изображения состоит из одного или нескольких компонентов, разделённых пробелами. Первый компонент имени называется тегом изображения. Второй и последующие компоненты являются атрибутами изображения.

Например, в имени изображения mary beach night happy тегом является mary, а атрибутами — beach, night и happy.

Отображаемый объект (displayable) — это всё, что Ren'Py может отрисовать на экране. Чаще всего это статическая картинка, задаваемая строкой с именем файла. В примере выше файлом изображения мог бы быть mary_beach_night_happy.png. Однако изображение может ссылаться на любой отображаемый объект, поддерживаемый Ren'Py, а не только на статическую графику. Таким образом, те же самые инструкции, которые используются для картинок, подходят для анимаций, сплошных заливок цветом и других типов объектов.

Слой

Слой — это список отображаемых объектов, выводимых на экран. Ren'Py поддерживает несколько слоёв, включая пользовательские. Порядок отрисовки слоёв фиксирован в игре (и настраивается переменной config.layers), в то время как порядок объектов внутри слоя определяется очерёдностью вызова инструкций scene и show, а также свойствами, переданными этим инструкциям.

Следующие слои встроены в Ren'Py по умолчанию:

master

Основной слой по умолчанию, используемый инструкциями scene, show и hide. Обычно используется для фонов и спрайтов персонажей.

transient

Слой по умолчанию для функций интерфейса (ui). Этот слой автоматически очищается в конце каждого взаимодействия (клика).

screens

Слой, используемый системой экранов.

overlay

Слой по умолчанию для функций интерфейса, вызываемых из overlay-функций. Очищается при перезапуске взаимодействия.

Дополнительные слои можно объявлять с помощью функции renpy.add_layer() и различных связанных со слоями переменных конфигурации. С помощью инструкции camera к слою можно применять одну или несколько трансформаций.

Объявление изображений

Существует два способа объявления изображений. Можно либо поместить файл картинки в каталог изображений, либо объявить изображение с помощью инструкции image. Первый способ проще — достаточно правильно назвать файлы в каталоге, тогда как второй даёт более тонкий контроль над определением изображения и позволяет использовать динамические отображаемые объекты.

Изображения, объявленные инструкцией image, имеют приоритет над изображениями из каталога изображений.

Каталог images

Каталог изображений называется «images» и располагается внутри каталога game. Когда файл с расширением .jpg, .jpeg, .png, .webp, .avif или .svg помещается в этот каталог, его расширение отбрасывается, оставшаяся часть имени переводится в нижний регистр, и полученное имя используется в качестве имени изображения, если изображение с таким именем ещё не было объявлено явно.

Этот процесс распространяется на все подкаталоги внутри каталога images. Например, все эти файлы объявят одно и то же изображение eileen happy:

game/images/eileen happy.png
game/images/Eileen Happy.jpg
game/images/eileen/eileen happy.png

Когда указано имя файла изображения и оно не найдено напрямую, поиск выполняется в каталоге images.

Каталог изображений можно настроить с помощью config.image_directories и config.image_extensions.

Избыточная дискретизация (Oversampling)

По умолчанию размер изображения в пикселях определяет размер, который оно занимает при показе на экране. Например, если картинка имеет размер 1920x1080 пикселей, а игра настроена с помощью gui.init() на разрешение 1920x1080, изображение заполнит весь экран.

Когда включён режим избыточной дискретизации (oversampling), размер отображения картинки становится меньше, чем её фактическое пиксельное разрешение. Например, если изображение имеет размер 3840x2160 и коэффициент oversample 2, то масштаб по каждой оси уменьшается вдвое, и картинка займёт ту же область 1920x1080.

Это особенно удобно, когда изображение может приближаться (zoom) и требуется высокая детализация. Избыточная дискретизация также полезна в связке с config.physical_width и config.physical_height для переиздания игры с графикой более высокого разрешения.

Режим oversampling включается автоматически, если имя файла перед расширением заканчивается на символ «@» и число. Например, файл eileen happy@2.png будет иметь коэффициент 2x, а eileen happy@3.png — 3x. Также его можно задать параметром oversample в функции Image().

Для каталога также можно задать общий коэффициент масштабирования: например, все файлы в images/@2/eileen happy.png получат масштаб 2x.

Если к изображению не применён явный oversampling, Ren'Py попытается найти подходящие версии автоматически. Например, если игра масштабируется с коэффициентом более 1x и до 2x включительно, Ren'Py при загрузке eileen happy.png проверит наличие eileen happy@2.png и использует его при наличии.

Инструкция image

Инструкция image используется для явного объявления изображения. Она состоит из одной логической строки, начинающейся с ключевого слова image, за которым следует имя изображения, знак равенства = и отображаемый объект. Например:

image eileen happy = "eileen_happy.png"
image black = "#000"
image bg tiled = Tile("tile.jpg")

image eileen happy question = VBox(
    "question.png",
    "eileen_happy.png",
    )

Когда файл картинки лежит не прямо в каталоге игры, необходимо указать путь к нему. Например, если файл находится по пути game/eileen/happy.png, можно написать:

image eileen happy = "eileen/happy.png"

Инструкция image выполняется на этапе инициализации (init time), до показа меню и запуска метки start. Если она не заключена в блок init явно, она выполняется с приоритетом init 500.

См. также ATL-вариант инструкции image.

Инструкция show

Инструкция show используется для отображения изображения на слое. Она состоит из одной логической строки, начинающейся с ключевого слова show, за которым следует имя изображения и ноль или более свойств.

Если инструкции show передано точное имя существующего изображения, на экран выводится именно оно. В противном случае Ren'Py попытается найти уникальное изображение, которое:

  • Имеет тот же тег, что и указанный в инструкции show.

  • Имеет все атрибуты, перечисленные в инструкции show.

  • Если изображение с тем же тегом уже отображается, разделяет с ним наибольшее количество атрибутов.

Если однозначно определить изображение невозможно, возникает ошибка.

Если изображение с тем же тегом уже отображается на слое, новое изображение заменяет его на той же позиции. В противном случае изображение помещается поверх всех остальных изображений на слое (то есть ближе всего к игроку). Этот порядок можно изменить с помощью свойств zorder и behind.

Инструкция show сама по себе не вызывает взаимодействия с игроком. Чтобы изображение действительно отобразилось на экране, должна выполниться инструкция, вызывающая взаимодействие (например, say, menu, pause или with).

Инструкция show поддерживает следующие свойства:

as

Принимает имя. Это имя используется вместо тега изображения при показе. Это позволяет одновременно отображать одно и то же изображение на экране дважды.

at

Принимает одно или несколько простых выражений, разделённых запятыми. Каждое выражение должно вычисляться в трансформацию (transform). Трансформации применяются к изображению слева направо.

Если конструкция at не указана, Ren'Py сохранит текущую трансформацию, применённую к изображению (если она была создана через ATL или Transform). Если трансформация не задана вовсе, изображение отображается с трансформацией default.

Подробнее см. раздел замена трансформаций.

behind

Принимает разделённый запятыми список имён тегов. Изображение будет показано позади всех отображаемых в данный момент изображений с указанными тегами.

onlayer

Принимает имя слоя. Отображает изображение на указанном слое.

zorder

Принимает целое число. Число задаёт относительный порядок отрисовки внутри слоя: чем больше число, тем ближе объект к зрителю.

Предположим, у нас объявлены следующие изображения:

image mary night happy = "mary_night_happy.png"
image mary night sad = "mary_night_sad.png"
image moon = "moon.png"

Примеры использования инструкции show:

# Базовый показ.
show mary night sad

# Поскольку 'mary night sad' уже отображается, следующая инструкция
# эквивалентна:
# show mary night happy
show mary happy

# Показ изображения в правой части экрана.
show mary night happy at right

# Показ одного и того же изображения дважды.
show mary night sad as mary2 at left

# Показ изображения позади другого.
show moon behind mary, mary2

# Показ изображения на пользовательском слое.
show moon onlayer user_layer

Управление атрибутами

Как показано выше, атрибуты можно задавать, добавлять и заменять.

Их также можно удалять с помощью знака минус:

# показ Сьюзан в нейтральном состоянии
show susan

# показ радостной Сьюзан
show susan happy

# повторный показ нейтральной Сьюзан
show susan -happy

Инструкция show expression

Вариант инструкции show заменяет имя изображения ключевым словом expression, за которым следует простое выражение. Выражение должно вычисляться в отображаемый объект, который и выводится на слой. Чтобы скрыть такой объект, ему необходимо назначить тег с помощью свойства as.

Например:

show expression "moon.png" as moon

Инструкция show layer

Инструкция show layer рассматривается ниже вместе с инструкцией camera.

Инструкция scene

Инструкция scene удаляет все отображаемые объекты со слоя, а затем при необходимости выводит на этот слой новое изображение. Она состоит из ключевого слова scene, за которым следует имя изображения и ноль или более свойств. Изображение выводится так же, как и в инструкции show, и принимает те же самые свойства.

Инструкция scene чаще всего используется для вывода фонового изображения на слой master. Например:

scene bg beach

Scene Expression. Как и show, инструкция scene может принимать выражения Python вместо имён изображений.

Очистка слоя. Когда имя изображения опущено вовсе, инструкция scene просто очищает все объекты со слоя, не показывая ничего взамен.

Инструкция hide

Инструкция hide удаляет изображение со слоя. Она состоит из ключевого слова hide, имени изображения и необязательного свойства. Инструкция hide берёт тег из имени изображения и скрывает любое изображение на слое с этим тегом.

Инструкции hide требуются достаточно редко. Если спрайт представляет персонажа, то hide необходим только тогда, когда персонаж полностью покидает сцену. Если же персонаж просто меняет эмоцию или позу, предпочтительнее использовать инструкцию show, так как она автоматически заменит предыдущее изображение с тем же тегом.

Инструкция hide поддерживает следующее свойство:

onlayer

Принимает имя слоя. Скрывает изображение с указанного слоя.

Например:

e "Я ухожу."

hide eileen

Никогда не следует писать:

hide eileen
show eileen happy

Вместо этого просто напишите:

show eileen happy

Инструкция with

Инструкция with используется для применения эффекта визуального перехода при смене сцены, делая появление и исчезновение изображений плавным. Она состоит из ключевого слова with, за которым следует простое выражение, вычисляющееся в объект перехода или специальное значение None.

Эффект перехода применяется между содержимым экрана на момент окончания предыдущего взаимодействия и текущим содержимым экрана после выполнения инструкций show и hide.

Инструкция with вызывает взаимодействие с игроком. Длительность перехода контролируется игроком, и игрок может прервать его кликом мыши.

Полный список доступных переходов приведён в главе Переходы.

Пример использования инструкции with:

show bg washington
with dissolve

show eileen happy at left
show lucy mad at right
with dissolve

Здесь происходят два перехода. Первая инструкция with использует переход dissolve для плавной смены предыдущего экрана на фон washington (по умолчанию dissolve длится 0.5 секунды).

Второй переход происходит после того, как показаны изображения Эйлин и Люси. Он плавно растворяет сцену, состоящую только из фона, в сцену со всеми тремя изображениями — в результате обе героини появляются одновременно.

Конструкция with None

В приведённом примере используются два перехода dissolve. Но что делать, если мы хотим, чтобы фон появился мгновенно, а персонажи затем появились плавно? Простое удаление первой инструкции with приведёт к тому, что все три изображения появятся одновременно при втором переходе.

Для этого используется специальное значение None. Инструкция with None вызывает мгновенное сокращённое взаимодействие без изменения того, что видит пользователь. Когда начнётся следующий переход, он будет отталкиваться от состояния экрана, зафиксированного этой инструкцией with None.

Например:

show bg washington
with None

show eileen happy at left
show lucy mad at right
with dissolve

В этом случае произойдёт только один визуальный переход — от фона washington к сцене со всеми тремя персонажами.

Конструкция with в инструкциях scene, show и hide

Инструкции show, scene и hide могут принимать необязательную конструкцию with, позволяющую совместить показ или скрытие изображения с переходом на одной строке. Она указывается в конце логической строки после параметров инструкции.

Конструкция with на строке эквивалентна добавлению инструкции with None перед строкой и вызову инструкции with сразу после неё. Например:

show eileen happy at left with dissolve
show lucy mad at right with dissolve

эквивалентно следующей записи:

with None
show eileen happy at left
with dissolve

with None
show lucy mad at right
with dissolve

Инструкции camera и show layer

Инструкция camera позволяет применить трансформацию ATL ко всему слою целиком (например, к слою "master") с помощью синтаксиса:

# Трансформацию flip достаточно объявить один раз в начале игры.
transform flip:
    xzoom -1 yzoom -1

camera at flip

или:

camera:
    xalign 0.5 yalign 0.5 rotate 180

Чтобы отменить применение трансформаций к слою, используйте:

camera

Инструкция camera принимает необязательное имя слоя между словом camera и конструкцией at или двоеточием:

camera mylayer at flip

Инструкция show layer — это более ранняя версия инструкции camera, имеющая некоторые отличия, но всё ещё используемая:

show layer master:
    blur 10

Различия между ними:

  • Camera сохраняет и распространяет состояние трансформации, тогда как show layer сбрасывает его.

  • Трансформации, применённые через show layer, автоматически сбрасываются при следующей инструкции scene, в то время как трансформации camera действуют до тех пор, пока не будут явно отменены.

  • show layer требует обязательного указания имени слоя, тогда как для camera по умолчанию используется слой master.

Инструкции window show и window hide

Инструкция window используется для управления отображением окна диалога, когда персонаж не произносит реплик (например, во время переходов и пауз). Инструкция window show отображает диалоговое окно, а window hide — скрывает его.

Если передан необязательный переход, он используется для показа или скрытия окна. Если он опущен, используются переменные config.window_show_transition и config.window_hide_transition. Передача None отменяет анимацию перехода.

Само окно выводится с помощью вызова config.empty_window (по умолчанию выводит пустую строку от имени рассказчика narrator).

show bg washington
show eileen happy
with dissolve

window show dissolve

"Я могу говорить..."

show eileen happy at right
with move

"...и перемещаться, пока окно диалога остаётся открытым."

window hide dissolve

Функции изображений

renpy.add_layer(layer, above=None, below=None, menu_clear=True, sticky=None)

Добавляет новый слой на экран. Если слой с таким именем уже существует, функция ничего не делает.

Необходимо обязательно указать один из параметров: above или below.

layer

Строка, задающая имя нового добавляемого слоя.

above

Если не None, строка с именем слоя, над которым должен быть размещён новый слой.

below

Если не None, строка с именем слоя, под которым должен быть размещён новый слой.

menu_clear

Если True, этот слой будет очищаться при входе в контекст игрового меню и восстанавливаться при выходе из него.

sticky

Если True, для любых тегов, добавленных на этот слой, он станет слоем по умолчанию до тех пор, пока они не будут скрыты. Если None, слой будет «липким» (sticky) только в том случае, если другие липкие слои уже существуют.

renpy.can_show(name, layer=None, tag=None)

Определяет, может ли name использоваться для отображения изображения. Функция интерпретирует name как тег и атрибуты. Они объединяются с атрибутами отображаемого в данный момент изображения с тегом tag на слое layer для попытки определить уникальное изображение для показа. Если уникальное изображение найдено, возвращает его имя в виде кортежа. В противном случае возвращает None.

tag

Тег изображения, из которого берутся атрибуты. Если не указан, по умолчанию используется первый компонент name.

layer

Слой для проверки. Если None, используется слой по умолчанию для данного tag.

renpy.change_zorder(layer, tag, zorder)

Изменяет порядок zorder изображения с тегом tag на слое layer на значение zorder.

renpy.check_image_attributes(tag, attributes)

Проверяет, существует ли уникальное изображение с указанным тегом и атрибутами. Если да, возвращает атрибуты в правильном порядке. В противном случае возвращает None.

renpy.clear_attributes(tag, layer=None)

Сбрасывает все атрибуты изображения для указанного тега tag. Если у тега не было привязанных атрибутов, функция ничего не делает.

layer

Слой для проверки. Если None, используется слой по умолчанию для данного tag.

renpy.copy_images(old, new)

Копирует изображения, начинающиеся с одного префикса, в изображения, начинающиеся с другого. Например:

renpy.copy_images("eileen", "eileen2")

создаст изображение с префиксом "eileen2" для каждого существующего изображения, начинающегося с "eileen". Если существует "eileen happy", будет создано "eileen2 happy".

old

Строка с разделёнными пробелами компонентами исходного имени изображения.

new

Строка с разделёнными пробелами компонентами нового имени изображения.

Эту функцию можно вызывать только внутри блока init. Вызов этой функции после начала игры приведёт к ошибке. Поскольку инструкция image выполняется с приоритетом init 500, эту функцию обычно следует вызывать с приоритетом init 501 или выше.

renpy.flush_cache_file(fn)

Сбрасывает все записи кэша изображений, ссылающиеся на файл fn. Эту функцию можно вызывать при изменении файла изображения на диске, чтобы принудительно заставить Ren'Py загрузить новую версию.

renpy.get_attributes(tag, layer=None, if_hidden=None)

Возвращает кортеж с атрибутами изображения для тега tag. Если с момента последнего скрытия тегу не было сопоставлено никаких атрибутов, возвращает значение if_hidden.

layer

Слой для проверки. Если None, используется слой по умолчанию для данного tag.

renpy.get_available_image_tags()

Возвращает список всех объявленных тегов изображений.

renpy.get_hidden_tags(layer='master')

Возвращает множество (set) тегов изображений на слое layer, которые в данный момент скрыты, но всё ещё имеют связанные с ними атрибуты.

renpy.get_image_bounds(tag, width=None, height=None, layer=None)

Если изображение с тегом tag отображается на слое layer, возвращает ограничивающий прямоугольник (bounding box) этого изображения. Если изображение не найдено, возвращает None.

Ограничивающий прямоугольник возвращается в виде кортежа (x, y, width, height). Компоненты кортежа выражены в пикселях и могут быть числами с плавающей точкой.

width, height

Ширина и высота области, содержащей изображение. Если None, используются соответственно ширина и высота экрана.

layer

Если None, используется слой по умолчанию для данного tag.

renpy.get_ordered_image_attributes(tag, attributes=(), sort=None)

Возвращает список атрибутов изображения, упорядоченных логичным для пользователя образом.

attributes

Если указано, рассматриваются только атрибуты, совместимые с переданными атрибутами. (Совместимые означает, что они могут присутствовать на одном изображении одновременно.)

sort

Если не None, возвращаемый список атрибутов сортируется с использованием этой функции одного аргумента в качестве ключа разрешения конфликтов — см. руководство по сортировке Python.

renpy.get_placement(d)

Возвращает параметры размещения отображаемого объекта d. На эти данные не предоставляется строгих гарантий, так как они могут измениться при отрисовке объекта и могут не существовать вовсе до первой отрисовки.

Возвращает объект со следующими полями, каждое из которых соответствует свойству стиля:

  • pos

  • xpos

  • ypos

  • anchor

  • xanchor

  • yanchor

  • offset

  • xoffset

  • yoffset

  • subpixel

renpy.get_registered_image(name)

Если изображение с таким именем было зарегистрировано, возвращает его. В противном случае возвращает None.

renpy.get_say_image_tag()

Возвращает тег изображения, соответствующий текущему говорящему персонажу (аргумент image, переданный объекту Character). Возвращает None, если сейчас никто не говорит или у говорящего персонажа нет связанного тега изображения.

renpy.get_showing_tags(layer='master', sort=False)

Возвращает множество (set) тегов изображений, которые отображаются на слое layer в данный момент. Если sort равен True, возвращает список тегов в порядке от дальних к ближним.

renpy.get_zorder_list(layer)

Возвращает список пар (tag, zorder) для слоя layer.

renpy.has_image(name, exact=False)

Возвращает True, если изображение с именем name существует, и False в противном случае.

name

Строка с именем изображения или кортеж строк с компонентами имени.

exact

Возвращает True тогда и только тогда, когда существует изображение с точно таким именем — совпадения по подмножеству атрибутов не учитываются.

renpy.list_images()

Возвращает список всех зарегистрированных в Ren'Py изображений в виде списка строк с пробелами между компонентами имён.

renpy.mark_image_seen(name)

Помечает изображение с указанным именем как уже просмотренное на системе текущего пользователя.

renpy.mark_image_unseen(name)

Помечает изображение с указанным именем как ещё не просмотренное на системе текущего пользователя.

renpy.seen_image(name)

Возвращает True, если изображение с указанным именем было просмотрено хотя бы один раз на системе пользователя. Изображение считается просмотренным, если оно было показано инструкцией show, инструкцией scene или функцией renpy.show(). (Обратите внимание, что бывают ситуации, когда игрок фактически не успевает увидеть изображение, например, если за show сразу же следует hide.)

renpy.showing(name, layer=None)

Возвращает True, если изображение с тем же тегом, что и name, отображается на слое layer.

image

Может быть строкой с именем изображения или кортежем компонентов имени. Также может быть строкой, содержащей только тег изображения.

layer

Слой для проверки. Если None, используется слой по умолчанию для данного тега.

renpy.start_predict(*args)

Функция принимает один или несколько отображаемых объектов в качестве аргументов. Она заставляет Ren'Py выполнять предварительную загрузку (predict) этих объектов во время каждого взаимодействия, пока объекты не будут удалены вызовом renpy.stop_predict().

Если имя отображаемого объекта является строкой, содержащей символ звёздочки *, звёздочки используются как подстановочные знаки (шаблоны). Если в строке есть хотя бы одна точка, сопоставление выполняется с именами файлов, в противном случае — с именами изображений Ren'Py.

Например:

$ renpy.start_predict("eileen *")

запускает предзагрузку всех изображений с тегом eileen, а:

$ renpy.start_predict("images/concert*.*")

находит все файлы, начинающиеся на concert, в каталоге images.

Предзагрузка выполняется в фоновом режиме во время обычного игрового процесса. Чтобы явно дождаться завершения предзагрузки, используйте аргумент predict в функции renpy.pause().

renpy.stop_predict(*args)

Принимает один или несколько отображаемых объектов в качестве аргументов и останавливает их фоновую предзагрузку при взаимодействиях.

Поддерживаются подстановочные шаблоны, аналогично renpy.start_predict().
