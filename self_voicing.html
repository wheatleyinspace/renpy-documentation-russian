Голосовое сопровождение интерфейса (Self-Voicing)

Ren'Py поддерживает режим голосового сопровождения (self-voicing), в котором синтезатор речи используется для чтения текста и элементов интерфейса вслух. Этот режим предназначен для того, чтобы сделать игры на Ren'Py доступными для слабовидящих и незрячих пользователей.

Режим голосового сопровождения можно переключать нажатием клавиши v. Различные режимы и параметры доступности можно выбрать через меню специальных возможностей, вызываемое комбинацией клавиш Shift+A.

В меню доступности (Shift+A) нажатие клавиши R сбрасывает настройки голосового сопровождения к значениям по умолчанию и включает его. Это можно использовать для сброса настроек, если пользователь изменил их до состояния, при котором озвучивание перестало работать.

В режиме голосового сопровождения клавиатурная навигация изменяется так, что клавиши со стрелками вверх и вниз последовательно перемещают фокус по всем интерактивным отображаемым объектам на экране.

Когда отображаемый объект получает фокус, Ren'Py зачитывает вслух связанный с ним текст. Если ни один интерактивный объект не сфокусирован, Ren'Py читает отображаемый на экране текст, не принимающий фокус. Обычно это диалоги и текст повествования игры.

Синтез речи

Обычно Ren'Py использует синтезаторы речи, предоставляемые операционной системой и веб-браузером. Исключением является Linux: для работы голосового сопровождения на Linux должна быть установлена команда espeak-ng.

Голос можно выбрать через меню специальных возможностей, которое использует функцию renpy.get_tts_voices() для получения списка доступных голосов и действие Preference() для выбора голоса. Точный список доступных голосов зависит от платформы и настроек компьютера.

На большинстве платформ Ren'Py полагается на службы синтеза речи операционной системы. Для настройки скорости речи и используемого голоса измените речевые настройки вашей платформы.

Другие режимы

Существует несколько других режимов, связанных с озвучиванием интерфейса:

Программа чтения с экрана (Screen Reader)

Режим чтения с экрана можно переключать нажатием Shift+V. В этом режиме Ren'Py напрямую взаимодействует с активными программами экранного доступа (такими как NVDA, JAWS, VoiceOver или Orca) через библиотеку Prism. Речевые уведомления одновременно отправляются в синтезатор речи и на дисплеи Брайля без использования буфера обмена и без конфликтов со звуком игры. Если ни одна программа экранного доступа не активна, движок корректно переключается на стандартный синтез речи ОС.

Если при запуске игры активна программа экранного доступа, этот режим включается автоматически по умолчанию. Этим поведением можно управлять через config.auto_screenreader_voicing.

Буфер обмена (Clipboard)

Режим буфера обмена переключается нажатием Shift+C. В этом режиме текст копируется в буфер обмена вместо воспроизведения через TTS. Это можно использовать со сторонними скринридерами или другими ассистивными технологиями.

Это также полезно для программ машинного перевода «на лету», умеющих считывать текст из буфера обмена.

Отладка (Debug)

Режим отладки переключается нажатием Shift+Alt+V. В режиме отладки текст, который был бы озвучен, отображается визуально на экране поверх интерфейса.

Рекомендации для разработчиков

Голосовое сопровождение Ren'Py работает путём извлечения текста из отображаемых объектов и озвучивания его игроку. Ren'Py извлекает этот текст из нескольких источников:

Текстовые отображаемые объекты

Ren'Py извлекает текст из объектов Text и делает его доступным для зачитывания игроку.

Альтернативный текст

Альтернативный текст задаётся свойством стиля alt отображаемого объекта. Он также может предоставляться экземплярами классов Action и BarValue. Явно заданный альтернативный текст имеет приоритет над текстом, предоставляемым действиями или BarValue, а они оба имеют приоритет над текстом, извлечённым из объектов Text.

Альтернативный текст переводится с помощью стандартного механизма строкового перевода Ren'Py. Альтернативный текст имеет приоритет над текстом, извлечённым из отображаемого объекта и его дочерних элементов, однако текст дочерних элементов остаётся доступным через подстановку вида "[text]". Никакие другие строковые подстановки в этом поле не допускаются.

Например:

screen information(message, planet, badness):
    text message:
        color color_from_badness(badness)
        alt "Информация для вас : [text]. Уровень опасности " + str(badness)

    text "ORIGIN_OF_MESSAGE_{color=#f00}[planet!u]{/color}":
        alt "Источник сообщения — " + planet

В приведённом примере переменные badness и planet нельзя подставить напрямую через "[badness]". Конкатенация строк в Python является решением.

Передача параметров who_alt и what_alt функции Character устанавливает свойство стиля alt для имени персонажа и текста реплики соответственно. Например, можно определить персонажа, который в визуальном отображении использует курсив для мыслей, но явно озвучивает их при голосовом сопровождении:

define thought = Character(None, what_italic=True, what_alt="Я думаю, [text]")

В экранах отображаемым объектам можно присвоить свойство group_alt, задающее префикс группы, который озвучивается при первой фокусировке элемента этой группы, но не повторяется, пока не будет сфокусирован элемент с другим префиксом.

Отображаемым объектам также можно задать свойство extra_alt, которое озвучивается при нажатии клавиши «?» в момент нахождения объекта в фокусе. Оно предназначено для вывода более подробной справки о том, как работает данный элемент управления.

define config.auto_image_alt = False

Если True, изображения, показанные без явного свойства стиля alt, будут озвучиваться с использованием их имени и атрибутов.

Описательный текст

Описательный текст — это текст, который отображается (и озвучивается) рассказчиком только в том случае, если голосовое сопровождение включено. Если оно отключено, этот текст не отображается. Описательный текст использует переменную alt, которая определена аналогично персонажу.

alt = ...

Объект, подобный Character, который использует рассказчика для произнесения текста, если включено голосовое сопровождение.

Например:

e "Держитесь, поездка будет не из лёгких!"

alt "И тут взорвалось солнце..."

# Сложная и захватывающая катсцена.
show event sun_exploding
pause 10

Переменная, управляющая описательным текстом:

define config.descriptive_text_character = None

Если не None, объект персонажа, используемый для отображения описательного текста вместо рассказчика.

Текстовые теги

Для голосового сопровождения предусмотрены два текстовых тега. Тег alt позволяет задать альтернативный текст, который озвучивается, но не отображается на экране. Тег noalt позволяет задать текст, который отображается на экране, но не озвучивается. Например:

p "Меня зовут {noalt}Шолмондели{/noalt}{alt}Чамли{/alt}."

Переменная config.tts_substitutions может использоваться для автоматической подстановки слов в озвучиваемом тексте, помогая скорректировать правильное произношение. Голос и скорость речи настраиваются через меню специальных возможностей (Shift+A). Выбранный голос сохраняется в preferences.tts_voice, а скорость — в preferences.tts_speed.

define config.auto_screenreader_voicing = True

Если True, Ren'Py автоматически включит режим чтения с экрана при запуске, если обнаружена активная программа экранного доступа (такая как NVDA, JAWS, VoiceOver или Orca).

Режим отладки голосового сопровождения можно активировать нажатием Shift+Alt+V. В этом режиме на экране будет отображаться текст, который был бы передан синтезатору речи.

Функции Python

Следующие функции предоставляются системой голосового сопровождения:

renpy.alt(s, translate=True, force=False)

Ставит строку s в очередь на озвучивание. Если translate равно True, строка будет переведена перед произнесением. Если force равно True, строка будет озвучена, даже если голосовое сопровождение отключено.

Эта функция предназначена для специальных возможностей (accessibility) и не должна использоваться в игровом процессе.

renpy.get_tts_voices()

Возвращает список имён доступных голосов синтезатора речи (TTS). Возвращает пустой список, если голоса недоступны или если платформа не поддерживает перечисление голосов.
