Drag and Drop

В Ren'Py есть система перетаскиваемых отображаемых объектов (drag and drop), позволяющая перемещать элементы по экрану с помощью мыши или сенсорного ввода. Некоторые из применений:

  • Свободное перемещение окон интерфейса пользователем с сохранением их позиций.

  • Карточные игры, требующие перемещения карт по столу (например, пасьянс).

  • Системы инвентаря (перетаскивание предметов в ячейки).

  • Сортировка списков и элементов перетаскиванием.

Система состоит из двух основных классов: класс Drag представляет собой элемент, который можно перетаскивать по экрану, область, на которую можно сбрасывать другие элементы, или и то, и другое одновременно. Класс DragGroup представляет собой группу объектов Drag — сброс (drop) одного объекта на другой возможен только тогда, когда оба принадлежат одной группе перетаскивания.

Систему drag and drop можно использовать как через экранный язык, так и программно в виде объектов Python. Экранный язык удобен, когда после создания объекта Drag к нему не требуется обращаться из кода (например, свободно перемещаемое окно диалога). Если же требуется программное взаимодействие (перемещение элементов кодом, привязка, опрос состояния), лучше создавать объекты Drag явно и добавлять их в DragGroup.

Сброс элементов (Dropping)

Ren'Py поддерживает два способа определения цели для сброса элемента:

  • Если свойство mouse_drop равно True, элемент сбрасывается на тот объект-приёмник, который находится непосредственно под курсором мыши.

  • Если mouse_drop равно False (по умолчанию), элемент сбрасывается на тот объект-приёмник, с которым он имеет наибольшую площадь геометрического перекрытия.

В отличие от начала перетаскивания, где учитывается свойство focus_mask, при определении сброса учитываются полные прямоугольные границы объектов (включая прозрачные пиксели). Это следует учитывать при дизайне графики элементов.

Отображаемые объекты

class Drag(d=None, drag_name=None, draggable=True, droppable=True, drag_raise=True, dragging=None, dragged=None, dropped=None, drag_handle=(0.0, 0.0, 1.0, 1.0), drag_joined=..., clicked=None, hovered=None, unhovered=None, mouse_drop=False, **properties)

Отображаемый объект, представляющий элемент, который можно свободно перетаскивать по окружающей его области. Также может представлять область (droppable), на которую можно сбрасывать другие объекты Drag.

Объект Drag перемещается внутри своего родительского контейнера (обычно Fixed() или DragGroup).

У Drag есть один дочерний элемент. Состояние дочернего элемента отражает текущий статус операции:

  • selected_hover — объект перетаскивается в данный момент.

  • selected_idle — на этот объект может быть сброшен перетаскиваемый элемент.

  • hover — объект находится под курсором и будет захвачен при клике.

  • idle — обычное состояние покоя.

Область захвата (drag handle) — прямоугольник внутри дочернего элемента. Курсор мыши должен находиться внутри области захвата для начала перетаскивания. Если свойство focus_mask равно True, пиксель под курсором не должен быть прозрачным.

Каждый вновь созданный перетаскиваемый объект добавляется в DragGroup по умолчанию. Объект может находиться только в одной DragGroup — при добавлении во вторую он удаляется из первой.

При первом рендеринге Drag, если его позиция не определена внутри DragGroup, координаты левого верхнего угла вычисляются по стандартному алгоритму компоновки. После вычисления свойства компоновки игнорируются, а позиция сохраняется внутри Drag.

Трансформации не следует применять к Drag напрямую — применяйте их к дочернему отображаемому объекту Drag.

d

Дочерний отображаемый объект данного Drag.

drag_name

Имя перетаскиваемого объекта. Доступно через свойство drag_name. Если в DragGroup уже был объект с таким именем, начальная позиция нового Drag берётся из него.

draggable

Если True, объект можно перетаскивать по экрану с помощью мыши.

droppable

Если True, на этот объект можно сбрасывать другие объекты Drag.

drag_raise

Если True, объект поднимается на передний план (поверх остальных) при начале перетаскивания. Если к нему привязаны другие объекты, они также поднимаются на передний план.

activated

Функция обратного вызова (или список функций), вызываемая при нажатии кнопки мыши на объекте Drag. Принимает один аргумент — список перемещаемых объектов Drag. Возвращаемое значение игнорируется.

dragging

Функция, вызываемая в процессе перемещения Drag. Принимает список перемещаемых объектов. Если функция возвращает значение, отличное от None, взаимодействие завершается, а это значение возвращается.

dragged

Функция, вызываемая по окончании перетаскивания Drag. Принимает два аргумента: список перемещаемых объектов и объект Drag, на который произошёл сброс (или None, если сброс не состоялся). Если возвращает значение, отличное от None, взаимодействие завершается.

dropped

Функция, вызываемая у объекта-приёмника, на который был сброшен Drag. Принимает два аргумента: сам объект-приёмник и список перемещаемых Drag. Если функция dragged вернула не None, dropped не вызывается.

clicked

Функция обратного вызова при клике на Drag без его перемещения. Принимает сам объект Drag.

alternate

Действие при клике правой кнопкой мыши или долгом нажатии без смещения на сенсорных экранах.

hovered

Действие при получении фокуса.

unhovered

Действие при потере фокуса.

tooltip

Всплывающая подсказка при наведении на Drag.

drag_handle

Кортеж (x, y, width, height), задающий область захвата внутри дочернего элемента.

drag_joined

Функция, принимающая текущий Drag и возвращающая список кортежей [ (drag, x, y) ], задающих объекты, перемещаемые совместно как единое целое.

drag_offscreen

Условия, при которых объект разрешено перетаскивать за границы экрана:

False

Запрещает выносить объект за границы экрана (по умолчанию).

True

Разрешает свободное перемещение за границы экрана в любых направлениях.

"horizontal"

Разрешает выход за экран только по горизонтали.

"vertical"

Разрешает выход за экран только по вертикали.

(width, height)

Объект можно выносить за экран при условии, что на экране остаётся прямоугольная область размером не менее width x height пикселей.

(min_x, max_x, min_y, max_y)

Числа, задающие допустимые отступы от краёв экрана в пикселях.

вызываемый объект (callable)

Функция fn(x, y), принимающая текущие координаты левого верхнего угла и возвращающая скорректированный кортеж (new_x, new_y).

mouse_drop

Если True, объект сбрасывается на элемент непосредственно под курсором мыши. Если False, сброс происходит на элемент с наибольшей площадью перекрытия.

drop_allowable

Функция, определяющая, разрешён ли сброс текущих перетаскиваемых объектов на данный приёмник.

snapped

Функция обратного вызова, вызываемая по завершении анимации привязки (snap). Принимает аргументы (drag, x, y, completed).

Все параметры (кроме d) доступны как поля объекта Drag. Кроме того, после первого рендеринга становятся доступны поля:

x, y

Позиция Drag относительно родительского контейнера в пикселях.

start_x, start_y

Координаты точки начала перетаскивания.

grab_x, grab_y

Координаты точки захвата мыши при начале перетаскивания.

last_drop

Последний допустимый объект Drag для сброса или None.

snapping

True, если в данный момент воспроизводится анимация привязки snap.

w, h

Ширина и высота дочернего элемента в пикселях.

bottom()

Опускает данный объект в самый низ стопки отображения своей DragGroup.

set_child(d)

Заменяет дочерний отображаемый объект на d.

snap(x, y, delay=0, warper=None)

Плавно или мгновенно перемещает Drag в координаты (x, y). Если delay > 0, перемещение занимает указанное количество секунд с использованием функции сглаживания warper (по умолчанию линейно).

top()

Поднимает данный объект на самый верх стопки отображения своей DragGroup.

class DragGroup(*children, **properties)

Группа перетаскиваемых объектов Drag. Перемещение объектов ограничено границами их DragGroup. Сброс возможен только между объектами одной группы.

Компоновка элементов в DragGroup аналогична контейнеру Fixed().

min_overlap

Минимальное количество перекрывающихся пикселей, необходимое для фиксации сброса.

add(child)

Добавляет дочерний объект Drag в данную группу поверх остальных элементов.

get_child_by_name(name)

Возвращает первый дочерний элемент с указанным drag_name.

remove(child)

Удаляет дочерний объект Drag из данной группы.

Примеры

Пример экрана say, позволяющего игроку свободно перемещать окно диалога по экрану:

screen say(who, what):

    drag:
        drag_name "say"
        yalign 1.0
        drag_handle (0, 0, 1.0, 30)

        xalign 0.5

        window id "window":
            # Окно должно быть меньше размера экрана.
            xmaximum 600

            has vbox

            if who:
                text who id "who"

            text what id "what"

Более сложный пример, показывающий влияние перетаскивания на игровой процесс — отправка детектива в город на карте:

init python:

    def detective_dragged(drags, drop):

        if not drop:
            return

        store.detective = drags[0].drag_name
        store.city = drop.drag_name

        return True

screen send_detective_screen:

    # Карта на фоне.
    add "europe.jpg"

    # DragGroup гарантирует, что детективов можно сбрасывать на города.
    draggroup:

        # Наши детективы.
        drag:
            drag_name "Айви"
            droppable False
            dragged detective_dragged
            xpos 100 ypos 100

            add "ivy.png"
        drag:
            drag_name "Зак"
            droppable False
            dragged detective_dragged
            xpos 150 ypos 100

            add "zack.png"

        # Города назначения.
        drag:
            drag_name "Лондон"
            draggable False
            xpos 450 ypos 140

            add "london.png"

        drag:
            drag_name "Париж"
            draggable False
            xpos 500 ypos 280

            add "paris.png"

label send_detective:
    "Нужно провести расследование! Кого и куда мы отправим?"

    call screen send_detective_screen

    "Отлично, отправляем [detective] в [city]."

Клауза as позволяет связать объект drag с переменной для вызова его методов (например, snap):

screen snap():

    drag:
        as carmen
        draggable True
        xpos 100 ypos 100
        frame:
            style "empty"
            background "carmen.png"
            xysize (100, 100)

            vbox:
                textbutton "Лондон" action Function(carmen.snap, 450, 140, 1.0)
                textbutton "Париж" action Function(carmen.snap, 500, 280, 1.0)
