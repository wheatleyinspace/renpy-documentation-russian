Возраст пользователя

Чтобы помочь вам соблюдать законодательные нормы, требующие ограничения доступа к определённому контенту в зависимости от возраста пользователя, Ren'Py предоставляет платформенный функционал, возвращающий диапазон возраста пользователя. Эта информация доступна только на поддерживающих её платформах и может предоставляться только для определённых юрисдикций.

renpy.get_user_age()

Возвращает диапазон возраста пользователя, если его удаётся определить. Возвращает кортеж из двух целых чисел, задающих минимальный и максимальный возраст пользователя. Если возраст определить невозможно, возвращает (-1, 150).

Функционал ограничен платформой (в настоящее время поддерживаются Android и iOS 26+), а данные могут быть доступны только в регионах мира, где действует соответствующее законодательство. Механизм предназначен для помощи разработчикам в соблюдении правовых норм, однако, как и вся система Ren'Py, предоставляется БЕЗ КАКИХ-ЛИБО ГАРАНТИЙ.

На Android используется Play Age Signals API. Используя его, вы должны согласиться с условиями использования по адресу https://developer.android.com/google/play/age-signals/overview, которые накладывают ограничения на способы обработки данных о возрасте.

На iOS используется Declared Age Range API (iOS 26+). Чтобы включить его, необходимо добавить право (entitlement) com.apple.developer.declared-age-range в проект, активировав возможность Declared Age Range в Xcode. Это право отсутствует в базовом шаблоне Ren'Py для iOS, поэтому его необходимо включить явно перед отправкой приложения в App Store: откройте раздел Signing & Capabilities, нажмите кнопку «+ Capability» и добавьте «Declared Age Range».

На неподдерживаемых платформах, при отсутствии соответствующего права или если диапазон возраста не удалось определить, функция возвращает False.

Пример

$ age_lower, age_upper = renpy.get_user_age()

if age_upper < 18:
    # Пользователю гарантированно меньше 18 лет. Закрываем доступ.
    jump under_18_screen
elif age_lower >= 18:
    # Пользователю гарантированно 18 лет или больше. Предоставляем доступ.
    jump bypass_age_check
else:
    # Запрашиваем подтверждение возраста у пользователя.
    jump age_check
