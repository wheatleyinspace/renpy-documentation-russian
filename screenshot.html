Снимки экрана

В Ren'Py есть встроенная поддержка создания снимков экрана (скриншотов) как всей игры, так и отдельных отображаемых объектов. Последнее подходит для создания составных «бумажных кукол» (аватаров, гардеробов персонажей) из нескольких отображаемых объектов и сохранения их на диск для последующего использования игроком.

Когда Ren'Py делает снимок экрана (всего экрана или отдельного отображаемого объекта), снимок создаётся в размере отрисовки (drawable size), после применения масштабирования окна и настроек High DPI. Это позволяет запечатлеть именно то, что пользователь видит на своём экране, а не исходный размер файлов ассетов.

По умолчанию захват снимка экрана привязан к клавише «s».

Существует несколько действий и функций экранов, связанных со снимками экрана:

  • Screenshot

  • FileScreenshot

  • FileTakeScreenshot

Функции

Для создания снимков экрана также можно использовать следующие функции:

renpy.render_to_file(d, filename, width=None, height=None, st=0.0, at=None, resize=False)

Выполняет рендеринг отображаемого объекта или Render и сохраняет результат в файл. Рендеринг выполняется графической подсистемой Ren'Py, так что если окно масштабировано, результат также будет отмасштабирован.

d

Отображаемый объект или Render для отрисовки. Если передан Render, параметры width, height, st и at игнорируются.

filename

Строка с именем файла для сохранения рендера. Интерпретируется относительно базового каталога. Имя файла должно заканчиваться на .png.

width

Ширина, предоставляемая d, в виртуальных пикселях. Если None, используется config.screen_width.

height

Высота, предоставляемая d, в виртуальных пикселях. Если None, используется config.screen_height.

st

Время рендеринга по шкале показа (shown timebase).

at

Время рендеринга по шкале анимации (animation timebase). Если None, используется st.

resize

Если True, изображение будет масштабировано до виртуального размера отображаемого объекта или render. Это может снизить качество результата.

Эта функция может быть вызвана только после запуска графической подсистемы Ren'Py, поэтому её нельзя вызывать во время фазы init или до первого взаимодействия с пользователем.

Ren'Py не выполняет повторное сканирование файлов во время работы игры, поэтому эту функцию не следует использовать для генерации ассетов, используемых в самой игре.

renpy.render_to_surface(d, width=None, height=None, st=0.0, at=None, resize=False)

Принимает отображаемый объект или Render и возвращает поверхность pygame Surface. Рендеринг выполняется графической подсистемой Ren'Py, так что если окно масштабировано, результат также будет отмасштабирован.

d

Отображаемый объект или Render для отрисовки. Если передан Render, параметры width, height, st и at игнорируются.

width

Ширина, предоставляемая d, в виртуальных пикселях. Если None, используется config.screen_width.

height

Высота, предоставляемая d, в виртуальных пикселях. Если None, используется config.screen_height.

st

Время рендеринга по шкале показа (shown timebase).

at

Время рендеринга по шкале анимации (animation timebase). Если None, используется st.

resize

Если True, поверхность будет масштабирована до виртуального размера отображаемого объекта или render. Это может снизить качество результата.

Эта функция может быть вызвана только после запуска графической подсистемы Ren'Py, поэтому её нельзя вызывать во время фазы init или до первого взаимодействия с пользователем.

renpy.screenshot(filename)

Сохраняет снимок экрана в файл filename.

Возвращает True, если снимок экрана был успешно сохранён, и False, если сохранение не удалось по какой-либо причине.

Переменные config.screenshot_pattern и _screenshot_pattern управляют форматом имени файла, в который сохраняется снимок экрана.

renpy.screenshot_to_bytes(size)

Возвращает снимок экрана в виде объекта bytes, который можно передать в im.Data(). Байты представляют собой изображение в формате PNG, так что код:

$ data = renpy.screenshot_to_bytes((640, 360))
show expression im.Data(data, "screenshot.png"):
    align (0, 0)

отобразит это изображение. Возвращённые объекты bytes можно сохранять в файлах сохранений и в постоянных данных (persistent data). Однако они могут иметь большой размер, поэтому следует соблюдать осторожность и не сохранять их слишком много.

size

Размер, до которого будет смасштабирован снимок экрана. Если None, снимок экрана будет соответствовать текущему размеру окна игрока (без чёрных полос по краям).

Эта функция может работать медленно, поэтому она предназначена для снимков экрана сохранений, а не для эффектов в реальном времени.
