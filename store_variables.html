Переменные хранилища

В Ren'Py существует ряд переменных хранилища (store variables), управляющих его функционированием. Переменные хранилища могут быть изменены в любой момент времени. Если переменная хранилища изменяется после старта игры, она сохраняется и загружается системой сохранений, а также возвращает свое значение при откате (rollback).

adv = Character(...)

Шаблонный персонаж режима ADV и тип персонажа по умолчанию, используемый при вызове Character().

_autosave = True

Эту переменную можно установить в значение False для отключения автосохранения.

_confirm_quit = True

Определяет, запрашивать ли подтверждение при выходе из игры. Устанавливается в значение False во время заставки (splashscreen) и игнорируется в главном меню.

_constant

Если установлена в True внутри хранилища, указывает, что это хранилище является константным. См. Константные хранилища.

default_mouse

По умолчанию не определена. Если определена и если переменная config.mouse была задана при запуске игры, этот ключ используется для поиска курсора мыши, когда текущий курсор не существует или является курсором по умолчанию. Используется переменной config.mouse и отображаемым объектом MouseDisplayable().

Подробнее см. раздел Пользовательские курсоры мыши.

_dismiss_pause = True

Если True, игрок может прерывать кликом мыши паузы и переходы.

_game_menu_screen = "save"

Экран, отображаемый при входе в игровое меню без указания конкретного экрана (например, по клику правой кнопкой мыши, нажатию Escape или при вызове ShowMenu() без аргументов). Если None, вход в игровое меню запрещен.

Устанавливается в None в начале заставки (splashscreen) и восстанавливается в исходное значение по завершении заставки.

_greedy_rollback = True

Определяет, выполняет ли игра «жадный откат» после загрузки сохранения. Жадный откат откатывает состояние непосредственно к моменту после последнего интерактивного оператора, а не прямо перед оператором, на котором находилась игра при сохранении.

_history = True

Если True, Ren'Py будет записывать историю диалогов при показе реплик (переменная config.history_length также должна быть задана).

_history_list = [ ]

Список объектов истории, соответствующих каждой строке истории от самых старых к самым новым. Подробнее см. раздел История диалогов.

_ignore_action = None

Если не None, Действие (Action), выполняемое при нажатии кнопки «Игнорировать» («Ignore») на экране обработки ошибок. Обычно это Jump() для перехода в безопасное место игры. Если None, выполнение продолжается со следующего оператора Ren'Py.

main_menu = False

Ren'Py устанавливает эту переменную в True во время нахождения в главном меню. Может использоваться для изменения внешнего вида экранов в главном меню.

_menu = False

Ren'Py устанавливает эту переменную в True при входе в контекст главного или игрового меню.

menu = renpy.display_menu

Функция, вызываемая для отображения игрового меню выбора. Должна принимать те же аргументы, что и renpy.display_menu(), и передавать неизвестные именованные аргументы без изменений. Присвоение значения nvl_menu() отобразит меню в режиме NVL.

mouse_visible = True

Управляет видимостью курсора мыши. Возможные значения:

  • "always" — курсор виден всегда.

  • True — курсор виден при движении, но скрывается после config.mouse_hide_time секунд бездействия или при вводе с контроллера.

  • False — курсор мыши никогда не виден.

Если перед входом в игровое меню переменная равна False, при входе в меню ей временно присваивается значение True, а при выходе восстанавливается исходное значение.

name_only = Character(...)

Шаблонный персонаж, используемый, когда в качестве имени говорящего в операторе say указана обычная строка. Конструкция:

"Эйлин" "Привет, мир."

эквивалентна:

$ temp_char = Character("Эйлин", kind=name_only)
temp_char "Привет, мир."

за исключением того, что переменная temp_char фактически не создается.

narrator = Character(...)

Персонаж-рассказчик, произносящий повествовательный текст (операторы say без указания персонажа или имени). Конструкция:

"Привет, мир."

эквивалентна:

narrator "Привет, мир."
_quit_slot = None

Если не None, строка с именем слота сохранения. При выходе из Ren'Py игра будет автоматически сохранена в этот слот.

_rollback = True

Определяет, разрешен ли откат назад в текущий момент.

say : Callable

Функция, вызываемая Ren'Py для отображения диалога, когда строка используется вместо говорящего персонажа:

define e = Character("Эйлин", who_color="#0f0")

label start:
    "Эйлин" "Меня зовут Эйлин." # вызовет функцию say
    e "Мне нравятся поезда!" # не вызовет функцию say

Функция должна иметь ту же сигнатуру, что и renpy.say(). Она не должна вызывать renpy.say(), а использовать другие эквиваленты оператора say.

Прямой вызов этой функции требуется редко. Переменная существует главным образом для переопределения и перехвата стандартного оператора say.

save_name = ""

Имя сохранения, записываемое в файл сохранения. Также используется временной шкалой Steam (Steam Timeline), если включена переменная config.automatic_steam_timeline. Обычно рассматривается как название текущей главы или эпизода.

_scene_show_hide_transition = None

Если не None, переход, выполняемый с помощью оператора with после серии операторов scene, show и hide, за которыми не следует явный оператор with или переход окна.

См. также

Автоматические переходы после Scene, Show и Hide

_screenshot_pattern = None

Если не None, эта строка используется вместо config.screenshot_pattern для определения имени файла снимка экрана. Формат строки описан в документации к указанной переменной.

_skipping = True

Определяет, разрешен ли быстрый пропуск текста в данный момент.

_version = ...

Принимает значение config.version при старте новой игры. Может использоваться меткой after_load или колбэками config.after_load_callbacks для определения необходимости обновления сохранений.

Устанавливается движком только один раз при начальном старте игры. В дальнейшем игра сама отвечает за обновление _version при необходимости.

_window = False

Устанавливается операторами window show и window hide, а также неявно режимом window auto. Если True, окно диалога отображается во время выполнения недиалоговых операторов.

_window_auto = False

Устанавливается в True оператором window auto и в False операторами window show и window hide. Если True, активно поведение автоматического управления окном.

_window_subtitle = ''

Добавляется к значению config.window_title для формирования полного заголовка окна игры. Автоматически принимает значение config.menu_window_subtitle во время нахождения в игровом меню.
