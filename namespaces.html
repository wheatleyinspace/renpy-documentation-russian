Пространства имён

Ren'Py использует пространства имён для упорядочивания переменных и методов. Этот файл содержит описания некоторых пространств имён, используемых в Ren'Py, главным образом для того, чтобы помочь редакторам кода обеспечивать автодополнение и подсказки документации.

achievement

Пространство имён, содержащее функции для выдачи достижений и управления ими (достижения). Оно также содержит большую часть интеграции со Steamworks.

bubble:

Пространство имён, содержащее переменные, управляющие отображением диалоговых облачков (речевых пузырей).

build:

Пространство имён, содержащее переменные, управляющие процессом сборки дистрибутивов.

config:

Пространство имён, содержащее переменные, управляющие конфигурацией Ren'Py. Эти переменные следует задавать на этапе инициализации (в блоках init python или с помощью инструкции define); их не следует изменять после начала игры.

define:

Пространство имён define содержит функции, определяющие новые переменные, такие как семейства переходов.

director:

Пространство имён director содержит функции, управляющие интерактивным режиссёром, который позволяет интерактивно добавлять изображения и музыку в игру.

define gui

Пространство имён gui содержит функции, управляющие стандартной системой графического интерфейса (GUI). Эти переменные имеют значение только при использовании стандартного графического интерфейса и могут не использоваться, если вы заменили его собственным. Инструкции define, влияющие на пространство имён gui, выполняются повторно при смене языка перевода.

iap

Пространство имён iap содержит функции, управляющие системой внутриигровых покупок (IAP).

im

Примечание: Большинство функций в пространстве имён im устарели.

Пространство имён im содержит манипуляторы изображений, загружающие или преобразующие изображения на CPU. Большинство этих операций эффективнее выполнять на GPU с помощью Transform.

layeredimage

Многослойные изображения — это способ объединения нескольких изображений в единый объект с использованием атрибутов и условий для управления отображением слоёв. Пространство имён layeredimage содержит классы, позволяющие создавать и изменять многослойные изображения из Python, что эквивалентно инструкции layeredimage.

persistent

Пространство имён persistent содержит постоянные данные (persistent). Поля этого объекта изначально равны None и сохраняют свои значения между запусками игры даже без загрузки слота сохранения.

Значения полей объекта persistent должны быть стандартными типами Python, такими как логические значения, числа, строки, списки, кортежи, словари и множества. Пользовательские классы не должны присваиваться объекту persistent.

preferences

Пространство имён Переменные настроек содержит переменные пользовательских настроек. Хотя их можно читать и изменять напрямую, чаще всего их инициализируют с помощью инструкции default с синтаксисом вида:

default preferences.fullscreen = True
preferences.volume

Пространство имён Переменные настроек содержит переменные, задающие громкость по умолчанию для каждого микшера. Их следует задавать с помощью инструкции default, например:

default preferences.volume.music = 0.5
renpy

Пространство имён renpy содержит функции и классы, являющиеся частью самого движка Ren'Py. Они могут быть эквивалентами инструкций языка Ren'Py или предоставлять функциональность, для которой нет отдельной инструкции.

renpy.audio.filter

Пространство имён renpy.audio.filter содержит классы и функции, создающие аудиофильтры.

renpy.music

Пространство имён renpy.audio.music содержит функции, управляющие аудиосистемой. По умолчанию эти функции работают с музыкальным каналом (music).

renpy.sound

Пространство имён renpy.audio.sound содержит функции, управляющие аудиосистемой. По умолчанию эти функции работают со звуковым каналом (sound). Большинство функций описаны в документации их эквивалентов в renpy.music.

style

Пространство имён style содержит стили и функции для манипуляции стилями. Стили используются для управления внешним видом текста, изображений и других элементов в Ren'Py. Использование инструкции style предпочтительнее прямого обращения к пространству имён style.

ui

Примечание: Большинство функций в пространстве имён ui устарели.

Пространство имён ui содержит устаревшие функции и классы, использовавшиеся для отображения элементов интерфейса. За исключением ui.adjustment, ui.interact, ui.callsinnewcontext и ui.invokesinnewcontext, эти функции считаются устаревшими.

updater

Пространство имён updater содержит функции, классы и переменные, управляющие системой обновления по HTTP/HTTPS.
