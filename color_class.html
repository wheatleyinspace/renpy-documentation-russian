Класс Color

В Ren'Py есть класс Color, который можно использовать для преобразования цвета из одного цветового пространства в другое, а также для выполнения различных операций теории цвета. Объекты Color неизменяемы (immutable) и могут использоваться везде, где допускается кортеж цвета.

Кортежи цветов работают в одном из трёх цветовых пространств:

  • RGB — Красный, Зелёный, Синий (Red, Green, Blue)

  • HLS — Тон, Светлота, Насыщенность (Hue, Lightness, Saturation)

  • HSV — Тон, Насыщенность, Значение (Hue, Saturation, Value)

В качестве примера некоторых вычислений, которые можно производить: все следующие записи представляют собой ярко-зелёный цвет:

# Стандартные цвета Ren'Py.
Color("#0f0")
Color("#00ff00")
Color((0, 255, 0, 255))

# Преобразование из других цветовых пространств.
Color(hls=(.333, 0.5, 1.0))
Color(hsv=(.333, 1.0, 1.0))

# Превращает красный в зелёный с помощью метода, возвращающего новый цвет.
Color("#f00").rotate_hue(.333)
class Color(color=None, hls=None, hsv=None, rgb=None, alpha=1.0)

Класс Color используется для представления цветов, манипуляций с ними и преобразования между различными цветовыми пространствами. Он также представляет непрозрачность в виде альфа-канала.

При создании объекта Color следует указывать не более одного из аргументов color, hls, hsv или rgb. (Если все они равны None, возвращается None.)

color

Цвет в одном из стандартных форматов, распознаваемых Ren'Py:

  • Объект Color.

  • Кортеж (r, g, b) или (r, g, b, a), в котором все числа лежат в диапазоне от 0 до 255.

  • Строка с шестнадцатеричным кодом цвета вида "#rgb", "#rgba", "#rrggbb" или "#rrggbbaa".

hls

Цвет в цветовом пространстве тон-светлота-насыщенность (Hue, Lightness, Saturation). Задаётся кортежем из трёх компонентов, каждый из которых лежит в диапазоне от 0.0 до 1.0.

hsv

Цвет в цветовом пространстве тон-насыщенность-значение (Hue, Saturation, Value). Задаётся кортежем из трёх компонентов, каждый из которых лежит в диапазоне от 0.0 до 1.0.

rgb

Цвет в цветовом пространстве красный-зелёный-синий (Red, Green, Blue). Задаётся кортежем из трёх компонентов, каждый из которых лежит в диапазоне от 0.0 до 1.0.

Если переданный цвет не содержит значения альфа-канала, используется параметр alpha. alpha должен быть в диапазоне от 0.0 до 1.0.

Объекты Color можно использовать как 4-компонентные кортежи (красный, зелёный, синий и альфа). При использовании в качестве кортежа значение каждого компонента находится в диапазоне от 0 до 255.

Объекты Color поддерживают операторы +, - и *, представляющие собой покомпонентное сложение, вычитание и умножение. Некоторые операции могут приводить к получению компонентов, выходящих за допустимые пределы. Такие цвета не следует передавать в другие подсистемы Ren'Py (метод normalize позволяет получить новый цвет с нормализованными значениями компонентов).

Объект Color имеет следующие свойства:

hls

Возвращает цвет в виде кортежа из трёх чисел с плавающей запятой: тон, светлота и насыщенность. Каждый компонент лежит в диапазоне от 0.0 до 1.0.

hsv

Возвращает цвет в виде кортежа из трёх чисел с плавающей запятой: тон, насыщенность и значение. Каждый компонент лежит в диапазоне от 0.0 до 1.0.

rgb

Возвращает цвет в виде кортежа из трёх чисел с плавающей запятой: красный, зелёный и синий. Каждый компонент лежит в диапазоне от 0.0 до 1.0.

rgba

Возвращает цвет в виде кортежа из четырёх чисел с плавающей запятой: красный, зелёный, синий и альфа со значениями от 0.0 до 1.0.

premultiplied

Возвращает цвет в виде кортежа из четырёх чисел с плавающей запятой со значениями от 0.0 до 1.0, где компоненты red, green и blue предварительно умножены на альфа (premultiplied alpha).

alpha

Возвращает альфа-канал (непрозрачность) цвета в виде числа от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный).

hexcode

Возвращает строку с шестнадцатеричным кодом цвета вида #rrggbbaa или #rrggbb.

Объекты Color имеют следующие методы. Поскольку объекты Color неизменяемы (immutable), эти методы всегда возвращают новый объект Color.

interpolate(other: ColorLike, fraction: float) → 'Color'

Выполняет интерполяцию между данным цветом и цветом other в цветовом пространстве RGB, возвращая новый Color в качестве результата. Если fraction равно 0.0, возвращается исходный цвет, если 1.0 — цвет other.

interpolate_hls(other: 'str | Color | tuple[float, float, float]', fraction: float) → 'Color'

Выполняет интерполяцию между данным цветом и цветом other в цветовом пространстве HLS, возвращая новый Color в качестве результата. Если fraction равно 0.0, возвращается исходный цвет, если 1.0 — цвет other.

other может быть строкой, объектом Color или кортежем HLS.

interpolate_hsv(other: 'str | Color | tuple[float, float, float]', fraction: float) → 'Color'

Выполняет интерполяцию между данным цветом и цветом other в цветовом пространстве HSV, возвращая новый Color в качестве результата. Если fraction равно 0.0, возвращается исходный цвет, если 1.0 — цвет other.

other может быть строкой, объектом Color или кортежем HSV.

multiply_hls_saturation(saturation: float) → 'Color'

Умножает насыщенность цвета на saturation и возвращает результат в виде нового Color. Операция выполняется в цветовом пространстве HLS.

multiply_hsv_saturation(saturation: float) → 'Color'

Умножает насыщенность цвета на saturation и возвращает результат в виде нового Color. Операция выполняется в цветовом пространстве HSV.

multiply_value(value: float) → 'Color'

Умножает значение цвета на value и возвращает результат в виде нового Color. Операция выполняется в цветовом пространстве HSV.

normalize()

Возвращает нормализованную версию этого цвета, где все компоненты приведены к диапазону от 0 до 255.

opacity(opacity: float) → 'Color'

Умножает альфа-канал цвета на opacity и возвращает новый Color.

replace_hls_saturation(saturation: float) → 'Color'

Заменяет насыщенность цвета значением saturation и возвращает результат в виде нового Color. Операция выполняется в цветовом пространстве HLS.

replace_hsv_saturation(saturation: float) → 'Color'

Заменяет насыщенность цвета значением saturation и возвращает результат в виде нового Color. Операция выполняется в цветовом пространстве HSV.

replace_hue(hue: float) → 'Color'

Заменяет цветовой тон на значение hue, которое должно находиться в диапазоне от 0.0 до 1.0. Возвращает новый Color.

replace_lightness(lightness: float) → 'Color'

Заменяет светлоту цвета значением lightness и возвращает результат в виде нового Color. Операция выполняется в цветовом пространстве HLS.

replace_opacity(opacity: float) → 'Color'

Заменяет альфа-канал цвета значением opacity и возвращает результат в виде нового Color.

replace_value(value: float) → 'Color'

Заменяет значение цвета на value и возвращает результат в виде нового Color. Операция выполняется в цветовом пространстве HSV.

rotate_hue(rotation: float) → 'Color'

Смещает цветовой тон на величину rotation по кругу и возвращает новый Color. rotation выражается долей полного оборота (от 0.0 до 1.0). Разделите на 360.0 для преобразования из градусов.

shade(fraction: float) → 'Color'

Создаёт затемнённый оттенок (shade) цвета путём смешивания с чёрным цветом. fraction задаёт долю исходного цвета в результирующем цвете. Если fraction равно 1.0, цвет остаётся неизменным; если 0.0 — возвращается чёрный цвет.

Альфа-канал остаётся без изменений.

tint(fraction: float) → 'Color'

Создаёт осветлённый оттенок (tint) цвета путём смешивания с белым цветом. fraction задаёт долю исходного цвета в результирующем цвете. Если fraction равно 1.0, цвет остаётся неизменным; если 0.0 — возвращается белый цвет.

Альфа-канал остаётся без изменений.
