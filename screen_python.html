Экраны и Python

Функции экранов

Следующие функции обеспечивают выполнение различных операций, связанных с экранами.

renpy.call_screen(_screen_name, *args, _with_none=True, _mode='screen', **kwargs)

Программный эквивалент оператора call screen.

Отображает _screen_name в качестве экрана, после чего запускает взаимодействие. Экран скрывается по окончании взаимодействия, а результат взаимодействия возвращается.

Позиционные аргументы и именованные аргументы, не начинающиеся со знака подчеркивания, передаются экрану.

Если _with_none равно False, в конце взаимодействия не выполняется "with None".

Если передан _mode, он становится режимом данного взаимодействия (иначе "screen").

renpy.current_screen()

Возвращает информацию об экране, который в данный момент обновляется, отрисовывается или обрабатывается.

Документированные поля возвращаемого объекта описаны в get_screen().

renpy.get_adjustment(bar_value)

Принимая bar_value, объект BarValue, возвращает используемый им регулятор ui.adjustment(). Регулятор имеет следующие атрибуты:

value

Текущее значение полосы.

range

Текущий диапазон полосы.

renpy.get_displayable(screen, id, layer=None, base=False)

Возвращает отображаемый объект с идентификатором id из экрана screen на слое layer. Возвращает None, если экран не существует или на нем нет виджета с таким id.

renpy.get_displayable_properties(id, screen=None, layer=None)

Возвращает свойства отображаемого объекта с id на экране screen на слое layer. Если screen равен None, возвращает свойства для текущего экрана. Может использоваться из Python или в коде свойств внутри экрана.

Возвращает словарь со свойствами виджета.

renpy.get_screen(name, layer=None, tag_only=False)

Возвращает информацию об экране с данным именем name на слое layer. name сначала интерпретируется как тег, а затем как имя экрана. Если экран не отображается, возвращает None.

Также может принимать список имен: в этом случае возвращается первый отображаемый экран.

tag_only

Если True, учитывается только тег.

Функцию можно использовать для проверки того, отображается ли экран:

if renpy.get_screen("say"):
    text "Экран say отображается."
else:
    text "Экран say скрыт."

Объекты, возвращаемые этой функцией, имеют следующие документированные поля:

layer

Слой, на котором отображается экран.

name

Имя экрана.

zorder

Порядок zorder отображения экрана.

Предупреждение

Возвращаемый объект предназначен для кратковременного использования сразу после вызова функции. Не рекомендуется включать его в данные сохранений или в систему отката.

renpy.get_screen_docstring(name, variant=None)

Возвращает строку документации (docstring) для экрана с именем name и вариантом variant.

name

Имя экрана.

variant

Вариант экрана. Если None, используется вариант по умолчанию.

renpy.get_screen_variable(name, *, screen=None, layer=None)

Возвращает значение переменной в области видимости экрана.

name

Имя возвращаемой переменной.

screen

Имя экрана. Если None, используется текущий экран (определен только при обновлении экрана и в действиях, выполняемых внутри него).

layer

Слой, на котором находится экран (если screen не None).

renpy.hide_screen(tag, layer=None, immediately=False)

Программный эквивалент оператора hide screen.

Скрывает экран с тегом tag на слое layer.

Если immediately равно True, экран скрывается мгновенно, без события 'on hide'.

renpy.set_focus(screen, id, layer='screens')

Пытается передать фокус отображаемому объекту с id на экране screen. Фокусировка не удастся, если объект не найден, окно не сфокусировано или фокус перехвачен.

Фокус может измениться, если мышь сдвинется даже незначительно после вызова.

renpy.set_screen_variable(name, value, *, screen=None, layer=None)

Устанавливает значение переменной в области видимости экрана. Обратите внимание: это не обновляет значение мгновенно — вызовите renpy.restart_interaction(), чтобы вызвать обновление экрана.

name

Имя переменной. Должна быть переменной, созданной оператором Default.

value

Устанавливаемое значение.

screen

Имя экрана. Если None, используется текущий экран.

layer

Слой экрана, если screen не None.

renpy.show_screen(_screen_name, *args, _layer=None, _zorder=None, _tag=None, _widget_properties={}, _transient=False, **kwargs)

Программный эквивалент оператора show screen.

Отображает указанный экран. Принимает следующие именованные аргументы:

_screen_name

Имя отображаемого экрана.

_layer

Слой отображения экрана (эквивалент предложения onlayer оператора Show Screen).

_zorder

Порядок отображения по оси Z (по умолчанию из экрана или 0).

_tag

Тег экрана (эквивалент предложения as оператора Show Screen).

_widget_properties

Словарь соответствия id виджета словарю свойство -> значение. Когда виджет с этим id отображается экраном, указанные свойства добавляются к нему.

_transient

Если True, экран автоматически скроется в конце текущего взаимодействия.

Остальные аргументы передаются экрану.

renpy.start_predict_screen(_screen_name, *args, **kwargs)

Заставляет Ren'Py начать предсказание экрана _screen_name с указанными аргументами. Заменяет любое предыдущее предсказание этого экрана. Для остановки предсказания вызовите renpy.stop_predict_screen().

Предсказание выполняется во время нормальной игры. Чтобы дождаться завершения предсказания, используйте аргумент predict функции renpy.pause().

renpy.stop_predict_screen(name)

Останавливает предсказание экрана с именем name.

renpy.variant(name)

Возвращает True, если name является вариантом экрана, соответствующим контексту, в котором сейчас выполняется Ren'Py. См. Варианты экранов.

name также может быть списком вариантов: в этом случае функция возвращает True, если совпадает хотя бы один из них.

class ui.adjustment(range=1, value=0, step=None, page=None, changed=None, adjustable=None, ranged=None, force_step=False, raw_changed=None)

Объекты регулятора (adjustment) представляют значение, которое можно настраивать с помощью полосы (bar) или области просмотра (viewport). Они содержат информацию о значении, диапазоне значения, а также о шаге регулировки и размере страниц.

Следующие параметры соответствуют полям или свойствам объекта регулятора:

range

Диапазон регулятора (число).

value

Текущее значение регулятора (число).

step

Размер шага (число). Если None, по умолчанию 1/10 страницы (если задана), иначе 1/20 диапазона. Используется при прокрутке области просмотра колесом мыши.

page

Размер страницы регулятора. Если None, устанавливается областью просмотра автоматически. Если не задан, по умолчанию равен 1/10 диапазона. Используется при клике по полосе прокрутки.

Следующие параметры управляют поведением регулятора:

adjustable

Если True, регулятор можно изменять полосой. По умолчанию True, если задана функция changed или если регулятор связан с областью просмотра.

changed

Функция, вызываемая с новым значением при изменении значения регулятора.

raw_changed

Функция, вызываемая при изменении значения регулятора. В отличие от changed, вызывается с «сырым» значением, которое может выходить за пределы диапазона. Принимает два аргумента: объект регулятора и новое значение.

ranged

Функция, вызываемая с объектом регулятора при установке его диапазона областью просмотра. Может вызываться многократно в процессе компоновки.

force_step

Если True, и значение меняется перетаскиванием связанной области просмотра или полосы, значение меняется только при достижении следующего шага. Если "release", после отпускания мыши значение округляется до ближайшего шага. Если False, значение меняется плавно, игнорируя шаг.

change(value)

Изменяет значение регулятора на value, обновляя все полосы и области просмотра, использующие этот регулятор.

ui.interact(*, roll_forward=None, mouse=None)

Вызывает взаимодействие с пользователем и возвращает результат этого взаимодействия. Заставляет Ren'Py перерисовать экран и начать обработку событий ввода. Когда отображаемый объект возвращает значение в ответ на событие, это значение возвращается из ui.interact, и взаимодействие завершается.

Эта функция редко вызывается напрямую: обычно ее вызывают другие части Ren'Py, включая операторы say, menu, with, pause, call screen, renpy.input() и другие.

При завершении взаимодействия слой transient и все экраны, показанные с параметром _transient=True, удаляются из списков сцен.

Документированные аргументы:

roll_forward

Информация, возвращаемая функцией при перемотке вперед (обычно результат вызова renpy.roll_forward_info()). Если None, перемотка вперед игнорируется.

mouse

Стиль курсора мыши: 'default', 'mainmenu' или 'gamemenu'.

Действия (Actions)

Многие отображаемые объекты, создаваемые в языке экранов, принимают действия в качестве аргументов. Действие может представлять собой одно из трех:

  • Вызываемый объект Python (например, функцию или связанный метод), не принимающий аргументов.

  • Экземпляр класса, наследующего от класса Action.

  • Список других объектов Action.

Преимущество наследования от класса Action заключается в возможности переопределять методы, определяющие, когда кнопка должна быть чувствительной к нажатию и когда она выбрана.

class Action

Для создания нового действия наследуйте от этого класса. Переопределите методы этого класса для настройки поведения действия.

__call__(self)

Метод, вызываемый при активации действия. Во многих случаях возвращение значения, отличного от None, приведет к завершению текущего взаимодействия.

Этот метод обязательно должен быть переопределен, так как метод по умолчанию вызывает исключение NotImplementedError (что вызовет ошибку в Ren'Py).

get_sensitive(self)

Вызывается для определения чувствительности кнопки с этим действием к нажатию. Должен возвращать True, если кнопка чувствительна.

Обратите внимание: метод __call__ может быть вызван, даже если get_sensitive вернул False.

Реализация по умолчанию возвращает True.

get_selected(self)

Должен возвращать True, если кнопка должна отрисовываться как выбранная (selected), и False в противном случае.

Реализация по умолчанию возвращает False.

get_tooltip(self)

Возвращает всплывающую подсказку (tooltip) по умолчанию для кнопки, если кнопке не назначена конкретная подсказка. Должен возвращать значение подсказки или None.

По умолчанию возвращает None.

periodic(self, st)

Этот метод вызывается один раз в начале каждого взаимодействия и затем периодически повторяется. Если он возвращает число, следующий вызов произойдет не позже, чем через указанное количество секунд (но может произойти и раньше).

Основное назначение — вызов renpy.restart_interaction(), если значения get_selected или get_sensitive должны измениться.

Принимает один аргумент:

st

Количество секунд с момента первого показа экрана или отображаемого объекта, с которым связано это действие.

unhovered(self)

Когда действие передано параметру hovered кнопки (или аналогичного объекта), этот метод вызывается при потере объектом фокуса.

alt

Текст для синтезатора речи, используемый для кнопок с этим действием, если у кнопки не задано свойство alt. Может быть строкой в классе, конструкторе или свойством Python (@property), возвращающим строку.

Для запуска действия из кода Python используйте renpy.run().

renpy.is_selected(action)

Возвращает True, если указанное действие или список действий находится в выбранном состоянии (selected), и False в противном случае.

renpy.is_sensitive(action)

Возвращает True, если указанное действие или список действий чувствителен к нажатию (sensitive), и False в противном случае.

renpy.run(action)

Запускает действие или список действий. Одиночное действие вызывается без аргументов, список действий выполняется по порядку, а None игнорируется.

Возвращает результат последнего действия, вернувшего непустое значение.

Значения полос (BarValues)

При создании bar, vbar или hotbar объект BarValue может быть передан свойству value. Методы объекта BarValue вызываются для получения регулятора (adjustment) и стилей.

class BarValue

Для определения нового значения полосы создайте класс-наследник и переопределите нужные методы.

get_adjustment(self)

Этот метод вызывается для получения объекта регулятора для полосы. Он должен создать регулятор с помощью ui.adjustment() и вернуть созданный объект.

Обязательно должен быть переопределен, иначе будет вызвано исключение NotImplementedError.

get_style(self)

Используется для определения стиля полос с этим значением. Должен возвращать кортеж из двух имен стилей или объектов стиля: первый используется для bar, а второй — для vbar.

По умолчанию ("bar", "vbar").

get_tooltip(self)

Возвращает подсказку по умолчанию для этой полосы. По умолчанию возвращает None.

replaces(self, other)

Вызывается, когда один BarValue заменяет другой (например, при обновлении экрана). Может использоваться для переноса состояния из старого значения. Вызывается до get_adjustment.

Обратите внимание, что other не обязательно того же типа, что и self.

periodic(self, st)

Вызывается один раз в начале каждого взаимодействия. Если возвращает число секунд, будет вызван снова не позже, чем через это время. Вызывается после get_adjustment.

Может использоваться для плавного обновления значения полосы во времени, подобно AnimatedValue().

alt

Текст для синтезатора речи для полос с этим BarValue (если у полосы не задано alt).

Значения ввода (InputValue)

При создании поля ввода (input) объект InputValue может быть передан свойству value. Методы InputValue вызываются для получения и установки текста, проверки доступности редактирования и обработки нажатия клавиши Enter.

class InputValue

Для создания нового значения ввода наследуйте от этого класса, переопределите методы и задайте значение поля default.

editable

Если False, полностью отключает редактирование поля ввода.

default

Если True, поле ввода активно для редактирования по умолчанию (получает каретку при показе экрана).

get_text(self)

Возвращает текст поля ввода по умолчанию. Обязателен к реализации.

set_text(self, s)

Вызывается при изменении текста поля ввода, принимая новый текст. Обязателен к реализации.

enter(self)

Вызывается при нажатии клавиши Enter пользователем. Если возвращает значение, отличное от None, это значение возвращается из взаимодействия. Может вызывать renpy.IgnoreEvent для игнорирования нажатия.

Следующие действия доступны как методы InputValue:

Enable()

Возвращает действие, включающее редактирование текста в данном поле ввода.

Disable()

Возвращает действие, отключающее редактирование текста.

Toggle()

Возвращает действие, переключающее режим редактирования текста.

Пользовательские операторы языка экранов

Ren'Py поддерживает создание пользовательских операторов языка экранов. Созданные разработчиком операторы представляют собой обертки вокруг оператора use. Позиционные аргументы остаются позиционными, свойства становятся именованными аргументами, а если оператор принимает блок строк, то его принимает и оператор use. Например, пользовательский оператор:

titledwindow "Окно теста":
    icon "icon.png"

    text "Это тест."

превращается в:

use titledwindow("Окно теста", icon="icon.png"):
    text "Это тест."

Пользовательские операторы языка экранов должны регистрироваться в блоке python early. Кроме того, файл с регистрацией должен загружаться раньше любого файла, использующего этот оператор. Поскольку Ren'Py загружает файлы в порядке сортировки Unicode их путей, имя файла с регистрацией обычно предваряют цифрами 01 (например, 01custom.rpy).

Пользовательские операторы регистрируются с помощью функции renpy.register_sl_statement:

class renpy.register_sl_displayable(name, displayable, style, nchildren=0, scope=False, *, replaces=False, default_keywords={}, default_properties=True, unique=False)

Регистрирует оператор языка экранов, создающий отображаемый объект.

name

Имя оператора языка экранов (строка, ключевое слово Ren'Py). Это слово используется для объявления нового оператора.

displayable

Функция, которая при вызове возвращает объект Displayable. Все позиционные аргументы, свойства и свойства стиля передаются как аргументы этой функции.

Должна возвращать Displayable. Если она возвращает составной объект, атрибут _main самого внешнего объекта должен указывать на «основной» объект, в который добавляются дочерние элементы.

style

Базовое имя стиля этого отображаемого объекта. Если свойство style не указано, к нему добавляется префикс стиля. Вычисленный стиль передается в функцию displayable как именованный аргумент style.

nchildren

Количество дочерних элементов:

0

Не принимает дочерних элементов.

1

Принимает 1 дочерний элемент. Если передано несколько, они оборачиваются в Fixed.

"many"

Принимает любое количество дочерних элементов (ноль или более).

unique

Следует установить в True, если функция возвращает объект, на который нет других ссылок.

Именованные аргументы:

replaces

Если True, и объект заменяет предыдущий, старый объект передается параметром новому.

default_keywords

Словарь аргументов по умолчанию, передаваемых отображаемому объекту.

default_properties

Если True, свойства интерфейса и позиционирования добавляются по умолчанию.

Возвращает объект, к которому можно добавлять позиционные аргументы и свойства с помощью вызова следующих методов. Каждый из этих методов возвращает сам объект, позволяя выстраивать цепочки вызовов.

add_positional(name)

Добавляет позиционный аргумент с именем name.

add_property(name)

Добавляет свойство с именем name. Свойства передаются как именованные аргументы.

add_style_property(name)

Добавляет семейство свойств стиля, оканчивающихся на name и снабженных различными префиксами стилей (например, при передаче "size" создаются size, idle_size, hover_size и т. д.).

add_prefix_style_property(prefix, name)

Добавляет семейство свойств стиля с префиксом prefix, префиксом состояния стиля и именем name (например, при префиксе text_ и имени size создаются text_size, text_idle_size и т. д.).

add_property_group(group, prefix='')

Добавляет группу свойств с префиксом prefix. group может быть одной из строк:

  • "bar"

  • "box"

  • "button"

  • "position"

  • "text"

  • "window"

Они соответствуют группам свойств из Свойства стилей. Также может быть "ui", в каковом случае добавляет общие свойства UI.

copy_positionals(name)

Копирует позиционные аргументы, которые могут передаваться оператору экрана name.

copy_keywords(name)

Копирует все стили и именованные аргументы, доступные оператору экрана name.

copy_properties(name)

Копирует все стили и позиционные/именованные аргументы оператора экрана name.

class renpy.register_sl_statement(name, children='many', screen=None)

Регистрирует пользовательский оператор языка экранов в Ren'Py.

name

Имя пользовательского оператора (одно слово).

children

Количество дочерних элементов: 0, 1 или "many" (ноль или более).

screen

Используемый экран. Если не указано, по умолчанию совпадает с name.

Возвращает объект, поддерживающий те же методы .add_, что и объект, возвращаемый функцией renpy.register_sl_displayable.

В качестве примера пользовательского оператора рассмотрим реализацию оператора titledwindow, приведенного выше. Сначала оператор регистрируется в блоке python early:

python early:
    renpy.register_sl_statement("titledwindow", children=1).add_positional("title").add_property("icon").add_property("pos")

Затем мы определяем экран, реализующий пользовательский оператор (экран может быть в любом файле):

screen titledwindow(title, icon=None, pos=(0, 0)):
    drag:
        pos pos

        frame:
            background "#00000080"

            has vbox

            hbox:
                if icon is not None:
                    add icon

                text title

            null height 15

            transclude

При использовании больших групп свойств (через add_property_group) имеет смысл использовать синтаксис **properties со свойством properties. Например:

screen titledwindow(title, icon=None, **properties):
    frame:
        # Если background не передан в properties, используется значение по умолчанию.
        background "#00000080"

        properties properties

        has vbox

        hbox:
            if icon is not None:
                add icon

            text title

        null height 15

        transclude

Пользовательские операторы языка экранов поддерживают предложение as, принимающее имя переменной. Если оно присутствует, этой переменной будет присвоено значение main из области видимости экрана.
