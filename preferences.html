Переменные настроек

Переменные настроек хранят значения параметров конфигурации Ren'Py. В то время как значение настройки обычно изменяется во время выполнения игры с помощью действия Preference(), переменные настроек следует использовать вместе с оператором default для задания значения настройки по умолчанию.

Например:

default preferences.text_cps = 40

устанавливает скорость текста по умолчанию на 40 знаков в секунду. Оператор default устанавливает значение настройки только в том случае, если значение по умолчанию изменилось с момента первоначальной установки настройки. Например, если игрок изменит скорость на 50, она останется равной 50 при последующих запусках игры. Если в обновлении значение по умолчанию будет изменено на 42, настройка игрока будет сброшена на 42 (после чего игрок сможет изменить её снова).

preferences.afm_after_click = False

Если True, режим авточтения продолжится после клика мыши. Если False, клик завершит режим авточтения. Эквивалент настройки «авточтение после клика» («auto-forward after click»).

preferences.afm_enable = False

Если True, режим авточтения включён, в противном случае — False. Эквивалент настройки «время авточтения» («auto-forward time»).

preferences.afm_time = 15

Время ожидания в режиме авточтения. Чем больше число, тем медленнее переход, хотя перевод в реальное время является комплексным, так как скорость учитывает длину строки текста. Эквивалент настройки «авточтение» («auto-forward»).

preferences.desktop_rollback_side = "disable"

На десктопных платформах: нажатия или клики по этой стороне окна вызывают откат назад. Одно из значений: "left", "right" или "disable". Это эквивалент настройки «сторона отката» («rollback side») на десктопных платформах.

preferences.mobile_rollback_side = "disable"

На мобильных платформах: касания или клики по этой стороне экрана вызывают откат назад. Одно из значений: "left", "right" или "disable". Это эквивалент настройки «сторона отката» («rollback side») на мобильных платформах.

preferences.language = None

Язык, выбранный игроком для запуска игры. Имеет значение None для языка по умолчанию или строку с именем языка, на который переведена игра.

Может использоваться для задания языка по умолчанию, а также читаться для определения текущего языка. Для смены языка можно использовать действие Language().

Подробнее см. Перевод.

preferences.emphasize_audio = False

Если True, Ren'Py будет выделять аудиоканалы, указанные в config.emphasize_audio_channels, снижая громкость других каналов (например, снижая громкость музыки во время звучания голоса). Если False, выделение не применяется.

preferences.fullscreen = False

Имеет значение True, когда Ren'Py находится в полноэкранном режиме, и False, когда он работает в окне. Эквивалент настройки «режим экрана» («display»).

preferences.gl_framerate = None

Либо целое число, либо None. Если не None, то задаёт целевую частоту кадров, которую Ren'Py пытается поддерживать. Если задано низкое значение (например, 30) на мониторе с высокой частотой обновления (скажем, 60 кадров в секунду), Ren'Py будет отрисовывать только каждый второй кадр.

Если None, Ren'Py попытается выполнять отрисовку с максимальной частотой монитора.

preferences.gl_powersave = True

Определяет, как часто Ren'Py будет перерисовывать статичный экран. Если True, Ren'Py будет перерисовывать экран всего 5 раз в секунду. Если False, он всегда будет рисовать с максимально возможной частотой кадров.

preferences.gl_tearing = False

Определяет, является ли разрыв кадра (True, tearing) или пропуск кадров (False, frameskip) предпочтительным поведением, когда игра не успевает за целевой частотой кадров.

preferences.mouse_move = True

Если True, курсор мыши автоматически перемещается к выбранной кнопке. Если False, перемещение не происходит. Эквивалент настройки «автоматическое перемещение» («automatic move»).

preferences.show_empty_window = True

Если True, операторы window show и window auto функционируют. Если False, эти операторы отключены. Эквивалент настройки «показывать пустое окно» («show empty window»).

preferences.skip_after_choices = False

Если True, пропуск текста возобновляется после совершения выбора. Если False, выбор остановит пропуск. Эквивалент настройки «после выборов» («after choices»).

preferences.skip_unseen = False

Если True, Ren'Py будет пропускать любой текст. Если False, Ren'Py будет пропускать только текст, уже прочитанный игроком в любых предыдущих сессиях. Эквивалент настройки «пропуск» («skip»).

preferences.text_cps = 0

Скорость отображения текста. 0 означает мгновенное появление, иначе это количество символов в секунду. Эквивалент настройки «скорость текста» («text speed»).

preferences.transitions = 2

Определяет, какие переходы должны отображаться. Значение 2 показывает все переходы, 0 — отключает показ переходов (значение 1 зарезервировано). Эквивалент настройки «переходы» («transitions»).

preferences.video_image_fallback = False

Если True, вместо видеоспрайтов отображаются статические изображения. Если False, видеоспрайты отображаются в обычном режиме. Эквивалент (инвертированный) настройки «видеоспрайты» («video sprites»).

preferences.voice_sustain = False

Если True, голос продолжает воспроизводиться до конца реплики или пока не начнётся следующая реплика с озвучкой. Если False, воспроизведение голоса прекращается при переходе к следующей реплике диалога. Эквивалент настройки «сохранять голос» («voice sustain»).

preferences.wait_voice = True

Если True, режим авточтения будет ожидать окончания воспроизведения голосовых файлов и синтеза речи (self-voicing) перед переходом дальше. Если False, ожидание не производится. Эквивалент настройки «ждать голос» («wait for voice»).

preferences.system_cursor = False

Если True, принудительно используется системный курсор мыши, игнорируя значения config.mouse и config.mouse_displayable. Если False — нет. Эквивалент настройки «системный курсор» («system cursor»).

preferences.audio_when_minimized = True

Если False, аудиоканалы приостанавливаются при сворачивании окна и возобновляются при его восстановлении. Если True, состояние окна не влияет на звук. Эквивалент настройки «звук при сворачивании» («audio when minimized»).

preferences.audio_when_unfocused = True

Если False, аудиоканалы приостанавливаются при потере клавиатурного фокуса окном и возобновляются при возвращении фокуса. Если True, потеря фокуса не влияет на звук. Эквивалент настройки «звук без фокуса» («audio when unfocused»).

preferences.web_cache_preload = False

Если True, файлы игры предварительно загружаются в кэш веб-браузера, позволяя играть в игру офлайн. Если False, файлы не кэшируются заранее, и для игры требуется постоянное интернет-подключение. Эквивалент настройки «предзагрузка веб-кэша» («web cache preload»).

preferences.voice_after_game_menu = False

Если True, голос продолжит звучать после открытия игрового меню. Если False, воспроизведение голоса остановится при показе игрового меню. Эквивалент настройки «голос после меню» («voice after menu»).

preferences.restore_window_position = True

Если True, Ren'Py попытается восстановить положение окна при перезапуске игры. Если False, положение окна восстанавливаться не будет. Эквивалент настройки «восстанавливать положение окна» («restore window position»).

preferences.force_mono = False

Если True, Ren'Py будет микшировать стереозвук в моно перед воспроизведением. Если False, стереозвук воспроизводится стандартно.

preferences.tts_voice = None

Имя голоса для автоозвучивания (self-voicing). Если None, используется голос по умолчанию. Эквивалент настройки «голос озвучивания» («self voicing voice»). Точный набор доступных голосов зависит от операционной системы и компьютера. Для текущего компьютера список возможных вариантов возвращает функция renpy.get_tts_voices().

preferences.tts_speed = 1.0

Скорость автоозвучивания (self-voicing). Число от 1.0 до 3.0, где 1.0 — самая медленная скорость, а 3.0 — самая быстрая. Эквивалент настройки «скорость озвучивания» («self voicing speed»).

Значения микшеров по умолчанию

Эти переменные могут быть заданы только с помощью оператора default.

preferences.volume.main = 1.0

Громкость по умолчанию для главного микшера, которая применяется ко всем каналам в дополнение к индивидуальному микшеру канала. Должна быть числом от 0.0 до 1.0, где 1.0 означает полную громкость.

preferences.volume.music = 1.0

Громкость по умолчанию для музыкального микшера, который используется для каналов music и movie. Должна быть числом от 0.0 до 1.0, где 1.0 означает полную громкость.

preferences.volume.sfx = 1.0

Громкость по умолчанию для микшера звуковых эффектов, который используется для каналов sound и audio. Должна быть числом от 0.0 до 1.0, где 1.0 означает полную громкость.

preferences.volume.voice = 1.0

Громкость по умолчанию для микшера голоса, который используется для канала voice (и, соответственно, оператора voice, автоозвучки и т. д.). Должна быть числом от 0.0 до 1.0, где 1.0 означает полную громкость.

Если используются каналы, зарегистрированные с помощью renpy.music.register_channel(), их громкость по умолчанию можно настроить с помощью синтаксиса preferences.volume.микшер, где микшер — имя зарегистрированного микшера.

Пример установки громкости музыкального микшера на 75% и звуковых эффектов на 50%:

default preferences.volume.music = 0.75
default preferences.volume.sfx = 0.5

Функции микшеров

Подробнее о микшерах см. раздел Громкость.

preferences.set_mixer(mixer, volume)

Устанавливает громкость volume для микшера mixer.

mixer

Строка с именем микшера. По умолчанию доступны микшеры "main", "music", "sfx" и "voice" ("main" является специальным мастер-микшером).

volume

Число от 0.0 до 1.0, где 0.0 соответствует -40 дБ (по мощности), а 1.0 — 0 дБ (по мощности).

preferences.get_mixer(mixer)

Возвращает текущую громкость для микшера mixer. Если звук микшера заглушён, возвращает 0.0. Возвращает число от 0.0 до 1.0, где 0.0 соответствует -40 дБ (по мощности), а 1.0 — 0 дБ (по мощности).

preferences.set_mute(mixer, mute)

Устанавливает заглушение звука для mixer. Если mute равно True, звук микшера отключается. Если mute равно False, громкость микшера восстанавливается до значения, предшествовавшего заглушению.

preferences.get_mute(mixer)

Возвращает состояние заглушения звука для микшера mixer.
