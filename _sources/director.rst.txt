.. _interactive-director:

==============================================
Интерактивный режиссёр (Interactive Director)
==============================================

Интерактивный режиссёр (Interactive Director) — это встроенный инструмент, позволяющий
редактировать сценарий игры прямо внутри запущенного окна Ren'Py с живым предпросмотром
вносимых изменений. Режиссёр не заменяет полнофункциональный текстовый редактор, который
по-прежнему необходим для написания диалогов, ветвлений выборов и сложной игровой логики.

Его цель — помочь в режиссуре визуальной новеллы, автоматизируя добавление и корректировку:

* Операторов отображения графики (:ref:`scene <scene-statement>`, :ref:`show <show-statement>` и :ref:`hide <hide-statement>`).
* Операторов визуальных переходов (:ref:`with <with-statement>`).
* Операторов звука и озвучки (``play``, ``queue``, ``stop`` и ``voice``).


Использование режиссёра
-----------------------

Открыть интерактивный режиссёр можно в любой момент после запуска игры, нажав клавишу
:kbd:`D` (без Shift) на клавиатуре. При первом запуске режиссёра в текущей сессии
Ren'Py автоматически перезагрузит проект для загрузки метаданных скрипта.

На основном экране режиссёра отображается список строк, выполненных перед текущим
моментом игры. Кликните мышью вне окна списка, чтобы продвинуться вперёд по сценарию,
или прокрутите колёсико мыши назад за пределами окна, чтобы совершить откат.
Нажмите значок :guilabel:`+` между строками, чтобы вставить новую строку, или значок
:guilabel:`✎` перед строкой для её изменения.

В окне редактирования строки можно выбрать тип оператора и настроить его параметры.
Нажмите :guilabel:`Add` (Добавить) для добавления новой строки, :guilabel:`Change` (Изменить)
для сохранения изменений существующей, :guilabel:`Cancel` (Отмена) для отмены редактирования
или :guilabel:`Remove` (Удалить) для удаления строки из скрипта.

По завершении работы нажмите :guilabel:`Done` (Готово).


Переменные
----------

В пространстве имён ``director`` определён ряд переменных, управляющих работой режиссёра.
Их можно задавать оператором :ref:`define <define-statement>` или изменять через код Python.


Scene, Show и Hide
^^^^^^^^^^^^^^^^^^

.. var:: director.tag_blacklist = { "black", "text", "vtext" }

    Чёрный список тегов изображений, которые не будут предлагаться для операторов
    show, scene или hide.

.. var:: director.scene_tags = { "bg" }

    Множество тегов, которые предлагаются для оператора scene и скрываются
    из списка оператора show.

.. var:: director.show_tags = set()

    Если множество не пусто, для оператора show будут предлагаться только теги,
    входящие в это множество.

.. var:: director.transforms = [ "left", "center", "right" ]

    Список трансформаций, доступных в интерфейсе редактора. Помимо перечисленных,
    любая трансформация, объявленная разработчиком в коде игры через оператор
    :ref:`transform <transform-statement>`, автоматически добавляется в этот список
    с последующей сортировкой.


With
^^^^

.. var:: director.transitions = [ "dissolve", "pixellate" ]

    Список переходов, доступных для выбора с оператором with. Поскольку переходы
    не могут определяться автоматически, их необходимо регистрировать в этом списке вручную.


Play, Queue, Stop и Voice
^^^^^^^^^^^^^^^^^^^^^^^^^

.. var:: director.audio_channels = [ "music", "sound", "audio" ]

    Список имён аудиоканалов, доступных для операторов play, queue и stop.

.. var:: director.voice_channel = "voice"

    Имя аудиоканала, используемого оператором voice.

.. var:: director.audio_patterns = [ "*.opus", "*.ogg", "*.mp3" ]

    Список файловых масок по умолчанию для поиска доступных аудиофайлов каналов.

.. var:: director.audio_channel_patterns = { }

    Словарь, связывающий имя канала со списком масок аудиофайлов, доступных конкретно
    в этом канале. Например, настройка вида
    ``{ 'sound' : [ 'sound/*.opus' ], 'music' : [ 'music/*.opus' ] }``
    задаёт раздельные каталоги поиска для каналов музыки и звуковых эффектов.


Доступ
^^^^^^

.. var:: director.button = True

    Если True, на экране отображается вспомогательная кнопка для открытия окна режиссёра.
    Если False, игра может реализовать собственный доступ с помощью действия :class:`director.Start`.


Отступы строк
^^^^^^^^^^^^^

.. var:: director.spacing = 1

    Количество пустых строк между строкой режиссёра (scene, show, hide, with, play, queue, voice)
    и обычной строкой сценария (или наоборот). Допустимы значения 0 или 1 строка.

.. var:: director.director_spacing = 0

    Количество пустых строк между двумя последовательными строками режиссёра.

.. var:: director.other_spacing = 0

    Количество пустых строк между двумя последовательными строками другого типа.


Область прокрутки (Viewport)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. var:: director.viewport_height = 280

    Максимальная высота областей прокрутки (viewports), используемых в окнах режиссёра.


Функции преобразования имён аудиофайлов
---------------------------------------

Существует ряд функций преобразования имён аудиофайлов, позволяющих транслировать
имена файлов на диске в имена, записываемые в исходном коде Python. Это полезно
для согласования с механизмами сопоставления путей в Ren'Py. Например, при настройке::

    define config.voice_filename_format = "v/{filename}.ogg"

можно определить функции в пространстве имён director::

    init python in director:

        def audio_code_to_filename(channel, code):
            """
            Преобразует имя аудиофайла из формата в коде в имя файла на диске.
            """

            if channel == "voice":
                return "v/" + code + ".ogg"

            return code

        def audio_filename_to_code(channel, fn):
            """
            Преобразует имя файла на диске в имя, записываемое в код сценария.
            """

            if channel == "voice":
                return fn.replace("v/", "").replace(".ogg", "")

            return fn

        def audio_filename_to_display(channel, fn):
            """
            Преобразует имя файла на диске для красивого отображения разработчику в интерфейсе.
            """

            if channel == "voice":
                return fn.replace("v/", "").replace(".ogg", "")

            return fn
