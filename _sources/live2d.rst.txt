.. _live2d:

=============
Live2D Cubism
=============

`Live2D Cubism <https://www.live2d.com/en/>`_ — это система, позволяющая анимировать двухмерные
изображения, например спрайты персонажей в визуальной новелле. Такие изображения отрисовываются
в виде набора слоёв: например, слой для зрачков и радужки, слой для белков глаз, слой для бровей
и так далее.

Программное обеспечение Live2D позволяет привязать полигональные сетки (меши) к каждому из этих слоёв,
а затем задать деформацию мешей (изменение их формы) при регулировке параметров. В программе Live2D
можно создавать файлы движений (motion), определяющие изменение параметров во времени, и файлы выражений
(expression), определяющие эмоции и мимику.

Интеграция Live2D в Ren'Py заключается в загрузке созданных файлов Live2D и использовании их
для определения анимаций в Ren'Py. Ren'Py обрабатывает движения и выражения, рассчитывая текущие
значения параметров, и передаёт их в Cubism SDK for Native. SDK возвращает список мешей для отображения,
Ren'Py выполняет их рендеринг, и на экране появляется живой персонаж Live2D.

Ren'Py поддерживает анимации Live2D в форматах Cubism 3, 4 и 5.
Поддерживается воспроизведение выражений и движений.

.. warning::

    Установка Live2D на платформе iOS требует ручного копирования статических библиотек
    в проект iOS.

Установка Live2D
----------------

Перед началом работы с Live2D необходимо скачать и установить Cubism SDK for Native
с `официального сайта Live2D <https://www.live2d.com/en/download/cubism-sdk/download-native/>`_.
Обратите внимание: если доход вашей компании превышает установленный порог, для использования Live2D
может потребоваться приобретение коммерческой лицензии.

После загрузки архива Live2D его можно установить прямо из лаунчера Ren'Py: перейдите в «Настройки»,
затем нажмите «Установить библиотеки». Поместите файл :file:`CubismSdkForNative-5-r.1.zip` в каталог
Ren'Py SDK (его можно открыть кнопкой в правом нижнем углу экрана установки библиотек). Затем нажмите
«Установить Live2D Cubism SDK for Native». Через некоторое время Live2D будет установлен.

Определение анимаций
--------------------

Анимации Live2D определяются с помощью отображаемого объекта Live2D и оператора image:

.. function:: Live2D(filename, zoom=None, top=0.0, base=1.0, height=1.0, aliases=None, loop=False, fade=None, seamless=None, attribute_function=None, attribute_filter=None, update_function=None, default_fade=1.0, old_beziers=None, deduplication_key=None, **properties)

    Этот отображаемый объект выводит анимацию Live2D.

    `filename`
        Файл model3.json, определяющий анимацию Live2D, либо каталог, содержащий эту анимацию.
        В последнем случае берётся имя каталога с добавлением суффикса .model3.json.

        Например, пути "Resources/Hiyori" и "Resources/Hiyori/Hiyori.model3.json" эквивалентны.

    `zoom`
        Если не None, коэффициент масштабирования. Имеет приоритет над `top` и `base`.

    `top`
        Верхняя граница изображения для расчёта размера (доля от высоты, где 0.0 — верх, 1.0 — низ).

    `base`
        Нижняя граница изображения для расчёта размера (доля от высоты, где 0.0 — верх, 1.0 — низ).
        Также становится значением yanchor по умолчанию.

    `height`
        Высота, к которой масштабируется изображение, выраженная как доля виртуальной высоты экрана.

    `loop`
        True, если финальное движение должно зацикливаться, иначе False.

    `aliases`
        Словарь, сопоставляющий пользовательские псевдонимы с именами движений или выражений.

    `fade`
        True, если угасание/перетекание движений (motion fading) включено; False, если выключено;
        и None для использования значения переменной :var:`_live2d_fade`.

    `nonexclusive`
        Если не None, список имён неисключающих выражений лица. По умолчанию выражения являются
        взаимоисключающими (одновременно отображается только одно). Неисключающие выражения могут
        показываться в любом количестве в дополнение к одному эксклюзивному выражению.

    `seamless`
        Определяет, используется ли бесшовное зацикливание (устраняющее переход между повторами одного
        и того же движения). Может быть True (всегда включено), False (выключено) или набором движений,
        к которым применяется бесшовное зацикливание.

    `default_fade`
        Время перехода по умолчанию при перетекании в движение или выражение и обратно. По умолчанию
        равно 1.0 секунде (согласно спецификации Live2D). Установите 0.0, если плавный переход должен
        происходить только по явному запросу.

    `attribute_function`
        Функция, принимающая кортеж атрибутов и возвращающая второй кортеж атрибутов. Используется
        для замены атрибутов исключительно в целях отображения. Должна гарантировать, что передано
        не более одного эксклюзивного выражения.

    `attribute_filter`
        Функция, принимающая кортеж атрибутов и возвращающая отфильтрованный кортеж. Обычно используется
        для разрешения конфликтов между неисключающими атрибутами. Атрибуты упорядочены так, что более
        свежие идут первыми (при конфликте побеждает первый).

    `update_function`
        Функция, вызываемая при рендеринге анимации после обновления параметров текущими движениями
        и выражениями. Функция принимает два аргумента:

        * Объект Live2D.
        * Время отображения (timebase) в секундах.

        Используется для динамического изменения параметров через метод `blend_parameter`.
        Должна возвращать задержку в секундах до следующего вызова или None для повторного вызова
        в начале следующего взаимодействия.

    `old_beziers`
        Если True, используется старое поведение кривых Безье со сглаживанием easing. Если False,
        используется интерпретация Кардано. Если None, берётся значение :var:`config.live2d_old_beziers`.

    `deduplication_key`
        Ключ дедупликации отображаемых объектов Live2D с одинаковым `filename`, но разными настройками.

    Различие между `attribute_function` и `attribute_filter`: первая заменяет комбинацию атрибутов
    (например, наличие двух атрибутов заменяется третьим), а второй разрешает конфликты
    (выбирает один допустимый атрибут из взаимоисключающей группы).

    Только аргумент `filename` передаётся позиционно, все остальные аргументы — именованные.

    Значения параметров `alias`, `fade`, `nonexclusive`, `seamless`, `default_fade`,
    `attribute_function`, `attribute_filter` и `update_function` разделяются между всеми объектами
    Live2D с одинаковым `filename`.

    .. method:: blend_parameter(name, blend, value, weight=1.0)

        Смешивает текущее значение параметра с новым значением `value`. Работает только внутри `update_function`.

        `name`
            Строка с именем изменяемого параметра.

        `blend`
            Тип смешивания: "Add", "Multiply" или "Overwrite".

        `value`
            Число с плавающей запятой — примешиваемое значение.

        `weight`
            Вес от 0.0 до 1.0, с которым новое значение влияет на текущее.

    .. method:: blend_opacity(name, blend, value, weight=1.0)

        Смешивает текущее значение непрозрачности части модели с `value`. Работает только внутри `update_function`.

        `name`
            Имя изменяемой части модели.

        `blend`
            Тип смешивания: "Add", "Multiply" или "Overwrite".

        `value`
            Значение непрозрачности с плавающей запятой.

        `weight`
            Вес от 0.0 до 1.0.

.. var:: config.live2d_old_beziers = False

    Если True, Live2D по умолчанию использует старое поведение кривых Безье (easing).
    Если False, используется интерпретация Безье по формуле Кардано.

Переменная конфигурации для отладки загружаемых движений и выражений:

.. var:: config.log_live2d_loading = False

    Если True, загруженные пути, движения и выражения записываются в файл log.txt при запуске.

Отображаемые объекты Live2D присваиваются операторам image::

    image hiyori = Live2D("Resources/Hiyori", base=.6)

Также можно определять атрибуты, что особенно удобно для задания различных масштабов и планов::

    image hiyori close = Live2D("Resources/Hiyori", base=.6)
    image hiyori far = Live2D("Resources/Hiyori", base=.9)

Имейте в виду: если оборудование пользователя не поддерживает Live2D, одиночный вызов Live2D()
может помешать запуску всей игры. Чтобы проект работал даже без поддержки Live2D, используйте обёртку::

    init python:
        def MyLive2D(*args, fallback=Placeholder(text="no live2d"), **kwargs):
            if renpy.has_live2d():
                return Live2D(*args, **kwargs)
            else:
                return fallback

    image kobayashi = MyLive2D(...)
    image eileen moving = MyLive2D(..., fallback="eileen happy")

Использование анимаций
----------------------

Стандартный способ отображения Live2D — оператор show. В дополнение к атрибутам оператора image
можно указывать имена выражений и движений::

    show natori exp_00 mtn_01
    show hiyori m10
    show hiyori m10 m01

Здесь используются стандартные имена из примеров Cubism SDK. Имена берутся из файлов Live2D,
переводятся в нижний регистр, а префикс, совпадающий с именем файла model3.json с последующим
подчёркиванием, удаляется (например, "Hiyori_Motion01" превращается в "motion01").

Одновременно может использоваться не более одного эксклюзивного выражения и любое количество
неисключающих выражений и движений. Если указано несколько движений, они воспроизводятся последовательно,
а последнее движение зацикливается при loop=True. Это позволяет сначала проиграть разовое действие,
а затем перейти к фоновой анимации ожидания (idle).

Существуют два специальных служебных атрибута: ``null`` и ``still``. Атрибут ``null`` сбрасывает
эксклюзивное выражение лица, возвращая стандартное выражение персонажа. Атрибут ``still``
останавливает все движения.

Неисключающие выражения сохраняются до тех пор, пока не будут сняты отрицанием атрибута::

    show hiyori -wave

Масштабирование
---------------

Многие модели Live2D создаются в высоком внутреннем разрешении. Для настройки размера Ren'Py
предоставляет два способа.

Первый способ — аргумент `zoom`. Он напрямую задаёт коэффициент масштабирования модели.
При использовании zoom остальные параметры масштабирования игнорируются.

Второй способ — аргументы `top`, `base` и `height`. Параметры top и base задают верхнюю
и нижнюю границы модели (0.0 — верх, 1.0 — низ изображения):

* Изображение масштабируется так, чтобы область между `top` и `base` занимала высоту `height`
  (доля от высоты экрана).
* Точка привязки выравнивается так, чтобы линия `base` совпала с нижним краем экрана.

Практический алгоритм настройки: сначала отрегулируйте параметр `base`, чтобы нужная часть тела
персонажа стояла на нижней границе экрана. Затем:

* Если персонаж слишком велик, уменьшайте `height`.
* Если персонаж слишком мал, увеличивайте `top`, чтобы уменьшить пустое пространство сверху.

Перетекание движений (Motion Fading)
------------------------------------

В отличие от стандартной резкой смены кадров, Live2D поддерживает плавную интерполяцию параметров
между старым и новым движениями (motion fading). Персонаж плавно переводит руки и тело в новую позу,
а не растворяется через Dissolve.

Перетекание контролируется аргументом `fade`. Если True — перетекание включено, если False — движения
меняются мгновенно. Если None, используется переменная ``_live2d_fade``:

.. var:: _live2d_fade = True

    Если True, анимации Live2D используют плавное перетекание движений. Если False, движения
    сменяются скачком.

Псевдонимы (Aliasing)
---------------------

Параметр `alias` позволяет задавать собственные удобные имена для автоматически определённых движений::

    image hiyori = Live2D("Resources/Hiyori", base=.6, aliases={"idle" : "m01"})

Это позволяет писать::

    show hiyori idle

Вместо::

    show hiyori m01

Зацикливание и предсказание изображений
---------------------------------------

Ren'Py может зацикливать финальное движение при установке аргумента `loop=True`. При циклической
анимации важно предусмотреть паузы длительностью более 0.2 секунды, которые движок сможет использовать
для ресурсоёмкого предсказания изображений.
