Raspberry Pi
============

Ren'Py имеет ограниченную поддержку работы на микрокомпьютерах Raspberry Pi.
Работоспособность подтверждена на модели Raspberry Pi 3B, но запуск возможен
и на других моделях.

Важно понимать, что Raspberry Pi представляет собой весьма ограниченную аппаратную платформу
даже по сравнению со смартфонами на Android и iOS. В связи с этим далеко не каждая игра на Ren'Py
будет работать хорошо — или вообще запустится — на Raspberry Pi. Более того, превышение
доступного объёма оперативной памяти (RAM) приведёт к аварийному завершению работы Ren'Py.

При правильной настройке Raspberry Pi движок Ren'Py работает с использованием аппаратного
ускорения OpenGL ES. Это влечёт за собой те же ограничения, что и на мобильных платформах
Android и iOS, в частности невозможность работы свойства :propref:`focus_mask`.


Настройка Raspberry Pi
----------------------

Перед запуском Ren'Py необходимо настроить Raspberry Pi с помощью утилиты raspi-config.
Требуемые параметры находятся в разделе дополнительных настроек (advanced options):

* Выделение памяти GPU (Memory Split): 256 МБ
* Разрешение экрана (Resolution): 1280x720 или меньше
* Видеодрайвер (GL Driver): GL (Fake KMS)

После изменения настроек перезагрузите Raspberry Pi.

Настройка Ren'Py
----------------

Для запуска на Raspberry Pi требуется пакет ARM Linux SDK. Эта версия Ren'Py включает
поддержку архитектуры ARM и доступна на странице загрузок Ren'Py 7.5 и более поздних версий.

После загрузки ARM-Linux SDK распакуйте архив tar и перейдите в созданный каталог.

Запуск игры
-----------

Поскольку Raspberry Pi сильно ограничен в ресурсах, мы рекомендуем не запускать лаунчер
Ren'Py. Вместо этого запускайте проект напрямую через скрипт :file:`renpy.sh` с помощью команды вида::

    ./renpy.sh /path/to/project

Этот же подход можно использовать для запуска игр Ren'Py, которые изначально не собирались
специально под Raspberry Pi.
