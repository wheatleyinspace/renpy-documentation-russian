.. _transforms:

=============
Трансформации
=============

Трансформации используются для преобразования одного :doc:`отображаемого объекта <displayables>`
в другой. Существует несколько видов трансформаций и различные способы их создания.
Встроенные трансформации служат для позиционирования изображений на экране, тогда как
пользовательские трансформации позволяют создавать сложные эффекты: движение, масштабирование,
вращение, а также комплексные манипуляции с цветом.

Краткое руководство
===================

Трансформации можно применять к изображениям через клаузу ``at`` операторов
:ref:`show <show-statement>` или ``scene``. Следующая команда применяет трансформацию
``right`` к изображению ``eileen happy``::

    show eileen happy at right

Можно применять несколько трансформаций, разделяя их запятыми. Они применяются слева направо::

    show eileen happy at halfsize, right

Простая трансформация ATL::

    transform slide_right:
        xalign 0.0
        linear 1.0 xalign 1.0

    label start:
        show eileen happy at slide_right
        pause

Вызов трансформаций через Python::

    label start:
        $ renpy.show("eileen happy", at_list=right)
        pause

Простая трансформация Python с использованием ``At()``::

    init python:
        def show_eileen_rotated():
            rotated = Transform(rotate=45)
            show_stmt = At("eileen happy", rotated)
            renpy.show("eileen", what=show_stmt)

    label start:
        $ show_eileen_rotated()
        pause


Встроенные трансформации
========================

Ren'Py поставляется с набором предустановленных трансформаций позиционирования. Ниже приведена
схема расположения объектов на экране при использовании каждой встроенной трансформации:

.. code-block:: none

                  +-----------------------------------------------------------+
                  | topleft, reset               top                 topright |
                  |                                                           |
                  |                                                           |
                  |                                                           |
                  |                                                           |
                  |                          truecenter                       |
                  |                                                           |
                  |                                                           |
                  |                                                           |
                  |                                                           |
    offscreenleft | left                   center, default              right | offscreenright
                  +-----------------------------------------------------------+

Трансформации :var:`offscreenleft` и :var:`offscreenright` размещают объекты за пределами
экрана слева и справа. Их можно использовать для анимации ухода с экрана (не забудьте затем
скрыть объект оператором hide, чтобы он не потреблял ресурсы).

Список встроенных трансформаций:

.. var:: center

    Центрирует объект по горизонтали и выравнивает по нижнему краю экрана.

.. var:: default

    Центрирует по горизонтали и выравнивает по низу экрана. Можно переопределить через
    :var:`config.default_transform` для изменения размещения изображений по умолчанию.

.. var:: left

    Выравнивает объект по левому нижнему углу экрана.

.. var:: offscreenleft

    Помещает объект за пределы экрана слева с выравниванием по нижнему краю.

.. var:: offscreenright

    Помещает объект за пределы экрана справа с выравниванием по нижнему краю.

.. var:: reset

    Сбрасывает свойства трансформации к значениям по умолчанию, удаляя ранее заданные параметры.

.. var:: right

    Выравнивает объект по правому нижнему углу экрана.

.. var:: top

    Центрирует объект по горизонтали и выравнивает по верхнему краю экрана.

.. var:: topleft

    Выравнивает объект по левому верхнему углу экрана.

.. var:: topright

    Выравнивает объект по правому верхнему углу экрана.

.. var:: truecenter

    Центрирует объект одновременно по горизонтали и по вертикали.


.. _atl:

ATL — язык анимации и трансформации (Animation and Transformation Language)
===========================================================================

Язык анимации и трансформации (ATL) — высокоуровневый декларативный язык Ren'Py для создания
анимаций, перемещения отображаемых объектов, настройки их положения, вращения и масштабирования.
Свойства могут плавно изменяться во времени и реагировать на события.

Объекты трансформаций ATL, создаваемые оператором :ref:`transform <transform-statement>`,
сами являются отображаемыми объектами: их можно передавать в экраны через элемент :ref:`sl-add`,
показывать через :ref:`show expression <show-expression-statement>` или функцию :func:`renpy.show`.


Операторы сценария Ren'Py
-------------------------

Существует три оператора Ren'Py, которые могут содержать блоки кода ATL.

.. _transform-statement:

Оператор Transform
~~~~~~~~~~~~~~~~~~

Оператор ``transform`` создает новую переиспользуемую трансформацию для анимации и
позиционирования объектов. Ее можно применять к изображениям в клаузе ``at`` операторов
:ref:`show <show-statement>` и ``scene``.

Трансформации объявляются как переменные в соответствующем :ref:`именованном хранилище <named-stores>`
(или хранилище по умолчанию) во время :ref:`фазы инициализации <init-phase>`.

**Синтаксис**

    Базовая форма::

        transform <имя_трансформации>:
            <блок_atl>

    С параметрами::

        transform <имя_трансформации>( <параметры> ):
            <блок_atl>

**Использование**

    .. table::
        :widths: auto

        ==================  =========  ===========
        Имя                 Тип        Описание
        ==================  =========  ===========
        имя_трансформации   слово      Имя трансформации (идентификатор Python, например ``my_transform`` или ``sprites.bounce``)
        параметры           --         (Необязательно) Параметры трансформации
        блок_atl            блок       Блок кода ATL, определяющий трансформацию
        ==================  =========  ===========

    Параметры работают аналогично параметрам функций Python.

    В настоящее время не поддерживаются:

    * Только позиционные параметры (с символом ``/``)
    * Обязательные именованные параметры (после ``*`` без значений по умолчанию)
    * ``*args``
    * ``**kwargs``

    .. note ::

        * Если у трансформации есть параметры без значений по умолчанию, им необходимо передать значения перед использованием трансформации.
        * См. также: :ref:`atl-partial`.

**Пример**

    ::

        transform left_to_right:
            xalign 0.
            linear 2 xalign 1.
            repeat

        transform ariana.left:
            xalign .3

        transform animated_ariana_disp(duration=1.0):
            "ariana"
            pause duration
            "ariana_reverse"
            pause duration
            repeat

        label start:
            show eileen happy at left_to_right
            pause
            show animated_ariana_disp
            pause

.. _atl-image-statement:

Оператор Image с блоком ATL
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Второй способ включения кода ATL — в составе оператора :ref:`image <image-statement>`.
Он связывает имя изображения с заданной трансформацией (обычно циклической анимацией).

**Синтаксис**

    ::

        image <имя_изображения>:
            <блок_atl>

**Использование**

    .. table::
        :widths: auto

        ================  =========  ===========
        Имя               Тип        Описание
        ================  =========  ===========
        имя_изображения   слова      Имя изображения
        блок_atl          блок       Блок кода ATL, определяющий анимацию
        ================  =========  ===========

**Пример**

    ::

        image animated_ariana_img:
            "ariana"
            pause 1.
            "ariana_reverse"
            pause 1.
            repeat


Операторы Scene и Show с блоком ATL
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Третий способ — указание блока ATL непосредственно после оператора :ref:`show <show-statement>`
или ``scene``. Это оборачивает показываемое изображение в созданную на лету анонимную трансформацию.

**Синтаксис**

    ::

        show <имя_изображения>:
            <блок_atl>

        scene <имя_изображения>:
            <блок_atl>

**Пример**

    ::

        show eileen happy:
            xalign 1.

        scene bg washington:
            zoom 2.


Синтаксис и операторы ATL
-------------------------

Операторы ATL могут быть однострочными либо составлять вложенные блоки. Операторы блока ATL
выполняются последовательно сверху вниз.

Если оператор ATL требует вычисления выражения, оно вычисляется в момент первого запуска
трансформации (при выполнении оператора show или при отображении экрана), а не при переходе
к конкретному вложенному оператору ATL.

Ниже описаны операторы ATL:

.. _atl-properties-statement:

Оператор задания свойств (Properties)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Устанавливает значения свойств трансформации.

**Синтаксис**

    ::

        <имя_свойства> <значение_свойства>

**Использование**

    .. table::
        :widths: auto

        ==================  ======  ===========
        Имя                 Тип     Описание
        ==================  ======  ===========
        имя_свойства        слово   Имя свойства трансформации (например, :tpref:`xalign`, :tpref:`alpha`...)
        значение_свойства   разный  Новое значение свойства
        ==================  ======  ===========

    Оператор задает одно или несколько свойств через пробел. См. :ref:`transform-properties`.

**Пример**

    ::

        transform rightoid:
            xalign .9

        transform ariana.left:
            xanchor .3 xpos 100


Оператор паузы (Number / Pause)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Приостанавливает выполнение блока ATL на указанное время в секундах. Ключевое слово ``pause`` необязательно.

**Синтаксис**

    ::

        pause <длительность>

**Использование**

    .. table::
        :widths: auto

        ==============  =================  ===========
        Имя             Тип                Описание
        ==============  =================  ===========
        "pause"         ключевое слово     (Необязательно) Ключевое слово паузы
        длительность    число (выражение)  Время паузы в секундах
        ==============  =================  ===========

**Примеры**

    ::

        transform pause_example(duration=0.5):
            xalign 0.0

            # Пауза на 2.0 секунды.
            pause 2.0
            xalign 1.0

            # Пауза на duration секунд.
            pause duration
            xalign 0.5

            # Пауза на 3.0 секунды без слова pause.
            3.0

            repeat


Оператор интерполяции (Interpolation)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Основной способ создания плавной анимации. Значения свойств плавно изменяются во времени
от начальных к заданным конечным.

Для управления динамикой перехода используется :ref:`функция деформации времени (warper) <warpers>`.

**Синтаксис**

    Базовая форма::

        <имя_деформатора> <длительность> <свойство_atl> [<свойство_atl> ...]

    С пользовательской функцией деформатора::

        warp <функция_деформатора> <длительность> <свойство_atl> [<свойство_atl> ...]

    Блочная форма::

        <имя_деформатора> <длительность>:
            <свойство_atl>
            <свойство_atl>
            ...

**Использование**

    .. table::
        :widths: auto

        ======================  ===============================  ===========
        Имя                     Тип                              Описание
        ======================  ===============================  ===========
        имя_деформатора         слово                            Имя :ref:`встроенного деформатора времени <warpers>` (linear, ease...)
        функция_деформатора     строка, функция                  Функция с сигнатурой ``(t: float) -> float``
        длительность            число                            Время интерполяции в секундах
        свойство_atl            свойство                         Интерполируемое свойство трансформации
        ======================  ===============================  ===========

**Примеры**

    Базовое использование::

        show logo base:
            xalign 0.0 yalign 0.0

            # Перемещение в нижний левый угол за 2.0 секунды.
            linear 2.0 yalign 1.0

    Одновременное изменение нескольких свойств::

        show logo base:
            xalign 0.0 yalign 0.0

            # Одновременно меняет xalign и yalign.
            linear 2.0 xalign 0.5 yalign 0.5

            # То же самое через блочную форму:
            linear 2.0:
                xalign 0.5
                yalign 0.5

**Сплайновая интерполяция (криволинейная траектория)**

    ::

        <свойство_atl> knot <значение_узла> [knot <значение_узла> ...]

    Начальная точка берется из текущего значения свойства, конечная — из переданного значения.
    Узлы (knots) управляют формой кривой. Квадратичная кривая Безье строится при одном узле,
    кубическая — при двух, сплайн Катмулла-Рома — при трех и более узлах::

        transform spline_motion_single_property:
            zoom 0.5 xalign 1.0 yalign 1.0

            # Квадратичная кривая Безье
            linear 2.0 xalign 0.5 knot 0.0

            # Кубическая кривая Безье
            linear 2.0 yalign 0.0 knot 0.2 knot 0.8

            # Сплайн Катмулла-Рома
            linear 2.0 xalign 0.0 knot 1.0 knot 0.5 knot 0.0

**Круговое движение**

    ::

        <свойство_atl> clockwise
        <свойство_atl> counterclockwise
        <свойство_atl> circles <количество_кругов>

    Клауза ``clockwise`` (по часовой стрелке) или ``counterclockwise`` (против часовой стрелки)
    задает направление вращения вокруг центра полярных координат (:tpref:`around`)::

        show logo base:
            xalign 1.0 yalign 0.0
            anchor (0.5, 0.5)

            # Круговое спиральное движение к верху экрана с 3 полными оборотами за 2 секунды.
            linear 2.0 yalign 0.0 clockwise circles 3


Оператор Pass
~~~~~~~~~~~~~

Оператор ``pass`` не производит никаких действий (пустая операция).

**Синтаксис**

    ::

        pass

    Используется для разделения идущих подряд блоков choice или создания пустых блоков.


Оператор Repeat
~~~~~~~~~~~~~~~

Оператор ``repeat`` заставляет содержащий его блок перезапуститься с начала.

**Синтаксис**

    Базовая форма::

        repeat

    С параметром количества повторений::

        repeat <счетчик>

    Оператор repeat должен быть последним оператором в блоке. Блок с ``repeat 2`` выполнится
    суммарно дважды.

**Пример**

    ::

        show logo base:
            xalign 0.0
            linear 1.0 xalign 1.0
            linear 1.0 xalign 0.0
            repeat


Оператор Block
~~~~~~~~~~~~~~

Оператор ``block`` группирует серию инструкций ATL, например, для их совместного повторения.

**Синтаксис**

    ::

        block:
            <блок_atl>

**Пример**

    ::

        show logo base:
            alpha 0.0 xalign 0.0 yalign 0.0
            linear 1.0 alpha 1.0

            block:
                linear 1.0 xalign 1.0
                linear 1.0 xalign 0.0
                repeat


Оператор Parallel
~~~~~~~~~~~~~~~~~

Оператор ``parallel`` задает набор блоков ATL, выполняющихся параллельно.

**Синтаксис**

    ::

        parallel:
            <блок_atl>
        parallel:
            <блок_atl>

    Блоки выполняются одновременно. Оператор parallel завершается, когда завершается последний
    из его параллельных блоков. Каждый блок должен изменять независимые свойства трансформации.

**Пример**

    ::

        show logo base:
            parallel:
                xalign 0.0
                linear 1.3 xalign 1.0
                linear 1.3 xalign 0.0
                repeat
            parallel:
                yalign 0.0
                linear 1.6 yalign 1.0
                linear 1.6 yalign 0.0
                repeat


Оператор Choice
~~~~~~~~~~~~~~~

Оператор ``choice`` задает случайный выбор одной из ветвей. Ren'Py случайно выбирает одну
из предложенных ветвей с учетом их весов.

**Синтаксис**

    ::

        choice:
            <блок_atl>
        choice <вес>:
            <блок_atl>

**Пример**

    ::

        image eileen random:
            choice:
                "eileen happy"
            choice:
                "eileen vhappy"
            choice 2.0:
                # Вдвое более вероятный выбор.
                "eileen concerned"

            pause 1.0
            repeat


.. _animation-atl-statement:

Оператор Animation
~~~~~~~~~~~~~~~~~~

Оператор ``animation`` должен быть первым оператором в блоке ATL и указывает Ren'Py
использовать временную шкалу анимации (``at``) вместо стандартной временной шкалы показа (``st``).
Подробнее см. :ref:`atl-timebases`.

**Синтаксис**

    ::

        animation

**Пример**

    ::

        image eileen happy moving:
            animation
            "eileen happy"
            xalign 0.0
            linear 5.0 xalign 1.0
            repeat

        image eileen vhappy moving:
            animation
            "eileen vhappy"
            xalign 0.0
            linear 5.0 xalign 1.0
            repeat

Оператор On
~~~~~~~~~~~

Оператор ``on`` определяет обработчик событий.

**Синтаксис**

    Для одного события::

        on <имя_события>:
            <блок_atl>

    Для нескольких событий::

        on <имя_события>, <имя_события>, ...:
            <блок_atl>

    Когда происходит событие, обработка любого предыдущего события завершается, и немедленно
    начинается обработка нового.

**Пример**

    ::

        show logo base:
            on show:
                alpha 0.0
                linear .5 alpha 1.0
            on hide:
                linear .5 alpha 0.0

        transform pulse_button:
            on hover, idle:
                linear .25 zoom 1.25
                linear .25 zoom 1.0

.. _displayable-atl-statement:

Оператор Displayable
~~~~~~~~~~~~~~~~~~~~

Устанавливает или заменяет дочерний :doc:`отображаемый объект <displayables>` трансформации
в момент выполнения. Можно указать переход с помощью клаузы ``with``.

**Синтаксис**

    Базовая форма::

        <отображаемый_объект>

    С переходом::

        <отображаемый_объект> with <переход>

**Пример**

    ::

        image atl example:
            "logo_base.png"
            pause 1.0
            "logo_bw.png" with Dissolve(0.5, alpha=True)

Оператор выражения трансформации (Transform Expression)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Включает другую трансформацию ATL в текущий блок.

**Синтаксис**

    ::

        <выражение_трансформации>

**Пример**

    ::

        transform move_right:
            linear 1.0 xalign 1.0

        image atl example:
            "logo_base.png"
            move_right


.. _inline-contains-atl-statement:

Строчный оператор Contains
~~~~~~~~~~~~~~~~~~~~~~~~~~

Устанавливает (или заменяет) дочерний элемент текущей трансформации значением выражения.

**Синтаксис**

    ::

        contains <отображаемый_объект>

**Пример**

    ::

        transform an_animation:
            "1.png"
            pause 2
            "2.png"
            pause 2
            repeat

        image move_an_animation:
            contains an_animation
            xalign 0.0
            linear 1.0 yalign 1.0


Блочный оператор Contains
~~~~~~~~~~~~~~~~~~~~~~~~~

Устанавливает дочерний элемент трансформации через один или несколько параллельных блоков.

**Синтаксис**

    ::

        contains:
            <блок_atl>

    Блоки автоматически группируются внутри контейнера :func:`Fixed` и становятся
    дочерним элементом трансформации.

**Пример**

    ::

        image test double:
            contains:
                "logo.png"
                xalign 0.0
                linear 1.0 xalign 1.0
                repeat

            contains:
                "logo.png"
                xalign 1.0
                linear 1.0 xalign 0.0
                repeat


Оператор Function
~~~~~~~~~~~~~~~~~

Позволяет вызывать функции Python из блока ATL.

**Синтаксис**

    ::

        function <имя_функции>

    Функция должна иметь сигнатуру ``(trans: Transform, st: float, at: float) -> float | None``:

    * `trans` — объект трансформации, свойства которого можно изменять напрямую как атрибуты.
    * `st` — временная шкала показа в секундах.
    * `at` — временная шкала анимации в секундах.
    * Возвращаемое число задает задержку в секундах до следующего вызова. Значение None передает управление следующему оператору ATL.

**Пример**

    ::

        init python:
            def slide_vibrate(trans, st, at, /):
                if st > 1.0:
                    trans.xalign = 1.0
                    trans.yoffset = 0
                    return None
                else:
                    trans.xalign = st
                    trans.yoffset = random.randrange(-10, 11)
                    return 0

        label start:
            show logo base:
                function slide_vibrate
                pause 1.0
                repeat


Оператор Time
~~~~~~~~~~~~~

Управляющий оператор временного перехвата.

**Синтаксис**

    ::

        time <значение>

    При достижении указанного времени (в секундах от старта блока) выполнение немедленно
    переходит к следующему оператору, прерывая работу текущих инструкций.

**Пример**

    ::

        image backgrounds:
            "bg band"
            xoffset 0
            block:
                linear 1 xoffset 10
                linear 1 xoffset 0
                repeat

            time 2.0
            xoffset 0
            "bg whitehouse"

            time 4.0
            "bg washington"


Оператор Event
~~~~~~~~~~~~~~

Генерирует событие с указанным именем внутри блока ATL.

**Синтаксис**

    ::

        event <имя_события>


.. _external-atl-events:

Внешние события
---------------

Следующие события генерируются автоматически:

``start``
    Псевдособытие при входе в оператор ``on`` при отсутствии более приоритетных событий.

``show``
    Генерируется при показе трансформации через show/scene, если изображения с таким тегом еще не было на экране.

``replace``
    Генерируется при замене одного изображения другим с тем же тегом.

``hide``
    Генерируется при скрытии объекта оператором ``hide``.

``replaced``
    Генерируется, когда трансформация заменяется другой.

``hover``, ``idle``, ``selected_hover``, ``selected_idle``, ``insensitive``, ``selected_insensitive``
    Генерируются при смене состояний кнопок, содержащих данную трансформацию или содержащихся в ней.


.. _atl-partial:

Каррирование и частичная передача параметров в ATL
--------------------------------------------------

Трансформации ATL поддерживают частичное применение параметров при вызове: возвращаемое
значение остается объектом трансформации с зафиксированными новыми значениями параметров
по умолчанию::

    transform screamer(child, screamee, wait_time=2, flash_time=.1):
        child
        pause wait_time
        screamee
        pause flash_time
        child

    define shorter_screamer = screamer(wait_time=1)
    define eileen_excited_screamer = screamer(screamee="eileen excited", flash_time=.2)

    label start:
        show hhannahh happy at screamer(screamee="hhannahh surprised", wait_time=1.5)
        show eileen vhappy at eileen_excited_screamer
        show patricia sad at eileen_excited_screamer(screamee="patricia wow")


.. _atl-child-param:

Специальный параметр child
--------------------------

Если трансформация ATL имеет параметр с именем ``child``, и этот параметр получает значение,
то одновременно дочерний элемент трансформации автоматически устанавливается в это значение.
При применении трансформации к объекту аргумент ``child=`` передается автоматически::

    transform lucy_jump_scare(child):
        pause 5
        "lucy mad"
        pause .2
        child

    transform marquee(width, height=1.0, duration=2.0, child=None):
        xcenter 0.5
        ycenter 0.5
        crop (0, 0, 0.5, 500)
        contains:
            child
            xanchor 0.0 xpos 1.0
            linear duration xanchor 1.0 xpos 0.0


.. _warpers:

Функции деформации времени (Warpers)
====================================

Деформатор времени (warper) — функция, отображающая прогресс времени `t` в интерполированное
значение `t'` (оба числа от 0.0 до 1.0).

Предустановленные деформаторы:

``pause``
    Пауза, затем мгновенный скачок к конечному значению.
``linear``
    Линейная интерполяция.
``ease``
    Плавное ускорение в начале и замедление в конце.
``easein``
    Быстрый старт с плавным замедлением в конце.
``easeout``
    Медленный старт с ускорением в конце.

Кроме того, поддерживаются стандартные функции плавности Роберта Пеннера:

.. include:: inc/easings

Новые деформаторы объявляются декоратором ``@renpy.atl_warper`` в блоке ``python early``::

    python early hide:
        @renpy.atl_warper
        def linear(t):
            return t


.. _replacing-transforms:

Замена трансформаций
====================

Когда одна трансформация заменяется другой трансформацией того же тега, свойства исходящей
трансформации автоматически наследуются входящей трансформацией.

При передаче нескольких трансформаций в списке ``at`` они сопоставляются с конца к началу::

    show eileen happy at a, b, c
    "Диалог!"
    show eileen happy at d, e

Здесь ``c`` будет заменена на ``e``, ``b`` на ``d``, а ``a`` останется без замены.


.. _atl-timebases:

Временные шкалы (Timebases)
===========================

Существуют две шкалы времени:

* ``st`` (shown timebase) — отсчитывается с момента первого появления данного конкретного объекта на экране.
* ``at`` (animation timebase) — отсчитывается с момента появления любого объекта с данным тегом на экране без скрытия.

По умолчанию трансформации используют шкалу ``st``. Оператор :ref:`animation <animation-atl-statement>`
переключает шкалу на ``at``.


Класс Transform
===============

Эквивалентом базовых трансформаций в Python является класс :class:`Transform`.

.. class:: Transform(child=None, *, function=None, reset=False, **properties)

    Создает объект трансформации, применяющий свойства и эффекты к своему дочернему элементу `child`.

    `child`
        Дочерний отображаемый объект.

    `reset`
        Если True, свойства сбрасываются к значениям по умолчанию при показе, а не наследуются от заменяемого объекта.

    .. function:: function(trans: Transform, st: float, at: float, /) -> float|None

        Функция обновления трансформации при отрисовке.

    .. attribute:: hide_request

        Устанавливается в True, когда объект готовится к скрытию.

    .. attribute:: hide_response

        Если ``hide_request`` равно True, установка в False предотвращает скрытие трансформации.

    .. attribute:: original_child

        Исходный дочерний объект до вызовов set_child.

    .. method:: set_child(child)

        Устанавливает новый дочерний объект.

    .. method:: update()

        Вызывается для применения изменений свойств трансформации, сделанных вне функции `function`.

    .. method:: unique()

        Помечает трансформацию как уникальную, предотвращая ее копирование при добавлении к объекту.


Применение трансформаций к отображаемым объектам в Python
=========================================================

В Python применить трансформацию ``t`` к объекту ``d`` можно несколькими способами:

#. Наиболее универсальный способ: ``At(d, t)`` (см. ниже).
#. ``d(child=t)`` для всех :ref:`трансформаций ATL <atl>`.
#. ``t(d)`` для :ref:`трансформаций Python <transforms-python>` и ATL-трансформаций без позиционных аргументов.

Функции как трансформации
=========================

В качестве трансформаций можно использовать простые функции Python, принимающие один
:doc:`отображаемый объект <displayables>` и возвращающие новый объект::

    init python:
        def right_or_left(d):
            if switch:
                return At(d, right)
            else:
                return At(d, left)
