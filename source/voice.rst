.. _voice:

=======
Озвучка
=======

Ren'Py поддерживает воспроизведение голосовой озвучки синхронно с диалогом.
Для этого используется инструкция ``voice``, которой передаётся имя
воспроизводимого аудиофайла::

    voice "line0001.ogg"
    "Добро пожаловать в Ren'Py"

Как правило, звучание голоса прекращается при переходе к следующему взаимодействию
(клику игрока). Инструкция ``voice sustain`` позволяет продлить воспроизведение
голоса сквозь смену диалоговых реплик. ::

    voice "line0001.ogg"
    "Добро пожаловать в Ren'Py..."

    voice sustain
    "...ваш движок создания визуальных новелл."

Переменная :var:`config.voice_filename_format` позволяет настроить шаблон имён
файлов озвучки, избавляя от необходимости каждый раз прописывать каталоги и расширения.

Теги озвучки
------------

Ren'Py включает систему тегов озвучки, позволяющую выборочно включать или
заглушать голоса конкретных персонажей. Чтобы воспользоваться этой системой,
передайте аргумент ``voice_tag`` при объявлении каждого :func:`Character`
и используйте действия :func:`SetVoiceMute` или :func:`ToggleVoiceMute`,
дающие игроку возможность переключать воспроизведение голоса.

Например::

    define e = Character("Эйлин", voice_tag="eileen")
    define l = Character("Люси", voice_tag="lucy")

    screen voice_toggle:
        vbox:
            textbutton "Заглушить Эйлин" action ToggleVoiceMute("eileen")
            textbutton "Заглушить Люси" action ToggleVoiceMute("lucy")

    label start:
        show screen voice_toggle

        voice "e01.ogg"
        e "Голос каждого персонажа можно включать и отключать отдельно."

        voice "l01.ogg"
        l "Да! Наконец-то я смогу заставить тебя замолчать!"

        voice "l02.ogg"
        l "Погоди... получается, они и меня могут заглушить?! Серьёзно?"

Автоматическая озвучка
----------------------

Ren'Py умеет автоматически определять файл озвучки для каждой реплики,
позволяя озвучивать игру без необходимости вручную прописывать инструкции
voice перед каждой строкой диалога.

Для этого аудиофайлы именуются в соответствии с уникальными идентификаторами
строк сценария. Чтобы узнать эти идентификаторы, экспортируйте диалоги в
таблицу через лаунчер Ren'Py: выберите «Извлечь диалог» (Extract Dialogue),
затем «Таблица с разделителями-табуляциями (dialogue.tab)» и нажмите «Продолжить».
Будет создан файл dialogue.tab, который можно открыть в табличном редакторе.

Первый столбец таблицы содержит идентификатор реплики, а остальные столбцы
дают дополнительную информацию о тексте и персонаже.

Чтобы включить автоматическую озвучку в Ren'Py, присвойте переменной
:var:`config.auto_voice` строку, содержащую шаблон ``{id}``. При выводе диалога
маркер ``{id}`` заменяется идентификатором реплики, образуя имя файла. Если файл
с таким именем существует, движок воспроизводит его.

Например, если задано::

    config.auto_voice = "voice/{id}.ogg"

И идентификатор реплики равен ``demo_minigame_03fc91ef``, то при показе этой строки
Ren'Py попытается загрузить файл :file:`voice/demo_minigame_03fc91ef.ogg`. Если
файл найден, он будет воспроизведён.

Многоязычная озвучка
--------------------

Чтобы задействовать систему перевода Ren'Py при дубляже игры на несколько языков,
можно использовать :ref:`перевод файлов изображений и ресурсов <image-file-translation>`.
Для игры, оригинальный язык которой английский, а дубляж выполнен на французском,
при наличии диалога::

    voice "omelette.ogg"
    e "Я люблю яичницу с сыром..."

Размещение английского аудиофайла в :file:`game/omelette.ogg`, а французского перевода
в :file:`game/tl/french/omelette.ogg` приведёт к тому, что Ren'Py автоматически выберет
французскую версию аудио при переключении игры на французский язык.

Этот же механизм работает и для автоматической озвучки, если относительный путь
файла перевода внутри :file:`game/tl/{<язык>}/` совпадает с относительным путем
оригинального файла в каталоге :file:`game/`\ .
