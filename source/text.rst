.. _text:

=====
Текст
=====

В Ren'Py есть несколько способов отображения текста. Операторы :ref:`say <say-statement>`
и :doc:`menu <menus>` в первую очередь предназначены для отображения текста пользователю.
Пользовательский интерфейс часто содержит текст, отображаемый с помощью операторов экранного языка
:ref:`text <sl-text>`, :ref:`textbutton <sl-textbutton>` и :ref:`label <sl-label>`.
Эти и другие функции создают отображаемые объекты :func:`Text` и показывают их на экране.

Отображаемый объект Text отвечает за управление процессом показа текста пользователю.
Отображаемый объект text выполняет действия в следующем порядке:

1. Перевод текста.
2. Интерполяция данных в текст.
3. Стилизация текста с помощью стилей и текстовых тегов.
4. Разметка и компоновка стилизованного текста.
5. Отрисовка текста на экране.

В этой главе рассматривается процесс отображения текста в Ren'Py.


Экранированные символы
======================

Существуют три специальных символа, управляющих отображением текста в Ren'Py.
Создателю визуальной новеллы важно знать об этих символах, чтобы написанный текст случайно
не был неверно истолкован движком.

\ (обратная косая черта, обратный слэш)
    Символ обратной косой черты используется для экранирования символов при написании строки Ren'Py
    или Python. Распространённые escape-последовательности:

    \" (обратный слэш-двойная кавычка)
        Вставляет двойную кавычку в строку, заключённую в двойные кавычки.

    \' (обратный слэш-одинарная кавычка)
        Вставляет одинарную кавычку в строку, заключённую в одинарные кавычки.

    \\\  (обратный слэш-пробел)
        Вставляет дополнительный пробел в строку Ren'Py. По умолчанию текст сценария
        Ren'Py объединяет соседние пробельные символы в один символ пробела.

    \n (обратный слэш-n)
        Вставляет символ перевода строки, начиная новую строку.

    \\\\ (двойной обратный слэш)
        Вставляет символ обратной косой черты в текст.

    \% (обратный слэш-процент)
        Вставляет экранированный символ процента в текст. Его также можно записать как
        %% : оба варианта приведут к появлению одиночного символа % в итоговом тексте.

[ (левая квадратная скобка)
    Левая квадратная скобка используется для обозначения интерполяции значения в текст.
    Чтобы вставить одну левую квадратную скобку в текст, удвойте её — напишите ``[[``.

{ (левая фигурная скобка)
    Левая фигурная скобка используется для обозначения текстового тега.
    Чтобы вставить левую фигурную скобку в текст, удвойте её — напишите ``{{``.

【 (левая линзовидная скобка)
    Левая линзовидная скобка используется для вставки руби-текста/фуриганы.
    Чтобы вставить левую линзовидную скобку в текст, удвойте её — напишите ``【【``.

Интерполяция данных
===================

Ren'Py поддерживает интерполяцию данных в текстовую строку перед её отображением.
Например, если имя игрока хранится в переменной ``playername``, можно написать строку диалога::

    g "Добро пожаловать в Институт Нэкомими, [playername]!"

Ren'Py будет искать переменные в следующем порядке:

* При использовании в экране — переменные, локальные для экрана.
* Переменные, найденные в пространстве имён ``interpolate``.
* Переменные, найденные в глобальном пространстве имён.

Ren'Py не ограничивается интерполяцией простых переменных. Он также может интерполировать любое
допустимое выражение Python. Таким образом, можно написать::

    g "Моё имя — [player.names[0]]."

При отображении чисел можно применять форматирование. Следующий пример выведет число с плавающей запятой
с точностью до двух знаков после запятой::

    g "Вы нравитесь мне на [100.0 * points / max_points:.2] процента!"

Форматирование строк в Ren'Py основано на синтаксисе форматирования строк :pep:`3101`.
Ren'Py использует символ [ для интерполяции строк, так как фигурные скобки { зарезервированы для текстовых тегов.

Наряду с флагами преобразования ``!s`` и ``!r``, поддерживаемыми Python, Ren'Py поддерживает ещё несколько флагов.
Флаг преобразования ``!q`` гарантирует правильное экранирование текстовых тегов, чтобы отображение строки не приводило
к появлению нежелательных конструкций форматирования. Например::

    g "Не пытайся меня обмануть, [playername!q]."

Флаг ``!t`` переводит интерполированную строку::

    if points > 5:
        $ mood = _("радостна")
    else:
        $ mood = _("раздражена")

    g "Я [mood!t] видеть вас."

Флаг ``!i`` выполняет дополнительную рекурсивную интерполяцию для интерполированной строки::

    define earned_points_info = _("[points]{image=points.png} заработанных очков")
    g "Я рада видеть вас, у вас [earned_points_info!ti]."

Этот флаг следует использовать для подстановки текста, внутри которого уже есть подстановка.
Это часто бывает полезно в экранном языке, см. :ref:`Постоянный текст <const-text>`.

Флаг ``!f`` передаёт полученную строку через функцию :var:`config.say_menu_text_filter`,
если она не равна None. Это позволяет фильтровать интерполированный текст.

Флаг ``!u`` переводит текст в верхний регистр, а флаг ``!l`` — в нижний регистр.
Флаг ``!c`` действует только на первый символ строки, делая его заглавным. Эти флаги можно комбинировать;
например, использование ``!cl`` сделает заглавным первый символ, а остальную часть текста переведёт в нижний регистр.

Следует отметить:

- порядок указания флагов не меняет результат: флаг ``!cl`` даст тот же результат, что и ``!lc``.
- Дополнительные восклицательные знаки игнорируются и не отменяют предыдущее правило: ``!l!c``
  даст тот же результат, что и ``!c!l`` или ``!cl``.

Преобразования выполняются в следующем порядке:

#. ``r``/``s`` (repr или str)
#. ``t`` (перевод)
#. ``i`` (рекурсивная интерполяция)
#. ``q`` (экранирование тегов)
#. ``u`` (верхний регистр)
#. ``l`` (нижний регистр)
#. ``c`` (капитализация первого символа)

Если вам нужно получить результирующую строку с аргументами, заменёнными фактическими данными,
вы можете передать её в функцию :func:`renpy.substitute`.

Стилизация и текстовые теги
===========================

В Ren'Py текст получает стилевую информацию двумя путями. Первый — из стиля, применяемого
ко всему блоку текста. Дополнительные сведения см. в разделе о :doc:`системе стилей <style>`,
особенно в подразделе о :ref:`свойствах стиля текста <text-style-properties>`.

Второй способ — через текстовые теги. Текстовые теги подходят для стилизации части текстового блока
или небольшой доли текстовых блоков в программе. Если вы обнаружите, что применяете одни и те же
текстовые теги к каждой строке текста, рассмотрите возможность использования стиля.

Существует два типа текстовых тегов. Некоторые текстовые теги являются самозакрывающимися,
в то время как другие требуют закрывающего тега. Закрывающий тег начинается с косой черты (/),
и теги закрываются в порядке LIFO (последним пришёл — первым ушёл). Каждый закрывающий тег должен
соответствовать парному открывающему тегу. В противном случае Ren'Py выдаст предупреждение линтера.

Например::

    # Эта строка корректна.
    "Обычный {b}Полужирный {i}Полужирный курсив{/i} Полужирный{/b} Обычный"

    # Эта строка некорректна и вызовет сбой разметки.
    "Обычный {b}Полужирный {i}Полужирный курсив{/b} Курсив{/i} Обычный"

Закрывать абсолютно все текстовые теги не обязательно. Ren'Py автоматически закроет все теги,
оставшиеся открытыми в конце текстового блока. Например::

    "{size=+20}Это крупный текст!"

Некоторые текстовые теги принимают аргумент. В этом случае за именем тега следует знак равенства (=)
и аргумент. Аргумент не может содержать символ правой фигурной скобки (}). Значение аргумента
различается в зависимости от тега.

Общие текстовые теги
--------------------

Теги, применимые ко всему тексту:

.. text-tag:: a

    Тег якоря (гиперссылки) создаёт гиперссылку между собой и закрывающим тегом.
    Хотя поведение гиперссылки контролируется свойством стиля :propref:`hyperlink_functions`,
    обработчик по умолчанию выполняет следующие действия:

    * Если аргумент начинается с ``jump:``, оставшаяся часть аргумента является меткой перехода.

    * Если аргумент начинается с ``call:``, оставшаяся часть аргумента является вызываемой меткой.
      Как обычно, вызов метки завершает текущий оператор Ren'Py.

    * Если аргумент начинается с ``call_in_new_context:``, оставшаяся часть аргумента является меткой,
      вызываемой в новом контексте (с помощью :func:`renpy.call_in_new_context`).

    * Если аргумент начинается с ``show:``, оставшаяся часть аргумента является экраном для отображения.

    * Если аргумент начинается с ``showmenu:``, оставшаяся часть аргумента является экраном игрового меню для показа.

    * В противном случае аргумент считается URL-адресом, который открывается в системном веб-браузере.

    Если в аргументе не указан протокол, к нему добавляется префикс :var:`config.hyperlink_protocol`.
    Если для config.hyperlink_protocol установлено значение "jump", выражения {a=label} и {a=jump:label}
    становятся эквивалентными. Разработчики могут определять новые протоколы с помощью
    :var:`config.hyperlink_handlers`.

    ::

        label test:

            e "Почему бы вам не посетить {a=https://renpy.org}главную страницу Ren'Py{/a}?"

            e "Или нажмите {a=jump:more_text}сюда для подробностей{/a}."

            return

        label more_text:

            e "В Хот-Спрингс, штат Арканзас, есть статуя Аль Капоне, рядом с которой можно сфотографироваться."

            e "Это подробная информация, но вряд ли та, которую вы искали, верно?"

            return


.. text-tag:: alpha

    Тег alpha отображает текст между собой и закрывающим тегом с указанной непрозрачностью.
    Непрозрачность должна быть числом от 0.0 до 1.0, соответствующим полностью прозрачному
    и полностью непрозрачному состоянию соответственно. Если значению предшествует знак + или -,
    непрозрачность изменяется на эту величину, а не заменяется полностью. Если значению
    предшествует знак \*, непрозрачность умножается на указанную величину. ::

        "{alpha=0.1}Этот текст едва различим!{/alpha}"
        "{alpha=-0.1}Этот текст на 10 процентов прозрачнее значения по умолчанию.{/alpha}"
        "{alpha=*0.5}Этот текст вдвое прозрачнее значения по умолчанию.{/alpha}"

.. text-tag:: alt

    Тег alt предотвращает отображение текста на экране, сохраняя его доступным для системы
    озвучивания текста (синтеза речи). ::

       g "Рада вас видеть! {image=heart.png}{alt}сердечко{/alt}"

    См. также персонажа :var:`alt`.

.. text-tag:: art

   Тег дополнительного верхнего текста руби помечает текст между собой и закрывающим тегом как
   альтернативный верхний текст руби. Дополнительную информацию см. в разделе :ref:`Руби-текст <ruby-text>`.

.. text-tag:: b

    Тег полужирного начертания отображает текст между собой и закрывающим тегом
    полужирным шрифтом. ::

        "Пример {b}полужирного текста{/b}."

.. text-tag:: color

    Тег цвета отображает текст между собой и закрывающим тегом указанным цветом.
    Цвет должен быть задан в формате #rgb, #rgba, #rrggbb или #rrggbbaa. ::

        "{color=#f00}Красный{/color}, {color=#00ff00}Зелёный{/color}, {color=#0000ffff}Синий{/color}"

.. text-tag:: cps

    Тег количества символов в секунду (characters per second) задаёт скорость отображения
    текста между открывающим и закрывающим тегом. Если аргумент начинается со звёздочки,
    он воспринимается как множитель к текущей скорости текста. В противном случае аргумент
    задаёт скорость вывода текста в символах в секунду. ::

        "{cps=20}Фиксированная скорость{/cps} {cps=*2}Двойная скорость{/cps}"


.. text-tag:: feature

    Тег feature включает или отключает функции типографики OpenType. Имя функции является
    частью тега и отделяется двоеточием. Аргумент должен быть равен 1 для включения функции
    или 0 для её отключения. Например, чтобы отключить лигатуры, используйте следующее: ::

        "{feature:liga=0}Traffic{/feature} is light today."

    Список функций макета шрифтов можно найти `здесь <https://learn.microsoft.com/en-us/typography/opentype/spec/featuretags>`_.

.. text-tag:: font

    Тег шрифта отображает текст между собой и закрывающим тегом указанным шрифтом.
    Аргументом является имя файла используемого шрифта. ::

        "Попробуйте шрифт {font=mikachan.ttf}mikachan{/font}."

.. text-tag:: i

   Тег курсива отображает текст между собой и закрывающим тегом курсивным начертанием. ::

       "Посетите {i}Пизанскую башню{/i}."

.. text-tag:: image

   Самозакрывающийся тег image вставляет изображение внутрь текста. Высота изображения
   должна соответствовать высоте одной строки текста. Аргументом должно быть либо имя файла
   изображения, либо имя изображения, определённого с помощью оператора image. ::

       g "Рада вас видеть! {image=heart.png}{alt}сердечко{/alt}"

.. text-tag:: k

   Тег кернинга регулирует межзнаковое расстояние между символами в диапазоне между
   открывающим и закрывающим тегами. В качестве аргумента он принимает число с плавающей
   запятой, указывающее количество пикселей кернинга, добавляемых к каждой паре символов.
   (Число может быть отрицательным для уменьшения расстояния). ::

       "{k=-.5}Отрицательный{/k} Обычный {k=.5}Положительный{/k}"

.. text-tag:: noalt

    Тег noalt предотвращает чтение текста системой синтеза речи. Он часто используется
    в сочетании с тегом alt для разделения визуальных элементов и доступного текста. ::

       g "Рада вас видеть! {noalt}<3{/noalt}{alt}сердечко{/alt}"

.. text-tag:: outlinecolor

    Тег outlinecolor изменяет цвет всех контуров (включая падающие тени) текста на заданный.
    Цвет должен быть задан в формате #rgb, #rgba, #rrggbb или #rrggbbaa. Этот тег лишь
    изменяет существующие контуры, но не создаёт новые. ::

        "{outlinecolor=#00ff00}Зелёный{/outlinecolor} контур текста."

.. text-tag:: plain

   Тег plain гарантирует, что к тексту не применяются полужирное начертание, курсив,
   подчёркивание или зачёркивание. ::

       "{b}Полужирный. {plain}Обычный.{/plain} Снова полужирный.{/b}"

.. text-tag:: rb

   Тег нижнего текста руби помечает текст между собой и закрывающим тегом как базовый
   (нижний) текст руби. Дополнительную информацию см. в разделе :ref:`Руби-текст <ruby-text>`.

.. text-tag:: rt

   Тег верхнего текста руби помечает текст между собой и закрывающим тегом как верхний текст
   руби (аннотацию фуриганы). Дополнительную информацию см. в разделе :ref:`Руби-текст <ruby-text>`.

.. text-tag:: s

   Тег зачёркивания отображает перечёркнутый текст между собой и закрывающим тегом. ::

       g "Было приятно {s}видеть вас{/s}."

.. text-tag:: shader

    Тег shader применяет текстовый шейдер к фрагменту текста. Аргументом является имя
    применяемого шейдера. ::

        "Этот текст {shader=jitter:u__jitter=1.0, 3.0}дрожит{/shader}."

    Дополнительную информацию см. в разделе :doc:`textshaders`.

.. text-tag:: size

   Тег size изменяет размер текста между собой и закрывающим тегом. Аргумент должен быть целым
   числом, перед которым при необходимости может стоять знак + или -. Если аргумент представляет
   собой просто целое число, размер устанавливается равным этому количеству пикселей по высоте.
   В противном случае размер увеличивается или уменьшается на указанную величину. ::

       "{size=+10}Крупнее{/size} {size=-10}Мельче{/size} {size=24}24 пикселя{/size}."

   Вы также можете указать число с плавающей запятой со знаком \* перед ним — в этом случае
   размер будет умножен на это число и затем округлён в меньшую сторону. ::

       "{size=*2}В два раза больше{/size} {size=*0.5}в два раза меньше.{/size}"

.. text-tag:: space

   Самозакрывающийся тег space вставляет горизонтальный отступ в строку текста. В качестве
   аргумента принимает целое число, задающее количество добавляемых пикселей пространства. ::

       "До пробела.{space=30}После пробела."

.. text-tag:: u

   Тег подчёркивания подчёркивает текст между собой и закрывающим тегом. ::

      g "Приятно {u}видеть{/u} вас."

.. text-tag:: vspace

   Самозакрывающийся тег vspace вставляет вертикальный отступ между строками текста. В качестве
   аргумента принимает целое число, задающее количество добавляемых пикселей пространства. ::

      "Строка 1{vspace=30}Строка 2"

.. text-tag:: #

   Текстовые теги, начинающиеся с #, игнорируются при выводе, но могут использоваться для
   различения одинаковых строк при переводе. ::

      "Новый{#playlist}"

Текстовые теги диалогов
-----------------------

Текстовые теги, применимые только к диалогам:

.. text-tag:: w

    Тег ожидания (wait) является самозакрывающимся тегом, который приостанавливает вывод
    и ожидает клика пользователя для продолжения. Если ему передан аргумент, он интерпретируется
    как число, и ожидание автоматически завершается по истечении этого количества секунд. ::

        "Строка 1{w} Строка 1{w=1.0} Строка 1"

.. text-tag:: p

    Тег паузы абзаца (paragraph pause) является самозакрывающимся тегом, который завершает
    текущий абзац и ожидает клика пользователя для продолжения. Если ему передан аргумент,
    он интерпретируется как число, и ожидание автоматически завершается по истечении этого
    количества секунд. ::

        "Строка 1{p}Строка 2{p=1.0}Строка 3"

.. text-tag:: nw

    Тег без ожидания (no-wait) является самозакрывающимся тегом, приводящим к автоматическому
    завершению и переходу текущей строки диалога сразу после того, как конец строки был отображён. ::

        g "Кажется, они{nw}"
        show trebuchet
        g "Кажется, они{fast} снова балуются со своим требушетом."

    Если тегу передан аргумент, он интерпретируется как число, и ожидание автоматически
    завершается по истечении этого количества секунд. ::

        g "Я упаду через пару секунд!{nw=2}"
        show g_gone

    Тег no-wait ожидает завершения автоматического озвучивания текста (self-voicing) перед переходом дальше.

.. text-tag:: fast

    Если тег fast встречается в строке текста, то весь текст перед ним отображается мгновенно,
    даже в режиме медленного вывода текста. Тег fast является самозакрывающимся. ::

        g "Кажется, они{nw}"
        show trebuchet
        g "Кажется, они{fast} снова балуются со своим требушетом."

    При наличии тег {fast} сохраняет звучание голосового файла из предыдущей строки.

.. text-tag:: done

    Текст после тега done не отображается. Зачем это нужно? Это позволяет тексту избежать
    «прыжков» компоновки, когда для :propref:`adjust_spacing` установлено значение True.

    Когда тег done присутствует, строка диалога не добавляется в буфер истории. Если в строке
    также есть тег nw, он должен располагаться перед тегом done. ::

        g "Кажется, они{nw}{done} снова балуются со своим требушетом."
        show trebuchet
        g "Кажется, они{fast} снова балуются со своим требушетом."

.. text-tag:: clear

    Текстовый тег clear имеет смысл только на отдельной строке в :ref:`режиме монолога NVL <nvl-monologue-mode>`.
    Он выполняет то же действие, что и оператор ``nvl clear``, не завершая при этом блок текста. ::

        """
        Блок 1 на странице 1.

        Блок 2 на странице 1.

        {clear}

        Блок 1 на странице 2.

        и т. д.
        """


Также можно определять :doc:`пользовательские текстовые теги <custom_text_tags>` на языке Python.

Теги стилей
-----------

Ren'Py поддерживает текстовые теги, обращающиеся к стилям. Это текстовые теги
с пустым именем тега. В этом случае аргумент воспринимается как имя стиля.
Например, тег {=mystyle} обращается к стилю ``mystyle``.

Текст между открывающим тегом и соответствующим закрывающим тегом получает следующие
свойства, определённые в этом стиле:

* :propref:`antialias` (может быть None)
* :propref:`axis` (может быть None)
* :propref:`black_color` (может быть None)
* :propref:`bold` (может быть None)
* :propref:`color` (может быть None)
* :propref:`font` (может быть None)
* :propref:`font_features` (может быть None)
* :propref:`hinting` (может быть None)
* :propref:`instance` (может быть None)
* :propref:`italic` (может быть None)
* :propref:`kerning`
* :propref:`size` (может быть None)
* :propref:`slow_cps`
* :propref:`slow_cps_multiplier`
* :propref:`strikethrough`
* :propref:`textshader` (может быть None)
* :propref:`underline`

Если поле в стиле равно None, оно наследует значение из родительского текста.


Неанглийские языки
==================

Шрифт по умолчанию в Ren'Py содержит символы для английского и многих других языков.
Из соображений размера файла он не содержит глифов, необходимых для отображения некоторых
других языков, включая китайский, японский и корейский. Чтобы поддерживать эти языки,
в проекте необходимо сначала сменить используемые шрифты.

После этого Ren'Py должен поддерживать большинство мировых языков без дополнительной настройки.
Однако корейский язык может быть написан как с пробелами между словами, так и без них.
В Ren'Py есть специальный режим для поддержки корейского с пробелами, который можно включить, задав::

    define gui.language = "korean-with-spaces"

Это значение можно изменить вместо стандартного "unicode" в файле gui.rpy.

В японском языке существует несколько правил переноса строк. Мы рекомендуем начинать
с "japanese-normal" и переходить на "japanese-loose" или "japanese-strict" для получения
соответственно большего или меньшего числа допустимых точек переноса строки. ::

    define gui.language = "japanese-loose"

Идеографические языки предоставляют огромное количество возможностей для переноса строк.
Чтобы включить более быстрый, но менее точный алгоритм переноса строк, используйте::

    define gui.language = "greedy"

Более быстрый алгоритм переноса строк не требуется, если только в игре не выводится
огромное количество текста одновременно (например, в режиме NVL).

Алгоритмы переноса строк можно дополнительно настроить с помощью функции
:func:`renpy.language_tailor`.


Вертикальный текст
------------------

Когда установлено свойство стиля :propref:`vertical`, Ren'Py выводит текст вертикально.
Текст пишется сверху вниз, справа налево.

Существуют два текстовых тега для работы с вертикальным текстом:

.. text-tag:: horiz

    Вставляет горизонтально ориентированный текст внутрь вертикального текста.

.. text-tag:: vert

    Вставляет вертикально ориентированный текст внутрь горизонтального текста.
    (Это не поворачивает текст в вертикальную ориентацию).

.. note::

    Если шрифт не содержит информации об интервалах вертикального текста, Ren'Py попытается
    синтезировать эту информацию на основе данных горизонтального текста. Интервалы могут
    не оставаться постоянными между выпусками Ren'Py.


.. _ruby-text:

Руби-текст
==========

Руби-текст (также известный как фуригана или межстрочные аннотации) — это способ
размещения мелкого пояснительного текста над символом или словом. Чтобы ваша игра поддерживала
руби-текст, необходимо выполнить несколько шагов.

Сначала настройте стили для руби-текста. Требуются следующие изменения стиля:

1. Одно из свойств :propref:`line_leading` или :propref:`ruby_line_leading` должно быть задано,
   чтобы оставить достаточно вертикального пространства для руби-текста.
2. Необходимо создать новый именованный стиль. Свойства этого стиля, такие как :propref:`size`,
   должны быть установлены соответствующим для руби-текста образом.
3. Свойство :propref:`yoffset` нового стиля должно быть настроено так, чтобы поднять руби-текст
   выше базовой линии.
4. Поле :propref:`ruby_style` стиля основного текста должно указывать на вновь созданный стиль
   как для диалогов, так и для текста в окне истории.

В новом стиле могут быть установлены следующие свойства:

* :propref:`antialias` (может быть None)
* :propref:`axis` (может быть None)
* :propref:`black_color` (может быть None)
* :propref:`bold` (может быть None)
* :propref:`color` (может быть None)
* :propref:`font` (может быть None)
* :propref:`font_features` (может быть None)
* :propref:`hinting` (может быть None)
* :propref:`instance` (может быть None)
* :propref:`italic` (может быть None)
* :propref:`kerning`
* :propref:`size` (может быть None)
* :propref:`slow_cps`
* :propref:`slow_cps_multiplier`
* :propref:`strikethrough`
* :propref:`textshader` (может быть None)
* :propref:`underline`
* :propref:`yoffset`

Если свойство равно None, оно наследует значение родительского текста.

Например::

    style ruby_style is default:
        size 12
        yoffset -20
        color None # Использовать тот же цвет, что и в основном тексте.
        font None # Использовать тот же шрифт, что и в основном тексте.

    style say_dialogue:
        ruby_line_leading 12
        ruby_style style.ruby_style

    style history_text:
        ruby_line_leading 12
        ruby_style style.ruby_style

(Для этой цели используйте синтаксис ``style.style_name`` для обращения к стилю).

После настройки Ren'Py руби-текст можно добавлять двумя способами.

**Линзовидные скобки.** Руби-текст можно записать, заключив его в полноширинные линзовидные
скобки (【】), разделяя нижний и верхний текст символом вертикальной черты (полноширинной ｜
или полуширинной \|). Например::

    e "Руби можно использовать для фуриганы (【東｜とう】 【京｜きょう】)."

    e "Оно также применяется для перевода (【東京｜Tokyo】)."

Руби-текст сработает только при наличии вертикальной черты. Левую линзовидную скобку можно
экранировать её удвоением. Линзовидный руби-текст не может содержать другие текстовые теги.

**Текстовые теги {rt} и {rb}.** Тег {rt} используется для обозначения одного или нескольких
символов в качестве текста руби. Если перед руби-текстом стоит текст, заключённый в тег {rb},
руби-текст центрируется над этим текстом. В противном случае он центрируется над предшествующим символом.

Например::

    e "Руби можно использовать для фуриганы (東{rt}とう{/rt} 京{rt}きょう{/rt})."

    e "Оно также применяется для перевода ({rb}東京{/rb}{rt}Tokyo{/rt})."

Создатель проекта несёт ответственность за то, чтобы руби-текст не выходил за границы текстового блока.
Может потребоваться добавить отступы или пробелы слева и справа от текста для предотвращения наложений.

Ren'Py также поддерживает альтернативный руби-текст — второй тип верхнего текста руби.
Он вводится с помощью текстового тега {art} (вместо {rt}) и свойства стиля :propref:`altruby_style`
(вместо :propref:`ruby_style`).

Шрифты
======

Ren'Py поддерживает масштабируемые шрифты в форматах OpenType, TrueType, WOFF и WOFF2.

Масштабируемые шрифты указываются именем файла шрифта в виде строки. Поиск шрифтов выполняется
в каталоге :file:`game` и в архивных файлах. Если шрифт не найден, поиск повторяется с префиксом
:file:`fonts/`. Например, при поиске "test.ttf" Ren'Py сначала ищет :file:`game/test.ttf`,
а затем :file:`game/fonts/test.ttf` (поиск также производится в файлах архивов).

Ren'Py поддерживает коллекции шрифтов TrueType/OpenType, содержащие более одного шрифта в одном файле.
При обращении к коллекции укажите индекс шрифта (начиная с 0), знак @ и имя файла.
Например, "0\@font.ttc" — первый шрифт в коллекции, "1\@font.ttc" — второй и так далее.

Хотя Ren'Py поддерживает файлы шрифтов любого размера (с учётом ограничений системной памяти),
инструменты сжатия WOFF2 могут испытывать проблемы с очень большими файлами шрифтов. См. :ghbug:`6605`.


Замена шрифтов
--------------

Переменная :var:`config.font_replacement_map` используется для сопоставления и замены шрифтов.
Комбинация имени файла шрифта, полужирности и курсива сопоставляется с аналогичной комбинацией.
Это позволяет использовать шрифт с настоящим разработанным курсивом вместо автоматически сгенерированного курсива.

Одним из примеров такой замены является замена курсивной версии шрифта DejaVu Sans на официальную
наклонную (oblique) версию (вам потребуется скачать шрифт из сети)::

    init python:
        config.font_replacement_map["DejaVuSans.ttf", False, True] = ("DejaVuSans-Oblique.ttf", False, False)

Такое сопоставление может значительно улучшить визуальный вид курсивного текста.

Имена и псевдонимы шрифтов
--------------------------

Переменная :var:`config.font_name_map` используется для присвоения имён или псевдонимов шрифтам.
Это даёт два преимущества: во-первых, делает строки диалогов с тегом ``{font}`` короче и удобнее,
а во-вторых, позволяет использовать группы шрифтов :ref:`fontgroup` внутри этих тегов. ::

    define config.font_name_map["jap"] = "electroharmonix.ttf"
    define config.font_name_map["tjap"] = FontGroup().add("OrthodoxHerbertarian.ttf", "A", "Z").add("electroharmonix.ttf", None, None)

    label yamato:
        e "Прости, что означает {font=jap}Black holes and revelations{/font}?"
        y "Это читается как {font=tjap}Black Holes And Revelations{/font}." # Заглавные буквы выводятся шрифтом OrthodoxHerbertarian


.. _fontgroup:

Группы шрифтов
--------------

При создании многоязычной игры может оказаться невозможным найти один-единственный шрифт,
который покрывал бы все письменные системы игры и при этом передавал желаемое автором настроение.
Для решения этой задачи Ren'Py поддерживает группы шрифтов, объединяющие символы из двух или более
шрифтов в один виртуальный шрифт.

Чтобы создать группу шрифтов, создайте объект :class:`FontGroup` и вызовите для него метод ``.add``
один или несколько раз. Объект FontGroup можно использовать везде, где допустимо имя шрифта.
Метод add принимает начальную и конечную кодовые точки диапазона символов Unicode; используется
первый диапазон, покрывающий запрошенный символ.

Например::

    style default:
        font FontGroup().add("english.ttf", 0x0020, 0x007f).add("japanese.ttf", 0x0000, 0xffff)

.. include:: inc/font_group

Обратите внимание: хотя объектам FontGroup можно присваивать имена через :var:`config.font_name_map`,
сам FontGroup принимает в качестве шрифтов только пути к файлам и не распознаёт имена или псевдонимы,
определённые этой переменной.

Шрифты на основе изображений
----------------------------

.. note:: Использование шрифтов на основе изображений не рекомендуется в новых проектах. Применение графических эффектов к шрифтам лучше выполнять с помощью текстовых шейдеров.

Шрифты на основе изображений можно зарегистрировать с помощью одной из следующих функций регистрации.
Регистрация шрифта на основе изображений требует указания имени, размера, полужирности, курсива
и подчёркивания. Когда все эти свойства совпадают с зарегистрированным шрифтом, используется
зарегистрированный растровый шрифт.

.. include:: inc/image_fonts

Пример использования BMFont::

    init python:
        renpy.register_bmfont("bmfont", 22, filename="bmfont.fnt")

    define ebf = Character('Эйлин', what_font="bmfont", what_size=22)

    label demo_bmfont:

        ebf "Наконец-то Ren'Py поддерживает BMFont."

Особенности медленного вывода текста
====================================

Ren'Py позволяет разработчику или игроку настроить постепенный (медленный) вывод текста. В этом случае
Ren'Py сначала отрисовывает текст в текстуру, а затем отображает прямоугольные области текстуры на экране.

К сожалению, это означает возможность появления артефактов отрисовки при перекрытии символов.
Чтобы свести к минимуму такие артефакты, убедитесь, что свойства :propref:`line_leading` и
:propref:`line_spacing` достаточно велики, чтобы строки не накладывались друг на друга.
Если нижние края символов первой строки обрезаются (особенно при отрицательном значении line_spacing),
рассмотрите возможность увеличения значения свойства :propref:`line_overlap_split`.

Горизонтальные артефакты также возможны при плотном кернинге символов, однако они менее заметны,
так как существуют всего в течение одного кадра.

Артефакты не возникают на статическом тексте, таком как текст в меню и других элементах интерфейса.

Журналирование переполнения текста
==================================

Ren'Py умеет вести журнал случаев, когда текст выходит за границы выделенной для него области.
Чтобы включить журналирование переполнения текста, выполните следующие шаги:

1. Установите для переменной :var:`config.debug_text_overflow` значение True.
2. Задайте свойства стиля :propref:`xmaximum` и :propref:`ymaximum` для отображаемого объекта Text
   или окружающего его контейнера.
3. Запустите игру.

Каждый раз, когда выводится текст, выходящий за пределы доступной области, Ren'Py запишет ошибку
в файл ``text_overflow.txt``.

Вариативные шрифты
==================

В Ren'Py есть поддержка вариативных шрифтов OpenType (variable fonts). Такие шрифты поддерживают
несколько осей вариации, таких как толщина (weight) и ширина (width), и в зависимости от значений
этих осей отображение шрифта может динамически изменяться. Вариативные шрифты также могут содержать
именованные экземпляры (instances), задающие конкретные предустановленные значения осей.
Например, именованный экземпляр "bold", скорее всего, предоставит полужирную версию шрифта,
а "regular" — обычную.

Вариативные шрифты требуют использования шейпера текста harfbuzz, управляемого свойством стиля
:propref:`shaper`. После его включения свойство :propref:`instance` выбирает именованный экземпляр,
а свойство :propref:`axis` задаёт значения одной или нескольких осей.

Их также можно настроить в системе gui. Например, можно написать::

    define gui.text_font = "nunito.ttf"
    define gui.text_instance = "light"
    define gui.text_axis = {"width" : 125}

Это начнёт с начертания light и сделает его широким.

Если экземпляр не указан, Ren'Py по умолчанию использует "regular" для обычного текста и "bold"
для полужирного текста.

Существуют два текстовых тега, поддерживающих вариативные шрифты:

.. text-tag:: instance

    Тег instance изменяет используемый именованный экземпляр шрифта. Например::

        "Это {instance=heavy}тяжёлый (heavy){/instance} текст."

    При использовании тега instance свойства осей переопределяются.

.. text-tag:: axis

    Тег axis изменяет значение одной или нескольких осей шрифта. Например::

        "Это {axis:width=125}широкий{/axis} текст."

    Тег axis можно использовать многократно, при этом значения объединяются:

        "Это {axis:width=125}{axis:weight=200}широкий и полужирный{/axis}{/axis} текст."

    Значение справа от знака равенства должно быть числом с плавающей запятой.

Чтобы получить доступные экземпляры и оси шрифта, используйте функцию :func:`renpy.variable_font_info`.
Эта функция предназначена для вызова из консоли. Чтобы открыть консоль, нажмите Shift+O и введите::

    renpy.variable_font_info("nunito.ttf")

Команда выведет подробную информацию о шрифте nunito.ttf.
