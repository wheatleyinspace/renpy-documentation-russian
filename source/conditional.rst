Условные инструкции
===================

Ren'Py включает несколько инструкций, позволяющих изменять ход выполнения программы
на основе значений выражений. Это дополняет инструкции :ref:`jump <jump-statement>`,
:ref:`call <call-statement>` и :ref:`return <return-statement>`, которые передают
управление безусловно.

Обратите внимание, что на этой странице рассматриваются инструкции, используемые
непосредственно внутри сценария Ren'Py. Встроенный в игру код Python использует
стандартные инструкции Python (while, if, for), но не может содержать в себе
инструкции языка Ren'Py.

.. _if-statement:

Инструкция if
-------------

Инструкция ``if`` условно выполняет блок инструкций, если выражение Python
истинно (True). Она состоит из конструкции ``if``, нуля или более конструкций
``elif`` и необязательной завершающей конструкции ``else``.

Каждая конструкция должна располагаться на отдельной логической строке, за которой
следует блок инструкций с отступом. За конструкциями if и elif следует выражение,
а заканчиваются все конструкции двоеточием ``:``.

Примеры использования::

    if flag:
        e "Флаг установлен!"

::

    if points >= 10:
        jump best_ending
    elif points >= 5:
        jump good_ending
    elif points >= 1:
        jump bad_ending
    else:
        jump worst_ending

Выражения в инструкции if вычисляются строго по порядку, от первого к последнему.
Когда выражение вычисляется в значение True, выполняется соответствующий блок
инструкций. Когда управление доходит до конца этого блока, оно переходит к
инструкции, следующей за всей конструкцией if.

Если все выражения вычисляются в значение False, выполняется блок, связанный
с конструкцией ``else`` (если конструкция ``else`` присутствует).

Инструкция while
----------------

Инструкция ``while`` выполняет блок инструкций до тех пор, пока выражение
вычисляется как True. Например::

    $ count = 10

    while count > 0:

        "До старта: [count]."

        $ count -= 1

    "Пуск!"

::

    $ lines = ["sounds/three.mp3", "sounds/two.mp3", "sounds/one.mp3"]
    while lines: # возвращает True, пока список не пуст
        play sound lines.pop(0) # извлекает и воспроизводит первый элемент
        pause

::

    while True:

        "Это песня, которая никогда не закончится."
        "Она продолжается снова и снова, друзья."

Выражение вычисляется при первом входе в инструкцию while, а затем каждый раз,
когда управление достигает конца блока. Когда выражение возвращает ложное значение (False),
выполняется инструкция, расположенная после блока while.

В языке Ren'Py нет отдельных инструкций continue, break или for. Инструкции
continue и break можно легко заменить переходом (jump) к меткам, расположенным
соответственно перед циклом while или после него. Первый пример цикла while выше
демонстрирует, как цикл while заменяет простую инструкцию for со счётчиком. Второй
пример показывает, как заменить цикл for, перебирающий элементы списка (в других
языках программирования известный как foreach).


.. _pass-statement:

Инструкция pass
---------------

Инструкция ``pass`` используется в ситуациях, когда синтаксис требует наличия блока,
но никакое действие выполнять не требуется. Она не делает ничего.

Например::

    if points >= 10:
        "У вас отличные результаты!"
    elif points >= 1:
        pass
    else:
        "Дела идут не очень хорошо."

::

    # event.step() — это функция, возвращающая True, пока ещё
    # остаются события, требующие выполнения.

    while event.step():
        pass
