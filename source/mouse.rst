=============================
Пользовательские курсоры мыши
=============================

В Ren'Py есть две системы создания пользовательских курсоров мыши. Первая использует
аппаратный курсор мыши операционной системы, а вторая отрисовывает отображаемый объект в позиции курсора.

Преимущества аппаратного курсора мыши:

* Высокая скорость реакции без задержек.
* Минимальные накладные расходы ресурсов, освобождающие процессорное время Ren'Py.

Ограничения аппаратного курсора:

* Ограничение по размеру: гарантируется поддержка 32x32 пикселей, на большинстве систем работает 64x64.
* Поддерживаются только статические изображения или покадровая анимация из файлов картинок.

Программный курсор на основе отображаемых объектов снимает эти ограничения: курсором может быть любой
отображаемый объект Ren'Py (включая сложные трансформации ATL и Live2D). Однако отрисовка выполняется
движком Ren'Py, поэтому при включённой тройной буферизации на компьютере может ощущаться небольшая
задержка отклика по сравнению с аппаратным курсором.


Аппаратный курсор мыши
----------------------

Аппаратный курсор настраивается с помощью переменной :var:`config.mouse`. Переменная представляет собой
словарь, сопоставляющий имена курсоров со списками кадров. Каждый кадр задаётся кортежем из трёх элементов:
пути к файлу изображения и смещений точки нажатия (хотспота) по осям X и Y внутри этого изображения.

Например::

    define config.mouse = { }
    define config.mouse['default'] = [ ( "gui/arrow.png", 0, 0) ]
    define config.mouse['spin' ] = [
        ( "gui/spin0.png", 7, 7 ),
        ( "gui/spin1.png", 7, 7 ),
        ( "gui/spin2.png", 7, 7 ),
        ( "gui/spin3.png", 7, 7 ),
        ( "gui/spin4.png", 7, 7 ),
        ( "gui/spin5.png", 7, 7 ),
        ( "gui/spin6.png", 7, 7 ),
        ( "gui/spin7.png", 7, 7 ),
    ]

Если анимация состоит из нескольких кадров, они воспроизводятся со скоростью 20 кадров/сек.
Ren'Py обновляет системный курсор только при изменении изображения или смещений.

В следующей таблице перечислены стандартные состояния курсора и контекст их использования:

.. list-table::
 :header-rows: 1

 * - Состояние
   - Назначение

 * - ``default``
   - Используется всегда, если не задано более специфичное состояние. Обязательно должен присутствовать.

 * - ``say``
   - Используется, когда на экране отображается окно диалога (Say).

 * - ``with``
   - Используется во время выполнения переходов.

 * - ``menu``
   - Используется в меню выбора (выборы в диалогах).

 * - ``prompt``
   - Используется при запросе текстового ввода от игрока.

 * - ``imagemap``
   - Используется при наведении на imagemap.

 * - ``button``
   - Используется при наведении курсора на кнопку или imagebutton.

 * - ``pause``
   - Используется во время паузы renpy.pause().

 * - ``mainmenu``
   - Используется в главном меню.

 * - ``gamemenu``
   - Используется в игровом меню (меню паузы).

К любому ключу можно добавить префикс ``pressed_``, определяющий вид курсора при зажатой кнопке мыши.
Например, ``pressed_button`` используется, когда пользователь нажимает кнопку. Ключ ``pressed_default``
задаёт вид зажатого курсора по умолчанию.

Например::

    define config.mouse = { }
    define config.mouse['default'] = [ ( "gui/arrow.png", 0, 0) ]
    define config.mouse['pressed_default'] = [ ( "gui/arrow_pressed.png", 0, 0) ]
    define config.mouse['button'] = [ ( "gui/arrow_button.png", 0, 0) ]
    define config.mouse['pressed_button'] = [ ( "gui/arrow_button_pressed.png", 0, 0) ]
    define config.mouse['menu'] = [ ( "gui/arrow_menu.png", 0, 0) ] # Курсор в меню
    # Поскольку "pressed_menu" не задан, при клике в меню используется "pressed_default"


Программный курсор (отображаемый объект)
----------------------------------------

Программный курсор настраивается с помощью переменной :var:`config.mouse_displayable`
и класса MouseDisplayable. Например::

    image mouse spin:
        "gui/spin0.png"
        rotate 0.0
        linear 1.0 rotate 360.0

        # Пауза для предсказания изображений
        pause 1.0

        repeat

    define config.mouse_displayable = MouseDisplayable(
        "gui/arrow.png", 0, 0).add("spin", "mouse spin", 9.9, 9.9)

.. include:: inc/mouse_displayable


Использование курсоров мыши
---------------------------

Стандартный способ назначения курсора — передача свойства ``mouse`` с именем курсора интерактивным
элементам экрана (кнопкам или полосам прокрутки)::

    screen test():
        textbutton "Тест мыши" action NullAction() mouse "spin"

Также можно изменить курсор глобально с помощью переменной :var:`default_mouse`::

    $ default_mouse = "spin"
