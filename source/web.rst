Веб / HTML5
===========

Ren'Py поддерживает запуск игр непосредственно в веб-браузере. Это реализовано с помощью
специальной версии Ren'Py, скомпилированной в WebAssembly, что позволяет перенести
максимально возможный объем функциональности Ren'Py в браузер. На этой странице
описаны ограничения работы в браузере, рекомендации по оптимизации игры и процедура
веб-сборки проекта.

Ограничения
-----------

Как и любые другие программы, работающие внутри веб-браузера, игры на Ren'Py имеют
ряд естественных ограничений. Некоторые из них накладываются песочницей (sandbox)
браузера, другие приняты намеренно для уменьшения объема данных, которые необходимо
скачать пользователю перед началом игры.

Среди основных ограничений:

* Воспроизведение видео выполняется встроенным медиаплеером браузера. Это ограничивает
  поддерживаемые форматы лишь теми, которые понимает сам браузер, а из функций Ren'Py
  поддерживается только :func:`renpy.movie_cutscene`.

* Для аудио может использоваться встроенная веб-аудиосистема браузера (она работает быстро)
  либо встроенная звуковая подсистема Ren'Py (она медленнее, но поддерживает больше форматов).
  Подробнее см. раздел ниже.

* Веб-порт не поддерживает многопоточность, поэтому вызовы :func:`renpy.invoke_in_thread`
  и стандартный модуль Python ``threading`` недоступны. Это также сказывается на производительности:
  в версиях для ПК и мобильных устройств фоновая предзагрузка изображений выполняется
  в отдельном потоке, тогда как в вебе это невозможно, и подгрузка графики может
  вызывать микрофризы кадровой частоты.

* Сетевые подключения не поддерживаются. Песочница безопасности браузера запрещает
  Ren'Py делать произвольные сетевые запросы через сокеты или библиотеку requests.

Кроме того, ограничения могут накладываться хостингом, где размещена игра. Некоторые
платформы ограничивают максимальный размер архива и количество файлов (например, см.
`требования к HTML5 на itch.io <https://itch.io/docs/creators/html5#zip-file-requirements>`_).
Браузеры также накладывают ограничения: файлы размером более 50 МБ обычно не кэшируются,
а значит, будут скачиваться заново при каждом запуске игры.

Поддерживаемые браузеры
-----------------------

Движок поддерживает работу в актуальных версиях современных браузеров (Chrome, Edge,
Firefox, Safari), а также в их мобильных версиях для iOS и Android. Работа в других
браузерах возможна, если они полноценно поддерживают WebAssembly и веб-стандарты,
требуемые Ren'Py.

Ren'Py задействует передовые возможности веб-платформы и не сможет работать, если
эти функции отключены или заблокированы в настройках браузера.

Сборка игры для веб
-------------------

Упаковка игр Ren'Py для веб осуществляется через раздел «Web (Beta)» в лаунчере.
В нём доступны четыре основных пункта:

Построить веб-приложение (Build Web Application)
    Упаковывает игру для веба. Будет создан архив :file:`web.zip`, содержащий всю игру,
    и папка с отдельными файлами проекта (прямой запуск игры из локальной папки без
    веб-сервера не поддерживается из-за политик безопасности CORS).

Построить и открыть в браузере (Build and Open in Browser)
    Собирает веб-версию игры и сразу запускает её в локальном браузере для тестирования.
    Лаунчер автоматически поднимает локальный веб-сервер на вашем компьютере и открывает страницу.
    Это стандартный способ тестирования веб-игры.

Открыть в браузере (Open in Browser)
    Запускает локальный веб-сервер и открывает браузер без повторной полной пересборки.

Открыть каталог сборки (Open build Directory)
    Открывает папку с результатами процесса веб-сборки на диске.


Создаваемые каталоги
--------------------

Если ваш проект находится в папке :file:`renpy/projects/main/yourproject`, лаунчер
создаст каталог :file:`renpy/projects/main/yourproject-1.0-dists`. Внутри него
будет находиться подкаталог :file:`yourproject-1.0-web` и готовый архив
:file:`yourproject-1.0-web.zip`.

Загрузка игры на сервер
-----------------------

После сборки игру необходимо загрузить на публичный веб-сервер. Для платформ вроде
itch.io достаточно загрузить архив :file:`web.zip`. При использовании собственного
хостинга загрузите всё содержимое сгенерированной веб-папки.

При самостоятельном хостинге убедитесь, что ваш веб-сервер отдаёт файлы ``.wasm``
с MIME-типом ``application/wasm``. Это существенно ускорит компиляцию WebAssembly
и устранит предупреждения в консоли браузера.

Некоторые хостинги могут отклонять файлы с расширением :file:`game.zip`. В этом случае
переименуйте файл в :file:`game.data` и отредактируйте :file:`index.html`, заменив
вхождение ``game.zip`` на ``game.data``.

.. _web-presplash:

Презаставка (Presplash)
-----------------------

По умолчанию веб-платформа использует стандартную презаставку Ren'Py. Чтобы заменить её,
поместите изображение с именем `web-presplash` и расширением `.jpg`, `.png` или `.webp`
в базовый каталог проекта.

Формат `.webp` позволяет использовать анимированную презаставку.

Иконка
------

Фавиконку веб-страницы можно настроить, добавив файл :file:`web-icon.png` в базовый
каталог проекта. Это изображение должно иметь квадратные пропорции и минимальное
разрешение 512x512 пикселей. Если файл отсутствует, используется стандартная иконка Ren'Py.

.. _progressive-downloading:

Постепенная загрузка (Progressive Downloading)
----------------------------------------------

Ren'Py поддерживает механизм прогрессивной догрузки данных, настраиваемый через файл
:file:`progressive_download.txt` в базовом каталоге проекта. Если этот файл отсутствует,
он будет автоматически создан при первой веб-сборке. Его стандартное содержимое::

    # RenPyWeb progressive download rules - first match applies"
    # '+' = progressive download, '-' = keep in game.data (default)
    # See https://www.renpy.org/doc/html/build.html#classifying-and-ignoring-files for matching
    #
    # +/- type path
    - image game/gui/**
    + image game/**
    + music game/audio/**
    + voice game/voice/**

Этот файл определяет, какие ресурсы скачиваются до запуска игры, а какие подгружаются
по мере необходимости в процессе игры. Строки с решёткой ``#`` — комментарии.
Строки с минусом ``-`` задают файлы, которые скачиваются сразу (обычно графика интерфейса
и заставки). Строки с плюсом ``+`` помечают файлы для отложенной загрузки по требованию.

Второй столбец указывает тип данных:

image
    Графические файлы изначально заменяются пикселизированной версией низкого разрешения
    и заменяются полным изображением по завершении загрузки. Во многих случаях Ren'Py
    успевает заранее предсказать и загрузить картинку в память, поэтому пикселизированная
    заглушка видна лишь при медленном соединении.
    
    Если полное изображение так и не появилось, проверьте правильность путей на веб-сервере.

music
    Музыкальные треки заменяются тишиной и начинают воспроизводиться сразу после загрузки.

voice
    Файлы озвучки заменяются тишиной и воспроизводятся после завершения загрузки.

Третий столбец содержит шаблон пути к файлам.


Аудио и видео
-------------

Из-за ограничений браузеров на автовоспроизведение рекламы со звуком музыка и звуковые
эффекты не будут воспроизводиться до тех пор, пока пользователь хотя бы один раз не
кликнет внутри окна игры.

Ren'Py поддерживает два способа воспроизведения звука: встроенную подсистему Web Audio
браузера и собственную программную аудиосистему Ren'Py. Система Web Audio работает быстрее,
однако браузер Safari не поддерживает формат OGG через Web Audio.

Переменная :var:`config.webaudio_required_types` управляет выбором аудиосистемы путём
проверки поддерживаемых браузером MIME-типов. Если в вашей игре используется только MP3,
можно задать::

    define config.webaudio_required_types = [ "audio/mpeg" ]

Воспроизведение видео также поддерживается и управляется двумя переменными:

:var:`config.web_video_base`
    Базовый URL, добавляемый перед именем файла видео для получения полного адреса
    воспроизведения. Может включать подкаталоги, например "https://share.renpy.org/movies-for-mygame/".
    Позволяет размещать тяжелые видеоролики на отдельном медиасервере или CDN.

:var:`config.web_video_prompt`
    В Mobile Safari на iOS для воспроизведения видео со звуком по умолчанию требуется клик
    пользователя. Эта переменная задаёт текст подсказки с предложением нажать на экран.

Кроме того, для Safari предусмотрен механизм фолбэка (fallback): если браузер не поддерживает
современный формат WebM, Ren'Py попытается автоматически загрузить файл с тем же именем
и расширением `.mp4` (например, при неудачной попытке воспроизвести oa4_launch.webm будет
запрошен файл oa4_launch.mp4).


JavaScript
----------

Ren'Py может выполнять произвольный код JavaScript с помощью трёх функций модуля
``emscripten``. Этот модуль доступен как :var:`renpy.emscripten` при работе на веб-платформе.
На всех остальных платформах значение renpy.emscripten равно False.


.. function:: renpy.emscripten.run_script(script)

    Выполняет указанный код JavaScript. Не возвращает результат.

.. function:: renpy.emscripten.run_script_int(script)

    Выполняет указанный код JavaScript и возвращает результат в виде целого числа.

.. function:: renpy.emscripten.run_script_string(script)

    Выполняет указанный код JavaScript и возвращает результат в виде строки.

Вы можете добавлять собственные функции JavaScript, редактируя файл :file:`web/index.html`
в шаблоне сборки. Обратите внимание: этот файл может быть перезаписан при обновлении Ren'Py.

Из JavaScript также можно обращаться к функциям Ren'Py с помощью методов `window.renpy_exc`,
`window.renpy_get` и `window.renpy_set`. Документацию по этим вызовам см. в :file:`web/renpy-pre.js`.


Меню «Гамбургер»
----------------

Кнопка меню «Гамбургер» расположена в левом верхнем углу окна игры и содержит три пункта:

Import saves
    Позволяет пользователю загрузить файлы сохранений Ren'Py и постоянные данные (persistent)
    со своего компьютера в веб-браузер.

Export saves
    Позволяет выгрузить ZIP-архив с сохранениями и постоянными данными игрока. Этот архив
    можно перенести в другой браузер, сохранить как резервную копию или распаковать
    в каталог сохранений ПК-версии игры.

Ren'Py log
    Скачивает текстовый файл журнала Ren'Py, содержащий отладочную информацию консоли.
