Прочие функции и переменные

Версия Ren'Py
-------------

.. include:: inc/renpy_version

.. var:: renpy.version_string

    Номер версии Ren'Py в виде строки формата «Ren'Py 1.2.3.456».

.. var:: renpy.version_only

    Номер версии Ren'Py без префикса «Ren'Py ». Строка формата «1.2.3.456».

.. var:: renpy.version_tuple

    Номер версии Ren'Py в виде кортежа формата (1, 2, 3, 456).

    Это именованный кортеж (namedtuple) с четырьмя полями: ``major``, ``minor``, ``patch``
    и ``commit``.

.. var:: renpy.version_name

    Человекочитаемое имя версии вида «Example Version».

.. var:: renpy.license

    Строка, содержащая текст лицензии, который должен быть включён в экран
    «Об игре» (about).

Определение платформы
---------------------

Ren'Py включает ряд переменных, значения которых устанавливаются в зависимости от
платформы, на которой выполняется игра.

.. var:: renpy.windows

    Имеет значение True при запуске в Windows.

.. var:: renpy.macintosh

    Имеет значение True при запуске в macOS.

.. var:: renpy.linux

    Имеет значение True при запуске в Linux или других POSIX-совместимых операционных системах.

.. var:: renpy.android

    Имеет значение True при запуске на Android.

.. var:: renpy.ios

    Имеет значение True при запуске на iOS.

.. var:: renpy.emscripten

    Имеет истинное значение при запуске в браузере. Этим значением является
    модуль emscripten, позволяющий взаимодействовать с браузером, см. :func:`renpy.emscripten.run_script`
    и аналогичные функции.

.. var:: renpy.mobile

    Имеет значение True при запуске на Android, iOS или в браузере.

Эти переменные устанавливаются только при запуске на реальных устройствах, а не в
эмуляторах. Они предназначены в основном для платформо-зависимого кода Python.
Для адаптации разметки интерфейса используйте :ref:`варианты экранов <screen-variants>`.

renpy.random
------------

Этот объект представляет собой генератор случайных чисел, реализующий
`интерфейс генерации случайных чисел Python <https://docs.python.org/library/random.html>`_.
Случайные значения можно получать вызовом различных методов этого объекта.
Полный список см. в документации Python, однако наиболее полезными являются:

* ``renpy.random.random()``

Возвращает следующее случайное вещественное число с плавающей точкой в диапазоне [0.0, 1.0).

* ``renpy.random.randint(a, b)``

Возвращает случайное целое число N, такое что a <= N <= b.

* ``renpy.random.choice(seq)``

Возвращает случайный элемент из непустой последовательности `seq`.

* ``renpy.random.shuffle(seq)``

Перемешивает элементы последовательности `seq` на месте (in-place). Не возвращает
новый список, а изменяет существующий.

В отличие от стандартного генератора случайных чисел Python, этот объект согласуется
с механизмом отката (rollback), генерируя одни и те же числа независимо от того, сколько раз
выполняется откат. Его следует использовать вместо стандартного модуля random Python. ::

    # возвращает случайное число с плавающей точкой от 0 до 1
    $ randfloat = renpy.random.random()

    # возвращает случайное целое число от 1 до 20
    $ d20roll = renpy.random.randint(1, 20)

    # возвращает случайный элемент из списка
    $ randfruit = renpy.random.choice(['apple', 'orange', 'plum'])

* ``renpy.random.Random(seed=None)``

Возвращает новый объект генератора случайных чисел, отдельный от основного, инициализированный
указанным значением зерна (seed), если оно передано.

SDL
---

Доступ к DLL SDL3 можно получить с помощью функции :func:`renpy.get_sdl_dll`.
Это позволяет использовать функции SDL3 напрямую. Однако для их использования часто
требуются знания модуля ctypes Python.

Гарантий относительно конкретной сборки SDL3, входящей в состав Ren'Py,
нет — в том числе относительно того, какие функции скомпилированы в библиотеку, а какие нет.
Эти функции могут завершаться ошибкой на платформах, где в остальном Ren'Py работает штатно.
Перед продолжением работы обязательно проверяйте возвращаемое значение на None.

В следующем примере позиция окна запрашивается из SDL3::

    init python:

        import ctypes

        def get_window_position():
            """Запрашивает положение окна из SDL3.

            Возвращает (x, y) верхнего левого угла окна или (0, 0),
            если оно неизвестно.
            """

            sdl = renpy.get_sdl_dll(3)

            if sdl is None:
                return (0, 0)

            win = renpy.get_sdl_window_pointer()

            if win is None:
                return (0, 0)

            x = ctypes.c_int()
            y = ctypes.c_int()

            result = sdl.SDL_GetWindowPosition(win, ctypes.byref(x), ctypes.byref(y))

            if result != 0:
                raise RuntimeError("Failed to get window position from SDL3.")

            return (x.value, y.value)
