Доступ к файлам

Эти функции Python предоставляют доступ к файлам ресурсов игры, которые могут находиться в каталоге game, в архивах RPA или в ресурсах Android (assets).

renpy.file(fn, encoding=None)

Псевдоним для renpy.open_file(), сохранённый для совместимости со старыми версиями Ren'Py.

renpy.list_files(common=False)

Возвращает список файлов в каталоге игры и в архивах RPA. В качестве разделителя каталогов в путях используется слэш /.

common

Если True, в результирующий список также включаются файлы из каталога common.

renpy.loadable(filename, directory=None, tl=True)

Возвращает True, если файл с именем filename доступен для загрузки (то есть может быть загружен с диска или из архива). В противном случае возвращает False.

directory

Если не None, задаёт каталог поиска на случай, если файл не найден в каталоге игры. Значение добавляется в начало пути filename при повторном поиске.

tl

Если True, поиск также выполняется в подкаталоге текущего перевода.

renpy.open_file(fn, encoding=None, directory=None)

Возвращает файлоподобный объект, открытый только для чтения, для доступа к файлу с именем fn. Поиск файла выполняется по стандартным правилам поиска Ren'Py — файл может находиться в каталоге игры, в архиве RPA или в ресурсах Android (assets).

Объект поддерживает большинство полей и методов стандартного файлового объекта Python, открытого в двоичном режиме (в частности, все методы, применимые к файлам, открытым только для чтения).

encoding

Если указано, файл открывается в текстовом режиме с заданной кодировкой. Если False, файл открывается в двоичном режиме. Если None (по умолчанию), кодировка определяется переменной config.open_file_encoding. В большинстве случаев значение None открывает файл в двоичном режиме.

directory

Если не None, задаёт каталог поиска на случай, если файл не найден в каталоге игры. Значение добавляется в начало пути filename при повторном поиске.

Возвращает объект io.BufferedReader, если кодировка None, или объект io.TextIOWrapper, если указана кодировка.

Редко используемые функции

Эти функции используются реже.

renpy.exists(filename)

Возвращает True, если файл с именем filename найден в путях поиска. Работает только для физических файлов на диске и не обнаруживает файлы внутри архивов.

В большинстве случаев вместо этой функции рекомендуется использовать renpy.loadable().

renpy.fsdecode(s: str | bytes) → str

Преобразует строку s из кодировки файловой системы в строку Юникода.

renpy.fsencode(s: str | bytes, force: bool = False) → str | bytes

Преобразует строку Юникода s в кодировку файловой системы.

renpy.image_size(im)

Принимает манипулятор изображений, загружает его и возвращает кортеж (width, height) с его размерами.

Функция считывает изображение с диска и распаковывает его в обход кэша изображений, поэтому её выполнение может быть медленным.
