Сетевые запросы HTTPS/HTTP

Ren'Py поддерживает получение данных по протоколам HTTP и HTTPS с помощью функции renpy.fetch(). Эта функция:

  • Поддерживает запросы методов GET, POST и PUT.

  • Поддерживает отправку необработанных данных (data) или структур JSON на сервер.

  • Может возвращать результат в виде байтов (bytes), строки (text) или объекта JSON.

Функция renpy.fetch() предназначена для вызова из основного потока Ren'Py после старта игры. Она работает на ПК, мобильных платформах и в браузере (веб). При работе в браузере запросы к сторонним серверам (отличным от того, с которого загружена сама игра) требуют поддержки сервером политики CORS.

Простой пример получения новостей с сервера:

$ news = renpy.fetch("https://example.com/news.txt", result="text")
"Свежие новости: [news]"

Пример отправки данных JSON на сервер с получением ответа в формате JSON:

$ result = renpy.fetch("https://example.com/api", json={"name": "Ren'Py"}, result="json")

Как и в любых сетевых приложениях, при использовании renpy.fetch() необходимо учитывать вопросы безопасности, особенно при отображении медиафайлов, полученных из сети (Ren'Py не содержит механизмов защиты от вредоносных изображений, видеороликов и аудиофайлов).

Прогресс выполнения активных сетевых запросов можно отображать на полосе прогресса с помощью значения шкалы FetchProgressValue.

renpy.fetch(url, method=None, data=None, json=None, content_type=None, timeout=5, result='bytes', params=None, headers={})

Выполняет HTTP- (или HTTPS-) запрос по указанному URL и возвращает содержимое ответа. При возникновении ошибки возбуждает исключение FetchError с описанием сбоя (которое, однако, может не подходить для непосредственного показа игроку).

url

URL-адрес для выполнения запроса.

method

Используемый метод HTTP-запроса. Обычно "GET", "POST" или "PUT", однако поддерживаются и другие стандартные методы. Если параметры data или json заданы (не None), по умолчанию используется "POST", иначе — "GET".

data

Если указано, байтовая строка данных для отправки в теле запроса.

json

Если указано, JSON-объект для отправки в теле запроса. Имеет приоритет над data.

content_type

Тип содержимого (MIME-тип). Если не указан, по умолчанию принимает значение "application/json", если передан параметр json, либо "application/octet-stream" в противном случае. Применяется только при запросах POST или PUT.

timeout

Время ожидания ответа сервера в секундах.

result

Способ обработки полученного результата. Значение "bytes" возвращает необработанные байты ответа. Значение "text" декодирует ответ в кодировке UTF-8 и возвращает строку Юникода. Значение "json" декодирует ответ как структуру JSON (при ошибках формата могут возникать исключения процесса декодирования).

params

Словарь параметров, добавляемых к URL в виде строки запроса (query string).

headers

Словарь HTTP-заголовков, отправляемых вместе с запросом.

Функцию можно вызывать как внутри, так и вне интеракции:

  • Вне интеракции в процессе ожидания ответа в пределах таймаута движок периодически вызывает renpy.pause(), не позволяя игре зависнуть. В этот момент имеет смысл отобразить экран с сообщением о ходе загрузки.

  • Внутри интеракции (например, внутри действия Action) функция блокирует графическую подсистему до завершения запроса или таймаута. При этом аудиоподсистема продолжает обслуживаться, сохраняя непрерывность воспроизведения звука.

Функция работает на всех платформах. Однако в веб-версии браузерные запросы к сторонним источникам завершаются ошибкой, если они не разрешены политикой CORS.

renpy.get_fetch_progress() → float

Возвращает прогресс активных сетевых запросов в виде числа с плавающей запятой от 0.0 до 1.0. Если в данный момент запросы не выполняются, возвращает 1.0.

Библиотека Requests

На настольных и мобильных платформах в состав Ren'Py входит библиотека Requests. Она предоставляет более широкие возможности, однако не так глубоко интегрирована в цикл событий Ren'Py (например, renpy.fetch() во время ожидания данных периодически вызывает renpy.pause(), тогда как функции Requests блокируют поток выполнения, что может приводить к прерываниям звука и задержкам анимации).
