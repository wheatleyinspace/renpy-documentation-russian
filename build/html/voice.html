Озвучка

Ren'Py поддерживает воспроизведение голосовой озвучки синхронно с диалогом. Для этого используется инструкция voice, которой передаётся имя воспроизводимого аудиофайла:

voice "line0001.ogg"
"Добро пожаловать в Ren'Py"

Как правило, звучание голоса прекращается при переходе к следующему взаимодействию (клику игрока). Инструкция voice sustain позволяет продлить воспроизведение голоса сквозь смену диалоговых реплик.

voice "line0001.ogg"
"Добро пожаловать в Ren'Py..."

voice sustain
"...ваш движок создания визуальных новелл."

Переменная config.voice_filename_format позволяет настроить шаблон имён файлов озвучки, избавляя от необходимости каждый раз прописывать каталоги и расширения.

Теги озвучки

Ren'Py включает систему тегов озвучки, позволяющую выборочно включать или заглушать голоса конкретных персонажей. Чтобы воспользоваться этой системой, передайте аргумент voice_tag при объявлении каждого Character() и используйте действия SetVoiceMute() или ToggleVoiceMute(), дающие игроку возможность переключать воспроизведение голоса.

Например:

define e = Character("Эйлин", voice_tag="eileen")
define l = Character("Люси", voice_tag="lucy")

screen voice_toggle:
    vbox:
        textbutton "Заглушить Эйлин" action ToggleVoiceMute("eileen")
        textbutton "Заглушить Люси" action ToggleVoiceMute("lucy")

label start:
    show screen voice_toggle

    voice "e01.ogg"
    e "Голос каждого персонажа можно включать и отключать отдельно."

    voice "l01.ogg"
    l "Да! Наконец-то я смогу заставить тебя замолчать!"

    voice "l02.ogg"
    l "Погоди... получается, они и меня могут заглушить?! Серьёзно?"

Автоматическая озвучка

Ren'Py умеет автоматически определять файл озвучки для каждой реплики, позволяя озвучивать игру без необходимости вручную прописывать инструкции voice перед каждой строкой диалога.

Для этого аудиофайлы именуются в соответствии с уникальными идентификаторами строк сценария. Чтобы узнать эти идентификаторы, экспортируйте диалоги в таблицу через лаунчер Ren'Py: выберите «Извлечь диалог» (Extract Dialogue), затем «Таблица с разделителями-табуляциями (dialogue.tab)» и нажмите «Продолжить». Будет создан файл dialogue.tab, который можно открыть в табличном редакторе.

Первый столбец таблицы содержит идентификатор реплики, а остальные столбцы дают дополнительную информацию о тексте и персонаже.

Чтобы включить автоматическую озвучку в Ren'Py, присвойте переменной config.auto_voice строку, содержащую шаблон {id}. При выводе диалога маркер {id} заменяется идентификатором реплики, образуя имя файла. Если файл с таким именем существует, движок воспроизводит его.

Например, если задано:

config.auto_voice = "voice/{id}.ogg"

И идентификатор реплики равен demo_minigame_03fc91ef, то при показе этой строки Ren'Py попытается загрузить файл voice/demo_minigame_03fc91ef.ogg. Если файл найден, он будет воспроизведён.

Многоязычная озвучка

Чтобы задействовать систему перевода Ren'Py при дубляже игры на несколько языков, можно использовать перевод файлов изображений и ресурсов. Для игры, оригинальный язык которой английский, а дубляж выполнен на французском, при наличии диалога:

voice "omelette.ogg"
e "Я люблю яичницу с сыром..."

Размещение английского аудиофайла в game/omelette.ogg, а французского перевода в game/tl/french/omelette.ogg приведёт к тому, что Ren'Py автоматически выберет французскую версию аудио при переключении игры на французский язык.

Этот же механизм работает и для автоматической озвучки, если относительный путь файла перевода внутри game/tl/<язык>/ совпадает с относительным путем оригинального файла в каталоге game/.

Функции озвучки

_get_voice_info()

Возвращает информацию об озвучке, воспроизводимой текущей инструкцией say. Эту функцию можно вызывать только во время выполнения инструкции say.

Возвращаемый объект имеет следующие поля:

VoiceInfo.filename

Имя файла воспроизводимого голоса или None, если аудиофайл не должен воспроизводиться.

VoiceInfo.auto_filename

Имя файла, которое Ren'Py искал для целей автоозвучивания, или None, если файл не был найден.

VoiceInfo.tag

Параметр voice_tag, переданный говорящему персонажу Character.

VoiceInfo.sustain

False, если файл был запущен в рамках этого взаимодействия. True, если он был удержан из предыдущего взаимодействия с помощью voice sustain.

voice(filename, tag=None)

Воспроизводит filename в канале voice. Эквивалент инструкции voice в сценарии Ren'Py.

filename

Имя воспроизводимого файла. Используется совместно с config.voice_filename_format для формирования итогового пути к файлу.

tag

Если не None, строка, задающая тег озвучки. Если None, значение по умолчанию берётся из параметра voice_tag персонажа Character, вызывающего следующее взаимодействие.

Тег озвучки используется для указания говорящего персонажа, чтобы игрок мог индивидуально заглушать или включать голоса конкретных героев.

voice_can_replay()

Возвращает True, если текущую реплику озвучки можно воспроизвести повторно.

voice_replay()

Повторно воспроизводит текущую реплику озвучки, если это возможно.

voice_sustain(ignored='', **kwargs)

Эквивалент инструкции voice sustain в сценарии Ren'Py.

Действия озвучки

PlayCharacterVoice(voice_tag, sample, selected=False)

Воспроизводит аудиофайл sample в канале voice так, как если бы его произнёс персонаж с тегом voice_tag. Это действие устанавливает громкость персонажа, но не выполняет другую связанную с репликами обработку файла — оно предназначено для использования в меню настроек, чтобы помочь игроку настроить громкость голоса персонажа.

voice_tag

Тег озвучки говорящего персонажа. Используется для определения уровня громкости.

sample

Полный путь к аудиофайлу примера.

selected

Если True, кнопки, использующие это действие, будут отмечены как выбранные (selected) во время воспроизведения аудиофайла.

SetCharacterVolume(voice_tag, volume=None)

Позволяет настраивать громкость голоса отдельных персонажей. Если volume равно None, возвращает значение BarValue, управляющее громкостью для voice_tag. В противном случае устанавливает громкость равной volume.

volume — число от 0.0 до 1.0, интерпретируемое как доля от общей громкости микшера канала voice.

SetVoiceMute(voice_tag, mute)

Если mute равно True, заглушает голоса, воспроизводимые с данным voice_tag. Если mute равно False, включает воспроизведение голосов с данным voice_tag.

ToggleVoiceMute(voice_tag, invert=False)

Переключает режим заглушения для voice_tag. Кнопка считается выбранной (selected), если указанный тег заглушён, если только invert не равно True (в этом случае кнопка выбрана, если голос включён).

VoiceReplay()

Повторно воспроизводит самую последнюю прозвучавшую реплику озвучки.
