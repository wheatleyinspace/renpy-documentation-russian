Продвинутый GUI

В этом разделе собраны различные сведения о продвинутом использовании GUI.

Функции Python

Для поддержки работы GUI существует несколько функций Python.

gui.button_properties(kind)

Принимая тип (kind) кнопки, возвращает словарь со стандартными свойствами стиля для этой кнопки. Устанавливает:

background

Как описано ниже.

padding

В значение gui.kind_borders.padding (если существует).

xsize

В значение gui.kind_width (если существует).

ysize

В значение gui.kind_height (если существует).

(Обратите внимание: если kind равен строке "nvl_button", будет искаться переменная gui.nvl_button_background.)

Фон (background) представляет собой фрейм (кадр), который берет фоновое изображение из первого существующего файла:

  • gui/button/kind_[prefix_].background.png

  • gui/button/[prefix_].background.png

Если переменная gui с именем gui.kind_borders существует, используется она. В противном случае используется gui.button_borders. Если переменная gui.kind_tile существует, она определяет, будут ли границы мозаичными (tiled), иначе мозаичностью управляет gui.button_tile.

О том, что означает [prefix_], см. в документации поиск префиксов стилей.

gui.init(width, height, fov=75)

Инициализирует GUI.

width

Ширина окна по умолчанию.

height

Высота окна по умолчанию.

fov

Угол обзора (field of view) 3D-сцены.

gui.rebuild()

Пересобирает GUI.

Примечание: Это очень медленная функция.

gui.text_properties(kind=None, accent=False)

Принимая тип (kind) текстовой кнопки (textbutton), возвращает словарь со стандартными свойствами стиля для текста внутри этой кнопки. Устанавливает:

font

В значение gui.kind_text_font, если существует.

size

В значение gui.kind_text_size, если существует.

xalign

В значение gui.kind_text_xalign, если существует.

textalign

В значение gui.kind_text_xalign, если существует.

layout

В значение "subtitle", если gui.kind_text_xalign больше нуля и меньше единицы.

Также имеется ряд переменных, устанавливающих свойство стиля текста color:

color

В значение gui.kind_text_color, если существует. Если переменная не задана, а accent равен True, устанавливает цвет текста в цвет акцента по умолчанию.

insensitive_color

В значение gui.kind_text_insensitive_color, если существует.

idle_color

В значение gui.kind_text_idle_color, если существует.

hover_color

В значение gui.kind_text_hover_color, если существует.

selected_color

В значение gui.kind_text_selected_color, если существует.

Все остальные свойства стиля текста также доступны. Когда kind не равен None, свойства стиля позиционирования также доступны. Например, gui.kind_text_outlines устанавливает свойство стиля outlines (обводка), gui.kind_text_kerning устанавливает kerning (кернинг) и так далее.

gui.variant(f, variant=None)

Декоратор, вызывающий функцию при первой инициализации GUI и повторно при каждой пересборке GUI. Предназначен для использования в качестве декоратора функций вида:

@gui.variant
def small():
    gui.text_size = 30
    # ...

Его также можно вызывать с аргументами f (функция) и variant (строка), указывающим имя варианта.

gui.button_text_properties(kind=None, accent=False):

Устаревший псевдоним для gui.text_properties().

Подробнее о gui.rebuild

Функция gui.rebuild — это довольно медленная функция, которая обновляет GUI в соответствии с текущим состоянием Ren'Py. Она выполняет следующие действия:

  • Повторно выполняет все операторы define, определяющие переменные в пространстве имен gui.

  • Повторно выполняет все блоки translate python для текущего языка.

  • Повторно выполняет все операторы style.

  • Пересобирает все стили в системе.

Обратите внимание, что блоки init python не выполняются повторно при вызове gui.rebuild. Поэтому

define gui.text_size = persistent.text_size

и:

init python:
    gui.text_size = persistent.text_size

работают по-разному.

Оператор default, пространство имен gui и gui.rebuild

Оператор default имеет измененную семантику при применении к пространству имен gui. При применении к переменной в пространстве имен gui оператор default выполняется вперемежку с оператором define, и операторы default не выполняются повторно при вызове gui.rebuild().

Это означает, что если у нас есть:

default gui.accent_color = "#c04040"
define gui.hover_color = gui.accent_color

При первом запуске игры будет установлен цвет акцента, а затем цвет наведения будет установлен равным цвету акцента. (Оба они затем используются для установки различных цветов стиля.)

Однако если в ходе сценария игры выполняется:

$ gui.accent_color = "#4040c0"
$ gui.rebuild()

Ren'Py перезапустит только define, поэтому он установит цвет наведения в соответствии с цветом акцента, а затем обновит стили. Это позволяет создавать элементы GUI, которые меняются по ходу игры.

При установке переменных gui во время выполнения может потребоваться вызвать gui.rebuild в метке after_load:

label after_load:
    $ gui.rebuild()
    return

Это относится только к переменным, заданным с помощью default. Все переменные в пространстве имен gui должны задаваться с помощью default или define.

Настройки GUI

Ren'Py также поддерживает систему настроек GUI, состоящую из одной функции и пары действий.

gui.SetPreference(name, value, rebuild=True)

Это действие (Action) устанавливает для настройки GUI с именем name значение value.

rebuild

Если True (по умолчанию), вызывается gui.rebuild(), чтобы изменения вступили в силу. Обычно этот параметр должен иметь значение True, за исключением случаев одновременного вызова нескольких действий gui.SetPreference, когда для всех, кроме последнего, следует передавать False.

Это очень медленное действие, и, вероятно, оно не подходит для использования при наведении курсора на кнопку (hovered).

gui.TogglePreference(name, a, b, rebuild=True)

Это действие (Action) переключает настройку GUI с именем name между значением a и значением b. Считается выбранным (selected), если значение равно a.

rebuild

Если True (по умолчанию), вызывается gui.rebuild(), чтобы изменения вступили в силу. Обычно этот параметр должен иметь значение True, за исключением случаев одновременного вызова нескольких действий gui.SetPreference, когда для всех, кроме последнего, следует передавать False.

Это очень медленное действие, и, вероятно, оно не подходит для использования при наведении курсора на кнопку (hovered).

gui.preference(name, default=...)

Эта функция возвращает значение настройки GUI с именем name.

default

Если указано, это значение становится значением по умолчанию для настройки GUI. Значение по умолчанию должно быть указано при первом использовании настройки.

Пример

Система настроек GUI используется путем вызова gui.preference() при определении переменных, с указанием имени настройки и значения по умолчанию. Например, настройки GUI можно использовать для задания шрифта и размера текста.

define gui.text_font = gui.preference("font", "DejaVuSans.ttf")
define gui.text_size = gui.preference("size", 22)

Затем можно использовать действия gui.SetPreference и gui.TogglePreference для изменения значений настроек. Вот несколько примеров, которые можно добавить на экран настроек (preferences).

vbox:
    style_prefix "check"
    label _("Опции")
    textbutton _("OpenDyslexic") action gui.TogglePreference("font", "OpenDyslexic-Regular.otf", "DejaVuSans.ttf")

vbox:
    style_prefix "radio"
    label _("Размер текста")
    textbutton _("Мелкий") action gui.SetPreference("size", 20)
    textbutton _("Средний") action gui.SetPreference("size", 22)
    textbutton _("Крупный") action gui.SetPreference("size", 24)
