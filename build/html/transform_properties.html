Свойства трансформаций

Свойства трансформаций используются в трансформациях для управления тем, как отображается графический объект. Обычно они задаются с помощью ATL или класса Transform.

Список свойств трансформаций

Доступны следующие свойства трансформаций.

Когда тип указан как position, его относительный компонент интерпретируется как доля от размера содержащей области (для pos) или от размера самого отображаемого объекта (для anchor).

Обратите внимание, что не все свойства независимы. Например, xalign и xpos изменяют одни и те же базовые параметры. В операторе parallel не следует изменять взаимосвязанные свойства в нескольких параллельных ветках. Свойства угла и радиуса задают одновременно горизонтальную и вертикальную координаты.

Позиционирование

pos
Type:

(position, position)

Default:

(0, 0)

Положение относительно верхнего левого угла содержащей области.

xpos
Type:

position

Default:

0

Положение по горизонтали относительно левого края содержащей области.

ypos
Type:

position

Default:

0

Положение по вертикали относительно верхнего края содержащей области.

anchor
Type:

(position, position)

Default:

(0, 0)

Точка привязки относительно верхнего левого угла отображаемого объекта.

xanchor
Type:

position

Default:

0

Положение точки привязки по горизонтали относительно левого края отображаемого объекта.

yanchor
Type:

position

Default:

0

Положение точки привязки по вертикали относительно верхнего края отображаемого объекта.

align
Type:

(float, float)

Default:

(0.0, 0.0)

Эквивалентно установке одинаковых значений для pos и anchor.

xalign
Type:

float

Default:

0.0

Эквивалентно установке этого значения для xpos и xanchor.

yalign
Type:

float

Default:

0.0

Эквивалентно установке этого значения для ypos и yanchor.

offset
Type:

(absolute, absolute)

Default:

(0, 0)

Смещение отображаемого объекта в пикселях по обоим направлениям. Положительные значения сдвигают объект вправо и вниз.

xoffset
Type:

absolute

Default:

0

Смещение отображаемого объекта в пикселях по горизонтали. Положительные значения сдвигают объект вправо.

yoffset
Type:

absolute

Default:

0

Смещение отображаемого объекта в пикселях по вертикали. Положительные значения сдвигают объект вниз.

xycenter
Type:

(position, position)

Default:

(0.0, 0.0)

Эквивалентно установке pos в переданное значение, а anchor в (0.5, 0.5).

xcenter
Type:

position

Default:

0.0

Эквивалентно установке xpos в переданное значение, а xanchor в 0.5.

ycenter
Type:

position

Default:

0.0

Эквивалентно установке ypos в переданное значение, а yanchor в 0.5.

subpixel
Type:

boolean

Default:

False

Если True, дочерний объект позиционируется с субпиксельной точностью.

Субпиксельное позиционирование влияет на сглаживание цветов и прозрачность пикселей на границах при движении, предотвращая дискретное подергивание.

Вращение

rotate
Type:

float or None

Default:

None

Если не None, поворачивает изображение по часовой стрелке на указанное число градусов. Поворот изменяет размер контейнера согласно настройке rotate_pad.

rotate_pad
Type:

boolean

Default:

True

Если True, вокруг повернутого объекта добавляются поля, равные гипотенузе исходных ширины и высоты, гарантируя постоянный размер контейнера при вращении. Если False, контейнер принимает минимальный описывающий размер.

transform_anchor
Type:

boolean

Default:

False

Если True, точка привязки anchor масштабируется и поворачивается вместе с объектом, становясь центром вращения и масштабирования.

Масштаб и отражение

zoom
Type:

float

Default:

1.0

Масштабирует отображаемый объект с указанным коэффициентом.

xzoom
Type:

float

Default:

1.0

Масштабирует объект по горизонтали. Отрицательное значение зеркально отражает объект по горизонтали.

yzoom
Type:

float

Default:

1.0

Масштабирует объект по вертикали. Отрицательное значение зеркально отражает объект по вертикали.

Пиксельные эффекты

nearest
Type:

boolean

Default:

None

Если True, объект отрисовывается с фильтрацией по ближайшему соседу (nearest-neighbor). Если False — с билинейной фильтрацией. Если None — наследуется от родителя или config.nearest_neighbor.

alpha
Type:

float

Default:

1.0

Управляет непрозрачностью отображаемого объекта от 0.0 (полностью прозрачный) до 1.0 (полностью непрозрачный).

additive
Type:

float

Default:

0.0

Степень аддитивного смешивания цветов. При 1.0 используется оператор ADD, при 0.0 — стандартный OVER.

matrixcolor
Type:

None or Matrix or MatrixColor

Default:

None

Цветовая матрица для перекрашивания отображаемого объекта. Подробнее см. Matrixcolor.

blur
Type:

None or float

Default:

None

Размывает отображаемый объект на указанное число пикселей blur.

Полярное позиционирование

around
Type:

(position, position)

Default:

(0.0, 0.0)

Задает точку отсчета, от которой откладывается полярный вектор (вычисленный из angle и radius). Сумма дает итоговую позицию pos.

angle
Type:

float

Угол полярных координат в градусах: 0 — вверх, 90 — вправо.

radius
Type:

position

Радиус полярных координат. Число с плавающей точкой масштабируется к меньшему из доступных измерений ширины и высоты.

Полярное позиционирование точки привязки

Примечание

Хотя полярные координаты точки привязки поддерживаются, часто удобнее установить anchor в (0.5, 0.5) и позиционировать центр объекта.

anchoraround
Type:

(position, position)

Точка отсчета полярных координат внутри отображаемого объекта.

anchorangle
Type:

(float)

Угол полярных координат точки привязки в градусах.

anchorradius
Type:

(position)

Радиус полярных координат точки привязки. Рекомендуется передавать целые числа или absolute() значения.

Обрезка и изменение размера

crop
Type:

None or (position, position, position, position)

Default:

None

Обрезает объект до прямоугольника (x, y, width, height). Координаты отсчитываются от верхнего левого угла дочернего объекта.

corner1
Type:

None or (position, position)

Default:

None

Верхний левый угол рамки обрезки.

corner2
Type:

None or (position, position)

Default:

None

Нижний правый угол рамки обрезки.

xysize
Type:

None or (position, position)

Default:

None

Масштабирует объект до указанных размеров (ширина, высота). Эквивалентно одновременной установке xsize и ysize.

xsize
Type:

None or position

Default:

None

Задает ширину отображаемого объекта.

ysize
Type:

None or position

Default:

None

Задает высоту отображаемого объекта.

fit
Type:

None or string

Default:

None

Управляет режимом подгонки размеров:

Значение

Описание

contain

Максимально возможный размер без выхода за границы контейнера с сохранением пропорций.

cover

Минимально возможный размер, покрывающий всю площадь контейнера с сохранением пропорций.

None или fill

Растягивает объект для точного совпадения с размерами без сохранения пропорций.

scale-down

Как contain, но никогда не увеличивает исходный размер объекта.

scale-up

Как cover, но никогда не уменьшает исходный размер объекта.

Панорамирование и замощение

xpan
Type:

None or float

Default:

None

Угол горизонтального панорамирования по круговой панораме 360 градусов (от -180 до 180).

ypan
Type:

None or float

Default:

None

Угол вертикального панорамирования.

xtile
Type:

int

Default:

1

Количество повторений (замощений) изображения по горизонтали.

ytile
Type:

int

Default:

1

Количество повторений (замощений) изображения по вертикали.

Переходы

См. раздел Переходы ATL.

delay
Type:

float

Default:

0.0

Длительность перехода в секундах, если трансформация используется в качестве перехода.

events
Type:

boolean

Default:

True

Если True, события пользовательского ввода передаются дочернему элементу трансформации. Если False — блокируются (полезно для старого виджета old_widget при переходах).

Другие свойства

fps
Type:

float or None

Default:

None

Дискретизирует время внутри трансформации (например, fps=10 имитирует 10 кадров в секунду).

show_cancels_hide
Type:

boolean

Default:

True

Если True, появление нового объекта с тем же тегом отменяет трансформацию скрытия (hide) старого.

Порядок применения свойств

Свойства трансформаций применяются в следующем строгом порядке:

  1. fps

  2. mesh, blur

  3. tile

  4. pan

  5. crop, corner1, corner2

  6. xysize, size, maxsize

  7. zoom, xzoom, yzoom

  8. point_to

  9. orientation

  10. xrotate, yrotate, zrotate

  11. rotate

  12. zpos

  13. matrixtransform, matrixanchor

  14. zzoom

  15. perspective

  16. nearest, blend, alpha, additive, shader

  17. matrixcolor

  18. Свойства GL, Uniform-переменные

  19. Свойства позиционирования

  20. show_cancels_hide

Устаревшие свойства трансформаций

Предупреждение

Следующие свойства не рекомендуется использовать в современных проектах. Они сохранены исключительно для обратной совместимости.

alignaround
Type:

(float, float)

Устанавливает одинаковые значения для anchor, around и anchoraround.

crop_relative
Type:

boolean

Default:

True

Если False, числа с плавающей точкой в crop интерпретируются как абсолютные пиксели. Вместо этого рекомендуется использовать тип absolute().

size
Type:

None or (int, int)

Default:

None

Устаревшая версия xysize.

maxsize
Type:

None or (int, int)

Default:

None

Вместо этого используйте xysize со свойством fit равным "contain".
