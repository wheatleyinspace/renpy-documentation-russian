Эквиваленты инструкций на Python

Чтобы Ren'Py можно было программировать на чистом Python, каждая инструкция Ren'Py имеет свой эквивалент на Python. Обычно это отдельная функция Python, но также может быть последовательность вызовов Python, выполняющих действие, эквивалентное данной инструкции.

Обратите внимание, что использование эквивалентов инструкций вместо исходных инструкций языка скрипта обычно отключает возможные проверки линтером (Инструмент Lint) и оптимизации предсказания (prediction), делая игру менее доступной для автоматической проверки и потенциально менее плавной. В некоторых случаях это может также отключать определённые возможности движка.

Диалог

Предупреждение

Некоторые функции, такие как пропуск уже прочитанных диалогов, недоступны при использовании версии на Python и работают только при использовании встроенной инструкции say.

Инструкция Инструкция say в Ren'Py эквивалентна вызову объекта персонажа (когда он указан) как функции. Вывод слов рассказчика (когда персонаж не указан) можно выполнять аналогичным образом с помощью персонажа narrator.

e "Hello, world."
$ e("Hello, world.")

"And then the sun exploded."
$ narrator("And then the sun exploded.")

Прокси-функции

Эта эквивалентность между объектами персонажей и вызываемыми объектами функций работает и в обратную сторону. Можно объявить функцию Python, а затем использовать её на месте объекта персонажа во встроенной инструкции say. Например, следующая функция использует переменную для выбора между двумя персонажами.

define lucy_normal = Character("Lucy")
define lucy_evil = Character("Evil Lucy")

init python:

    def l(what, **kwargs):
        if lucy_is_evil:
            lucy_evil(what, **kwargs)
        else:
            lucy_normal(what, **kwargs)

label start:

    $ lucy_is_evil = False

    l "Usually, I feel quite normal."

    $ lucy_is_evil = True

    l "But sometimes, I get really mad!"

Функция, используемая таким образом, должна либо игнорировать неизвестные именованные аргументы, либо передавать их функции персонажа. Это позволит игре продолжать нормально работать, если будущие версии Ren'Py добавят дополнительные именованные аргументы к вызовам персонажей.

Обратите внимание, что в отличие от других возможных аргументов, параметр interact=True всегда передаётся функции, если только вручную не передан аргумент (interact=False). Инструкция Инструкция say с аргументами передаёт аргументы (включая дополнительный interact) функции. Например:

e "Hello, world." (what_size=32)

разворачивается в следующий вызов:

e("Hello, world.", what_size=32, interact=True)

При вызове объекта Character напрямую передавать interact=True не обязательно. Следующий вызов работает точно так же:

$ e("Hello, world.", what_size=32)

Когда e является Character, это также эквивалентно следующему:

$ Character(kind=e, what_size=32)("Hello, world.")

Однако можно использовать config.say_arguments_callback или обернуть персонаж в функцию e для изменения поведения.

Существует ещё один способ замены инструкции say на Python:

renpy.say(who, what, *args, **kwargs)

Эквивалент инструкции say.

who

Персонаж, произносящий реплику, None для рассказчика (narrator) или строка с именем персонажа. В последнем случае вызывается функция хранилища say.

what

Строка с репликой. В этой строке выполняются подстановки процентов.

interact

Если True, Ren'Py ожидает ввода игрока при отображении диалога. Если False, Ren'Py отображает диалог, но не выполняет взаимодействие. (Передаётся в виде именованного аргумента.)

Эта функция требуется редко, поскольку следующие три строки эквивалентны.

e "Hello, world."
$ renpy.say(e, "Hello, world.")
$ e("Hello, world.") # когда e не является строкой
$ say(e, "Hello, world.") # когда e — строка

Управление окном диалога

Управление окном осуществляется установкой переменных _window и _window_auto, а также вызовом следующих двух функций:

_window_hide(trans=False, auto=False)

Эквивалент инструкции window hide на Python.

trans

Если False, используется переход скрытия окна по умолчанию. Если None, переход не используется. В противном случае используется указанный переход.

auto

Если True, становится эквивалентом инструкции window auto hide.

_window_show(trans=False, auto=False)

Эквивалент инструкции window show на Python.

trans

Если False, используется переход показа окна по умолчанию. Если None, переход не используется. В противном случае используется указанный переход.

auto

Если True, становится эквивалентом инструкции window auto show.

Меню выбора

Инструкция menu имеет эквивалентную функцию Python.

class renpy.Choice(value, /, *args, **kwargs)

Инкапсулирует вариант выбора меню с аргументами. Первый позиционный аргумент — это значение, которое будет возвращено, а остальные аргументы передаются в экран выбора (choice screen).

Предназначен для использования в списке items функции renpy.display_menu() для передачи аргументов этому экрану.

value

Значение, передаваемое в экран выбора.

Позиционные и именованные аргументы сохраняются в этом объекте и используются renpy.display_menu.

renpy.display_menu(items, *, interact=True, screen='choice', type='menu', _layer=None, args=None, kwargs=None)

Отображает меню пользователю. items должен быть списком кортежей из двух элементов. В каждом кортеже первый элемент — это текстовая метка, а второй — значение, возвращаемое при выборе этого пункта. Если значение равно None, первый элемент используется как заголовок меню.

Эта функция принимает множество необязательных аргументов, из которых описаны лишь основные. За исключением items, все аргументы должны передаваться как именованные.

interact

Если False, меню отображается, но взаимодействие с пользователем не выполняется.

screen

Имя экрана, используемого для отображения меню.

type

Может быть "menu" или "nvl". Если "nvl", меню отображается в режиме NVL. В противном случае оно отображается в режиме ADV.

_layer

Слой, на котором отображается меню. Если не указан, по умолчанию используется config.choice_layer для обычных меню выбора и config.nvl_choice_layer для меню выбора NVL. Если переменная конфигурации равна None, используется собственный слой экрана, по умолчанию "screens".

_args

Если не None, кортеж, содержащий позиционные аргументы меню, переданные этому меню.

_kwargs

Если не None, словарь, содержащий именованные аргументы меню, переданные этому меню.

Обратите внимание, что в большинстве игр Ren'Py заголовки меню не используются, вместо этого используется реплика рассказчика. Чтобы показать меню со словами рассказчика, напишите:

$ narrator("Which direction would you like to go?", interact=False)
$ result = renpy.display_menu([ ("East", "east"), ("West", "west") ])

Если требуется передать аргументы для конкретного пункта меню, используйте объекты renpy.Choice в качестве значений. Например:

renpy.display_menu([
    ("East", renpy.Choice("east", icon="right_arrow")),
    ("West", renpy.Choice("west", icon="left_arrow"))
    ])

Отображение изображений

Инструкции image, scene, show и hide имеют соответствующие эквиваленты в виде функций Python (исходные инструкции описаны в разделе Отображение изображений).

renpy.get_at_list(name, layer=None)

Возвращает список трансформаций, применяемых к изображению с тегом name на слое layer. Возвращает пустой список, если трансформации не применяются, или None, если изображение не отображается.

Если layer равен None, используется слой по умолчанию для заданного тега.

renpy.hide(name, layer=None)

Скрывает изображение со слоя. Эквивалент инструкции hide на Python.

name

Имя скрываемого изображения. Используется только тег изображения, и скрывается любое изображение с этим тегом (точное имя атрибутов значения не имеет).

layer

Слой, на котором выполняется функция. Если None, используется слой по умолчанию, связанный с тегом.

renpy.image(name, d)

Определяет изображение. Эта функция является эквивалентом инструкции image на Python.

name

Имя определяемого изображения (строка).

d

Отображаемый объект, связываемый с этим именем изображения.

Эта функция может выполняться только внутри блока init. Вызов этой функции после запуска игры приведёт к ошибке.

renpy.scene(layer=None, tag=None)

Удаляет все отображаемые объекты со слоя layer. Это эквивалентно инструкции scene, когда инструкции scene не передано изображение для показа.

Полная инструкция scene эквивалентна вызову renpy.scene с последующим вызовом renpy.show(). Например:

scene bg beach

эквивалентно:

$ renpy.scene()
$ renpy.show("bg beach")
tag

Если не None и layer равен None, используется слой по умолчанию для тега. В противном случае layer по умолчанию равен "master".

renpy.show(name, at_list=[], layer=None, what=None, zorder=0, tag=None, behind=[], atl=None, **kwargs)

Отображает изображение на слое. Программный эквивалент инструкции show.

name

Имя отображаемого изображения (строка).

at_list

Список трансформаций, применяемых к изображению. Эквивалент свойства at.

layer

Строка, задающая имя слоя, на котором будет показано изображение. Эквивалент свойства onlayer. Если None, используется слой по умолчанию, связанный с тегом.

what

Если не None, отображаемый объект, который будет показан вместо поиска изображения по имени. (Эквивалент инструкции show expression.) При указании параметра what параметр name можно использовать для связывания тега с изображением.

zorder

Целое число, эквивалент свойства zorder. Если None, zorder сохраняется, если он существовал, иначе устанавливается в 0.

tag

Строка, используемая для указания тега отображаемого изображения. Эквивалент свойства as.

behind

Список строк с тегами изображений, позади которых отображается данное изображение. Эквивалент свойства behind.

atl

Если не None, трансформация ATL, которая будет применена. Принимает только само ATL, не применяя предшествующее состояние.

show a
$ renpy.show("a")

show expression w
# anonymous show expression : no equivalent

show expression w as a
$ renpy.show("a", what=w)
$ renpy.show("y", what=w, tag="a") # в этом случае name игнорируется

show a at T, T2
$ renpy.show("a", at_list=(T, T2))

show a onlayer b behind c zorder d as e
$ renpy.show("a", layer="b", behind=["c"], zorder="d", tag="e")
renpy.show_layer_at(at_list, layer='master', reset=None, camera=False)

Эквивалент инструкции show layer layer at at_list на Python. Если camera равно True — эквивалент инструкции camera.

reset

Если True, состояние трансформации сбрасывается к начальному при показе. Если False, состояние трансформации сохраняется, позволяя новой трансформации обновить это состояние. Если None, считается True для show layer и False для camera.

Переходы

Эквивалентом инструкции with является функция renpy.with_statement().

renpy.with_statement(trans, always=False)

Запускает переход. Это эквивалент инструкции with на Python.

trans

Переход.

always

Если True, переход будет происходить всегда, даже если пользователь отключил переходы.

Эта функция возвращает True, если пользователь прервал переход кликом, и False в противном случае.

Переход (Jump)

Эквивалентом инструкции jump является функция renpy.jump().

renpy.jump(label)

Завершает выполнение текущей инструкции и передаёт управление на указанную метку label.

Вызов (Call)

Эквивалентом инструкции call является функция renpy.call().

renpy.call(label, *args, from_current=False, **kwargs)

Завершает текущую инструкцию Ren'Py и выполняет переход к метке label. Когда вызов возвращает управление, оно передаётся инструкции, следующей за текущей.

Метка должна иметь вид "global_name" либо "global_name.local_name". Форма вида ".local_name" не допускается.

from_current

Если True, управление вернётся к текущей инструкции, а не к инструкции, следующей за ней. (Это приведёт к повторному выполнению текущей инструкции. Параметр должен передаваться как именованный аргумент.)

renpy.return_statement(value=None)

Выполняет возврат из текущего вызова на уровне Ren'Py.

Пауза (Pause)

Эквивалентом инструкции pause является функция renpy.pause().

renpy.pause(delay=None, *, predict=False, modal=True, hard=False)

Приостанавливает выполнение Ren'Py (пауза). Возвращает True, если пользователь кликнул для завершения паузы, или False, если время паузы истекло либо она была пропущена.

delay

Если указано, количество секунд, на которое Ren'Py должен приостановить выполнение.

Следующие параметры должны передаваться как именованные аргументы:

predict

Если True, пауза завершится, когда будет завершено всё предсказание, включая запланированное через renpy.start_predict() и renpy.start_predict_screen().

Это также заставляет Ren'Py отдавать приоритет предсказанию, а не плавности отображения на время паузы. В связи с этим рекомендуется не отображать анимации во время предсказания.

Пауза по-прежнему может завершиться и другими путями — по клику пользователя, пропуску или по истечении времени delay (если задано).

modal

Если True, пауза по таймеру не завершится (будет удерживаться), пока отображается модальный экран. Если False, пауза завершится во время отображения модального экрана.

hard

Если True, Ren'Py может запретить пользователю кликать для прерывания паузы. Если игрок включает пропуск, жесткая пауза будет пропущена. Могут быть и другие обстоятельства, когда жесткая пауза завершается преждевременно или мешает нормальной работе Ren'Py; это не считается ошибкой.

В целом, использование жестких пауз не рекомендуется, так как это нарушает взаимодействие с пользователем. Когда пользователь нажимает на экран для продолжения игры, это явное действие игрока. Игнорировать его — значит считать, что разработчик понимает желания игрока лучше его самого.

Кратко: не используйте renpy.pause с hard=True.

Вызов renpy.pause гарантирует, что всё отображаемое на экране будет показано хотя бы в течение одного кадра и, следовательно, станет видимым игроку.

Послойные изображения (Layeredimage)

Инструкция layeredimage имеет эквиваленты на Python. Инструкция group их не имеет: имя группы передаётся в Attribute, а функционал auto может быть реализован с помощью renpy.list_images().

class Attribute(group, attribute, image=None, default=False, *, prefix=None, variant=None, **kwargs)

Используется для представления слоя многослойного изображения (LayeredImage), управляемого атрибутом. Один атрибут может управлять несколькими слоями; в этом случае все слои, соответствующие этому атрибуту, будут отображены.

group

Строка, задающая имя группы, в которую входит атрибут. Может быть None, в этом случае создаётся группа с тем же именем, что и атрибут.

attribute

Строка, задающая имя атрибута.

image

Если не None, отображаемый объект, который выводится при вызове этого атрибута.

default

Если True и никакой другой атрибут для группы не выбран, будет выбран данный атрибут.

Также распознаются следующие именованные аргументы:

at

Трансформация или список трансформаций, применяемых к изображению.

when

Строка, содержащая выражение when, описанное в разделе Выражение When. Отображаемый объект показывается только тогда, когда выражение удовлетворяется набором атрибутов, применённых в данный момент к layeredimage.

variant

Строка, задающая вариант атрибута. Используется при поиске отображаемого объекта, если image равно None.

Другие именованные аргументы интерпретируются как свойства трансформации. Если они указаны, создаётся трансформация, оборачивающая изображение (например, pos=(100, 200) смещает изображение на 100 пикселей по горизонтали и 200 по вертикали).

Если параметр image опущен или равен None, а объекту LayeredImage был передан параметр image_format, этот формат используется для генерации имени файла изображения.

class Condition(condition, image=None, *, nested=None, **kwargs)

Когда условие истинно, слой отображается. В противном случае ничего не отображается.

Используется для реализации одиночного оператора layeredimage if, elif или else (для else параметр condition должен быть равен "True"). Несколько Condition можно передать в ConditionGroup для эмуляции полной конструкции if/elif/else.

condition

Строка, задающая условие Python, определяющее отображение слоя.

image

Если не None, отображаемый объект, выводимый при истинности условия.

nested

Если не None, объект ConditionGroup, задающий вложенную конструкцию if/elif/else, которая выводится вместо image при истинности условия.

when

Строка с выражением when, описанным в разделе Выражение When. Условие вычисляется только тогда, когда выражение удовлетворяется набором активных атрибутов.

at

Трансформация или список трансформаций для изображения.

Другие именованные аргументы интерпретируются как свойства трансформации.

class ConditionGroup(conditions)

Принимает список объектов Condition для объединения их в один ConditionSwitch().

Реализует конструкцию if/elif/else.

class LayeredImage(attributes, at=[], name=None, image_format=None, format_function=<function format_function at 0x00000000086dafc0>, attribute_function=None, offer_screen=None, **kwargs)

Объект, подобный изображению, который при показе с правильным набором атрибутов отображает объект, скомпонованный из отображаемых объектов, связанных с этими атрибутами.

attributes

Список объектов Attribute, Condition, ConditionGroup или отображаемых объектов. Каждый элемент представляет собой слой, который может быть показан в составе изображения. Элементы располагаются в порядке снизу вверх (первый элемент дальше от зрителя, последний — ближе всего). Прямая передача отображаемого объекта эквивалентна оператору always в layeredimage.

at

Трансформация или список трансформаций, применяемых к отображаемому объекту после параметризации.

name

Имя layeredimage. Используется как часть имён компонентов изображения.

image_format

Если задано, имя изображения подставляется в image_format для формирования пути к файлу. Например, "sprites/eileen/{image}.png" ищет файл в подкаталоге sprites. (Не используется группами auto).

format_function

Функция, используемая вместо layeredimage.format_function для форматирования информации об изображении в отображаемый объект.

attribute_function

Функция, вызываемая с набором атрибутов, переданных изображению, и возвращающая набор атрибутов для выбора слоёв. Вызывается после выбора самих атрибутов.

offer_screen

Определяет, учитывается ли доступная область при размещении и масштабировании дочерних элементов. Если False, учитывается доступная область; если True — выделяется область всего экрана. Если None, берётся значение config.layeredimage_offer_screen.

Дополнительные именованные аргументы могут содержать свойства трансформации. Оставшиеся аргументы передаются в контейнер Fixed, создаваемый для хранения слоёв. Если не переопределено явно, параметры xfit и yfit для Fixed установлены в True (он сжимается до минимального размера, вмещающего все слои).

LayeredImage не является отображаемым объектом в строгом смысле и не может использоваться во всех контекстах, где требуются отображаемые объекты. Его следует выводить через операторы scene или show, либо обращаясь по имени изображения.

add(a)
a

Объект Attribute, Condition, ConditionGroup или отображаемый объект.

Добавляет переданный слой в список слоёв layeredimage, аналогично передаче в аргументе attributes конструктора.
