Пользовательские текстовые теги

В Ren'Py есть поддержка создания собственных текстовых тегов. Эти теги могут манипулировать текстом и тегами, определёнными внутри них, включая добавление и удаление текста и других текстовых тегов.

Пользовательские текстовые теги создаются путём привязки функции тега к записи в одном из следующих словарей. Тег должен находиться либо в одном, либо в другом словаре, но не в обоих одновременно.

define config.custom_text_tags = { }

Сопоставляет имена текстовых тегов с функциями тегов, когда текстовый тег может оборачивать другой текст (парный тег).

define config.self_closing_custom_text_tags = { }

Сопоставляет имена текстовых тегов с функциями самозакрывающихся тегов, когда тег не оборачивает другой текст (одиночный тег).

Предупреждение

Эти функции могут быть вызваны в любой момент в рамках процесса предсказания (prediction). По этой причине их поведение не должно зависеть от состояния игры (обычно от глобальных переменных), и они не должны вызывать побочных эффектов (например, вызывать Эквиваленты инструкций на Python или изменять глобальные переменные).

Функция текстового тега принимает три аргумента: сам тег, аргумент тега и список кортежей содержимого. Например, для текста:

"{big=2}Hello, {b}World{/b}{/big}"

тегом будет "big", аргументом — строка "2", а список кортежей содержимого будет иметь вид:

[
    (renpy.TEXT_TEXT, "Hello, "),
    (renpy.TEXT_TAG, "b"),
    (renpy.TEXT_TEXT, "World"),
    (renpy.TEXT_TAG, "/b"),
]

Функция текстового тега должна возвращать новый список кортежей содержимого, который используется для замены текстового тега и его содержимого.

Кортежи содержимого состоят из двух компонентов. Первый компонент — одна из констант из следующего списка. Второй компонент зависит от первого компонента, как описано ниже:

renpy.TEXT_TEXT

Второй компонент — это строка текста, предназначенная для отображения пользователю.

renpy.TEXT_TAG

Второй компонент — это содержимое текстового тега без окружающих фигурных скобок.

renpy.TEXT_DISPLAYABLE

Второй компонент — отображаемый объект, который должен быть встроен в текст.

renpy.TEXT_PARAGRAPH

Обозначает перенос абзаца, второй компонент не определён (но должен присутствовать).

Функция самозакрывающегося тега устроена аналогично, за исключением того, что она не принимает третий аргумент.

Списки токенов можно передавать в Text(), когда аргумент tokenized равен True.

Предупреждение

Диалоговые текстовые теги {p}, {w}, {nw} и {fast} обрабатываются до пользовательских текстовых тегов и должны либо не включаться внутрь пользовательского текстового тега, либо передаваться без изменений.

Примеры

В качестве примера тег big работает подобно тегу {size}, но применяет множитель к своему аргументу.

init python:

    def big_tag(tag, argument, contents):

        size = int(argument) * 20

        return [
                (renpy.TEXT_TAG, u"size={}".format(size)),
            ] + contents + [
                (renpy.TEXT_TAG, u"/size"),
            ]

    config.custom_text_tags["big"] = big_tag


"This is {big=3}BIG!{/big}"

В следующем примере текстовый тег rot13 применяет шифр ROT13 к тексту. Обратите внимание, что ROT26 (дважды применённый ROT13) — это исходный обычный текст.

init python:

    def rot13_transform(s):

        ROT13 = { }

        for i, j in zip("ABCDEFGHIJKLM", "NOPQRSTUVWXYZ"):
             ROT13[i] = j
             ROT13[j] = i

             i = i.lower()
             j = j.lower()

             ROT13[i] = j
             ROT13[j] = i

        return "".join(ROT13.get(i, i) for i in s)

    def rot13_tag(tag, argument, contents):
        rv = [ ]

        for kind, text in contents:

            if kind == renpy.TEXT_TEXT:
                text = rot13_transform(text)

            rv.append((kind, text))

        return rv

    config.custom_text_tags["rot13"] = rot13_tag

"Rot0. {rot13}Rot13. {rot13}Rot26. {/rot13}Rot13. {/rot13}Rot0."

Тег bang вставляет специальный восклицательный знак в текст и не требует закрывающего тега.

init python:
    def bang_tag(tag, argument):
        return [ ( renpy.TEXT_TAG, "size=40"), (renpy.TEXT_TEXT, "!"), (renpy.TEXT_TAG, "/size") ]

    config.self_closing_custom_text_tags["bang"] = bang_tag

"This is awesome{bang}"
