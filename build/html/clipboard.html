Буфер обмена

Ren'Py поддерживает чтение из системного буфера обмена и запись в него. Это позволяет игре копировать текст и графические данные для вставки в другие приложения, а также считывать данные, скопированные игроком.

Поддержка буфера обмена зависит от платформы. На настольных системах (Windows, macOS, Linux) буфер обмена поддерживается в полном объёме. На веб- и мобильных платформах поддержка может быть ограничена текстом и стандартными MIME-типами.

renpy.get_clipboard_data(mime_type: str) → bytes

Возвращает данные буфера обмена для указанного mime_type или вызывает исключение, если данные для этого MIME-типа отсутствуют.

mime_type

Извлекаемый MIME-тип, например "image/png".

Возвращает байты (bytes).

renpy.get_clipboard_mime_types() → list[str]

Возвращает список строк MIME-типов, доступных в данный момент в буфере обмена.

renpy.get_clipboard_text() → str

Возвращает текст, находящийся в буфере обмена, или вызывает исключение, если текстовые данные отсутствуют.

Возвращает строку (str).

renpy.put_clipboard_data(data_dict: dict[str | bytes, str | bytes]) → None

Записывает данные в буфер обмена сразу для нескольких MIME-типов.

data_dict

Словарь, сопоставляющий строки или байты MIME-типов со строками или байтами данных. Строковые значения кодируются в UTF-8.

renpy.put_clipboard_image_file(filename: str, absolute_path: bool = False) → None

Копирует файл изображения в системный буфер обмена. Изображение помещается в буфер обмена в исходном формате, а также как PNG (если исходный файл не в формате PNG).

Использование этой функции повышает совместимость со сторонними приложениями, многие из которых принимают изображения только в формате image/png.

filename

Имя файла изображения для копирования.

absolute_path

Если True, filename считается абсолютным путём в файловой системе. Если False (по умолчанию), файл открывается через стандартный механизм загрузки файлов Ren'Py.

renpy.put_clipboard_text(text: str) → None

Помещает строку text в буфер обмена.

text

Строка текста для копирования в буфер обмена.

renpy.put_clipboard_text_file(filename: str, absolute_path: bool = False) → None

Копирует текстовый файл в системный буфер обмена в виде вложения text/plain.

filename

Имя текстового файла для копирования в буфер обмена.

absolute_path

Если True, filename считается абсолютным путём в файловой системе. Если False (по умолчанию), файл открывается через стандартный механизм загрузки Ren'Py.
