Android

Ren'Py поддерживает устройства под управлением операционной системы Android, такие как смартфоны и планшеты. Хотя на этих устройствах доступна не вся функциональность Ren'Py на 100%, с минимальными доработками визуальные новеллы можно упаковать и портировать на мобильные устройства.

RAPT (Ren'Py Android Packaging Tool) — инструмент сборки пакетов Android для Ren'Py, загружаемый отдельно через лаунчер. Он создаёт установочные пакеты Android для тестирования и релизной публикации.

Ren'Py работает на Android 5.0 и выше на устройствах с поддержкой OpenGL ES 3.0. Игра не запустится на устройствах, поддерживающих только OpenGL ES 2.0. Старым устройствам также может не хватать оперативной памяти для комфортной работы масштабных игр.

Обязательное уведомление о лицензиях

Некоторые библиотеки, используемые RAPT, распространяются на условиях лицензии GNU Lesser General Public License (LGPL). Для распространения игр Ren'Py необходимо соблюдать условия этой лицензии. Инструкции для пользователя

При запуске игры Ren'Py на Android действуют следующие системные сочетания и клавиши:

Домой (Home)

Возвращает на главный экран Android, приостанавливая игру Ren'Py. В процессе приостановки Ren'Py автоматически сохраняет текущее состояние игры. При возврате в игру это сохранение будет автоматически восстановлено при необходимости.

Громкость вверх, Громкость вниз

Управляют громкостью мультимедиа в Android.

Отличия платформы

Между сенсорной платформой Android и настольными платформами с мышью существует ряд важных различий. Изменения, обусловленные аппаратными и программными особенностями Android:

  • Сенсорный экран обрабатывается как мышь. Однако события мыши генерируются только тогда, когда пользователь физически касается экрана.

  • Ввод текста (например, renpy.input()) ограничен методами ввода, не требующими системного автодополнения (латиница и кириллица обычно работают нормально, тогда как языки со сложным иероглифическим вводом могут не поддерживаться).

Кроме того, разработчику необходимо учитывать эргономические факторы:

  • Поскольку экраны смартфонов значительно меньше мониторов ПК, может потребоваться увеличить размер шрифта.

  • Сенсорный ввод пальцем менее точен, чем курсор мыши, поэтому сенсорные кнопки должны быть ощутимо крупнее кнопок настольного интерфейса.

Чтобы помочь вам адаптировать игру к этим различиям, Ren'Py для Android автоматически выбирает варианты экранов на основе физического размера экрана и характеристик устройства.

В силу политик безопасности мобильных платформ функционал MultiPersistent ограничен только данной игрой и её обновлениями (данные не могут разделяться между разными играми).

Тестирование и эмуляция

Для целей тестирования Ren'Py поддерживает три режима эмуляции Android. Доступ к ним осуществляется через раздел «Android» в лаунчере:

Phone

Эмулирует смартфон Android. Сенсорное управление симулируется мышью при зажатой кнопке мыши. Клавиша Escape привязана к кнопке меню, а Page Up — к кнопке «Назад».

Tablet

Эмулирует планшет Android. Сенсорное управление симулируется мышью при зажатой кнопке мыши. Клавиша Escape привязана к кнопке меню, а Page Up — к кнопке «Назад».

Television

Эмулирует телевизионную приставку или консоль на Android TV. Клавиатура сопоставлена с пультом ДУ или геймпадом: стрелки служат для навигации, Enter — кнопка подтверждения, Escape — вызов меню, Page Up — кнопка «Назад».

В этом режиме отображается наложение безопасной зоны для ТВ (overscan area). Содержимое вне безопасной зоны может обрезаться на некоторых телевизорах.

Хотя эмуляторы удобны для быстрого тестирования, настоятельно рекомендуется также проверять игру на реальных устройствах: эмуляторы не воспроизводят тактильные ощущения и реальные физические размеры пальцев пользователя.

Сборка приложений для Android

Ren'Py предоставляет удобные инструменты для сборки и развёртывания игр на Android. Вы собираете пакет на компьютере и передаёте его на подключённое мобильное устройство. После этого игра запускается как стандартное приложение Android. Убедившись в её корректной работе, вы можете загрузить собранный пакет в Google Play и другие магазины приложений.

Процесс сборки приложения Android состоит из пяти шагов:

  1. Загрузите и установите Java Development Kit (JDK) и USB-драйверы Android (ссылки ниже).

  2. Установите Android SDK с помощью лаунчера Ren'Py.

  3. Сгенерируйте ключи подписи через лаунчер.

  4. Настройте параметры сборки Android в лаунчере.

  5. Запустите сборку приложения через лаунчер.

После выполнения этих шагов вы получите готовый установочный пакет Android. Шаг 3 выполняется один раз для проекта; чаще всего вы будете выполнять шаг 5 при создании каждого нового билда игры.

Шаг 1: Установка зависимостей

Перед сборкой пакетов вам потребуется вручную установить следующие компоненты:

Java Development Kit (JDK). Java Development Kit содержит утилиты, необходимые RAPT, включая инструменты генерации ключей и цифровой подписи пакетов. Его можно скачать по ссылкам:

https://adoptium.net/temurin/releases/?version=21 https://adoptopenjdk.net/releases.html

Вам потребуется JDK версии 21.

Обратите внимание: комплект разработчика JDK отличается от обычной пользовательской среды JRE; для сборки пакетов Android обязательно требуется именно JDK.

Устройство Android. Подготовьте мобильное устройство к разработке: включите режим разработчика и отладку по USB, а также установите драйверы Android на компьютер. Инструкции доступны на:

https://developer.android.com/studio/run/device

Вы также можете запускать приложение в образе x86_64 официального эмулятора Android (обратите внимание: архитектура x86 не поддерживается). Настройка эмулятора выходит за рамки данного руководства.

Шаг 2: Настройка Android SDK и среды разработки

Следующий шаг — загрузка Android SDK и подготовка среды разработки. Этот этап:

  • Проверяет корректность установки JDK.

  • Загружает и устанавливает Android SDK.

  • Загружает необходимые пакеты инструментов сборки через Android SDK.

Для выполнения этого шага требуется подключение к Интернету.

Выберите пункт «Install SDK» (Установить SDK) на экране Android в лаунчере Ren'Py. RAPT отобразит ход загрузки и предложит принять условия лицензионных соглашений.

Если вы не хотите загружать SDK повторно для каждого проекта, можно создать файл sdk.txt в корне Ren'Py с одной строкой — полным путём к уже установленному SDK.

Шаг 3: Генерация ключей

После установки SDK выберите «Generate Keys» (Сгенерировать ключи) для создания ключей подписи Android (android.keystore) и бандла (bundle.keystore).

Предупреждение

Ключи, сгенерированные RAPT, защищены стандартным паролем. Вы обязаны надёжно сохранить эти файлы и не потерять к ним доступ!

Храните файлы android.keystore и bundle.keystore в надёжном месте и обязательно сделайте их резервную копию. Без этих ключей вы не сможете выпускать обновления для ранее опубликованных в магазинах приложений.

Ни в коем случае не выкладывайте эти файлы в открытый доступ и не коммитьте их в публичные репозитории систем контроля версий.

При создании ключей Ren'Py делает их резервную копию в папку бэкапов скриптов, однако это не заменяет полноценного собственного резервного копирования.

Шаг 4: Настройка параметров игры

Перед сборкой необходимо указать Ren'Py параметры сборки Android для вашей игры. Для этого выберите пункт «Configure» (Настроить) на экране Android в лаунчере Ren'Py.

При необходимости изменить настройки вы можете запустить настройку заново — ранее введённые ответы сохраняются.

Шаг 5: Сборка и установка пакета

Наконец, можно собрать и установить пакет. Сначала выберите один из двух форматов релиза:

Play Bundle

Релизы в формате Android App Bundle (AAB). Предназначены исключительно для загрузки в магазин Google Play, хотя их также можно установить на устройства с сервисами Google Play.

Размер Play Bundle может достигать 2 ГБ, однако он разделяется на 4 файла быстрого скачивания (fast-follow pack) объёмом по 500 МБ каждый. Каждый файл игры привязывается к одному из четырёх бандлов. Это может вызвать сложность при наличии неделимых файлов: например, пять файлов размером по 300 МБ не поместятся в четыре 500-мегабайтных пакета.

Universal APK

Универсальный APK-файл, подходящий для прямой установки на любые устройства Android через Ren'Py, ADB, сторонние магазины приложений или скачивание с сайта.

Размер Universal APK может достигать 2 ГБ без ограничений на распределение файлов.

Лаунчер предлагает команды, позволяющие выполнять сборку пакета, установку на подключённое устройство и немедленный запуск приложения для тестирования.

При переключении между режимами сборки (Play Bundle и APK) может потребоваться предварительно удалить старую версию приложения с устройства.

Игры очень большого размера

В Ren'Py можно создавать игры для Android объёмом более 2 ГБ. Это делается с помощью модуля Загрузчик больших игр на мобильных платформах: базовое приложение небольшого размера включается в Play Bundle или Universal APK, а остальная часть игровых файлов загружается при первом запуске с высокоскоростного веб-сервера.

Иконка и изображения презаставки (presplash)

Иконка

Ren'Py формирует адаптивную иконку приложения из двух файлов в базовом каталоге игры:

android-icon_foreground.png

Передний план иконки (foreground). Размер 432x432 пикселя, прозрачный фон.

android-icon_background.png

Фоновый слой иконки (background). Размер 432x432 пикселя, непрозрачный фон.

Адаптивные иконки Android работают путём наложения маски на оба слоя в центральной области размером не менее 132x132 пикселей. Область за пределами этой безопасной зоны может отображаться, но может и обрезаться маской. Выход элементов за пределы безопасной зоны рекомендуется. При перетаскивании иконки на рабочем столе Android слои могут слегка смещаться относительно друг друга, создавая эффект параллакса.

Подробнее об адаптивных иконках см.:

https://medium.com/google-design/designing-adaptive-icons-515af294c783

Обратите внимание: 1 dp соответствует 4 реальным пикселям.

При сборке приложения Ren'Py автоматически масштабирует эти изображения под различные плотности экранов устройств и генерирует статическую иконку для старых версий Android, не поддерживающих адаптивные иконки.

Презаставка (Presplash)

Презаставка отображается во время начальной загрузки Ren'Py, до показа заставки (splashscreen) и главного меню. На Android это особенно важно: при первом запуске игры Ren'Py распаковывает служебные файлы данных, что может занять некоторое время.

android-presplash.jpg

Изображение, отображаемое при загрузке приложения. Должно иметь одноцветную рамку толщиной в 1 пиксель. При отображении изображение масштабируется под экран с сохранением пропорций, а оставшееся пространство экрана заливается цветом рамки.

android-downloading.jpg

Изображение, отображаемое при загрузке ресурсов через Google Play Asset Delivery. Также должно быть окружено одноцветной рамкой в 1 пиксель. При показе картинка масштабируется с сохранением пропорций, а края заливаются цветом рамки.

В нижней части экрана (с отступом в 20 пикселей снизу, слева и справа) отображается индикатор выполнения загрузки высотой 20 пикселей.

Pyjnius

При работе на Android доступна библиотека Pyjnius. Она позволяет опытным разработчикам вызывать методы Java-классов Android напрямую из Python.

В частности, может потребоваться получить ссылку на главную активность (Activity). Её можно найти в поле mActivity класса org.renpy.android.PythonSDLActivity. Например:

init python:
    if renpy.android:
        import jnius
        mActivity = jnius.autoclass("org.renpy.android.PythonSDLActivity").mActivity
    else:
        mActivity = None

Разрешения (Permissions)

Хотя самому Ren'Py не требуются дополнительные системные разрешения для работы, если ваша игра использует Pyjnius для вызова системных функций Android, может потребоваться запросить соответствующие разрешения. Ren'Py предоставляет переменную конфигурации и две функции для работы с системой разрешений Android.

build.android_permissions = [ ]

Список строк, где каждая строка задаёт полное имя разрешения Android. Например, "android.permission.WRITE_EXTERNAL_STORAGE". Эта переменная объявляет, что приложение может запрашивать данные разрешения; для фактического запроса необходимо использовать функции renpy.check_permission() и renpy.request_permission().

renpy.check_permission(permission)

Проверяет, было ли предоставлено разрешение Android данному приложению.

permission

Строка с именем разрешения, например "android.permission.WRITE_EXTERNAL_STORAGE".

Возвращает True, если разрешение было предоставлено, и False, если оно не предоставлено или если вызов совершён не на платформе Android.

renpy.request_permission(permission)

Запрашивает у Android предоставление разрешения данному приложению. Пользователю может быть показано стандартное системное диалоговое окно запроса разрешения.
