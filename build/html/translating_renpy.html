Перевод Ren'Py

Вы можете перевести сам движок Ren'Py. Полная локализация включает перевод пользовательского интерфейса (GUI), различных системных сообщений Ren'Py, шаблонов новых проектов и лаунчера. Это покрывает большинство сценариев игры и разработки. На данный момент не все внутренние сообщения об ошибках подлежат переводу.

Чтобы создать новый перевод Ren'Py:

  1. Откройте лаунчер Ren'Py.

  2. В настройках («Preferences») выберите «Открыть проект лаунчера» («Open launcher project»).

  3. Выберите «Сгенерировать переводы» («Generate Translations»).

  4. Введите имя языка для перевода строчными буквами ASCII и знаками подчёркивания (например, "japanese", "russian" или "ancient_klingon").

  5. Нажмите «Сгенерировать переводы» («Generate Translations»).

Та же процедура используется для обновления существующего перевода. Чтобы переключиться на созданный перевод, вернитесь в настройки лаунчера и выберите новый язык. По умолчанию новый перевод будет копией английской версии.

Файлы перевода

Файлы перевода располагаются в каталоге launcher/game/tl/language/. За исключением script.rpy, все файлы представляют собой строковые переводы, выполняемые по правилам строкового перевода. Некоторые строки начинаются с "## " — это комментарии, которые переводятся, форматируются и автоматически включаются в файлы options.rpy и gui.rpy при создании новых проектов.

Файлы перевода:

common.rpy

Содержит строки интерфейса, которые Ren'Py выводит игрокам во время игры.

developer.rpy

Содержит строки меню разработчика, предназначенные исключительно для авторов игр.

error.rpy

Содержит строки экрана обработки критических ошибок.

gui.rpy

Содержит комментарии, помещаемые в создаваемый по умолчанию файл gui.rpy проекта.

launcher.rpy

Содержит строки интерфейса лаунчера Ren'Py.

obsolete.rpy

Содержит устаревшие строки, не используемые в современных версиях Ren'Py.

options.rpy

Содержит строки комментариев для файла options.rpy создаваемого проекта.

screens.rpy

Содержит строки стандартных экранов и комментарии для screens.rpy.

script.rpym

Содержимое этого файла дословно копируется в script.rpy при создании нового проекта.

style.rpy

Файл изначально отсутствует, но создаётся при необходимости. В нём настраиваются стили лаунчера и шрифты для создаваемых проектов.

Специфические для языка переводы

Существует один особый перевод. Строка "{#language name and font}" должна быть заменена на самоназвание языка, при необходимости обёрнутое в тег шрифта лаунчера (если используются не-ASCII символы). Например:

translate french strings:

    old "{#language name and font}"
    new "{font=fonts/Roboto-Light.ttf}Français{/font}"

Это используется для корректного отображения названия языка в меню лаунчера, когда активен другой язык интерфейса.

Строки, начинающиеся с "{#in language font}", оформляются аналогично:

translate french strings:

    old "{#in language font}Start using Ren'Py in [lang_name]"
    new "{font=fonts/Roboto-Light.ttf}Commencez à utiliser Ren'Py en [lang_name]{/font}"

Смена шрифтов

Ren'Py поставляется со стандартным шрифтом DejaVuSans, покрывающим большинство западных алфавитов, однако для других языков (кириллицы, иероглифов) часто требуются другие шрифты. Шрифт настраивается в файле launcher/game/tl/language/style.rpy:

init python:
    translate_font("language", "myfont.ttf")

где "language" — имя языка (например, "russian"), а "myfont.ttf" — файл шрифта. Файл шрифта должен быть помещён в папку launcher/game/tl/language, чтобы лаунчер мог его обнаружить.

Изменение стилей лаунчера

Стили интерфейса лаунчера настраиваются с помощью переменных в блоке translate python. Доступны следующие переменные (они действуют только внутри лаунчера):

define gui.LIGHT_FONT = "Roboto-Light.ttf"

Путь к шрифту для обычного текста в лаунчере.

define gui.REGULAR_FONT = "Roboto-Regular.ttf"

Путь к шрифту для акцентного (полужирного) текста в лаунчере.

define gui.REGULAR_BOLD = False

Если True, акцентный текст дополнительно выделяется полужирным.

define gui.FONT_SCALE = 1.0

Коэффициент масштабирования размера всего текста в лаунчере.

Блок translate python используется для настройки этих переменных. Например, для арабской локализации Ren'Py используется:

translate arabic python:
    gui.REGULAR_FONT = "DejaVuSans.ttf"
    gui.LIGHT_FONT = "DejaVuSans.ttf"
    gui.FONT_SCALE = .9
    gui.REGULAR_BOLD = True

Функции

Следующие функции служат для настройки локализации лаунчера и вызываются из блока init python:

translate_font(language, font)

Задаёт шрифт для языка language. Этот шрифт используется в лаунчере, а также в играх, генерируемых на этом языке. Файл шрифта должен находиться в game/fonts.

font

Имя файла шрифта (строка).

translate_define(language, define, value, help=None)

Задаёт значение переменной define при генерации нового проекта (например, для изменения размера шрифта по умолчанию).

language

Язык проекта.

define

Имя объявляемой переменной (строка).

value

Строковое представление значения ("10", "False" или "'Font.ttf'").

comment

Комментарий перед объявлением define (если переменной ещё нет в gui.rpy). Префикс "## " писать не нужно — он добавится автоматически.

Например, изменение размера текста диалогов для марсианского языка:

translate_define("martian", "gui.text_size", 12)
