.. _transitions:

======================
Переходы (Transitions)
======================

Переходы используются как часть :ref:`оператора with <with-statement>`, а также в других
механизмах Ren'Py для применения визуальных эффектов при смене сцены или плавной трансформации
одного отображаемого объекта в другой. Ren'Py поставляется с набором готовых переходов,
которые можно указывать напрямую в операторе with. Например::

    show bg washington
    with dissolve

Предустановленные переходы
==========================

.. var:: dissolve

    Плавное растворение старого экрана в новом длительностью 0.5 секунды. Экземпляр
    класса переходов :func:`Dissolve`.

.. var:: fade

    Плавное затухание в черный экран за 0.5 секунды и последующее плавное появление
    нового экрана за 0.5 секунды. Экземпляр класса :func:`Fade`.

.. var:: pixellate

    Пикселизация старой сцены за 0.5 секунды и обратное проявление новой сцены еще за
    0.5 секунды. Экземпляр класса :func:`Pixellate`.

.. var:: move

    Перемещение изображений, изменивших координаты, на их новые позиции за 0.5 секунды.
    Экземпляр класса :func:`MoveTransition`.

    Переходы перемещения и аналогичные им (например, ease) могут применяться только к
    отдельному слою или всем слоям сразу с помощью :ref:`оператора with <with-statement>`.
    Они не работают внутри :ref:`ATL <displayable-atl-statement>`, :func:`ComposeTransition`
    или других контекстов.

.. var:: moveinright

    Также: **moveinleft, moveintop, moveinbottom**

    Перемещают входящие изображения на экран с соответствующей стороны за 0.5 секунды.

.. var:: moveoutright

    Также: **moveoutleft, moveouttop, moveoutbottom**

    Перемещают уходящие изображения за пределы экрана через соответствующую сторону за 0.5 секунды.

.. var:: ease

    Также: **easeinright, easeinleft, easeintop, easeinbottom, easeoutright, easeoutleft, easeouttop, easeoutbottom**

    Аналогичны семейству переходов move, но используют косинусоидальную кривую замедления
    для плавного ускорения в начале и торможения в конце перехода.

.. var:: zoomin

    Увеличение масштаба (приближение) входящих изображений за 0.5 секунды.

.. var:: zoomout

    Уменьшение масштаба (удаление) уходящих изображений за 0.5 секунды.

.. var:: zoominout

    Приближение входящих изображений и одновременное удаление уходящих изображений за 0.5 секунды.

.. var:: vpunch

    Вертикальная встряска экрана длительностью четверть секунды. Для имитации и более
    гибкой настройки таких эффектов лучше использовать :ref:`atl-transitions`.

.. var:: hpunch

    Горизонтальная встряска экрана длительностью четверть секунды.

.. var:: blinds

    Эффект вертикальных жалюзи длительностью 1 секунда. Экземпляр класса :func:`ImageDissolve`.

.. var:: squares

    Эффект проявления через квадратные блоки длительностью 1 секунда.

.. var:: wipeleft

    Также: **wiperight, wipeup, wipedown**

    Стирание сцены в указанном направлении. Экземпляры класса :func:`CropMove`.

.. var:: slideleft

    Также: **slideright, slideup, slidedown**

    Скольжение новой сцены в указанном направлении поверх старой. Экземпляры класса :func:`CropMove`.

.. var:: slideawayleft

    Также: **slideawayright, slideawayup, slideawaydown**

    Уход старой сцены скольжением в указанном направлении. Экземпляры класса :func:`CropMove`.

.. var:: pushright

    Также: **pushleft, pushup, pushdown**

    Новая сцена выталкивает старую сцену за край экрана в указанном направлении. Экземпляры
    класса :func:`PushMove`.

.. var:: irisin

    Также: **irisout**

    Прямоугольная диафрагма для открытия нового экрана или скрытия старого. Экземпляры
    класса :func:`CropMove`.


Классы переходов
================

Классы переходов — это функции, вызываемые для создания новых объектов переходов. Эти функции
параметризованы, что позволяет настраивать целые семейства переходов. Вопреки названию,
в Python они обычно являются фабричными функциями, а не классами.

Вызов классов переходов можно производить прямо в операторе with::

    # Очень медленное растворение.
    with Dissolve(10.0)

Если один и тот же переход используется регулярно, оператор :ref:`define <define-statement>`
позволяет присвоить его переменной::

    define dissolve1 = Dissolve(1.0)

    label start:
        show bg washington
        with dissolve1

Параметр `time_warp`, принимаемый многими переходами, поддерживает встроенные функции
деформации времени модуля ``_warper`` (см. :ref:`деформаторы времени <warpers>`).

Словарные переходы для слоев
============================

В большинстве мест, где Ren'Py ожидает переход, можно вместо этого передать словарь,
сопоставляющий имена слоев переходам. В этом случае Ren'Py применит каждый переход
к соответствующему слою.

При использовании словарного перехода стандартная пауза, блокирующая взаимодействие во
время перехода, не происходит. Оператор завершается немедленно, а переходы запускаются
синхронно в начале следующего взаимодействия.

Это можно использовать с базовым слоем master, чтобы переходы происходили прямо во время
показа реплик диалога на экране::

    define dis = { "master" : Dissolve(1.0) }

    label start:
        show eileen happy
        with dis

        e "Привет, мир."

Растворение будет происходить прямо во время чтения реплики.

Исключение составляет случай, когда словарь содержит ключ ``None``. Если словарный переход
сопоставляет слой ``None`` с переходом, этот переход выполняется со стандартной блокирующей паузой.

Словарные переходы для слоев применимы везде, где поддерживаются переходы по слоям:
оператор :ref:`with <with-statement>`, клауза ``with`` операторов :ref:`scene <scene-statement>`,
:ref:`show <show-statement>` и :ref:`hide <hide-statement>`, функции :func:`renpy.with_statement`
и :func:`renpy.transition`, действия :func:`Show` и :func:`Hide`, а также конфигурационные
переменные переходов. Словарные переходы *не работают* внутри конструкций, не оперирующих
слоями напрямую, таких как :ref:`atl`, :func:`ComposeTransition` и :func:`MultipleTransition`.

Это позволяет устранять нежелательное мигание при автоматическом скрытии и показе диалогового
окна (режим ``window auto``), настроив в :file:`options.rpy`::

    define config.window_show_transition = { "screens" : Dissolve(.25) }
    define config.window_hide_transition = { "screens" : Dissolve(.25) }

Переходы ATL
============

*См. также:* :ref:`atl`

Для создания перехода можно использовать трансформации ATL. Такие трансформации должны
принимать именованные аргументы `old_widget` и `new_widget`, которые получают отображаемые
объекты старого и нового экрана соответственно.

ATL-переход должен самостоятельно устанавливать свойство :tpref:`delay`, равное длительности
перехода в секундах. Свойство :tpref:`events` может использоваться для предотвращения
получения событий старым отображаемым объектом::

    transform spin(duration=1.0, *, new_widget=None, old_widget=None):

        # Длительность перехода.
        delay duration

        # Центрирование.
        xcenter .5
        ycenter .5

        # Вращение старого экрана.
        old_widget
        events False
        rotate 0.
        easeout (duration / 2) rotate 360.0

        # Вращение нового экрана.
        new_widget
        events True
        easein (duration / 2) rotate 720.0


.. _transitions-python:

Переходы Python
===============

В качестве перехода можно использовать любую вызываемую функцию Python. Она должна принимать
два именованных аргумента (`old_widget` и `new_widget`) и возвращать отображаемый объект,
выполняющий переход (обычно делегируя его другому переходу).

Возвращаемый объект должен содержать атрибут ``delay`` с длительностью перехода в секундах::

    init python:
        def dissolve_or_pixellate(old_widget=None, new_widget=None):
            if persistent.want_pixellate:
                return pixellate(old_widget=old_widget, new_widget=new_widget)
            else:
                return dissolve(old_widget=old_widget, new_widget=new_widget)

Автоматические переходы после Scene, Show и Hide
================================================

Ren'Py может автоматически воспроизводить переход после серии операторов scene, show и hide.
Для включения этого поведения переменной :var:`_scene_show_hide_transition` присваивается
желаемый переход.

Переход сработает после одного или нескольких операторов :ref:`scene <scene-statement>`,
:ref:`show <show-statement>` и :ref:`hide <hide-statement>`, если за ними не следует явный
оператор :ref:`with <with-statement>` или переход, вызванный :ref:`управлением диалоговым окном <dialogue-window-management>`.
Поведение также отключено в контексте меню::

    define _scene_show_hide_transition = Dissolve(0.25)

    label start:
        scene bg washington
        show eileen happy

        "Здесь переход не покажется, так как окно диалога появилось с собственным переходом."

        show lucy mad at right

        "Здесь переход будет воспроизведен."

        hide lucy mad
        show eileen vhappy

        "И здесь переход тоже сработает."
