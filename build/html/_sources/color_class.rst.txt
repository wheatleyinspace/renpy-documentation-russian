===========
Класс Color
===========

В Ren'Py есть класс Color, который можно использовать для преобразования цвета
из одного цветового пространства в другое, а также для выполнения различных операций
теории цвета. Объекты Color неизменяемы (immutable) и могут использоваться везде,
где допускается кортеж цвета.

Кортежи цветов работают в одном из трёх цветовых пространств:

* RGB — Красный, Зелёный, Синий (Red, Green, Blue)
* HLS — Тон, Светлота, Насыщенность (Hue, Lightness, Saturation)
* HSV — Тон, Насыщенность, Значение (Hue, Saturation, Value)

В качестве примера некоторых вычислений, которые можно производить: все следующие
записи представляют собой ярко-зелёный цвет::

    # Стандартные цвета Ren'Py.
    Color("#0f0")
    Color("#00ff00")
    Color((0, 255, 0, 255))

    # Преобразование из других цветовых пространств.
    Color(hls=(.333, 0.5, 1.0))
    Color(hsv=(.333, 1.0, 1.0))

    # Превращает красный в зелёный с помощью метода, возвращающего новый цвет.
    Color("#f00").rotate_hue(.333)
