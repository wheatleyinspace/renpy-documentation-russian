.. _pygame:

======
pygame
======

Многие внутренние подсистемы Ren'Py основаны на встроенной вендорной реализации API
pygame, работающей поверх библиотеки SDL. Этот модуль доступен как пакет ``renpy.pygame``::

    from renpy import pygame

При запуске Ren'Py этот пакет также регистрируется под именами ``pygame``
и ``pygame_sdl2``, поэтому вызов ``import pygame`` корректно работает и внутри
пользовательского кода игры.

Совместимость
-------------

Реализация pygame в Ren'Py стремится сохранять совместимость с актуальным (не устаревшим)
публичным API проекта `pygame-ce <https://github.com/pygame-community/pygame-ce>`_.
Если вам не хватает каких-либо методов, вы можете оформить запрос на добавление функции
(feature request) в репозитории проекта.

В то же время модуль pygame в Ren'Py содержит дополнительные возможности, выходящие
за рамки стандартного API pygame, однако они рассматриваются как внутренние детали
реализации движка. Если вам требуется доступ к нестандартному функционалу, рекомендуется
запросить его открытие через пространство имён ``renpy``.

Подмодули
---------

Доступны следующие подмодули библиотеки. Обратите внимание, что классы ``Surface``
и ``Rect`` также доступны напрямую из корня пакета:

``color``
    Класс Color и предопределённые имена цветов.

``constants``
    Типы событий и прочие константы. Те же константы также доступны как ``locals``
    и непосредственно в пространстве имён ``renpy.pygame``.

``controller``
    Поддержка игровых контроллеров и геймпадов.

``display``
    Инициализация и управление графическим окном и дисплеем.

``draw``
    Рисование графических примитивов (прямоугольники, полигоны, окружности, линии)
    на поверхностях Surface.

``event``
    Доступ к системной очереди событий.

``gfxdraw``
    Рисование геометрических примитивов со сглаживанием (антиалиасингом).

``image``
    Загрузка и сохранение изображений. Например, ``pygame.image.save`` позволяет
    сохранить поверхность Surface в графический файл формата PNG.

``joystick``
    Поддержка джойстиков.

``key``
    Опрос состояния клавиш клавиатуры.

``mouse``
    Опрос состояния кнопок и координат указателя мыши.

``power``
    Информация о состоянии электропитания и заряде батареи устройства.

``rect``
    Класс Rect для работы с координатами и размерами прямоугольных областей.

``scrap``
    Доступ к системному буферу обмена.

``surface``
    Класс Surface для работы с растровыми графическими поверхностями.

``time``
    Функции для работы со временем и таймерами, включая класс управления тактовой частотой ``Clock``.

``transform``
    Геометрические трансформации поверхностей Surface: масштабирование, вращение и зеркальное отражение.
