.. _textshaders:

=================
Текстовые шейдеры
=================

В Ren'Py есть система текстовых шейдеров, позволяющая управлять отображением текста на экране.
При включении этой системы движок использует :doc:`модельный рендеринг <model>`, отрисовывая
два треугольника для каждого символа Unicode. Фрагменты шейдеров, заданные разработчиком
или сгенерированные Ren'Py, применяются к модели и изменяют внешний вид и анимацию текста.

Документация по текстовым шейдерам состоит из трёх разделов:

1. Как использовать текстовые шейдеры
2. Встроенные текстовые шейдеры в Ren'Py
3. Как создавать собственные текстовые шейдеры

.. note::

    Хотя использование готовых текстовых шейдеров максимально просто, создание собственных
    требует базовых знаний языка GLSL и системы :doc:`модельного рендеринга <model>`.

Использование текстовых шейдеров
================================

Существуют три способа применения текстовых шейдеров:

**Шейдер по умолчанию.** Первый способ — задать шейдер текста по умолчанию с помощью
переменной :var:`config.default_textshader`::

    define config.default_textshader = "wave:10"

В этом случае шейдер применяется ко всему тексту, для которого не указан иной шейдер.
Он также объединяется с текстовыми шейдерами, включающими шейдер по умолчанию.
Обычно шейдер по умолчанию отвечает за анимацию постепенного появления текста (slow text).

**Стили.** Второй способ — свойство стиля :propref:`textshader` (напрямую или через стили персонажей)::

    style default:
        textshader "dissolve"

    define goldfinger = Character("Голдфингер", what_textshader="linetexture:gold.png")

    screen purchase():
        vbox:
            text "Купите дополнение!" textshader "wave"
            textbutton "Купить":
                text_textshader "wave" action iap.Purchase("dlc")

**Текстовые теги.** Третий способ — использование :tt:`текстового тега <shader>` для стилизации
отдельного фрагмента текста::

    "Что это? Письмо, возникшее {shader=zoom}из ниоткуда{/shader}?"

**Примечание:** Текстовый блок должен либо целиком использовать текстовые шейдеры, либо не использовать
их вовсе — смешивание в одном блоке не поддерживается. Если вы используете тег `{shader=...}`,
установите :var:`config.default_textshader` или свойство стиля :propref:`textshader`.

Задание текстовых шейдеров
--------------------------

Текстовые шейдеры указываются в виде строк, например::

    "dissolve"
    "jitter:u__jitter=1.0, 3.0"
    "texture:gold.png"

Например, для независимого дрожания каждого символа в течение полусекунды::

    "jitter:u__duration=0.5:u__individual=1"

Или внутри строки диалога через текстовый тег::

    "Подожди, {shader=jitter:u__duration=0.5:u__individual=1}что?{/shader}"

По умолчанию эффект jitter продолжается бесконечно и смещает все символы синхронно.
Длительность 0 или отрицательное число означает бесконечную анимацию. Положительная длительность
начинает отсчёт с момента появления текста.

Первая часть строки (до первого двоеточия) — имя текстового шейдера.
Остальная часть строки — последовательность uniform-переменных, разделённых двоеточиями.

Uniform-переменные можно указывать по имени с знаком равенства (`u__jitter=...`) или позиционно по порядку.
Префикс `u_` можно опускать для краткости.

Значением uniform-переменной может быть:

* От 1 до 4 чисел через запятую (для типов float, vec2, vec3 или vec4).
* Цвет, начинающийся с символа # (например, #f00 или #ff0000). Создаёт вектор vec4 с предварительно
  умноженной альфой.
* :doc:`Отображаемый объект <displayables>`, используемый как текстура (тип sampler2D).

Значения uniform-переменных в строке не могут быть выражениями Python, но можно использовать
стандартную интерполяцию строк Ren'Py для подстановки значений.

Текстовые шейдеры можно комбинировать оператором ``|``::

    "jitter:1.0, 3.0|wave"

Это применит к тексту одновременно эффекты jitter и wave (если шейдеры совместимы).

Если для шейдера не указано ``include_default=False``, он автоматически комбинируется
с шейдером по умолчанию :var:`config.default_textshader`.

Обратные вызовы текстовых шейдеров (Callbacks)
----------------------------------------------

Переменная :var:`config.textshader_callbacks` позволяет назначить функцию обратного вызова,
динамически выбирающую шейдер (например, в зависимости от пользовательских настроек)::

    default persistent.dissolve_text = True

    init python:
        def get_default_textshader():
            if persistent.dissolve_text:
                return "dissolve"
            else:
                return "typewriter"

    define config.default_textshader = "default"
    define config.textshader_callbacks["default"] = get_default_textshader

Создание текстовых шейдеров
===========================

Текстовые шейдеры представляют собой программы на языке GLSL, выполняемые на GPU. Они регистрируются
с помощью функции renpy.register_text_shader.

Как и другие шейдеры, текстовые шейдеры пишутся на одном из двух диалектов GLSL (см. :ref:`Версии GLSL <glsl-version>`).

.. include:: inc/textshader

Переменные в текстовых шейдерах
-------------------------------

Помимо пользовательских uniform-переменных (начинающихся с ``u__``), Ren'Py предоставляет шейдерам
текста специальный набор встроенных переменных. Чтобы использовать переменную, объявите её
в аргументе `variables` функции renpy.register_text_shader.

Также доступны стандартные :ref:`uniforms и атрибуты модельного рендеринга <model-uniforms>`
(особенно `a_position`, `a_tex_coord`, `u_time` и `u_random`).

Uniform-переменные
^^^^^^^^^^^^^^^^^^

``float u_text_depth``
    Глубина слоя текста. Основной текст имеет глубину 0.0, первый контур или тень — 1.0, второй контур — 2.0 и т. д.

``float u_text_main``
    Равно 1.0 для основного текста и 0.0 для контура или тени.

``float u_text_max_depth``
    Максимальное значение u_text_depth (общее количество отрисовываемых контуров и теней).

``vec2 u_text_offset``
    Смещение текста от центра символа в физических пикселях отрисовки (x, y).

``float u_text_outline``
    Ширина контура вокруг текста в пикселях.

``float u_text_slow_duration``
    Длительность появления одного символа при медленном выводе текста (0.0 при мгновенном показе).

``float u_text_slow_time``
    Время в секундах с начала эффекта медленного вывода текста. Достигает максимума при завершении
    показа или клике игрока.

``float u_text_time``
    Время в секундах с момента начала отображения текстового блока (продолжает расти всё время показа).

``float u_text_to_drawable``
    Коэффициент масштабирования из виртуальных пикселей в физические пиксели отрисовки.

``float u_text_to_virtual``
    Коэффициент перевода из физических пикселей в виртуальные.

``sampler2D tex0``
    Текстура, содержащая отрисованный текст на текущей глубине.

``vec2 res0``
    Разрешение текстуры tex0 в пикселях отрисовки.

Атрибуты
^^^^^^^^

При отрисовке текста каждая вершина принадлежит отдельному глифу (символу):

``float a_text_ascent``
    Высота выносных элементов шрифта над базовой линией в пикселях.

``vec2 a_text_center``
    Позиция центра базовой линии глифа в пикселях.

``float a_text_descent``
    Глубина спуска шрифта под базовую линию в пикселях.

``float a_text_index``
    Индекс выводимого символа (0 для первого символа, увеличивается на единицу для каждого следующего).

``vec2 a_text_min_time``
    Минимальное время, в которое должна появиться любая вершина глифа.

``vec2 a_text_max_time``
    Максимальное время, в которое должна появиться любая вершина глифа.

``float a_text_time``
    Время, в которое должна отобразиться данная вершина (-3600.0 при мгновенном показе).

``vec4 a_text_pos_rect``
    Прямоугольник глифа (x, y, width, height) в пикселях отрисовки.

``float a_text_pseudo_glyph``
    Равно 1.0, если вершина принадлежит псевдоглифу, иначе 0.0.

Псевдоглифы
-----------

Ren'Py создаёт служебные псевдоглифы в начале и конце каждой строки (или на всю пустую строку).
Они необходимы для покрытия областей, куда могут выступать широкие контуры текста с соседних строк.

Пример
------

Пример текстового шейдера, вращающего символы вокруг своей оси при появлении::

    init python:

        def adjust_extra_slow_time(ts, u__delay, **kwargs):
            """
            Корректирует дополнительное время показа для шейдера вращения.
            """
            ts.extra_slow_time = u__delay

        renpy.register_textshader(
            "spin",
            adjust_function = adjust_extra_slow_time,

            variables = """
            uniform float u__delay;
            uniform float u__offset;
            uniform float u_text_slow_time;
            in vec2 a_text_center;
            in float a_text_min_time;
            """,

            vertex_50 = """
            float l__angle = clamp((u_text_slow_time - a_text_min_time) / u__delay, 0.0, 1.0) * 2.0 * 3.1415926536;
            float l__sin = sin(l__angle);
            float l__cos = cos(l__angle);

            gl_Position.y -= u__offset;
            gl_Position.xy -= a_text_center;
            gl_Position = vec4(
                gl_Position.x * l__cos - gl_Position.y * l__sin,
                gl_Position.x * l__sin + gl_Position.y * l__cos,
                gl_Position.z,
                gl_Position.w
                );
            gl_Position.xy += a_text_center;
            gl_Position.y += u__offset;
            """,

            u__delay = 1.0,
            u__offset = 0,
        )

Использование в сценарии::

    define config.default_textshader = "typewriter"

    label start:

        "Пример использования текстового шейдера {shader=spin:0.5:-5}вращения{/shader}."
