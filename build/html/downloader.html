Загрузчик больших игр на мобильных платформах

На мобильных платформах, таких как Android и iOS, действуют строгие ограничения на максимальный размер приложения, загружаемого непосредственно из магазинов приложений (App Store и Google Play). Для поддержки крупномасштабных игр Ren'Py предоставляет механизм загрузчика: компактную игру-загрузчик, которая скачивает и развёртывает основную игру на устройстве пользователя.

Требования

Для работы этого механизма потребуется надёжный веб-хостинг. Простые файлообменники вроде Mega или страницы игр на itch.io для этой цели не подойдут. Работа загрузчика протестирована на виртуальных серверах (VPS) с веб-сервером Nginx, а также с хранилищем Cloudflare R2, предоставляющим бесплатный тариф до 10 ГБ.

В частности, веб-сервер должен поддерживать прямое скачивание файлов по HTTP/HTTPS, а также параллельные запросы с диапазонами байтов (HTTP Range requests).

Принцип работы

Для использования загрузчика необходимо собрать две отдельные игры:

  1. Игра-загрузчик (downloader game) — компактное приложение, содержащее движок Ren'Py и логику загрузчика. Именно этот файл упаковывается и публикуется в магазине приложений.

  2. Основная игра (main game) — полноценная визуальная новелла, в которую будет играть пользователь. Она скачивается игрой-загрузчиком и устанавливается во внутреннюю память устройства.

Обе игры должны быть собраны на одной и той же версии Ren'Py. При несовпадении версий загрузчик автоматически обновит основную игру. В дальнейшем основная игра может обновлять себя самостоятельно, поскольку система обновления Ren'Py Updater теперь поддерживает мобильные устройства.

При запуске игры-загрузчика она проверяет наличие установленной основной игры. Если игра найдена и версии совпадают, немедленно запускается основная игра. В противном случае запускается процесс загрузки с предложением скачать необходимые файлы.

Сборка и выгрузка основной игры

Главное изменение, которое необходимо внести в проект основной игры — добавить строку:

define build.game_only_update = True

в начало файла options.rpy. Это активирует новый пункт меню в разделе лаунчера «Сборка дистрибутивов» (Build Distributions) — «Game-Only Update for Mobile» (Обновление только файлов игры для мобильных платформ).

В окне «Сборка дистрибутивов» отметьте пункт «Game-Only Update for Mobile» и снимите флажки со всех остальных пакетов сборки. В блоке параметров убедитесь, что включён пункт «Собрать обновления» (Build Updates), а остальные параметры выставлены по вашему усмотрению (значений по умолчанию обычно достаточно).

Затем запустите сборку.

По завершении сборки в каталоге проекта появятся файлы обновления. Вам необходимо загрузить на свой веб-сервер файлы updates.json, updates.ecdsa и всю папку rpu/ с её содержимым (убедитесь, что каталог rpu/ расположен на сервере рядом с файлами updates.json и updates.ecdsa, а файлы .rpu находятся внутри папки rpu/).

Создание игры-загрузчика

Игра-загрузчик представляет собой стандартный проект Ren'Py, размер которого должен быть значительно меньше 100 МБ. В ней можно реализовать любую логику небольшой игры: показать начальную заставку, проиграть фоновую музыку и т. д. Её проект создаётся отдельно и собирается для Android или iOS по стандартной схеме.

При этом игра должна запросить подтверждение пользователя на загрузку, предупредить о возможном расходе мобильного трафика и начать скачивание.

Для максимальной безопасности скопируйте открытый ключ public_key.pem, созданный при сборке основной игры, в базовый каталог проекта игры-загрузчика. Этот публичный ключ будет использоваться для криптографической проверки подлинности скачиваемых пакетов.

Пример сценария игры-загрузчика (с использованием графики из демонстрационного проекта):

# URL-адрес к updates.json на вашем веб-сервере.
define URL = "https://www.domain.com/game-updates/updates.json"

# Отключаем сохранения в игре-загрузчике.
define config.save = False

define e = Character("Эйлин", image="eileen")

label splashscreen:

    scene bg washington
    show eileen happy at left

    $ downloader = updater.start_game_download(URL)

    e "Добро пожаловать в загрузчик игры."

    e "Сейчас на ваш телефон будут загружены файлы основной игры."

    if downloader.download_total:
        $ download_mb = int(round(downloader.download_total / 1024 / 1024, 0))

        e "Для запуска игры необходимо скачать [download_mb] МБ данных. Если вы не подключены к Wi-Fi, мобильный оператор может списать плату за трафик. Коснитесь экрана для продолжения."

    else:

        e "Для запуска игры необходимо скачать файлы данных. Если вы не подключены к Wi-Fi, мобильный оператор может списать плату за трафик. Коснитесь экрана для продолжения."

    $ updater.continue_game_download()

Этот сценарий достаточно прост, но в нём есть важные детали. Во-первых, переменная config.save устанавливается в False. Это критически важно: так отключается система сохранений и настроек загрузчика, чтобы они не конфликтовали с основной игрой.

Весь код размещается в метке splashscreen, благодаря чему он начинает выполняться сразу при запуске без входа в главное меню игры.

В начале вызывается updater.start_game_download() для запроса метаданных о размере загрузки. Пока движок опрашивает сервер, игра отображает диалог с Эйлин, с пользой занимая время ожидания ответа.

После нескольких кликов игрока размер загрузки либо уже определён, либо ещё неизвестен, поэтому используется условие проверки downloader.download_total. Если размер известен, он переводится в мегабайты и сообщается игроку, иначе выводится обобщённый текст (также можно указать примерный размер игры вручную).

Наконец, вызывается updater.continue_game_download(), запускающая непосредственное скачивание. На экране появляется интерфейс загрузки — в этот момент управление ограничено, однако музыка продолжает играть, а анимации ATL продолжают работать.

После успешного скачивания основная игра запустится автоматически. В случае сетевого сбоя загрузчик перезапустится, позволяя игроку повторить попытку.

Экран загрузчика

Интерфейс процесса скачивания отображается с помощью экрана downloader. Стандартный экран определён в файле renpy/common/00updater.rpy, и его можно переопределить, скопировав в каталог game/ вашего проекта.

Исходный код стандартного экрана:

screen downloader(u):

    style_prefix "downloader"

    frame:

        has vbox

        if u.state == u.CHECKING or u.state == u.PREPARING:
            text _("Подготовка к загрузке данных игры.")
        elif u.state == u.DOWNLOADING or u.state == u.UNPACKING:
            text _("Загрузка данных игры.")
        elif u.state == u.FINISHING or u.state == u.DONE:
            text _("Данные игры успешно загружены.")
        else: # Ошибка или неизвестное состояние.
            text _("Произошла ошибка при загрузке данных игры:")

            if u.message is not None:
                text "[u.message!q]"

            text _("Игра не может быть запущена без загрузки необходимых файлов.")

        if u.progress is not None:
            null height gui._scale(10)
            bar value (u.progress or 0.0) range 1.0

        if u.can_proceed:
            textbutton _("Повторить") action u.proceed

style downloader_frame:
    xalign 0.5
    xsize 0.5
    xpadding gui._scale(20)

    ypos .25
    ypadding gui._scale(20)

style downloader_vbox:
    xfill True
    spacing gui._scale(10)

style downloader_text:
    xalign 0.5
    text_align 0.5
    layout "subtitle"

style downloader_label:
    xalign 0.5

style downloader_button:
    xalign 0.5

Функции загрузчика

updater.continue_game_download(screen='downloader')

Продолжает процесс скачивания игровых данных. Цикл выполняется до тех пор, пока загрузка не завершится или пользователь не выйдет из игры.

updater.start_game_download(url, **kwargs)

Начинает процесс скачивания игровых данных по указанному url. Запускает процедуру проверки необходимых для загрузки пакетов и возвращает объект Update.
