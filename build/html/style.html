Стили

Стили позволяют настраивать внешний вид отображаемых объектов путем изменения значений свойств стиля. Например, изменяя свойство background, можно изменить фон окна диалога или кнопки.

Свойствам стилей (Свойства стилей) могут предшествовать префиксы-идентификаторы, указывающие, в каком состоянии объекта применяется свойство. Например, свойство кнопки hover_background используется при наведении курсора (фокусе), тогда как idle_background — в состоянии покоя. (Задание базового свойства background одновременно устанавливает и idle_background, и hover_background, среди прочих).

Хотя Ren'Py поддерживает более 100 свойств стиля, в данном разделе рассматриваются лишь некоторые из них.

Использование стилей и наследование

Каждый отображаемый объект имеет встроенный в него стиль. При создании отображаемого объекта (напрямую в Python или через систему экранов) ему можно передать свойства стиля, изменяющие его вид. В следующем примере:

image big hello world = Text("Привет, мир", size=40)

свойство size передается отображаемому объекту Text, позволяя задать размер текста. Это изменит вид объекта, отображая текст высотой в 40 пикселей (что также зависит от параметров шрифта).

Аналогично в языке экранов (Screen Language) каждый оператор пользовательского интерфейса принимает соответствующие свойства стиля:

screen big_hello_world:
    text "Привет, мир" size 40

Отдельные стили существуют для группировки свойств, чтобы их можно было применять к отображаемым объектам совместно. Например, эти два текста будут выглядеть одинаково:

image big one = Text("Привет, мир", size=40, color="#f00")
image big two = Text("Привет, мир", style="big_red")

style big_red:
    size 40
    color "#f00"

Каждый стиль содержит набор свойств и имеет одного родителя. Когда заданный стиль применяется к отображаемому объекту, каждое свойство стиля ищется среди свойств самого стиля. Если оно не найдено, поиск продолжается в родительском стиле, затем в родителе родителя и так далее по цепочке наследования.

Каждый отображаемый объект принимает свойство style, применяющее указанный стиль к объекту:

image big hello world = Text("Привет, мир", style="big")

screen hello_world:
    text "Привет, мир" style "big"

Если свойство style не указано, родитель выбирается автоматически на основе типа отображаемого объекта. Например, кнопки (включая imagebutton и textbutton) по умолчанию используют стиль "button", сетки — стиль "grid" и так далее. На выбор родителя также влияет свойство style_prefix операторов в языке экранов.

Когда стиль определяется без явного указания родителя, родитель выбирается автоматически. Если имя стиля содержит символ подчеркивания (_), имя родителя формируется путем отсечения всего текста до первого подчеркивания включительно. При обращении к несуществующему стилю, имя которого содержит подчеркивание, Ren'Py автоматически создаст его с родителем по умолчанию. Например, стиль my_button унаследует свойства от стиля button. Наследование можно изменить с помощью оператора style или методов класса Style. В остальных случаях родителем выступает стиль "default".

Имена стилей, начинающиеся с символа подчеркивания, зарезервированы для внутреннего использования движком Ren'Py.

Поскольку Ren'Py строит дерево стилей при запуске игры, именованные стили не следует изменять после завершения фазы инициализации.

Во время разработки очень полезен инспектор стилей (Shift+I), позволяющий проверить, какие стили и свойства применяются к отображаемому объекту под курсором.

Определение стилей: оператор style

Предпочтительным способом определения стилей является оператор style:

style my_text is text:
    size 40
    font "gentium.ttf"

Если стиль с таким именем еще не существует, оператор style создает его. В противном случае существующий стиль дополняется или изменяется.

Примечание

В отличие от операторов screen, transform или image, оператор style не уникален для конкретного имени: несколько операторов могут ссылаться на один и тот же стиль и модифицировать его последовательно, иногда конкурирующим образом. В таких случаях порядок выполнения на этапе инициализации имеет решающее значение для итогового результата.

Оператор style начинается с ключевого слова style и имени определяемого стиля. Далее на первой строке могут следовать клаузы и необязательное двоеточие.

Если двоеточие присутствует, за ним должен следовать блок с отступом, каждая строка которого содержит одну или несколько клауз.

Оператор style принимает следующие клаузы:

свойство-стиля простое-выражение

Присваивает значение простого выражения указанному свойству стиля.

is родитель

Устанавливает или заменяет родителя стиля. Родителем должно быть слово с именем стиля.

clear

Удаляет все свойства стиля, присвоенные до выполнения этого оператора. Это не мешает стилю наследовать свойства от родителей и не изменяет родителя стиля. Чтобы сбросить родителя стиля, используйте вместо этого конструкцию is default.

take имя-стиля

Очищает все ранее заданные свойства этого стиля и заменяет их свойствами указанного стиля. Не изменяет родителя стиля.

variant простое-выражение

Вычисляет выражение для получения строки или списка строк, интерпретируемых как варианты экранов. Если хотя бы один из вариантов активен, оператор выполняется, иначе блок игнорируется.

properties простое-выражение

Вычисляет словарь, сопоставляющий свойства стилей значениям. Значения присваиваются так, будто они были перечислены напрямую в операторе style.

Примеры операторов style:

# Создает новый стиль, наследуемый от default.
style big_red:
    size 40

# Обновляет существующий стиль.
style big_red color "#f00"

# Заимствует свойства big_red для label_text, но только на сенсорных устройствах.
style label_text:
    variant "touch"
    take big_red

# Стиль a получает все свойства стиля c; отсутствующие в c свойства
# берутся из b или родителей b.
style a is b:
    take c

Операторы style всегда выполняются во время фазы инициализации.

Определение стилей в Python

Именованные стили доступны как атрибуты глобального объекта style. Чтобы создать новый стиль, создайте экземпляр класса Style и присвойте его полю объекта style:

init python:
    style.big_red = Style(style.default)

Свойства стиля можно задавать, присваивая значения полям объектов Style:

init python:
    style.big_red.color = "#f00"
    style.big_red.size = 42

Обратите внимание, что значения свойств стиля нельзя прочитать таким способом — в них можно только записывать.

class Style(parent)
parent

Родительский стиль. Может быть другим объектом Style или строкой с именем стиля.

clear()

Удаляет все свойства стиля из этого объекта. Значения будут наследоваться от родителя этого объекта.

Эквивалент клаузы clear в операторе style.

set_parent(parent)

Устанавливает родителя стиля в parent (объект Style или строку с именем).

Эквивалент клаузы is в операторе style.

take(other)

Заимствует все свойства стиля из other (объект Style или строку).

Эквивалент клаузы take в операторе style.

Индексированные стили

Индексированные стили — это легковесные стили, используемые для настройки вида отображаемого объекта на основе переданных ему данных. Индексированный стиль создается путем индексации существующего объекта Style строкой или целым числом. Если индексированный стиль еще не существует, индексация автоматически создает его как дочерний элемент исходного объекта Style.

init python:
    style.button["Foo"].background = "#f00"
    style.button["Bar"].background = "#00f"

screen indexed_style_test:
    vbox:
        textbutton "Foo" style style.button["Foo"]
        textbutton "Bar" style style.button["Bar"]

Настройки стилей

Примечание

Настройки GUI часто предоставляют более удобный способ решения аналогичных задач, так как настройка GUI может менять переменную, используемую во множестве стилей одновременно.

Часто желательно предоставить пользователю возможность настраивать аспекты интерфейса, выраженные в виде стилей (например, размер текста, цвет шрифта или обводку). Для этого служат настройки стилей (style preferences).

Настройка стиля управляет одним или несколькими свойствами стиля. Она имеет имя и один или несколько вариантов (альтернатив). В любой момент времени выбран один из вариантов, который сохраняется в постоянных данных (persistent data). По умолчанию выбирается первый зарегистрированный вариант.

Вариант содержит одну или несколько привязок стиля, свойства и его значения. При выборе этого варианта (а также при первом запуске игры) указанным свойствам стилей присваиваются соответствующие значения.

Следует следить за тем, чтобы все варианты одной настройки стиля изменяли один и тот же набор стилей и свойств во избежание недетерминированного поведения.

Пример регистрации настройки стиля, позволяющей пользователю выбирать между крупным простым текстом и меньшим текстом с контуром:

init python:
    # Вариант "decorated" настройки "text" устанавливает размер 22 для стиля "say_dialogue".
    renpy.register_style_preference("text", "decorated", style.say_dialogue, "size", 22)
    renpy.register_style_preference("text", "decorated", style.say_dialogue, "outlines", [ (1, "#000", 0, 0) ])

    renpy.register_style_preference("text", "large", style.say_dialogue, "size", 24)
    renpy.register_style_preference("text", "large", style.say_dialogue, "outlines", [ ])

    # Вариант "decorated" будет вариантом по умолчанию, так как он был зарегистрирован первым.

Переключение вариантов с помощью кнопок:

textbutton "С оформлением" action StylePreference("text", "decorated")
textbutton "Крупный" action StylePreference("text", "large")
StylePreference(preference, alternative)

Действие, которое устанавливает alternative в качестве выбранного варианта для указанной настройки стиля.

При вызове этого действия генерируется событие update.

preference

Строка с именем настройки стиля.

alternative

Строка с именем варианта настройки.

renpy.get_style_preference(preference)

Возвращает строку с именем выбранного варианта для указанной настройки стиля.

preference

Строка с именем настройки стиля.

renpy.register_style_preference(preference, alternative, style, property, value)

Регистрирует информацию о варианте для настройки стиля.

preference

Строка, имя настройки стиля.

alternative

Строка, имя варианта.

style

Стиль, который будет обновляться. Может быть объектом стиля или строкой с его именем.

property

Строка с именем обновляемого свойства стиля.

value

Значение, которое будет присвоено свойству стиля.

renpy.set_style_preference(preference, alternative)

Устанавливает выбранный вариант для настройки стиля.

При вызове этой функции генерируется событие update.

preference

Строка с именем настройки стиля.

alternative

Строка с именем варианта.

Другие функции стилей

style.rebuild()

Заставляет Ren'Py перестроить именованные стили, позволяя вносить изменения в стили после завершения фазы инициализации.

Предупреждение

Именованные стили не сохраняются в файлах сохранений игры. Это означает, что изменения, внесенные в них, не переживут цикл сохранения и загрузки.
