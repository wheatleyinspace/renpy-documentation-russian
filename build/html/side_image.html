Боковые изображения

Во многих визуальных новеллах портрет говорящего персонажа отображается как часть интерфейса. В Ren'Py такое изображение называется боковым изображением (side image). Движок поддерживает автоматический выбор и отображение бокового изображения во время диалога.

Поддержка боковых изображений предполагает, что персонаж Character() объявлен со связанным тегом изображения:

define e = Character("Эйлин", image="eileen")

Когда персонаж говорит, Ren'Py ищет подходящее боковое изображение. Боковое изображение должно иметь:

  • Тег "side".

  • Атрибут, соответствующий связанному тегу изображения говорящего персонажа (в данном случае "eileen").

  • Как можно больше атрибутов, которые в данный момент связаны с тегом изображения говорящего персонажа.

Затем Ren'Py ищет единственное изображение, удовлетворяющее этим критериям. Если такое изображение найдено, оно используется в качестве бокового изображения. Если изображение не найдено или найдено более одного подходящего изображения, боковое изображение показано не будет.

Например, пусть у нас есть следующий сценарий:

define e = Character("Эйлин", image="eileen")

image eileen happy = "eileen_happy.png"
image eileen concerned = "eileen_concerned.png"
image eileen space suit = "eileen_space_suit.png"


image side eileen happy = "side_eileen_happy.png"
image side eileen = "side_eileen.png"
image side eileen space = "side_eileen_space.png"
image side eileen suit = "side_eileen_suit.png"

label start:

    show eileen happy

    e "Обозначим эту реплику как точку A."

    e concerned "А эту реплику как точку B."

    e space suit "И эту реплику как точку C."

В точке A говорит персонаж e, связанный с тегом изображения "eileen". На экране отображается изображение "eileen happy", поэтому атрибут "eileen" должен присутствовать обязательно, а "happy" — по возможности. Мы ищем изображение с тегом "side" и как можно большим количеством этих атрибутов — и находим "side eileen happy", которое Ren'Py и выведет на экран.

В точке B отображается изображение "eileen concerned". Атрибут "eileen" должен присутствовать обязательно, а "concerned" — по возможности. Мы ищем изображение с тегом "side" и максимальным совпадением атрибутов и находим "side eileen", так как изображение "side eileen concerned" не существует.

Наконец, в точке C отображается изображение "eileen space suit". Атрибут "eileen" обязателен, а "space" и "suit" желательны. Мы ищем изображение с тегом "side" и максимальным числом совпадений, и получаем сразу два варианта: "side eileen space" и "side eileen suit". Поскольку оба имеют одинаковое количество совпадающих атрибутов, Ren'Py не может сделать однозначный выбор между ними, и боковое изображение не отображается.

Невидимые персонажи

Другое применение бокового изображения — отображение портрета персонажа игрока, когда этот персонаж произносит реплику. Для этого свяжите тег изображения с персонажем, а затем используйте конструкцию реплики с атрибутами (say with attributes) для выбора отображаемого бокового изображения.

Например:

define p = Character("Игрок", image="player")

image side player happy = "side_player_happy.png"
image side player concerned = "side_player_concerned.png"

label start:

    p happy "Эта реплика отображается с изображением 'side player happy'."

    p "Эта реплика также отображается с 'side player happy'."

    p concerned "А эта реплика отображается с 'side player concerned'."

Переменные конфигурации и хранилища

Существует ряд параметров боковых изображений, которыми можно управлять с помощью переменных конфигурации.

_side_image_tag = None
define config.side_image_tag = None

Если значение _side_image_tag не равно None, оно имеет приоритет над config.side_image_tag.

Если эта переменная задана, боковое изображение отслеживает указанный тег изображения, а не изображение, связанное с говорящим в данный момент персонажем. Например:

define e = Character("Эйлин", image="eileen")
define config.side_image_tag = "eileen"

Указывает боковому изображению отслеживать тег изображения "eileen", связанный с персонажем e.

define config.side_image_only_not_showing = False

Если установлено значение True, боковое изображение отображается только в том случае, если изображение с этим тегом ещё не выведено на экран.

_side_image_prefix_tag = None
define config.side_image_prefix_tag = 'side'

Если значение _side_image_prefix_tag не равно None, оно имеет приоритет над config.side_image_prefix_tag.

Префикс тега, используемый при поиске бокового изображения.

define config.side_image_null = Null()

Отображаемый объект Null, используемый, когда боковое изображение не отображается. Значение можно изменять, но только на другие объекты Null. Одной из причин изменения может быть необходимость задать размер Null (например, Null(width=200, height=150)), чтобы растворения (dissolve) не обрезались.

define config.side_image_same_transform = None

Если не None, трансформация, которая применяется, когда новое боковое изображение имеет тот же тег изображения, что и предыдущее боковое изображение.

define config.side_image_change_transform = None

Если не None, трансформация, которая применяется, когда новое боковое изображение не имеет того же тега изображения (или если одно из изображений — старое или новое — отсутствует).

Трансформации и переходы

Трансформации config.side_image_same_transform и config.side_image_change_transform вызываются с двумя аргументами — старым и новым отображаемыми объектами бокового изображения — при каждом отображении бокового изображения. Их можно использовать для перемещения боковых изображений или применения переходов между ними.

Следующий код заставляет боковое изображение плавно выезжать и заезжать при смене связанного с изображением персонажа:

transform change_transform(old, new):
    contains:
        old
        yalign 1.0
        xpos 0.0 xanchor 0.0
        linear 0.2 xanchor 1.0
    contains:
        new
        yalign 1.0
        xpos 0.0 xanchor 1.0
        linear 0.2 xanchor 0.0

define config.side_image_change_transform = change_transform

Следующий пример используется для растворения между старым и новым боковыми изображениями, когда персонаж остаётся прежним (например, при смене эмоции персонажа). Для правильной работы Dissolve оба боковых изображения должны иметь одинаковый размер:

transform same_transform(old, new):
    old
    new with Dissolve(0.2, alpha=True)

define config.side_image_same_transform = same_transform

Если отображаемый объект SideImage() уменьшается в масштабе, имеет смысл включить мипмаппинг в Dissolve():

transform same_transform(old, new):
    old
    new with Dissolve(0.2, alpha=True, mipmap=True)

define config.side_image_same_transform = same_transform

Функции

renpy.get_side_image(prefix_tag, image_tag=None, not_showing=None, layer=None)

Пытается найти изображение для отображения в качестве бокового изображения.

Сначала определяет набор атрибутов изображения. Если указан image_tag, атрибуты изображения извлекаются из этого тега. В противном случае они извлекаются из свойства image, переданного говорящему в данный момент персонажу. Если атрибуты недоступны, функция возвращает None.

Затем выполняется поиск изображения с тегом prefix_tag и атрибутами, состоящими из:

  • Тега изображения (из image_tag или свойства image говорящего персонажа).

  • Атрибутов.

Если такое изображение существует, оно возвращается.

not_showing

Если значение равно True, боковое изображение возвращается только в том случае, если изображение с тегом, из которого берутся атрибуты, в данный момент не отображается на экране. Если False, функция всегда возвращает изображение при наличии возможности. Если None, берётся значение из config.side_image_only_not_showing.

layer

Если указан, слой, на котором выполняется поиск тега изображения и атрибутов. Если None, используется слой по умолчанию для данного тега.

renpy.set_tag_attributes(name, layer=None)

Устанавливает атрибуты, связанные с тегом изображения, когда это изображение не отображается на экране. Основное применение функции — прямая установка атрибутов, используемых боковым изображением.

Например:

$ renpy.set_tag_attributes("lucy mad")
$ renpy.say(l, "Я очень рассержена.")

и:

l mad "Я очень рассержена."

эквивалентны.
