История диалогов

В Ren'Py есть система истории диалогов (лога реплик), которая сохраняет каждую строку диалога после её показа игроку. Сохранённые строки можно повторно просматривать в специальном окне журнала.

Система истории диалогов управляется двумя переменными:

Переменная config.history_length задаёт максимальное количество сохраняемых записей истории и должна быть установлена для включения истории в игре. Переменная _history позволяет временно отключать и повторно включать запись реплик в историю.

Переменная _history_list хранит фактический список записей истории в виде объектов HistoryEntry. Объекты HistoryEntry содержат следующие поля данных:

class HistoryEntry
kind

Тип персонажа, создавшего запись. Во время показа реплики Ren'Py устанавливает это поле в "current", а затем в "adv" или "nvl".

who

Строка с именем говорящего персонажа или None, если имя отсутствует.

what

Строка с текстом произнесённой реплики.

who_args

Словарь со свойствами стиля, переданными текстовому виджету who (имя персонажа) при показе.

what_args

Словарь со свойствами стиля, переданными текстовому виджету what (текст реплики).

window_args

Словарь свойств стиля окна диалога при показе.

show_args

Словарь свойств, переданных экрану say при показе реплики.

image_tag

Тег изображения, связанный с Character(), или None, если тег не был задан.

voice

Объект, возвращаемый функцией _get_voice_info(), хранящий информацию о воспроизводимом голосовом файле.

rollback_identifier

Идентификатор, который можно передать действию RollbackToIdentifier() для отката к строке сценария, создавшей эту запись истории. Откат возможен только в том случае, если точка всё ещё присутствует в журнале отката; иначе действие неактивно.

После создания объект HistoryEntry передаётся каждой функции обратного вызова из списка config.history_callbacks, что позволяет пользовательскому коду добавлять собственные поля данных.
