Текстовые облачка (Speech Bubbles)

Ren'Py поддерживает отображение диалогов в текстовых облачках (речевых бабблах), которые можно интерактивно размещать на экране. Это предоставляет альтернативу стандартным текстовым окнам игр стиля ADV и полноэкранному тексту в режиме NVL.

Чтобы использовать текстовые облачка в вашей игре, вам потребуется объявить персонажей (Character) с тегом изображения и типом bubble. Например:

define e = Character(None, image="eileen", kind=bubble) # Эйлин
define l = Character(None, image="lucy", kind=bubble)   # Люси

Хотя указание имени персонажа поддерживается, в большинстве случаев говорящий персонаж понятен по направлению «хвостика» баббла, поэтому имя можно опустить.

После этого вы можете писать диалоги для этих персонажей обычным образом.

Чтобы позиционировать бабблы, нажмите комбинацию клавиш Shift+B для вызова редактора речевых облачков. Для каждого персонажа с активным бабблом в редакторе будут отображаться две кнопки.

Нажатие кнопки области (area) запускает режим редактирования области. Этот редактор позволяет перетаскиванием мыши выделить прямоугольную область на сетке, где будет расположен баббл. После отпускания кнопки мыши баббл переместится в указанное место.

Нажатие кнопки свойств (properties) переключает между наборами свойств, связанными с данным бабблом. Для баббла по умолчанию различные наборы свойств управляют положением хвостика облачка.

После того как вы изменили область или свойства для персонажа (или группы персонажей с одинаковыми тегами изображений), эти параметры остаются в силе до следующего изменения или до следующей инструкции scene.

Когда область или свойства задаются непосредственно на текущей строке диалога, соответствующая кнопка подсвечивается ярче. Если значения наследуются из предыдущей строки диалога или установлены по умолчанию, кнопка затемнена. Клик правой кнопкой мыши по кнопке предотвращает сохранение этого значения для текущей строки.

Удерживаемые бабблы (Retained Bubbles)

Ren'Py поддерживает режим, при котором бабблы сохраняются между строками диалога, появляясь один за другим, пока предыдущие облачка не будут очищены с экрана. Чтобы включить этот режим, установите свойство retain персонажа-баббла в True:

define e = Character(None, image="eileen", kind=bubble, retain=True)

После этого облачка будут продолжать оставаться на экране. Каждое облачко потребуется разместить индивидуально, чтобы они не перекрывали друг друга. В редакторе бабблов нажатие кнопки «(clear retained bubbles)» удаляет все удерживаемые бабблы с экрана, кроме самого последнего.

При перемещении к строке диалоги с бабблами восстанавливают удерживаемые бабблы и историю диалогов вдоль воспроизведённого пути. Правила компоновки бабблов и автоматической очистки сохраняются; бабблы без флага retain не остаются на экране.

Советы

Речевые бабблы используют те же идентификаторы строк, что и система переводов. Подробнее о них см. раздел Советы по переводу. Эти идентификаторы могут измениться, если:

  • Изменяется текст реплики.

  • Добавляется или удаляется другая реплика с таким же текстом внутри той же метки.

  • Добавляется или удаляется метка перед репликой (однако добавление или удаление метки с параметром hide не меняет идентификатор перевода).

Если вы отредактировали сцену, рекомендуется воспроизвести её, чтобы убедиться, что изменения не повлияли на позиционирование бабблов.

К бабблам можно применять трансформации, отредактировав экран bubble.

Если вы хотите, чтобы индикатор клика (CTC) отображался внутри экрана баббла, передайте аргументу ctc_position функции Character значение "screen-variable". Также может потребоваться добавить:

showif ctc:
    add ctc

в конец экрана bubble, если эта строка там отсутствует. Затем персонаж определяется следующим образом:

define e = Character(
    None,
    image="eileen",
    kind=bubble,
    ctc_position="screen-variable",
    ctc=Transform("ctc_image.png", align=(0.5, 1.0))
    )

Переменные конфигурации

Система речевых бабблов управляется переменными в пространстве имён bubble, а также экраном bubble и связанными с ним стилями.

Пространство имён bubble содержит следующие переменные:

bubble.area_property = "window_area"

Имя свойства, содержащего область речевого баббла. Задаётся так же, как если бы передавалось в Character(), с той же системой префиксов. По умолчанию это "window_area", что означает, что область передаётся как свойство отображаемому объекту window. Другой полезный вариант — "show_area", при котором область передаётся как аргумент area непосредственно в экран bubble.

bubble.clear_retain_statements = [ "call screen", "menu",  "say", "say-centered", "say-nvl", "scene", ]

Список инструкций, выполнение которых автоматически приводит к очистке удерживаемых бабблов.

bubble.cols = 24

Дискретность сетки по горизонтали, используемой для позиционирования и изменения размеров бабблов.

bubble.db_filename = "bubble.json"

Файл базы данных в каталоге игры, содержащий информацию о расположении речевых бабблов.

bubble.default_area = (15, 1, 8, 5)

Область по умолчанию для размещения речевых бабблов, если иная область не указана. Представляет собой кортеж вида (x, y, w, h), где каждое значение указывает количество ячеек сетки.

bubble.expand_area = { ... }

Отображение из имени набора свойств в кортеж (left, top, right, bottom). Если имя найдено в этом словаре, область баббла расширяется на указанное количество пикселей.

Это делает баббл больше области, выделенной разработчиком. Это предназначено для того, чтобы выделять основную часть («тело») баббла без оглядки на хвостик, а также чтобы сам текст оставался на месте при переключении набора свойств и перемещении хвостика.

По умолчанию задано следующее значение:

define bubble.expand_area = {
    "bottom_left" : (0, 0, 0, 22),
    "bottom_right" : (0, 0, 0, 22),
    "top_left" : (0, 22, 0, 0),
    "top_right" : (0, 22, 0, 0),
}
bubble.layer = "screens"

Слой, на котором размещаются обычные (неудерживаемые) бабблы.

bubble.properties = { ... }

Свойства (помимо области), используемые для настройки речевого баббла. Это словарь, сопоставляющий имя набора свойств со словарём свойств и их значений. Эти свойства переопределяют свойства персонажа и передаются в экран bubble.

Используется та же система префиксов, что и в Character(). У свойств с префиксом window_ префикс удаляется, и они передаются отображаемому объекту с идентификатором "window" в экране bubble (то есть самому бабблу). Свойства с what_ передаются объекту с id "what" (тексту внутри баббла). Свойства с who_ передаются имени персонажа. Свойства с show_ передаются как аргументы самому экрану bubble.

В новом проекте файл screens.rpy содержит:

define bubble.frame = Frame("gui/bubble.png", 55, 55, 55, 95)

define bubble.properties = {
    "bottom_left" : {
        "window_background" : Transform(bubble.frame, xzoom=1, yzoom=1),
        "window_bottom_padding" : 27,
    },

    "bottom_right" : {
        "window_background" : Transform(bubble.frame, xzoom=-1, yzoom=1),
        "window_bottom_padding" : 27,
    },

    "top_left" : {
        "window_background" : Transform(bubble.frame, xzoom=1, yzoom=-1),
        "window_top_padding" : 27,
    },

    "top_right" : {
        "window_background" : Transform(bubble.frame, xzoom=-1, yzoom=-1),
        "window_top_padding" : 27,
    },
}

Переменная bubble.frame используется для удобства задания bubble.properties. Для каждого из четырёх стилей баббл зеркально отражается, чтобы хвостик оказался в нужном месте, а внутренние отступы (padding) корректируются, чтобы освободить место под хвостик.

bubble.properties_order = [ ]

Список имён наборов свойств в том порядке, в котором они должны переключаться в редакторе речевых бабблов. Если список не задан, свойства переключаются в алфавитном порядке.

bubble.properties_callback = None

Если не None, функция, принимающая тег изображения и возвращающая список или кортеж имён свойств, которые должны использоваться для этого тега, в порядке их переключения. Имеет приоритет над bubble.properties_order и может использоваться для индивидуальной настройки списка свойств для каждого персонажа.

bubble.retain_layer = "screens"

Слой, на котором размещаются удерживаемые бабблы.

bubble.rows = 24

Дискретность сетки по вертикали, используемой для позиционирования и изменения размеров бабблов.

Экран bubble

Экран bubble по умолчанию находится в screens.rpy и устроен аналогично экрану say:

screen bubble(who, what):
    style_prefix "bubble"

    window:
        id "window"

        if who is not None:

            window:
                id "namebox"
                style "bubble_namebox"

                text who:
                    id "who"

        text what:
            id "what"

Он отделён от экрана say, поскольку использует собственный набор стилей: bubble_window, bubble_what, bubble_namebox и bubble_who. Эти стили можно настраивать напрямую, чтобы избежать необходимости указывать свойства во всех наборах свойств в bubble.properties.

Если вы хотите применить визуальные эффекты к речевому бабблу, вы можете добавить трансформацию к экрану bubble, реагирующую на события трансформации show и hide:

screen bubble(who, what):
    style_prefix "bubble"

    window:
        id "window"

        at transform:
            on show:
                alpha 0.0
                linear .5 alpha 1.0

            on hide:
                linear .5 alpha 0.0

        if who is not None:

            window:
                id "namebox"
                style "bubble_namebox"

                text who:
                    id "who"

        text what:
            id "what"

Добавление поддержки бабблов в существующую игру

Игры, созданные до выхода Ren'Py 8.1, не содержат стандартных экранов и настроек, необходимых для системы речевых бабблов. Чтобы добавить их, выполните два шага. Сначала скачайте:

  • https://raw.githubusercontent.com/renpy/renpy/master/gui/game/gui/bubble.png

  • https://raw.githubusercontent.com/renpy/renpy/master/gui/game/gui/thoughtbubble.png

и поместите эти файлы в каталог game/gui вашей игры. Затем добавьте следующий код в конец файла screens.rpy:

## Bubble screen ###############################################################
##
## Экран bubble используется для отображения диалогов игроку при использовании
## речевых бабблов. Экран bubble принимает те же параметры, что и экран say,
## обязан создавать отображаемый объект с id "what", и может создавать
## отображаемые объекты с id "namebox", "who" и "window".
##
## https://www.renpy.org/doc/html/bubble.html#bubble-screen

screen bubble(who, what):
    style_prefix "bubble"

    window:
        id "window"

        if who is not None:

            window:
                id "namebox"
                style "bubble_namebox"

                text who:
                    id "who"

        text what:
            id "what"

style bubble_window is empty
style bubble_namebox is empty
style bubble_who is default
style bubble_what is default

style bubble_window:
    xpadding 30
    top_padding 5
    bottom_padding 5

style bubble_namebox:
    xalign 0.5

style bubble_who:
    xalign 0.5
    textalign 0.5
    color "#000"

style bubble_what:
    align (0.5, 0.5)
    text_align 0.5
    layout "subtitle"
    color "#000"

define bubble.frame = Frame("gui/bubble.png", 55, 55, 55, 95)
define bubble.thoughtframe = Frame("gui/thoughtbubble.png", 55, 55, 55, 55)

define bubble.properties = {
    "bottom_left" : {
        "window_background" : Transform(bubble.frame, xzoom=1, yzoom=1),
        "window_bottom_padding" : 27,
    },

    "bottom_right" : {
        "window_background" : Transform(bubble.frame, xzoom=-1, yzoom=1),
        "window_bottom_padding" : 27,
    },

    "top_left" : {
        "window_background" : Transform(bubble.frame, xzoom=1, yzoom=-1),
        "window_top_padding" : 27,
    },

    "top_right" : {
        "window_background" : Transform(bubble.frame, xzoom=-1, yzoom=-1),
        "window_top_padding" : 27,
    },

    "thought" : {
        "window_background" : bubble.thoughtframe,
    }
}

define bubble.expand_area = {
    "bottom_left" : (0, 0, 0, 22),
    "bottom_right" : (0, 0, 0, 22),
    "top_left" : (0, 22, 0, 0),
    "top_right" : (0, 22, 0, 0),
    "thought" : (0, 0, 0, 0),
}
