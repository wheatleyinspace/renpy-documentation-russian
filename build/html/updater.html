Обновление по HTTPS/HTTP

Ren'Py включает встроенную систему обновлений (updater), которая может автоматически загружать и устанавливать обновления для игры Ren'Py с веб-сервера. Обновления работают на всех настольных платформах, за исключением приложений macOS.

В процессе работы средство обновления Ren'Py отображает экран обновления (screen updater), предлагая пользователю подтвердить действие или позволяя отменить его при необходимости.

Поддерживаются два формата обновлений. Современный формат называется RPU и был представлен в Ren'Py 8.2. Более старый формат zsync считается устаревшим, однако его можно генерировать для обеспечения обновления со старых версий игры.

Требования к серверу

Для работы системы обновлений требуется собственный веб-хостинг. Файлы обновлений должны быть доступны для прямого скачивания по URL-адресу, а ваш веб-сервер должен поддерживать диапазонные HTTP-запросы (HTTP range requests).

Сборка обновления

Пакеты обновлений формируются автоматически при сборке дистрибутивов. Чтобы включить создание обновления, установите переменную build.include_update в True в файле options.rpy. Это разблокирует пункт «Создать обновления» («Build Updates») в разделе лаунчера «Построить дистрибутивы». Отметьте этот пункт, и Ren'Py создаст файлы обновления.

Файлы обновления состоят из:

updates.json

Индекс доступных обновлений и номеров их версий.

updates.ecdsa

Цифровая подпись файла updates.json, используемая для проверки его целостности и подлинности.

rpu/

Каталог rpu содержит метаданные и фрагменты данных, используемые при обновлении.

Все эти файлы и каталог следует загрузить в одно место на вашем веб-сервере.

Функции

Чтобы запустить процесс обновления, вызовите функцию updater.update() либо экранное действие updater.Update().

updater.Update(*args, **kwargs)

Действие (action), вызывающее updater.update(). Все переданные аргументы сохраняются и передаются этой функции.

updater.UpdateVersion(url, check_interval=21600, simulate=None, **kwargs)

Обращается к серверу по адресу url и определяет, доступна ли более новая версия программы. Если новая версия есть, возвращает её номер. В противном случае возвращает None.

Поскольку обращение к серверу может занять время, функция запускает фоновый поток и немедленно возвращает версию из предыдущего сеанса связи с сервером (или None, если обращение к серверу ещё ни разу не выполнялось). Фоновый поток перезапустит текущее взаимодействие после получения ответа сервера, что вызовет обновление экранов, использующих эту функцию.

Каждый URL опрашивается не более одного раза за сеанс Ren'Py и не чаще одного раза в каждые check_interval секунд. Когда обращение к серверу не выполняется, возвращаются кэшированные данные.

Дополнительные именованные аргументы (включая simulate) передаются механизму обновления так же, как если бы они были переданы в updater.update().

updater.can_update(base=None)

Возвращает True, если процесс обновления в принципе возможен. Возвращает False, если обновление заведомо невозможно (например, если каталог обновлений был удалён).

Обратите внимание: эта функция не определяет, доступна ли новая версия. Для проверки доступности используйте updater.UpdateVersion().

updater.get_installed_packages(base=None)

Возвращает список имён установленных DLC-пакетов.

base

Базовый каталог для обновления. По умолчанию используется базовый каталог текущего проекта.

updater.update(url, base=None, force=False, public_key=None, simulate=None, add=[], restart=True, confirm=True, patch=True, prefer_rpu=True, allow_empty=False, done_pause=True, allow_cancel=True, screen='updater')

Обновляет эту игру Ren'Py до последней версии.

url

URL-адрес файла updates.json.

base

Базовый каталог, который будет обновлён. По умолчанию используется базовый каталог текущей игры (обычно этот параметр можно не указывать).

force

Принудительно выполнить обновление, даже если номера версий совпадают (используется для тестирования).

public_key

Путь к файлу в формате PEM, содержащему открытый ключ, с помощью которого проверяется цифровая подпись обновления (обычно можно не указывать).

simulate

Используется для тестирования интерфейса обновления без реального скачивания файлов:

  • None — выполнить реальное обновление.

  • "available" — симулировать наличие доступного обновления.

  • "not_available" — симулировать отсутствие обновлений.

  • "error" — симулировать ошибку обновления.

add

Список пакетов для добавления во время этого обновления (необходимо только для DLC).

restart

Если True, игра перезапустится после завершения обновления. Если передана строка "utter", вместо этого будет вызвана функция renpy.utter_restart(). Если False, процесс обновления просто завершится без перезапуска.

confirm

Запрашивать ли у пользователя подтверждение на установку обновления? Если False, обновление начнётся без подтверждения.

patch

Если True, Ren'Py попытается применить дифференциальный патч к игре, скачивая только изменившиеся фрагменты данных. Если False, будет загружена полная копия игры. Автоматически устанавливается в False, если URL не начинается с «http:».

Этот параметр игнорируется при использовании современного формата обновлений RPU.

prefer_rpu

Больше не используется, сохранён для обратной совместимости.

allow_empty

Если True, Ren'Py разрешит продолжить обновление, даже если в базовом каталоге отсутствует информация об обновлениях (в этом случае параметр add обязателен).

done_pause

Если True, игра сделает паузу после завершения обновления. Если False, сразу перейдёт к следующему шагу (перезапуску или возврату).

allow_cancel

Если True, пользователю будет разрешено отменить обновление. Если False, кнопка отмены обновления будет недоступна.

screen

Имя экрана обновления, который будет отображаться.

Экран обновления

Чтобы настроить внешний вид окна обновления, вы можете переопределить экран updater. Пример экрана обновления:

screen updater(u=None):

   add "#000"

   frame:
      style_group ""

      has side "t c b":
         spacing gui._scale(10)

      label _("Обновление")

      fixed:

         vbox:

            if u.state == u.ERROR:
               text _("Произошла ошибка:")
            elif u.state == u.CHECKING:
               text _("Проверка наличия обновлений.")
            elif u.state == u.UPDATE_NOT_AVAILABLE:
               text _("Установлена актуальная версия программы.")
            elif u.state == u.UPDATE_AVAILABLE:
               text _("Доступна версия [u.version]. Хотите установить её?")
            elif u.state == u.PREPARING:
               text _("Подготовка к загрузке обновлений.")
            elif u.state == u.DOWNLOADING:
               text _("Загрузка обновлений.")
            elif u.state == u.UNPACKING:
               text _("Распаковка обновлений.")
            elif u.state == u.FINISHING:
               text _("Завершение установки.")
            elif u.state == u.DONE:
               text _("Обновления успешно установлены. Программа будет перезапущена.")
            elif u.state == u.DONE_NO_RESTART:
               text _("Обновления успешно установлены.")
            elif u.state == u.CANCELLED:
               text _("Обновление было отменено.")

            if u.message is not None:
               null height gui._scale(10)
               text "[u.message!q]"

         bar:
            adjustment u.progress_adjustment
            yalign 0.5

      hbox:
         spacing gui._scale(25)

         if u.can_proceed:
            textbutton _("Продолжить") action u.proceed

         if u.can_cancel:
            textbutton _("Отмена") action u.cancel
