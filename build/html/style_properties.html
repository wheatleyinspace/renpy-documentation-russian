Свойства стилей

Свойства стилей, связанные со стилями, управляют отображением отображаемых объектов (Отображаемые объекты). Свойства стиля могут задаваться без префикса (в этом случае они применяются ко всем состояниям объекта) либо с префиксом, ограничивающим применение свойства определенными состояниями.

Префиксы свойств стилей

Применение префикса к свойству стиля позволяет объекту менять свой внешний вид в зависимости от наличия фокуса или выбора. Например, кнопка может менять свой цвет при наведении курсора мыши или подсвечиваться, если представленный ею вариант активен.

Существует пять основных состояний отображаемого объекта:

insensitive

Используется, когда объект неактивен и пользователь не может взаимодействовать с ним.

idle

Используется, когда объект доступен, но не находится под фокусом и не выбран.

hover

Используется, когда объект находится под фокусом (под курсором), но не выбран.

selected_idle

Используется, когда объект выбран, но не находится под фокусом.

selected_hover

Используется, когда объект и выбран, и находится под фокусом одновременно.

Кнопки и полосы (а также их разновидности) обновляют собственное состояние и состояние своих дочерних элементов в ответ на события. Например, при наведении курсора на невыбранную кнопку она сама и все ее дочерние элементы переходят в состояние hover.

Префиксы свойств стилей позволяют настраивать свойства для различных состояний. Действует система наследования (импликации), при которой префикс может задавать свойство сразу для нескольких состояний.

Правила импликации:

префикс

состояния, подразумеваемые префиксом

(без префикса)

insensitive, idle, hover, selected_idle, selected_hover

idle_

idle, selected_idle

hover_

hover, selected_hover

selected_

selected_idle, selected_hover

insensitive_

insensitive

selected_idle_

selected_idle

selected_hover_

selected_hover

selected_insensitive_

selected_insensitive

Рассмотрим это на примере текстовой кнопки (textbutton). Текстовые кнопки по умолчанию используют два стиля: button для самой кнопки и button_text для текста внутри нее. Свойство стиля background задает фон кнопки, а свойство color — цвет текста.:

# Фон кнопки серый, когда она неактивна, светло-синий при наведении
# и темно-синий в остальных случаях.
style button:
    background "#006"
    insensitive_background "#444"
    hover_background "#00a"

# Текст кнопки желтый, когда кнопка выбрана, и белый в остальных случаях.
style button_text:
    color "#fff"
    selected_color "#ff0"

Значения свойств стилей

Каждое свойство стиля ожидает определенный тип данных. Многие из них являются стандартными типами Python, но некоторые уникальны для Ren'Py. Ниже приведено описание этих типов.

position

Позиции (координаты) используются для задания положения относительно верхнего левого угла содержащей области. (Для размещения и размера содержащая область определяется макетом, в котором находится объект, либо экраном; для точек привязки anchor содержащей областью является размер самого отображаемого объекта).

Интерпретация значения позиции зависит от типа переданного значения:

int (целое число: 0, 1, 37, 42)

Число пикселей от левого или верхнего края содержащей области.

float (число с плавающей точкой: 0.0, 0.5, 1.0)

Доля от размера содержащей области. Например, 0.5 — середина стороны содержащей области, а 1.0 — правый или нижний край.

absolute(value, /)

Например, absolute(100.25) или absolute(a+b).

Число типа absolute интерпретируется как точное количество пикселей от левого или верхнего края экрана при субпиксельном рендеринге.

position(absolute, relative, /)

Например, position(-10, .5).

Комбинация абсолютного смещения absolute и относительного смещения relative. Два компонента складываются для вычисления итоговой координаты.

displayable

Любой отображаемый объект. Если путь содержит подстановку "[prefix_]", выполняется поиск префикса, как описано ниже.

color

Цвета в Ren'Py могут выражаться в виде строк, начинающихся со знака решетки (#), за которым следует шестнадцатеричная тройка или четверка значений.

В тройке компоненты задают красный, зеленый и синий цвета (RGB). В четверке — красный, зеленый, синий и альфа-канал непрозрачности (RGBA). Например:

  • "#f00" и "#ff0000" задают непрозрачный красный цвет.

  • "#0f08" и "#00ff0080" задают полупрозрачный зеленый цвет.

Шестнадцатеричные коды цветов аналогичны используемым в HTML.

Цвет также может быть представлен в виде кортежа из 4 целых чисел от 0 до 255 в формате (R, G, B, A).

  • (0, 0, 255, 255) задает непрозрачный синий цвет.

Наконец, цвет может быть экземпляром класса Color.

Поиск префикса стиля

Когда свойство стиля содержит подстановку "[prefix_]", выполняется поиск префикса. Поиск производится раздельно для каждого состояния объекта, включая состояния, подразумеваемые исходным свойством.

Например, при наличии следующего правила:

style button:
    hover_background "[prefix_]background.png"

раздельный поиск выполняется для состояний hover и selected_hover. Набор проверяемых префиксов зависит от состояния:

состояние

порядок поиска

idle

"idle_", ""

hover

"hover_", ""

insensitive

"insensitive_", "", "idle_"

selected_idle

"selected_idle_", "idle_", "selected_", ""

selected_hover

"selected_hover_", "hover_", "selected_", ""

selected_insensitive

"selected_insensitive_", "hover_", "selected_", "", "selected_idle_", "idle_"

При поиске каждый префикс пробуется по порядку. В строке подстрока "[prefix_]" заменяется на префикс, после чего Ren'Py проверяет наличие загружаемого файла или изображения с таким именем. Если файл найден, поиск завершается и используется найденный объект. Иначе проверка переходит к следующему префиксу.

Префикс стиля также передается через контейнеры, трансформации и фреймы, не принимающие пользовательский ввод.

Пример: если существуют файлы idle_button.png и hover_button.png:

style button:
    background "[prefix_]button.png"

эквивалентно:

style button:
    idle_background "idle_button.png"
    hover_background "hover_button.png"
    insensitive_background "idle_button.png"

    selected_idle_background "idle_button.png"
    selected_hover_background "hover_button.png"
    selected_insensitive_background "idle_button.png"

Список всех свойств стилей

Свойства стилей определяют визуальный вид различных отображаемых объектов. Поскольку не все свойства применимы ко всем объектам, они разделены на смысловые группы.

Свойства стиля позиционирования

Эти свойства применимы ко всем отображаемым объектам и в основном управляют положением объекта внутри области, выделенной ему макетом, либо на экране (если объект вне макета).

alt -  string or None

Альтернативный текст для объекта при включенном синтезе речи (self-voicing). Подробнее см. Голосовое сопровождение интерфейса (Self-Voicing).

xpos -  position

Положение отображаемого объекта относительно левого края содержащей области.

ypos -  position

Положение отображаемого объекта относительно верхнего края содержащей области.

pos -  tuple of (position, position)

Эквивалентно заданию xpos равным первому элементу кортежа, а ypos — второму.

xanchor -  position

Положение точки привязки (anchor) относительно левого края отображаемого объекта.

yanchor -  position

Положение точки привязки (anchor) относительно верхнего края отображаемого объекта.

Если объект является Text(), поддерживается специальное значение renpy.BASELINE, привязывающее точку к базовой линии первой строки текста.

anchor -  tuple of (position, position)

Эквивалентно заданию xanchor первому элементу кортежа, а yanchor — второму.

xalign -  float

Эквивалентно установке одинакового значения для xpos и xanchor. Размещает объект по горизонтали в долях экрана: 0.0 — левый край, 0.5 — центр, 1.0 — правый край.

yalign -  float

Эквивалентно установке одинакового значения для ypos и yanchor. Размещает объект по вертикали: 0.0 — верхний край, 0.5 — середина по вертикали, 1.0 — нижний край.

align -  tuple of (float, float)

Эквивалентно установке xalign первому элементу кортежа, а yalign — второму.

xcenter -  position

Эквивалентно установке xpos в переданное значение, а xanchor — в 0.5.

ycenter -  position

Эквивалентно установке ypos в переданное значение, а yanchor — в 0.5.

xycenter -  tuple of (position, position)

Эквивалентно установке xcenter первому элементу кортежа, а ycenter — второму.

xoffset -  int

Смещение в пикселях, добавляемое к горизонтальной позиции, вычисленной через xpos и xalign.

yoffset -  int

Смещение в пикселях, добавляемое к вертикальной позиции, вычисленной через ypos и yalign.

offset -  tuple of (int, int)

Эквивалентно установке xoffset первому элементу кортежа, а yoffset — второму.

xmaximum -  int

Максимальный горизонтальный размер отображаемого объекта в пикселях.

ymaximum -  int

Максимальный вертикальный размер отображаемого объекта в пикселях.

maximum -  tuple of (int, int)

Эквивалентно установке xmaximum первому элементу кортежа, а ymaximum — второму.

xminimum -  int

Минимальная ширина отображаемого объекта в пикселях. Действует только для объектов, способных изменять свой размер.

yminimum -  int

Минимальная высота отображаемого объекта в пикселях. Действует только для объектов, способных изменять свой размер.

minimum -  tuple of (int, int)

Эквивалентно установке xminimum первому элементу кортежа, а yminimum — второму.

xsize -  int or float

Эквивалентно установке xminimum и xmaximum в одинаковое значение. Задает фиксированную ширину объекта. Число с плавающей точкой задает долю ширины родительского контейнера.

ysize -  int or float

Эквивалентно установке yminimum и ymaximum в одинаковое значение. Задает фиксированную высоту объекта. Число с плавающей точкой задает долю высоты родительского контейнера.

xysize -  tuple of (int or float, int or float)

Эквивалентно установке xsize первому элементу кортежа, а ysize — второму.

xfill -  boolean

Если True, объект растягивается по всей доступной ширине контейнера. Если False, его размер достаточен лишь для вмещения дочерних элементов.

yfill -  boolean

Если True, объект растягивается по всей доступной высоте контейнера. Если False, его размер достаточен лишь для вмещения дочерних элементов.

area -  tuple of (int, int, int, int)

Кортеж вида (xpos, ypos, width, height). Размещает объект так, чтобы его верхний левый угол находился в точке xpos, ypos, а размеры составляли width и height.

mipmap -  boolean or None

Управляет генерацией mipmap-уровней текстур для данного отображаемого объекта (применимо к Text(), Movie() и переходам dissolve). Если None, берется из переменных конфигурации (config.mipmap_text и др.).

Свойства стиля текста

antialias -  boolean

Если True (по умолчанию), текст шрифтов TrueType отрисовывается со сглаживанием (антиалиасингом).

adjust_spacing -  boolean or str

Если True, Ren'Py корректирует интервалы текста экранного разрешения под виртуальное разрешение, гарантируя неизменность границ фреймов и контейнеров при масштабировании. "horizontal" корректирует только горизонтальные интервалы, "vertical" — только вертикальные. По умолчанию True для большинства текстов и False для текста в input.

altruby_style -  style or None

Объект стиля, используемый для альтернативного руби-текста (фуриганы).

axis -  dict or None

Словарь настройки осей вариативного шрифта. Пример:

style default:
    font "VariableFont.ttf"
    axis { "weight" : 500, "width" : 95 }
black_color -  color

При отрисовке растровых шрифтов черный цвет отображается этим цветом (для TrueType не действует).

bold -  boolean

Если True, текст выводится полужирным начертанием.

caret -  displayable or None

Отображаемый объект, используемый в качестве текстового курсора в виджете ввода. По умолчанию мигающая вертикальная линия толщиной 1 пиксель.

color -  color

Цвет отображаемого текста.

emoji_font -  string

Шрифт для отображения символов Emoji.

first_indent -  int

Отступ первой строки абзаца (красная строка) в пикселях.

font -  string

Имя файла или зарегистрированное имя шрифта (например, "DejaVuSans.ttf").

font_features -  dict or None

Словарь параметров типографики OpenType Layout:

style default:
    font "SomeFont.ttf"
    font_features { "liga" : True, "smcp" : True, "calt" : False }
hinting -  str

Режим хинтинга шрифта: "auto", "auto-light", "bytecode", "none". Может также быть True для выборки из config.font_hinting.

hyperlink_functions -  tuple of (function, function, function)

Кортеж из трех функций для гиперссылок: (стиль ссылки, клик по ссылке, фокус ссылки).

instance -  string or None

Имя именованного начертания для вариативного шрифта (например, "Bold").

italic -  boolean

Если True, текст отображается курсивным начертанием.

justify -  boolean

Если True, текст выравнивается по ширине (за исключением последней строки абзаца).

kerning -  float

Кернинг — дополнительное расстояние в пикселях между парами символов.

language -  string

Языковые правила переноса строк: "unicode" (по умолчанию), "japanese-strict", "japanese-normal", "japanese-loose", "korean-with-spaces", "thaic90", "western", "anywhere".

layout -  string

Алгоритм компоновки слов по строкам: "tex" (по умолчанию, алгоритм Кнута-Пласса для минимизации разницы длин строк), "subtitle" (равномерное распределение строк), "greedy" (жадный перенос на новую строку), "nobreak" (запрет переносов).

line_leading -  int

Отступ над строкой текста в пикселях.

line_overlap_split -  int

Количество пикселей перекрытия строк при медленном выводе текста, относящихся к верхней строке.

line_spacing -  int

Отступ под строкой текста в пикселях (межстрочный интервал).

min_width -  int

Минимальная ширина каждой строки текста в пикселях.

newline_indent -  boolean

Если True, отступ first_indent применяется после каждого символа новой строки.

outlines -  list of tuple of (int, color, int, int)

Список контуров (обводок), рисуемых позади текста. Каждый кортеж задает (толщина, цвет, xoffset, yoffset). Отрисовываются от задних к передним.

outline_scaling -  string

Режим масштабирования обводок: "linear" (по умолчанию) или "step".

prefer_emoji -  boolean

Определяет предпочтительный рендеринг символов с двойной природой (Emoji или стандартный текст).

reading_order -  string

Направление чтения текста: None (автоопределение), "ltr", "rtl", "wltr", "wrtl".

rest_indent -  int

Отступ для второй и последующих строк абзаца в пикселях.

ruby_line_leading -  int

Дополнительное расстояние над строкой с руби-текстом в пикселях (в дополнение к line_leading).

ruby_style -  style or None

Объект стиля для отображения руби-текста (фуриганы).

shaper -  "harfbuzz" or "freetype"

Шейпер текста: "harfbuzz" (поддерживает сложные лигатуры, индийские языки, комбинированные эмодзи) или "freetype".

size -  int

Размер шрифта в пикселях.

slow_abortable -  boolean

Если True, клик по тексту прерывает эффект медленного появления и мгновенно выводит остаток текста.

slow_cps -  int or True

Скорость вывода текста (число символов в секунду либо True для использования скорости из настроек).

slow_cps_multiplier -  float

Множитель скорости вывода текста.

strikethrough -  boolean

Если True, текст отображается зачеркнутым.

textalign -  float

Выравнивание текста в пределах строки: 0.0 — по левому краю, 0.5 — по центру, 1.0 — по правому краю.

underline -  boolean

Если True, текст отображается с подчеркиванием.

vertical -  boolean

Если True, текст отображается вертикально.

Свойства стиля окон

Свойства окон задают вид окон, фреймов и кнопок. Раздел Свойства стиля внешних отступов (Margin) также входит в эту категорию.

background -  displayable or None

Фон окна (часто Frame(), позволяющий масштабировать рамку фона под размер окна). Если None, фон не рисуется.

foreground -  displayable or None

Если не None, отображается поверх содержимого окна.

left_padding -  int

Внутренний отступ слева в пикселях.

right_padding -  int

Внутренний отступ справа в пикселях.

xpadding -  int

Эквивалентно установке одинакового значения для left_padding и right_padding.

top_padding -  int

Внутренний отступ сверху в пикселях.

bottom_padding -  int

Внутренний отступ снизу в пикселях.

ypadding -  int

Эквивалентно установке одинакового значения для top_padding и bottom_padding.

padding -  tuple

Кортеж из двух (x, y) или четырех (left, top, right, bottom) внутренних отступов.

size_group -  string or None

Строковый идентификатор группы размеров. Ren'Py выравнивает размеры всех окон с одинаковым size_group до единого размера.

modal -  boolean or callable

Если True, окно является модальным (события не проходят сквозь него к нижним слоям). Может быть функцией проверки условий.

Свойства стиля кнопок

child -  displayable or None

Отображаемый объект, заменяющий дочерний элемент кнопки (например, insensitive_child может отображать значок замка на заблокированной кнопке).

hover_sound -  string

Звук при получении кнопкой фокуса (наведении курсора).

activate_sound -  string

Звук при активации (клике) кнопки. Также воспроизводится при взаимодействии с полосой bar.

mouse -  string

Курсор мыши при наведении на кнопку (ключ из config.mouse).

focus_mask -  multiple

Маска фокуса кнопки: - Displayable: непрозрачные области определяют область кликабельности. - True: сама кнопка используется как маска. - callable: функция проверки координат точки клика. - None: вся прямоугольная область кнопки активна.

keyboard_focus -  boolean

Если True, кнопка может выбираться с помощью клавиатуры или геймпада.

keyboard_focus_insets -  (int, int, int, int) or None

Кортеж сужения прямоугольника фокуса (left, top, right, bottom) в пикселях для перекрывающихся кнопок.

key_events -  boolean

Если True, клавиатурные события передаются дочерним элементам кнопки.

Свойства стиля полос (Bar)

Полосы (bars) используются для индикаторов, полос прокрутки и слайдеров.

bar_vertical -  boolean

Если True, полоса ориентирована вертикально. Если False — горизонтально.

bar_invert -  boolean

Если True, значение полосы заполняется справа налево или сверху вниз.

bar_resizing -  boolean

Если True, стороны полосы масштабируются. Если False — обрезаются (crop).

left_gutter -  int

Размер левого желоба в пикселях.

right_gutter -  int

Размер правого желоба в пикселях.

top_gutter -  int

Размер верхнего желоба в пикселях.

bottom_gutter -  int

Размер нижнего желоба в пикселях.

left_bar -  displayable

Отображаемый объект для левой (заполненной) стороны полосы.

right_bar -  displayable

Отображаемый объект для правой стороны полосы.

top_bar -  displayable

Отображаемый объект для верхней стороны вертикальной полосы.

bottom_bar -  displayable

Отображаемый объект для нижней стороны вертикальной полосы.

base_bar -  displayable

Базовый отображаемый объект для всей полосы.

thumb -  displayable or None

Бегунок (ползунок), отображаемый на границе между сторонами полосы.

thumb_align -  float

Выравнивание бегунка относительно полосы (0.5 для центрирования бегунка по толщине).

thumb_shadow -  displayable or None

Тень ползунка.

thumb_offset -  int or tuple of (int, int)

Смещение перекрытия бегунка и полосы в пикселях.

mouse -  string

Стиль курсора мыши при наведении на полосу.

unscrollable -  string or None

Поведение при неактивной прокрутке: None (обычный вид), "insensitive" (неактивный вид), "hide" (скрыть полосу с сохранением места).

keyboard_focus -  boolean

Доступность полосы для управления с клавиатуры или геймпада.

Свойства стиля блоков (Box)

Используются контейнерами горизонтального (hbox) и вертикального (vbox) размещения.

spacing -  int

Расстояние между элементами блока в пикселях.

first_spacing -  int

Расстояние между первым и вторым элементами блока в пикселях.

box_reverse -  boolean

Если True, порядок размещения элементов обратный (справа налево для hbox, снизу вверх для vbox).

box_wrap -  boolean

Если True, элементы переносятся на новую строку/колонку при достижении границы контейнера.

box_wrap_spacing -  int

Расстояние между строками или столбцами при включенном box_wrap.

box_align -  float or None

Выравнивание рядов или колонок внутри блока (0.0 — по левому/верхнему краю, 0.5 — по центру).

order_reverse -  boolean

Если True, порядок отрисовки элементов обратный (первый элемент рисуется поверх остальных).

box_justify -  boolean or "first" or "all"

Выравнивание элементов по ширине блока с подгонкой расстояний между ними.

Свойства стиля сеток (Grid)

spacing -  int

xspacing -  int or None
