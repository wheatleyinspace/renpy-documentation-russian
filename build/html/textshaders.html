Текстовые шейдеры

В Ren'Py есть система текстовых шейдеров, позволяющая управлять отображением текста на экране. При включении этой системы движок использует модельный рендеринг, отрисовывая два треугольника для каждого символа Unicode. Фрагменты шейдеров, заданные разработчиком или сгенерированные Ren'Py, применяются к модели и изменяют внешний вид и анимацию текста.

Документация по текстовым шейдерам состоит из трёх разделов:

  1. Как использовать текстовые шейдеры

  2. Встроенные текстовые шейдеры в Ren'Py

  3. Как создавать собственные текстовые шейдеры

Примечание

Хотя использование готовых текстовых шейдеров максимально просто, создание собственных требует базовых знаний языка GLSL и системы модельного рендеринга.

Использование текстовых шейдеров

Существуют три способа применения текстовых шейдеров:

Шейдер по умолчанию. Первый способ — задать шейдер текста по умолчанию с помощью переменной config.default_textshader:

define config.default_textshader = "wave:10"

В этом случае шейдер применяется ко всему тексту, для которого не указан иной шейдер. Он также объединяется с текстовыми шейдерами, включающими шейдер по умолчанию. Обычно шейдер по умолчанию отвечает за анимацию постепенного появления текста (slow text).

Стили. Второй способ — свойство стиля textshader (напрямую или через стили персонажей):

style default:
    textshader "dissolve"

define goldfinger = Character("Голдфингер", what_textshader="linetexture:gold.png")

screen purchase():
    vbox:
        text "Купите дополнение!" textshader "wave"
        textbutton "Купить":
            text_textshader "wave" action iap.Purchase("dlc")

Текстовые теги. Третий способ — использование текстового тега для стилизации отдельного фрагмента текста:

"Что это? Письмо, возникшее {shader=zoom}из ниоткуда{/shader}?"

Примечание: Текстовый блок должен либо целиком использовать текстовые шейдеры, либо не использовать их вовсе — смешивание в одном блоке не поддерживается. Если вы используете тег {shader=...}, установите config.default_textshader или свойство стиля textshader.

Задание текстовых шейдеров

Текстовые шейдеры указываются в виде строк, например:

"dissolve"
"jitter:u__jitter=1.0, 3.0"
"texture:gold.png"

Например, для независимого дрожания каждого символа в течение полусекунды:

"jitter:u__duration=0.5:u__individual=1"

Или внутри строки диалога через текстовый тег:

"Подожди, {shader=jitter:u__duration=0.5:u__individual=1}что?{/shader}"

По умолчанию эффект jitter продолжается бесконечно и смещает все символы синхронно. Длительность 0 или отрицательное число означает бесконечную анимацию. Положительная длительность начинает отсчёт с момента появления текста.

Первая часть строки (до первого двоеточия) — имя текстового шейдера. Остальная часть строки — последовательность uniform-переменных, разделённых двоеточиями.

Uniform-переменные можно указывать по имени с знаком равенства (u__jitter=...) или позиционно по порядку. Префикс u_ можно опускать для краткости.

Значением uniform-переменной может быть:

  • От 1 до 4 чисел через запятую (для типов float, vec2, vec3 или vec4).

  • Цвет, начинающийся с символа # (например, #f00 или #ff0000). Создаёт вектор vec4 с предварительно умноженной альфой.

  • Отображаемый объект, используемый как текстура (тип sampler2D).

Значения uniform-переменных в строке не могут быть выражениями Python, но можно использовать стандартную интерполяцию строк Ren'Py для подстановки значений.

Текстовые шейдеры можно комбинировать оператором |:

"jitter:1.0, 3.0|wave"

Это применит к тексту одновременно эффекты jitter и wave (если шейдеры совместимы).

Если для шейдера не указано include_default=False, он автоматически комбинируется с шейдером по умолчанию config.default_textshader.

Обратные вызовы текстовых шейдеров (Callbacks)

Переменная config.textshader_callbacks позволяет назначить функцию обратного вызова, динамически выбирающую шейдер (например, в зависимости от пользовательских настроек):

default persistent.dissolve_text = True

init python:
    def get_default_textshader():
        if persistent.dissolve_text:
            return "dissolve"
        else:
            return "typewriter"

define config.default_textshader = "default"
define config.textshader_callbacks["default"] = get_default_textshader

Встроенные текстовые шейдеры

Ren'Py содержит набор встроенных текстовых шейдеров:

dissolve

Текстовый шейдер dissolve плавно растворяет текст при медленном выводе: начало строки появляется первым, а конец — последним.

u__duration = 10.0

Количество символов, одновременно изменяющих свою прозрачность. Если равно 0, волна растворения проходит по тексту попиксельно.

Использование этого шейдера отключает действие шейдера по умолчанию.

flip

Текстовый шейдер flip переворачивает символы по горизонтали при медленном выводе: начало строки переворачивается первым, а конец — последним.

u__duration = 10.0

Количество одновременно переворачивающихся символов. Если равно 0, символы переворачиваются мгновенно.

Использование этого шейдера отключает действие шейдера по умолчанию.

jitter

Текстовый шейдер jitter хаотично смещает символы текста в случайные позиции относительно исходного положения. Позиция обновляется каждый кадр.

u__jitter = (3.0, 3.0)

Величина дрожания текста в пикселях.

u__duration = 0.0

Длительность эффекта дрожания в секундах с момента появления текста. После истечения этого времени текст возвращается в нормальное состояние. Значение 0 (по умолчанию) или отрицательное число означает непрерывную анимацию. Не зависит от скорости медленного вывода текста.

u__individual = 0.0

Если 0 (по умолчанию), все символы двигаются синхронно. Если 1, каждый символ дрожит независимо.

linetexture

Умножает цвет текста на текстуру построчно. Текстура выравнивается по левому краю строки. Вертикальный центр текстуры выравнивается по базовой линии текста (нижняя половина текстуры обычно остаётся невидимой).

u__texture = ...

Текстура для наложения на текст.

u__scale = (1.0, 1.0)

Масштаб текстуры. Например, (1.0, 0.5) сделает текстуру вдвое ниже.

offset

Текстовый шейдер offset смещает весь текст на фиксированную величину.

u__offset = (0.0, 0.0)

Величина смещения текста в виртуальных пикселях.

slowalpha

Шейдер slowalpha предназначен для совместного использования с другими шейдерами медленного текста (такими как typewriter или dissolve). Он заставляет ещё не появившийся текст отображаться с лёгкой полупрозрачностью u__alpha = 0.2 вместо полной невидимости.

u__alpha = 0.2

Значение непрозрачности ещё не раскрытого текста.

texture

Текстовый шейдер texture умножает цвета текста на изображение текстуры (не затрагивая контуры и тени). Текстура выравнивается по левому верхнему углу текстового блока.

u__texture = ...

Текстура для наложения на текст.

typewriter

Текстовый шейдер typewriter выводит текст по одному символу за раз, как при печати на печатной машинке.

Использование этого шейдера отключает действие шейдера по умолчанию.

wave

Текстовый шейдер wave заставляет текст волнообразно раскачиваться вверх и вниз.

u__amplitude = 5.0

Амплитуда колебаний текста в пикселях.

u__frequency = 2.0

Количество волн в секунду.

u__wavelength = 20.0

Длина волны (количество символов между пиками).

zoom

Текстовый шейдер zoom масштабирует символы при медленном выводе от начального размера u__zoom = 0.0 до полного размера.

u__zoom = 0.0

Начальный масштаб символа при старте показа.

u__duration = 10.0

Количество одновременно масштабирующихся символов.

Использование этого шейдера отключает действие шейдера по умолчанию.

Создание текстовых шейдеров

Текстовые шейдеры представляют собой программы на языке GLSL, выполняемые на GPU. Они регистрируются с помощью функции renpy.register_text_shader.

Как и другие шейдеры, текстовые шейдеры пишутся на одном из двух диалектов GLSL (см. Версии GLSL).

renpy.register_textshader(name, shaders=(), extra_slow_time=0.0, extra_slow_duration=0.0, redraw=None, redraw_when_slow=0.0, include_default=True, adjust_function=None, doc=None, **kwargs)

Создаёт текстовый шейдер и регистрирует его под именем name.

Функция принимает следующие аргументы:

name

Имя текстового шейдера. Также используется для регистрации фрагмента шейдера textshader.`name`.

shaders

Фрагменты шейдеров, применяемые к тексту (строка, список или кортеж строк). Это должен быть фрагмент, зарегистрированный с помощью renpy.register_shader() или этой функции. Если имя фрагмента начинается с '-', он удаляется из списка (например, '-textshader.typewriter').

Фрагменты, зарегистрированные этой функцией, имеют префикс "textshader.".

extra_slow_time

Дополнительное время в секундах, добавляемое к эффекту медленного появления символов. Полезно для шейдеров с длительными переходами. Если True, шейдер обновляется непрерывно.

extra_slow_duration

Добавляется к extra_slow_time, умножаясь на время вывода одного символа (1 / cps).

redraw

Интервал в секундах до перерисовки текста после завершения медленного вывода и истечения extra_slow_time.

redraw_when_slow

Интервал в секундах до перерисовки текста во время медленного вывода.

include_default

Если True, при прямом использовании шейдер комбинируется с config.default_textshader.

adjust_function

Функция, вызываемая с объектом шейдера и переданными ему uniform-переменными. Может настраивать поля extra_slow_time, extra_slow_duration, redraw и redraw_when_slow.

doc

Строка документации.

Именованные аргументы с префиксом u_ передаются как uniform-переменные в шейдер (строки с # интерпретируются как цвета). Большинство uniform-переменных должны начинаться с u__, используя локальные переменные шейдеров.

Аргументы variables, glsl, а также все аргументы на fragment_ и vertex_ передаются в функцию renpy.register_shader(). Для новых шейдеров следует указывать glsl=300.

Переменные в текстовых шейдерах

Помимо пользовательских uniform-переменных (начинающихся с u__), Ren'Py предоставляет шейдерам текста специальный набор встроенных переменных. Чтобы использовать переменную, объявите её в аргументе variables функции renpy.register_text_shader.

Также доступны стандартные uniforms и атрибуты модельного рендеринга (особенно a_position, a_tex_coord, u_time и u_random).

Uniform-переменные

float u_text_depth

Глубина слоя текста. Основной текст имеет глубину 0.0, первый контур или тень — 1.0, второй контур — 2.0 и т. д.

float u_text_main

Равно 1.0 для основного текста и 0.0 для контура или тени.

float u_text_max_depth

Максимальное значение u_text_depth (общее количество отрисовываемых контуров и теней).

vec2 u_text_offset

Смещение текста от центра символа в физических пикселях отрисовки (x, y).

float u_text_outline

Ширина контура вокруг текста в пикселях.

float u_text_slow_duration

Длительность появления одного символа при медленном выводе текста (0.0 при мгновенном показе).

float u_text_slow_time

Время в секундах с начала эффекта медленного вывода текста. Достигает максимума при завершении показа или клике игрока.

float u_text_time

Время в секундах с момента начала отображения текстового блока (продолжает расти всё время показа).

float u_text_to_drawable

Коэффициент масштабирования из виртуальных пикселей в физические пиксели отрисовки.

float u_text_to_virtual

Коэффициент перевода из физических пикселей в виртуальные.

sampler2D tex0

Текстура, содержащая отрисованный текст на текущей глубине.

vec2 res0

Разрешение текстуры tex0 в пикселях отрисовки.

Атрибуты

При отрисовке текста каждая вершина принадлежит отдельному глифу (символу):

float a_text_ascent

Высота выносных элементов шрифта над базовой линией в пикселях.

vec2 a_text_center

Позиция центра базовой линии глифа в пикселях.

float a_text_descent

Глубина спуска шрифта под базовую линию в пикселях.

float a_text_index

Индекс выводимого символа (0 для первого символа, увеличивается на единицу для каждого следующего).

vec2 a_text_min_time

Минимальное время, в которое должна появиться любая вершина глифа.

vec2 a_text_max_time

Максимальное время, в которое должна появиться любая вершина глифа.

float a_text_time

Время, в которое должна отобразиться данная вершина (-3600.0 при мгновенном показе).

vec4 a_text_pos_rect

Прямоугольник глифа (x, y, width, height) в пикселях отрисовки.

float a_text_pseudo_glyph

Равно 1.0, если вершина принадлежит псевдоглифу, иначе 0.0.

Псевдоглифы

Ren'Py создаёт служебные псевдоглифы в начале и конце каждой строки (или на всю пустую строку). Они необходимы для покрытия областей, куда могут выступать широкие контуры текста с соседних строк.

Пример

Пример текстового шейдера, вращающего символы вокруг своей оси при появлении:

init python:

    def adjust_extra_slow_time(ts, u__delay, **kwargs):
        """
        Корректирует дополнительное время показа для шейдера вращения.
        """
        ts.extra_slow_time = u__delay

    renpy.register_textshader(
        "spin",
        adjust_function = adjust_extra_slow_time,

        variables = """
        uniform float u__delay;
        uniform float u__offset;
        uniform float u_text_slow_time;
        in vec2 a_text_center;
        in float a_text_min_time;
        """,

        vertex_50 = """
        float l__angle = clamp((u_text_slow_time - a_text_min_time) / u__delay, 0.0, 1.0) * 2.0 * 3.1415926536;
        float l__sin = sin(l__angle);
        float l__cos = cos(l__angle);

        gl_Position.y -= u__offset;
        gl_Position.xy -= a_text_center;
        gl_Position = vec4(
            gl_Position.x * l__cos - gl_Position.y * l__sin,
            gl_Position.x * l__sin + gl_Position.y * l__cos,
            gl_Position.z,
            gl_Position.w
            );
        gl_Position.xy += a_text_center;
        gl_Position.y += u__offset;
        """,

        u__delay = 1.0,
        u__offset = 0,
    )

Использование в сценарии:

define config.default_textshader = "typewriter"
