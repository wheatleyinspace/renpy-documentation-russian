Игровые меню

Во многих визуальных новеллах игроку предлагается совершать выборы, влияющие на развитие сюжета. Язык Ren'Py включает инструкцию menu, позволяющую легко выводить варианты выбора игроку.

Вот пример инструкции menu:

menu:
     "Что мне делать?"

     "Выпить кофе.":
         "Я пью кофе, и он превосходен до последней капли."

     "Выпить чай.":
         $ drank_tea = True

         "Я пью чай, стараясь не делать при этом политических заявлений."

     "Поклониться.":
         jump genuflect_ending

label after_menu:

     "Выпив свой напиток, я продолжил заниматься утренними делами."

Инструкция menu начинается с ключевого слова menu. За ним может следовать имя метки; в этом случае это эквивалентно размещению метки непосредственно перед меню. Например:

menu drink_menu:
    ...

За инструкцией menu следует блок с отступом. Этот блок может содержать инструкцию say и обязан содержать как минимум один вариант выбора. Если инструкция say присутствует, её текст отображается на экране одновременно с вариантами выбора.

Варианты выбора меню (Menu Choices). Вариант выбора — это пункт, который игрок может выбрать в игровом меню. Вариант выбора начинается со строки текста. За строкой может следовать конструкция if, делающая выбор условным. Вариант выбора заканчивается двоеточием и обязательно должен содержать следующий за ним блок инструкций Ren'Py с отступом.

Когда игрок выбирает данный пункт, выполняется соответствующий блок инструкций. Если выполнение доходит до конца блока, сценарий продолжается с инструкции, следующей сразу за инструкцией menu.

Конструкция if состоит из ключевого слова if и выражения Python. Вариант выбора отображается только в том случае, если выражение истинно (True). В следующем меню:

menu:
    "Пойти налево.":
        ...
    "Пойти направо.":
        ...
    "Полететь над ними." if drank_tea:
        ...

Третий вариант будет предложен только в том случае, если переменная drank_tea истинна. (Однако, если переменная конфигурации config.menu_include_disabled установлена в True, этот пункт отобразится как неактивная кнопка.)

Если условия if не выполнены ни для одного из вариантов выбора, меню будет пропущено, а управление перейдёт к инструкции, следующей за меню.

Конструкция set в меню

Инструкция menu может принимать конструкцию set на отдельной строке. Если она присутствует, в меню отображаются только те пункты, текст которых ещё не входит в указанное множество (set). Когда вариант выбран, его текст может быть добавлен в это множество.

Как и в случае с условиями if, если доступных вариантов не осталось, управление переходит к инструкции после меню.

По историческим причинам объектом set может быть как объект множества (set), так и список (list).

default menuset = set()


menu chapter_1_places:

    set menuset
    "Куда мне отправиться?"

    "Пойти на занятия.":
        jump go_to_class

    "Пойти в бар.":
        jump go_to_bar

    "Пойти в участок.":
        jump go_to_jail

label chapter_1_after_places:

    "Ого, вот это был вторник."

Аргументы меню

Аргументы можно передавать как самому меню, так и отдельным вариантам выбора. Чтобы передать аргументы меню в целом, добавьте их в строку menu после необязательного имени метки и непосредственно перед двоеточием. Чтобы передать аргументы варианту выбора, укажите их после строки текста выбора и перед ключевым словом if или двоеточием.

menu ("jfk", screen="airport"):

    "Чикаго, Иллинойс" (200):
        jump chicago_trip

    "Даллас, Техас" (150, sale=True):
        jump dallas_trip

    "Хот-Спрингс, Арканзас" (300) if secret_unlocked:
        jump hot_springs_trip

Аргументы, переданные самому меню, передаются в экран выбора, за исключением аргумента screen, выбирающего экран для показа, и аргумента nvl, выбирающего меню в режиме NVL.

См. также документацию по экрану choice и функции обратного вызова config.menu_arguments_callback.
