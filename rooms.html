Галерея изображений

Галерея изображений — это экран, позволяющий игроку разблокировать изображения и затем просматривать их. Экран содержит одну или несколько кнопок, и с каждой кнопкой связано одно или несколько изображений. С кнопками и изображениями также связаны условия, определяющие факт их разблокировки.

Галереи изображений управляются экземплярами класса Gallery. Один экземпляр класса Gallery может совместно использоваться несколькими экранами галерей.

У галереи есть одна или несколько кнопок, у кнопки — одно или несколько изображений, а у каждого изображения — один или несколько отображаемых объектов. Кнопкам и изображениям можно назначать условия. Кнопка считается разблокированной, если все связанные с ней условия выполнены и хотя бы одно изображение этой кнопки разблокировано. Изображение считается разблокированным, если выполнены все связанные с ним условия.

Создание галереи изображений состоит из следующих четырёх шагов:

  1. Создать экземпляр класса Gallery.

  2. Добавить кнопки и изображения в эту галерею вместе с условиями, определяющими, разблокированы ли эти кнопки и изображения. Это также многоэтапный процесс:

    1. Объявить новую кнопку вызовом Gallery.button().

    2. При необходимости добавить одно или несколько условий разблокировки к кнопке вызовом Gallery.unlock() или Gallery.condition().

    3. Объявить изображение вызовом Gallery.image() с одним или несколькими отображаемыми объектами в качестве аргументов. Или воспользоваться вспомогательным методом Gallery.unlock_image().

    4. При необходимости вызвать Gallery.transform() для связывания трансформаций с отображаемыми объектами.

    5. При необходимости добавить одно или несколько условий разблокировки к изображению вызовом Gallery.unlock(), Gallery.condition() или Gallery.allprior().

    Дополнительные изображения добавляются к кнопке повторением шагов 3–5, а новые кнопки добавляются в галерею повторением всех пяти шагов.

  3. Создать экран галереи изображений. Экран должен отображать фон и навигацию, позволяющую переходить к другим галереям или возвращаться в главное меню либо меню бонусов.

  4. Добавить кнопку вызова экрана галереи изображений в главное меню или меню бонусов.

Пример:

init python:

    # Шаг 1. Создание объекта галереи.
    g = Gallery()

    # Шаг 2. Добавление кнопок и изображений в галерею.

    # Кнопка с изображением, которое всегда разблокировано.
    g.button("title")
    g.image("title")

    # Кнопка, содержащая изображение, которое разблокируется автоматически.
    g.button("dawn")
    g.image("dawn1")
    g.unlock("dawn1")

    # С этой кнопкой связано несколько изображений. Мы используем unlock_image,
    # чтобы не вызывать отдельно .image и .unlock. Также применяем
    # трансформацию к первому изображению.
    g.button("dark")
    g.unlock_image("bigbeach1")
    g.transform(slowpan)
    g.unlock_image("beach1 mary")
    g.unlock_image("beach2")
    g.unlock_image("beach3")

    # С этой кнопкой связано условие, позволяющее игре определять,
    # какие изображения разблокированы.
    g.button("end1")
    g.condition("persistent.unlock_1")
    g.image("transfer")
    g.image("moonpic")
    g.image("girlpic")
    g.image("nogirlpic")
    g.image("bad_ending")

    g.button("end2")
    g.condition("persistent.unlock_2")
    g.image("library")
    g.image("beach1 nomoon")
    g.image("bad_ending")

    # С последним изображением в этой кнопке связано условие: оно разблокируется,
    # только если игрок получил обе концовки.
    g.button("end3")
    g.condition("persistent.unlock_3")
    g.image("littlemary2")
    g.image("littlemary")
    g.image("good_ending")
    g.condition("persistent.unlock_3 and persistent.unlock_4")

    g.button("end4")
    g.condition("persistent.unlock_4")
    g.image("hospital1")
    g.image("hospital2")
    g.image("hospital3")
    g.image("heaven")
    g.image("white")
    g.image("good_ending")
    g.condition("persistent.unlock_3 and persistent.unlock_4")

    # Последние две кнопки содержат изображения, состоящие из нескольких картинок одновременно.
    # Это можно использовать для наложения спрайта персонажа на фон.
    g.button("dawn mary")
    g.unlock_image("dawn1", "mary dawn wistful")
    g.unlock_image("dawn1", "mary dawn smiling")
    g.unlock_image("dawn1", "mary dawn vhappy")

    g.button("dark mary")
    g.unlock_image("beach2", "mary dark wistful")
    g.unlock_image("beach2", "mary dark smiling")
    g.unlock_image("beach2", "mary dark vhappy")

    # Переход при переключении изображений.
    g.transition = dissolve

# Шаг 3. Экран галереи.
screen gallery:

    # Гарантируем замену главного меню.
    tag menu

    # Фон.
    add "beach2"

    # Сетка кнопок.
    grid 3 3:

        xfill True
        yfill True

        # Вызываем make_button для отображения конкретной кнопки.
        add g.make_button("dark", "gal-dark.png", xalign=0.5, yalign=0.5)
        add g.make_button("dawn", "gal-dawn.png", xalign=0.5, yalign=0.5)
        add g.make_button("end1", "gal-end1.png", xalign=0.5, yalign=0.5)

        add g.make_button("end2", "gal-end2.png", xalign=0.5, yalign=0.5)
        add g.make_button("end3", "gal-end3.png", xalign=0.5, yalign=0.5)
        add g.make_button("end4", "gal-end4.png", xalign=0.5, yalign=0.5)

        add g.make_button("dark mary", "gal-dark_mary.png", xalign=0.5, yalign=0.5)
        add g.make_button("dawn mary", "gal-dawn_mary.png", xalign=0.5, yalign=0.5)
        add g.make_button("title", "title.png", xalign=0.5, yalign=0.5)


    # Экран отвечает за возврат в главное меню или переход к другим экранам галереи.
    textbutton "Return" action Return() xalign 0.5 yalign 0.5

Шаг 4 зависит от структуры вашей игры, но одним из способов его реализации является добавление следующей строки в экран главного меню (main_menu):

textbutton "Gallery" action ShowMenu("gallery")
class Gallery

Этот класс обеспечивает создание галереи изображений, управляя блокировкой изображений, предоставляя экранное действие для показа одного или нескольких изображений и метод для создания кнопок, использующих это действие.

enter_transition

Переход, используемый при показе первого изображения, связанного с кнопкой галереи.

intra_transition

Переход, используемый при переключении между изображениями одной кнопки галереи (всеми, кроме первого).

exit_transition

Переход, используемый при возврате от последнего изображения кнопки галереи обратно к экрану галереи.

transition

Используется вместо enter_transition, intra_transition или exit_transition, если один или несколько из них не были явно заданы.

locked_button

Отображаемый объект по умолчанию, используемый make_button для заблокированной кнопки.

hover_border

Рамка при наведении по умолчанию, используемая make_button.

idle_border

Рамка в состоянии покоя по умолчанию, используемая make_button.

unlocked_advance

Если True, галерея будет переключаться только между разблокированными изображениями.

navigation

Если True, галерея будет отображать кнопки навигации и слайд-шоу поверх изображений.

Для настройки внешнего вида навигации можно переопределить экран gallery_navigation. Экран по умолчанию определён в renpy/common/00gallery.rpy.

span_buttons

Если True, при достижении конца изображений текущей кнопки галерея перейдёт к следующей кнопке.

slideshow_delay

Время задержки между сменой изображений в режиме слайд-шоу в секундах.

image_screen = "_gallery"

Экран, используемый для отображения отдельных изображений в этой галерее. Этому экрану передаются следующие именованные аргументы:

locked

True, если изображение заблокировано.

displayables

Список трансформированных отображаемых объектов, которые должны быть показаны пользователю.

index

Индекс отображаемого изображения, начиная с 1.

count

Общее количество изображений, привязанных к текущей кнопке.

gallery

Объект галереи изображений.

Дополнительные аргументы могут быть переданы с префиксом show_ в вызовах Gallery.image и Gallery.unlock_image.

Экран по умолчанию определён в нижней части renpy/common/00gallery.rpy.

Action(name)

Экранное действие, отображающее изображения, связанные с указанным именем кнопки name.

Next(unlocked=False)

Переходит к следующему изображению в галерее.

unlocked

Если True, учитывает только разблокированные изображения.

Previous(unlocked=False)

Переходит к предыдущему изображению в галерее.

unlocked

Если True, учитывает только разблокированные изображения.

Return()

Останавливает отображение изображений галереи и возвращает к экрану выбора.

ToggleSlideshow()

Переключает режим слайд-шоу.

allprior()

Условие, которое истинно, если все предшествующие изображения, связанные с текущей кнопкой, были разблокированы.

button(name)

Создаёт новую кнопку с именем name.

name

Имя создаваемой кнопки.

condition(expression)

Условие, которое выполняется, когда выражение Python expression возвращает True.

expression

Строка, содержащая выражение Python.

get_fraction(name, format='{seen}/{total}')

Возвращает текстовую строку с количеством разблокированных изображений и общим числом изображений для кнопки с именем name. Если name равно None, возвращает аналогичную информацию суммарно для всех кнопок.

format

Строка форматирования Python, используемая для вывода чисел. Поддерживает три подставляемых значения:

{seen}

Количество просмотренных изображений.

{total}

Общее количество изображений в кнопке.

{locked}

Количество изображений, которые всё ещё заблокированы.

image(*displayables, **properties)

Добавляет новое изображение к текущей кнопке, где изображение состоит из одного или нескольких отображаемых объектов.

Свойства, начинающиеся с show_, очищаются от этого префикса и передаются в экран gallery.image_screen в качестве дополнительных именованных аргументов.

Принимает один именованный аргумент:

movie

Должен быть установлен в True, если один из отображаемых объектов является видеороликом со звуком. Это приведёт к скрытию видео во время перехода.

make_button(name, unlocked, locked=None, hover_border=None, idle_border=None, style=None, **properties)

Создаёт кнопку, отображающую изображения, связанные с указанным именем кнопки.

name

Имя создаваемой кнопки.

unlocked

Отображаемый объект, показываемый для этой кнопки, когда она разблокирована.

locked

Отображаемый объект, показываемый для этой кнопки, когда она заблокирована. Если None, используется значение поля locked_button объекта галереи.

hover_border

Отображаемый объект рамки при наведении, когда кнопка разблокирована и находится в фокусе. Если None, используется поле hover_border объекта галереи.

idle_border

Отображаемый объект рамки в состоянии покоя, когда кнопка разблокирована, но не в фокусе. Если None, используется поле idle_border объекта галереи.

style

Стиль, от которого наследуется кнопка. Если None, по умолчанию используется стиль "empty", чтобы не наследовать лишние границы и отступы.

Дополнительные именованные аргументы становятся свойствами стиля создаваемого объекта кнопки.

transform(*transforms)

Применяет трансформации к последнему зарегистрированному изображению. Метод должен вызываться с тем же количеством трансформаций, сколько отображаемых объектов содержит изображение. Трансформации применяются к соответствующим отображаемым объектам.

Если трансформация равна None, используется трансформация по умолчанию.

unlock(*images)

Условие, принимающее одно или несколько имён изображений в качестве аргументов и выполняющееся, когда все указанные изображения были просмотрены игроком. Имена изображений должны быть строками.

unlock_image(*images, **properties)

Удобный метод, эквивалентный вызову image и unlock с теми же параметрами. (Именованные аргументы, начинающиеся с show_, передаются только в image.) Это приведёт к отображению изображения, если оно уже встречалось игроку ранее.

Изображения должны быть строками, задающими имена изображений.

Музыкальная комната

Музыкальная комната — это экран, позволяющий пользователю выбирать и слушать музыкальные композиции из игры. В начале игры треки могут быть заблокированы и будут разблокироваться по мере того, как игрок слушает их во время прохождения.

Музыкальная комната управляется экземпляром класса MusicRoom. В игре может быть несколько экземпляров MusicRoom, что позволяет создавать раздельные музыкальные комнаты. Создание музыкальной комнаты состоит из следующих четырёх шагов:

  1. Создать экземпляр MusicRoom. Конструктор MusicRoom принимает параметры для управления каналом воспроизведения музыки, а также временем плавного затухания и нарастания громкости.

  2. Добавить музыкальные файлы в экземпляр.

  3. Создать экран, использующий экземпляр MusicRoom для генерации экранных действий кнопок, imagebutton или hotspot. Эти действия могут выбирать конкретный трек, переходить к следующему или предыдущему треку, а также запускать и останавливать музыку.

    Обратите внимание, что используемые действия являются методами экземпляра MusicRoom, поэтому если экземпляр назван mr, действие воспроизведения вызывается как mr.Play("track1.ogg").

  4. Добавить переход к экрану музыкальной комнаты в главное меню или меню бонусов.

Пример:

init python:

    # Шаг 1. Создание экземпляра MusicRoom.
    mr = MusicRoom(fadeout=1.0)

    # Шаг 2. Добавление музыкальных файлов.
    mr.add("track1.ogg", always_unlocked=True)
    mr.add("track2.ogg")
    mr.add("track3.ogg")


# Шаг 3. Создание экрана музыкальной комнаты.
screen music_room:

    tag menu

    frame:
        has vbox

        # Кнопки запуска каждого трека.
        textbutton "Track 1" action mr.Play("track1.ogg")
        textbutton "Track 2" action mr.Play("track2.ogg")
        textbutton "Track 3" action mr.Play("track3.ogg")

        null height 20

        # Кнопки переключения треков.
        textbutton "Next" action mr.Next()
        textbutton "Previous" action mr.Previous()

        null height 20

        # Кнопка выхода из музыкальной комнаты.
        textbutton "Main Menu" action ShowMenu("main_menu")

    # Запуск музыки при входе в музыкальную комнату.
    on "replace" action mr.Play()

    # Восстановление музыки главного меню при выходе.
    on "replaced" action Play("music", "track1.ogg")

Шаг 4 зависит от структуры вашей игры, но одним из способов является добавление следующей строки в экран главного меню:

textbutton "Music Room" action ShowMenu("music_room")

С помощью функции Preferences(), в частности Preferences("music volume"), на экран музыки можно добавить ползунок регулировки громкости.

class MusicRoom(channel='music', fadeout=0.0, fadein=0.0, loop=True, single_track=False, shuffle=False, stop_action=None)

Музыкальная комната, содержащая набор композиций, которые могут разблокироваться пользователем, и действия, позволяющие воспроизводить треки из списка по порядку.

channel

Канал, на котором работает данная музыкальная комната.

fadeout

Длительность затухания старой музыки при смене трека в секундах.

fadein

Длительность нарастания громкости новой музыки при смене трека в секундах.

loop

Определяет, будет ли воспроизведение зацикливаться или останавливаться по достижении конца плейлиста.

single_track

Если True, воспроизводится только один трек. Если loop равно True, этот трек зацикливается. В противном случае воспроизведение остановится после окончания трека.

shuffle

Если True, треки перемешиваются и воспроизводятся в случайном порядке. Если False, треки воспроизводятся в порядке добавления в MusicRoom.

stop_action

Действие, выполняемое при остановке воспроизведения музыки.

Параметры single_track и shuffle несовместимы друг с другом: только один из них может быть равен True в любой момент времени (действия, устанавливающие single_track и shuffle, автоматически обеспечивают это правило).

Next()

Действие, переключающее музыкальную комнату на следующий разблокированный файл в плейлисте.

Play(filename=None)

Это действие запускает воспроизведение в музыкальной комнате. Если указан параметр filename, начинает воспроизводиться данный файл. В противном случае текущий трек начинает воспроизводиться сначала (если он разблокирован) либо запускается первый файл.

Если параметр filename указан, кнопки с этим действием будут нечувствительными (заблокированными), пока filename заблокирован, и будут выбраны (selected), когда filename воспроизводится.

Previous()

Действие, переключающее музыкальную комнату на предыдущий разблокированный файл в плейлисте.

RandomPlay()

Это действие запускает воспроизведение случайно выбранного разблокированного музыкального трека.

SetLoop(value)

Это действие устанавливает свойство loop (зацикливание).

SetShuffle(value)

Это действие устанавливает свойство shuffle (случайный порядок).

SetSingleTrack(value)

Это действие устанавливает свойство single_track (один трек).

Stop()

Это действие останавливает воспроизведение музыки.

ToggleLoop()

Это действие переключает значение свойства loop.

TogglePause()

Если музыка воспроизводится, приостанавливает (pause) или возобновляет её воспроизведение.

Кнопка выбрана (selected), когда воспроизведение приостановлено.

TogglePlay()

Если музыка в данный момент не играет, запускает воспроизведение первого разблокированного трека. В противном случае останавливает текущую музыку.

Кнопка выбрана (selected), когда воспроизводится любая музыка.

ToggleShuffle()

Это действие переключает значение свойства shuffle.

ToggleSingleTrack()

Это действие переключает значение свойства single_track.

add(filename, always_unlocked=False, action=None)

Добавляет музыкальный файл filename в эту музыкальную комнату. Музыкальная комната будет воспроизводить разблокированные файлы в порядке их добавления в комнату.

always_unlocked

Если True, музыкальный файл всегда будет разблокирован. Это позволяет файлу появиться в музыкальной комнате ещё до того, как он прозвучал в игре.

action

Действие или список действий, вызываемых при воспроизведении данного файла.

Например, эти действия могут использоваться для изменения экрана, фона или описания в зависимости от играющего файла.

is_unlocked(filename)

Возвращает True, если файл разблокирован (или всегда разблокирован), и False, если он всё ещё заблокирован.

Повтор сцен (Replay)

Ren'Py также поддерживает воспроизведение сюжетных сцен непосредственно из главного или внутриигрового меню. Это можно использовать для создания галереи сцен или галереи воспоминаний, позволяющей игроку заново пережить важные моменты истории. После окончания сцены Ren'Py возвращает управление туда, откуда был запущен повтор.

Повтор сцен также возможен с помощью действия Start(). Различия между двумя режимами:

  • Повтор сцены (Replay) можно запустить с любого экрана, тогда как Start можно использовать только в главном меню или на экранах, показанных главным меню.

  • По завершении повтора управление возвращается в точку вызова повтора (например, в главное меню или игровое меню). Если при вызове повтора шла игра, состояние игры полностью сохраняется.

  • Сохранение игры отключено во время режима повтора сцены. Перезагрузка (которая требует сохранения) также отключена.

  • В режиме повтора сцены вызов renpy.end_replay() завершает повтор. В обычном режиме игры end_replay ничего не делает.

Чтобы воспользоваться режимом повтора сцены, последовательность должна начинаться с метки и завершаться вызовом renpy.end_replay(). Последовательность не должна делать предположений относительно состояния слоёв или переменных, которые могут сильно отличаться в обычном режиме и режиме повтора (за исключением переменных, переданных через параметр scope при входе в повтор). Когда повтор начинается, метка вызывается на фоне чёрного экрана.

Например:

    "And finally, I met the wizard himself."

label meaning_of_life:

    scene revelation

    "Mage" "What is the meaning of life, you say?"

    "Mage" "I've thought about it long and hard. A long time, I've
            spent pondering that very thing."

    "Mage" "And I'll say - the answer - the meaning of life
            itself..."

    "Mage" "Is forty-three."

    $ renpy.end_replay()

    "Mage" "Something like that, anyway."

С последовательностью, определённой таким образом, повтор сцены можно запустить с помощью действия Replay:

textbutton "The meaning of life" action Replay("meaning_of_life")

В режиме повтора сцены используется одна переменная хранилища:

_in_replay

В режиме повтора содержит метку, с которой был начат повтор сцены — метку, которая была вызвана, а не ту, откуда произошёл вызов. Вне режима повтора равна None.

Кроме того, config.enter_replay_transition и config.exit_replay_transition используются при входе в режим повтора сцены и выходе из него соответственно. config.replay_scope добавляет переменные в очищенное хранилище при входе в повтор и по умолчанию устанавливает _game_menu_screen, чтобы правый клик мыши во время повтора по умолчанию открывал экран настроек.

В режиме повтора сцены используются следующие переменные и действия:

EndReplay(confirm=True)

Завершает текущий повтор (replay).

confirm

Если True, запрашивает подтверждение пользователя перед завершением повтора.

Replay(label, scope={}, locked=None)

Экранное действие, запускающее метку label в режиме повтора (replay).

scope

Словарь, сопоставляющий имена переменных с их значениями. Эти переменные устанавливаются при входе в режим повтора.

locked

Если True, это действие нечувствительно (кнопка заблокирована) и ничего не делает при активации. Если False, ведёт себя обычным образом. Если None, действие блокируется, если метка ещё не была просмотрена ни в одном из прохождений игры.

renpy.call_replay(label, scope={})

Вызывает метку в качестве воспоминания / повтора сцены.

Аргумент scope используется для задания начальных значений переменных в контексте повтора сцены.

renpy.end_replay()

Если игра находится в режиме повтора, немедленно завершает его. В противном случае ничего не делает.
