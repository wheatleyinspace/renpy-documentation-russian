Достижения

Модуль достижений (Achievement) позволяет разработчику выдавать достижения игроку, сбрасывать достижения и проверять, было ли получено то или иное достижение. Он также позволяет отслеживать прогресс выполнения достижения.

По умолчанию модуль достижений сохраняет информацию в файле постоянных данных (persistent). Если доступна и включена поддержка Steam, данные о достижениях автоматически синхронизируются со Steam.

Поддержку Steam необходимо отдельно добавить в Ren'Py, чтобы гарантировать, что она распространяется только разработчиками, принятыми в партнёрскую программу Steam. Чтобы установить её, в лаунчере выберите «Настройки» (preferences) -> «Установить библиотеки» (Install libraries) -> «Установить поддержку Steam» (Install Steam Support).

achievement.Sync()

Экранное действие, вызывающее achievement.sync(). Кнопка с этим действием активна, только если достижения рассинхронизированы.

achievement.clear(name)

Сбрасывает достижение с именем name.

achievement.clear_all()

Сбрасывает все достижения.

achievement.get_progress(name)

Возвращает текущий прогресс достижения name или 0, если прогресс не был зарегистрирован либо если достижение неизвестно.

achievement.grant(name)

Выдаёт игроку достижение с именем name, если оно ещё не было получено.

achievement.has(name)

Возвращает True, если игрок уже получил достижение name.

achievement.progress(name, complete)

Сообщает о прогрессе в получении достижения name, если оно ещё не было получено. Достижение должно быть зарегистрировано со значением завершения (stat_max).

name

Имя достижения. Это должно быть имя достижения, а не название характеристики (stat).

complete

Целое число, указывающее количество единиц прогресса по отношению к достижению.

achievement.register(name, **kwargs)

Регистрирует достижение. Регистрация достижений не является строго обязательной, но позволяет передавать информацию бэкендам (например, Steam).

name

Имя регистрируемого достижения.

Следующие именованные параметры являются необязательными:

steam

Имя достижения для использования в Steam. Если не указано, по умолчанию равно name.

stat_max

Целочисленное значение характеристики, при достижении которого разблокируется достижение.

stat_modulo

Если значение прогресса по модулю stat_max равно 0, прогресс отображается пользователю. Например, если stat_modulo равен 10, прогресс будет отображаться пользователю при достижении 10, 20, 30 и т. д. По умолчанию 0.

achievement.sync()

Синхронизирует зарегистрированные достижения между локальным хранилищем и другими бэкендами (например, Steam).

Переменные, управляющие достижениями:

achievement.steam_position = None

Если не None, задаёт позицию всплывающего уведомления Steam. Должно быть строкой, одной из следующих: "top left", "top right", "bottom left" или "bottom right".

define config.steam_appid = None

Если не None, задаёт appid игры в Steam. Ren'Py автоматически установит этот appid при запуске. Задаётся с помощью инструкции define:

define config.steam_appid = 12345
define config.automatic_steam_timeline = True

Если True, при запуске под Steam игра будет автоматически обновлять временную шкалу Steam Timeline.

В настоящее время это включает в себя:

  • Обновление фазы игры в соответствии с save_name, если эта переменная задана.

  • Обновление режима игры для отражения нахождения игрока внутри меню.

API Steamworks

Когда Steam доступен, привязка на основе ctypes к API Steamworks доступна как achievement.steamapi. Привязка представляет собой экземпляр модуля steamapi, расположенного здесь, и представляет собой машинный перевод C++ API Steamworks на Python.

Кроме того, большое количество функций доступно в объекте achievement.steam, если и только если доступен API Steamworks.

achievement.steam

Если Steam успешно инициализирован, представляет собой пространство имён с высокоуровневыми методами Steam. Если Steam не инициализирован, значение равно None. Всегда проверяйте, что это значение не равно None, перед вызовом методов.

Приложения Steam (Steam Apps)

achievement.steam.dlc_installed(appid)

Возвращает True, если DLC appid установлено, или False в противном случае.

achievement.steam.dlc_progress(appid)

Возвращает информацию о прогрессе загрузки DLC.

achievement.steam.get_app_build_id()

Возвращает ID сборки (Build ID) установленной игры.

achievement.steam.get_current_beta_name()

Возвращает имя текущей бета-версии или None, если получить его не удалось.

achievement.steam.get_current_game_language()

Возвращает имя языка, выбранного пользователем для игры.

achievement.steam.get_steam_ui_language()

Возвращает имя языка интерфейса Steam.

achievement.steam.install_dlc(appid)

Запрашивает установку DLC с указанным appid.

achievement.steam.is_subscribed_app(appid)

Возвращает True, если пользователь владеет приложением с appid, и False в противном случае.

achievement.steam.uninstall_dlc(appid)

Запрашивает удаление DLC с указанным appid.

Оверлей Steam (Steam Overlay)

achievement.steam.activate_overlay(dialog)

Активирует оверлей Steam.

dialog

Диалог, на котором открывается оверлей. Одно из следующих значений: "Friends", "Community", "Players", "Settings", "OfficialGameGroup", "Stats", "Achievements".

achievement.steam.activate_overlay_to_store(appid, flag=None)

Открывает оверлей Steam на странице магазина.

appid

Идентификатор приложения (appid) для открытия.

flag

Одно из следующих значений: achievement.steam.STORE_NONE, .STORE_ADD_TO_CART или .STORE_ADD_TO_CART_AND_SHOW.

achievement.steam.activate_overlay_to_web_page(url)

Активирует оверлей Steam и открывает веб-страницу по адресу url.

achievement.steam.is_overlay_enabled()

Возвращает True, если оверлей Steam включён. (После запуска игры может потребоваться некоторое время, прежде чем функция начнёт возвращать True.)

achievement.steam.overlay_needs_present()

Возвращает True, если оверлей Steam требует вызова отрисовки (present).

achievement.steam.set_overlay_notification_position(position)

Задаёт позицию всплывающих уведомлений оверлея Steam. Параметр position должен быть одной из констант: achievement.steam.POSITION_TOP_LEFT, .POSITION_TOP_RIGHT, .POSITION_BOTTOM_LEFT или .POSITION_BOTTOM_RIGHT.

Статистика Steam (Steam Stats)

achievement.steam.clear_achievement(name)

Сбрасывает достижение с именем name. Вызовите achievement.steam.store_stats(), чтобы отправить изменения на сервер.

achievement.steam.get_achievement(name)

Получает состояние достижения с именем name. Возвращает True, если достижение было получено, False, если нет, и None, если достижение неизвестно или возникла ошибка.

achievement.steam.get_float_stat(name)

Возвращает значение характеристики с именем name или None, если такой характеристики не существует.

achievement.steam.get_int_stat(name)

Возвращает значение характеристики с именем name или None, если такой характеристики не существует.

achievement.steam.grant_achievement(name)

Выдаёт достижение с именем name. Вызовите achievement.steam.store_stats(), чтобы отправить изменения на сервер.

achievement.steam.indicate_achievement_progress(name, cur_progress, max_progress)

Отображает пользователю прогресс в получении достижения. Это не разблокирует достижение.

achievement.steam.list_achievements()

Возвращает список имён достижений.

achievement.steam.retrieve_stats()

Запрашивает достижения и статистику из Steam.

achievement.steam.set_float_stat(name, value)

Устанавливает значение характеристики name, которая должна иметь тип FLOAT. Вызовите achievement.steam.store_stats(), чтобы отправить изменения на сервер.

achievement.steam.set_int_stat(name, value)

Устанавливает значение характеристики name, которая должна иметь тип INT. Вызовите achievement.steam.store_stats(), чтобы отправить изменения на сервер.

achievement.steam.store_stats()

Сохраняет статистику и достижения на сервере Steam.

Временная шкала Steam (Steam Timeline)

achievement.steam.add_timeline_event(icon, title, description, priority=0, start_offset=0.0, duration=0.0, possible_clip=None)

Добавляет событие на временную шкалу (Timeline) Steam. Обратите внимание, что порядок аргументов здесь отличается от API Steam.

icon

Иконка события. Строка, задающая одну из стандартных иконок Steam либо иконку, загруженную вами в Steam.

title

Заголовок события.

description

Описание события.

priority

Приоритет события для разрешения конфликтов. Целое число от 0 до 1000.

start_offset

Смещение начала события относительно текущего времени в секундах.

duration

Продолжительность события в секундах.

possible_clip

Определяет, может ли событие формировать видеоклип. Должно быть одной из констант achievement.steam.CLIP_PRIORITY...: CLIP_PRIORITY_NONE, CLIP_PRIORITY_STANDARD или CLIP_PRIORITY_FEATURED.

achievement.steam.clear_timeline_state_description(time_delta)

Очищает описание текущего состояния на временной шкале Steam.

achievement.steam.set_timeline_state_description(description, time_delta=0.0)

Устанавливает описание текущего состояния на временной шкале Steam.

description

Строка с описанием текущего состояния.

time_delta

Время, прошедшее с момента последнего изменения состояния.

Пользователь Steam (Steam User)

achievement.steam.cancel_ticket()

Аннулирует билет (тикет), возвращённый функцией achievement.steam.get_session_ticket().

achievement.steam.get_account_id()

Возвращает ID аккаунта пользователя.

achievement.steam.get_csteam_id()

Возвращает полный CSteamID пользователя в виде 64-битного числа.

achievement.steam.get_game_badge_level(series, foil)

Возвращает уровень значка Steam пользователя для вашей игры.

achievement.steam.get_persona_name()

Возвращает публично видимое имя (никнейм) пользователя.

achievement.steam.get_session_ticket(identity=None)

Получает сессионный тикет, который можно отправить на сервер для аутентификации данного пользователя.

Мастерская Steam (Steam Workshop)

achievement.steam.get_subscribed_item_path(item_id)

Возвращает путь, по которому установлен элемент пользовательского контента (UGC). Возвращает None, если элемент не установлен.

item_id

Идентификатор элемента контента (item id).

achievement.steam.get_subscribed_items(include_disabled=False)

Возвращает список идентификаторов элементов, на которые пользователь подписан в мастерской Steam (Steam Workshop).

include_disabled

Если True, включает элементы, которые отключены.
