Действия, значения и функции экранов

Ren'Py поставляется с множеством действий (actions), значений (values) и функций, предназначенных для использования с экранами и языком экранов.

Действия (Actions)

Действия вызываются при активации кнопки (включая imagebutton, textbutton и hotspot), при наведении курсора на нее (hovered) или при уходе курсора с нее (unhovered). Действия также могут определять, когда кнопка является выбранной (selected) или нечувствительной (insensitive).

Наряду с этими предопределенными классами действий, действием может выступать любая функция без аргументов. Функция вызывается при срабатывании действия. Если функция возвращает значение, отличное от None, это значение возвращается из взаимодействия (interaction).

Вместо одного действия обычно можно передать список действий: в этом случае действия в списке выполняются по порядку. Список действий считается чувствительным к нажатию, если все действия в нем чувствительны, и выбранным, если хотя бы одно из них выбрано, если только в списке не используются SensitiveIf() или SelectedIf() соответственно.

Действия управления

Эти действия управляют экранами, результатами взаимодействий и потоком выполнения.

Call(label, *args, **kwargs)

Завершает текущий оператор и вызывает метку label, заданную в виде строки. Позиционные и именованные аргументы передаются в renpy.call().

CallInNewContext(label, *args, **kwargs)

Вызывает метку label, заданную в виде строки, в новом контексте. Это полезно при вызове метки из экрана, который сам вызван через call screen. Обратите внимание: находясь в новом контексте, игрок не сможет сохранить игру, а состояние сцены и аудио сбросится при возвращении во внешний контекст. Дополнительные сведения см. в разделе Контексты. Аргументы передаются в renpy.call_in_new_context().

Hide(screen=None, transition=None, _layer=None, immediately=False)

Скрывает экран, если он отображается.

screen

Строка, задающая имя скрываемого экрана, или None для скрытия текущего экрана.

transition

Если не None, переход, применяемый при скрытии экрана.

_layer

Передается в качестве аргумента layer в функцию renpy.hide_screen(). Игнорируется, если screen равен None.

immediately

Если True, экран скрывается мгновенно, без вызова события 'on hide'.

Jump(label)

Передает управление метке label, заданной в виде строки.

NullAction()

Не делает ничего.

Может использоваться для того, чтобы сделать кнопку отзывчивой к наведению курсора (hover/unhover), не привязывая к ней фактического действия.

Return(value=None)

Заставляет текущее взаимодействие вернуть указанное значение (отличное от None). Часто используется в меню и картах изображений для задания возвращаемого значения взаимодействия. Если экран был вызван оператором call screen, возвращаемое значение помещается в переменную _return.

При использовании в меню осуществляет возврат из меню (в этом случае значение должно быть None).

Show(screen, transition=None, *args, **kwargs)

Отображает другой экран. screen — строка с именем экрана. Аргументы передаются отображаемому экрану.

Если не None, transition используется для показа нового экрана.

Это действие принимает именованные аргументы _layer, _zorder и _tag, имеющие то же значение, что и в функции renpy.show_screen().

ShowTransient(screen, transition=None, *args, **kwargs)

Отображает временный (transient) экран. Временный экран скрывается по завершении текущего взаимодействия. Аргументы передаются отображаемому экрану.

Если не None, transition используется для показа нового экрана.

Это действие принимает именованные аргументы _layer, _zorder и _tag, имеющие то же значение, что и в функции renpy.show_screen().

ToggleScreen(screen, transition=None, *args, **kwargs)

Переключает видимость экрана screen. Если экран в данный момент не отображается, он показывается с переданными аргументами. В противном случае экран скрывается.

Если не None, transition используется для показа и скрытия экрана.

Это действие принимает именованные аргументы _layer, _zorder и _tag, имеющие то же значение, что и в функции renpy.show_screen().

Методы доступа определяют цель, значение которой будет изменено, а менеджер определяет, каким станет новое значение. Принцип их работы прост и логичен:

  • Действия -Variable изменяют значение глобальной переменной с именем name, находящейся в общем хранилище (store). Аргумент name должен быть строкой и может быть как простым именем ("strength"), так и составным с точками для доступа к полям ("hero.strength", "persistent.show_cutscenes").

  • Действия -ScreenVariable изменяют значение переменной с именем name, связанной с текущим экраном верхнего уровня. Во вложенном (use) экране это действие задает переменную в контексте экрана, содержащего вложенные.

  • Действия -LocalVariable изменяют значение переменной с именем name локально в том экране, где они находятся. Это действие полезно только в экранах, включенных другим экраном через use (см. Use). Во всех остальных случаях следует отдавать предпочтение действиям -ScreenVariable, так как они обеспечивают лучшую производительность и позволяют кэшировать большую часть экрана. Действия -LocalVariable должны создаваться в том же контексте, где переменная задана — их нельзя передавать извне.

  • Действия -Field изменяют значение поля field объекта object.

  • Действия -Dict изменяют значение по ключу key в словаре dict: они выполняют операцию dict[key] = .... Это также работает со списками.

  • Действия Set- просто присваивают цели переданное значение value: target = value. (Не путайте с типом данных set в Python).

  • Действия Toggle- инвертируют логическое (булево) значение цели между true_value (если задано) и false_value (если задано). Когда оба равны None: target = not target.

  • Действия Cycle- циклически переключают значения из переданной последовательности values (список, кортеж или range). Если текущее значение цели отсутствует в последовательности при вызове, устанавливается первое значение из нее. Параметр loop (по умолчанию True) определяет поведение при достижении конца: при True цикл начинается заново, при False вызывается исключение. Параметр reverse (по умолчанию False) обращает порядок обхода.

  • Действия Increment- прибавляют amount к цели (по умолчанию 1, либо любой совместимый с целью тип): target = target + amount.

Следующие действия с данными не укладываются в приведенную схему. Некоторые из них связаны с типом данных set в Python (не путать с действиями Set- выше).

AddToSet(set, value)

Добавляет value в множество или список set.

set

Множество, в которое добавляется элемент. Может быть объектом set или list в Python; в случае списка значение добавляется в конец.

value

Добавляемое значение.

RemoveFromSet(set, value)

Удаляет value из множества или списка set.

set

Множество или список, из которого удаляется элемент.

value

Удаляемое значение.

ToggleSetMembership(set, value)

Переключает принадлежность value к множеству или списку set. Если значение отсутствует в множестве, оно добавляется. В противном случае оно удаляется.

Кнопки с этим действием помечаются как выбранные (selected) тогда и только тогда, когда значение присутствует в множестве.

set

Множество или список, в который добавляется или из которого удаляется элемент. В случае списка новые элементы добавляются в конец.

value

Переключаемое значение.

Действия меню

Эти действия вызывают меню или используются главным образом внутри главного или игрового меню.

Continue(regexp='[^_]', confirm=True)

Загружает последнее сохранение. Предназначено для загрузки последнего сохранения игрока из главного меню.

regexp

Если указано, используется в renpy.newest_slot. Шаблон по умолчанию продолжит игру с любого сохранения, включая быстрые и автоматические сохранения. Если вы хотите загружать только сохранения, сделанные непосредственно игроком, установите этот параметр в r"\d".

confirm

Если True, Ren'Py спросит у пользователя подтверждение продолжения игры с места сохранения, если игрок не находится в главном меню.

MainMenu(confirm=True, save=True)

Возвращает в главное меню.

confirm

Если True, Ren'Py запрашивает подтверждение перед возвратом в главное меню.

save

Если True, игра сохраняется в слот _quit_slot перед тем, как Ren'Py перезапустится и вернет пользователя в главное меню. Игра не сохраняется, если _quit_slot равен None.

Quit(confirm=None)

Завершает работу игры.

confirm

Если True, запрашивает подтверждение выхода. Если None, запрашивает подтверждение только в том случае, если пользователь не находится в главном меню.

ShowMenu(screen=_game_menu_screen, *args, _transition=config.intra_transition, **kwargs)

Осуществляет вход в игровое меню, если игра еще не находится в нем. Если игра уже находится в игровом меню, отображает указанный экран или переходит к метке.

screen обычно является именем экрана, который отображается с помощью механизма экранов. Если экран не существует, к имени добавляется "_screen", и осуществляется переход (jump) к этой метке. На экран передаются аргументы *args и **kwargs. Если экран не существует, к имени добавляется "_screen", и происходит переход к метке с игнорированием args и kwargs.

Если передан необязательный именованный аргумент _transition, экран меню сменится с использованием указанного перехода. Если параметр не задан вручную, по умолчанию используется переход config.intra_transition.

  • ShowMenu("preferences")

Действия фокуса

CaptureFocus(name='default')

Если при выполнении этого действия отображаемый объект находится в фокусе, прямоугольник, содержащий этот объект, сохраняется под именем name. Затем этот прямоугольник можно получить с помощью действия GetFocusRect() или свойства focus отображаемого объекта Nearrect.

Если ни один отображаемый объект не сфокусирован, ранее сохраненный прямоугольник с этим именем удаляется.

name

Имя сохраняемого прямоугольника фокуса (строка). Имя "tooltip" является специальным, так как оно автоматически сохраняется при изменении подсказки.

ClearFocus(name='default')

Очищает сохраненный прямоугольник фокуса, зафиксированный действием CaptureFocus(). Если name равно None, очищаются все прямоугольники фокуса.

GetFocusRect(name='default')

Если прямоугольник фокуса с указанным именем был сохранен (либо с помощью CaptureFocus(), либо автоматически подсказкой), возвращает прямоугольник (x, y, h, w). В противном случае возвращает None.

name

Имя извлекаемого прямоугольника фокуса. Имя "tooltip" является специальным, так как оно фиксируется автоматически при изменении подсказки.

ToggleFocus(name='default')

Если прямоугольник фокуса существует, очищает его, иначе захватывает.

name

Имя сохраняемого прямоугольника фокуса. Должно быть строкой. Имя "tooltip" является специальным, так как фиксируется автоматически при смене подсказки.

Confirm(prompt, yes, no=None, confirm_selected=False, screen=None, **kwargs)

Запрашивает у пользователя подтверждение действия. Если пользователь выбирает «Да», выполняется действие yes. В противном случае выполняется действие no.

Текст запроса, отображаемый пользователю.

code

Исходный код JavaScript для выполнения.

Это действие вызывает callable(*args, **kwargs).

callable

Вызываемый объект. Предполагается, что если два вызываемых объекта равны при сравнении, вызов любого из них будет эквивалентен.

Именованные аргументы, передаваемые в callable.

Если True, взаимодействие перезапускается, и экраны обновляются после возврата из функции.

Если функция возвращает значение, отличное от None, взаимодействие останавливается и возвращает это значение. (При вызове через оператор call screen результат помещается в переменную _return.)

Прокручивает полосу (Bar), область просмотра (Viewport) или сетку (Vpgrid).

Идентификатор bar, viewport или vpgrid на текущем экране.

SelectedIf(action, /)

Указывает, что одно действие из списка действий должно использоваться для определения того, выбрана ли кнопка. Имеет смысл только тогда, когда кнопке передан список действий. Например:

    action [ SelectedIf(SetVariable("mars_flag", True)), SetVariable("on_mars", True) ]

# Кнопка активна только если mars_flag равен True
textbutton "Марсополис":
    action [ SensitiveIf(SetVariable("mars_flag", True)), SetVariable("on_mars", True) ]

Настройки (Preferences)

Хотя все настройки можно определить на основе действий и значений полос, приведенных выше, это требует глубокого знания Ren'Py. Конструктор Preference упрощает задачу, создавая подходящее действие или значение автоматически на основе имен, используемых в стандартном экране настроек.

Значение переменной save_name на момент сохранения игры.

_renpy_version

Версия Ren'Py, в которой было создано сохранение.

_version

Значение config.version на момент создания сохранения.

_game_runtime

Результат вызова renpy.get_game_runtime().

_ctime

Время создания сохранения (в секундах с 1 января 1970 года, UTC).

FileLoadable(name, page=None, slot=False)

Функция, возвращающая True, если файл доступен для загрузки, и False в противном случае.

FileNewest(name, page=None, slot=False)

Возвращает True, если это самый новый слот сохранения, и False в противном случае.

FilePageName(auto='a', quick='q')

Возвращает имя текущей страницы файлов в виде строки. Для обычной страницы возвращает номер страницы, для служебных — значение auto или quick.

FileSaveName(name, empty='', page=None, slot=False)

Возвращает значение save_name, действовавшее в момент сохранения файла, или empty, если файл не существует.

FileScreenshot(name, empty=None, page=None, slot=False)

Возвращает скриншот, связанный с данным файлом. Если файл невозможно загрузить, возвращается empty (если None, создается объект Null).

Возвращаемое значение является отображаемым объектом (Displayable).

FileSlotName(slot, slots_per_page, auto='a', quick='q', format='%s%d')

Возвращает имя пронумерованного слота. Предполагается, что слоты на обычных страницах нумеруются линейно с 1, и нумерация страниц также начинается с 1. Если slot равен 2, а slots_per_page равен 10:

  • На первой странице возвращает "2".

  • На второй странице возвращает "12".

  • На странице автосохранений возвращает "a2".

  • На странице быстрых сохранений возвращает "q2".

slot

Номер слота.

slots_per_page

Количество слотов на странице.

auto

Префикс для страницы автосохранений.

quick

Префикс для страницы быстрых сохранений.

format

Строка форматирования. Принимает два аргумента: строку с префиксом страницы и целое число с номером слота.

FileTime(name, format='%b %d, %H:%M', empty='', page=None, slot=False)

Возвращает время сохранения файла, отформатированное в соответствии с format. Если файл не найден, возвращается empty.

Возвращаемое значение — строка.

Возвращает список занятых числовых слотов на странице.

page

Имя сканируемой страницы. Если None, используется текущая страница.

highest_first

Если True, первыми идут слоты с наибольшими номерами. Иначе — с наименьшими.

Функции боковых изображений (Side Image)

HasSideImage()

Возвращает True, если для текущего взаимодействия отображается боковое изображение (side image), и False в противном случае. Всплывающие подсказки (Tooltips)

К всплывающим подсказкам теперь можно обращаться через свойство tooltip, доступное для всех отображаемых объектов, и функцию GetTooltip. Функция GetTooltip возвращает значение свойства tooltip при получении объектом фокуса.

Напоминаем, что значения, передаваемые свойству tooltip, должны поддерживать сравнение на равенство.

Пример:

screen tooltip_example():
    vbox:
        textbutton "Север":
            action Return("n")
            tooltip "Повстречать белого медведя."

        textbutton "Юг":
            action Return("s")
            tooltip "Прямиком в тропики."

        textbutton "Восток":
            action Return("e")
            tooltip "Встретить рассвет."

        textbutton "Запад":
            action Return("w")
            tooltip "Любоваться лучшими закатами."

        $ tooltip = GetTooltip()

        if tooltip:
            text "[tooltip]"

Отображаемый объект Nearrect можно использовать для вывода всплывающих подсказок в стиле всплывающих окон. Он поддерживает специальное имя фокуса "tooltip", указывающее на координаты последнего объекта в фокусе, установившего подсказку:

screen tooltip_example2():
    frame:

        padding (20, 20)
        align (.5, .3)

        has vbox

        textbutton "Север":
            action Return("n")
            tooltip "Повстречать белого медведя."

        textbutton "Юг":
            action Return("s")
            tooltip "Прямиком в тропики."

        textbutton "Восток":
            action Return("e")
            tooltip "Встретить рассвет."

        textbutton "Запад":
            action Return("w")
            tooltip "Любоваться лучшими закатами."

    # Этот блок должен быть последним на экране.

    $ tooltip = GetTooltip()

    if tooltip:

        nearrect:
            focus "tooltip"
            prefer_top True

            frame:
                xalign 0.5
                text tooltip
GetTooltip(screen=None, last=False)

Возвращает подсказку (tooltip) сфокусированного в данный момент отображаемого объекта или None, если ни один объект не находится в фокусе.

screen

Имя или тег экрана. Если указано, функция возвращает подсказку только в том случае, если сфокусированный объект принадлежит этому экрану.

last

Если True, возвращает последнее непустое (не None) значение, которое вернула бы эта функция.

Устаревший вариант

Предупреждение

Этот вариант устарел и заменен описанным выше, однако может встречаться в старых проектах.

Класс Tooltip обновляет экран при наведении курсора на кнопку.

class Tooltip(default)

Объект подсказки (Tooltip) можно использовать для выделения части экрана, обновляемой при наведении курсора мыши на область.

Объект tooltip имеет поле value, инициализируемое значением default, переданным конструктору при создании. Когда курсор наводится на кнопку, использующую созданное этим tooltip действие, поле value принимает значение, связанное с действием.

Action(value)

Возвращает действие, обычно используемое в качестве свойства hovered кнопки. При наведении курсора на кнопку поле value этого tooltip устанавливается в value. При потере кнопкой фокуса поле value сбрасывается к значению по умолчанию.

При использовании tooltip на экране обычно создается объект tooltip в операторе default. Затем поле value и метод Action можно использовать внутри экрана. Порядок их размещения на экране не имеет значения: к value можно обращаться до вызова Action.

Подсказки могут принимать любое значение. В приведенном ниже примере оператор text выводит строку на экран, однако можно также использовать оператор add для отображения любого графического объекта.

screen tooltip_test:

    default tt = Tooltip("Ни одна кнопка не выбрана.")

    frame:
        xfill True

        has vbox

        textbutton "Один.":
            action Return(1)
            hovered tt.Action("Самое одинокое число.")

        textbutton "Два.":
            action Return(2)
            hovered tt.Action("Пара для диалога.")

        textbutton "Три.":
            action Return(3)
            hovered tt.Action("Уже компания.")

        text tt.value
