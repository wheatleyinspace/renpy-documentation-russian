Манипуляторы изображений (Image Manipulators)

Манипулятор изображений (image manipulator) — это отображаемый объект, который принимает изображение или другой манипулятор изображений и либо загружает его, либо выполняет над ним графическую операцию. Манипуляторы изображений могут принимать на вход только другие манипуляторы изображений или пути к графическим файлам.

Манипулятор изображений можно использовать в любом месте, где допустим отображаемый объект (displayable), но не наоборот. Функция Image() создаёт разновидность манипулятора изображений, поэтому Image() можно использовать везде, где требуется манипулятор изображений.

Предупреждение

Использование манипуляторов изображений считается устаревшим и сохраняется ради обратной совместимости. Многие манипуляторы изображений, описанные в ранних версиях документации, больше не рекомендуются к использованию из-за ограничений производительности и кэширования. В большинстве случаев (за исключением im.Data()) отображаемый объект Transform() предоставляет аналогичный функционал, лишённый этих недостатков.

class im.AlphaMask(base, mask, **properties)

Манипулятор изображений, принимающий два манипулятора изображений — base и mask. Он заменяет альфа-канал base красным каналом mask.

Используется для хранения альфа-канала изображения в отдельном файле (например, один JPEG для данных цвета, а второй — для альфа-маски). В ряде случаев два JPEG-файла занимают меньше места на диске, чем один PNG.

Оба изображения должны иметь одинаковый размер и одинаковый коэффициент передискретизации (oversampling).

Обратите внимание, что параметры этого класса отличаются от AlphaMask(), использующего альфа-канал маски. Преобразование можно выполнить с помощью шейдера "renpy.red_to_alpha". Ниже приведён более быстрый современный эквивалент данного манипулятора:

AlphaMask(base, Transform(mask, shader="renpy.red_to_alpha"))
class im.Blur(im, xrad, yrad=None, **properties)

Манипулятор изображений, размывающий изображение im по эллиптическому ядру, задаваемому радиусом xrad и опциональным радиусом yrad.

Если yrad равен None, используется значение xrad, что даёт круговое ядро размытия.

image logo blurred = im.Blur("logo.png", 1.5)

Устарело, начиная с версии 7.4.0: Используйте свойство трансформации blur.

class im.Crop(im, rect)

Манипулятор изображений, вырезающий область rect (кортеж вида (x, y, width, height)) из манипулятора изображений im.

image logo crop = im.Crop("logo.png", (0, 0, 100, 307))

Устарело, начиная с версии 7.4.0: Используйте свойство трансформации crop.

class im.Data(data: bytes, filename: str, **properties)

Манипулятор изображений, загружающий изображение из двоичных данных в памяти.

data

Байтовая строка, содержащая сжатые графические данные в одном из поддерживаемых форматов файлов.

filename

Имя файла, ассоциированное с изображением. Используется в качестве подсказки для Ren'Py относительно формата данных в data (с диска файл не считывается).

class im.FactorScale(im, width, height=None, bilinear=True, **properties)

Манипулятор изображений, масштабирующий im в width раз по ширине и в height раз по высоте относительно исходных размеров. Если height опущен, используется значение width.

Если bilinear равно True, используется билинейная фильтрация масштабирования, иначе — интерполяция по ближайшим соседям (nearest neighbor).

image logo doubled = im.FactorScale("logo.png", 1.5)

Устарело, начиная с версии 7.4.0: Используйте свойства трансформации zoom либо xzoom и yzoom.

class im.Flip(im, horizontal=False, vertical=False, **properties)

Манипулятор изображений, зеркально отражающий im по вертикали или горизонтали. Параметры vertical и horizontal задают оси отражения.

image eileen flip = im.Flip("eileen_happy.png", vertical=True)

Устарело, начиная с версии 7.4.0: Задайте отрицательное значение для свойств xzoom (для горизонтального отражения) или yzoom (для вертикального отражения).

im.Grayscale(im, **properties)

Манипулятор изображений, создающий обесцвеченную (чёрно-белую) версию изображения im.

Устарело, начиная с версии 7.4.0: Задайте свойство трансформации matrixcolor равным SaturationMatrix(0).

im.Sepia(im, **properties)

Манипулятор изображений, создающий версию изображения im в оттенках сепии.

Устарело, начиная с версии 7.4.0: Задайте свойство трансформации matrixcolor равным SepiaMatrix().

class im.Tile(im, size=None, **properties)

Манипулятор изображений, многократно повторяющий (замащивающий) изображение im плиткой до достижения размера size.

size

Если не None, кортеж (width, height). Если None, по умолчанию принимает значение (config.screen_width, config.screen_height).

Устарело, начиная с версии 7.4.0: Используйте Tile(im, xysize=size, **properties).

im.MatrixColor

Предупреждение

Манипулятор изображений im.MatrixColor заменён объектами Transform и свойствами ATL, задающими свойство трансформации matrixcolor. Для каждого генератора im.matrix создан эквивалент на основе Matrix, описанный в документации по матрицам цветов.

Манипулятор изображений im.MatrixColor применяет матрицу для линейного преобразования цветовых компонентов изображения. В качестве матрицы используется объект im.matrix, кодирующий матрицу размером 5x5 и поддерживающий операцию матричного умножения. Объекты im.matrix можно перемножать между собой, получая результирующую матрицу, выполняющую обе операции за один проход. Например:

image city blue = im.MatrixColor(
    "city.jpg",
    im.matrix.desaturate() * im.matrix.tint(0.9, 0.9, 1.0))

Сначала изображение обесцвечивается, а затем тонируется в синий оттенок. Когда промежуточное изображение не требуется, перемножение матриц работает значительно быстрее и экономит место в кэше текстур по сравнению с двумя последовательными вызовами im.MatrixColor.

Предупреждение

Новые объекты Matrix перемножаются в порядке, противоположном старым объектам im.matrix. Если X — матрица Matrix, соответствующая im.Matrixcolor.x, то матрице im.a*im.b*im.c будет соответствовать произведение C*B*A.

class im.MatrixColor(im, matrix, **properties)

Манипулятор изображений, использующий матрицу matrix для линейного преобразования цветов изображения im.

matrix должна быть списком, кортежем или объектом im.matrix() длиной 20 или 25 элементов. Если передано 25 элементов, значения после 20-го игнорируются.

Если четыре цветовые компоненты исходного цвета равны R, G, B и A в диапазоне от 0.0 до 1.0; четыре компоненты преобразованного цвета равны R', G', B' и A' в том же диапазоне; а элементы матрицы обозначены как:

[ a, b, c, d, e,
  f, g, h, i, j,
  k, l, m, n, o,
  p, q, r, s, t ]

то компоненты преобразованного цвета вычисляются по формулам:

R' = (a * R) + (b * G) + (c * B) + (d * A) + e
G' = (f * R) + (g * G) + (h * B) + (i * A) + j
B' = (k * R) + (l * G) + (m * B) + (n * A) + o
A' = (p * R) + (q * G) + (r * B) + (s * A) + t

Значения результирующих компонент цвета ограничиваются диапазоном [0.0, 1.0].

Устарело, начиная с версии 7.4.0: Используйте Transform(im, matrixcolor=matrix, **properties). См. Transform() и свойство matrixcolor.

class im.matrix

Создаёт объект im.matrix из matrix. Объекты im.matrix поддерживают матричное умножение, умножение на скаляр, а также поэлементное сложение и вычитание. Эти операции вызываются стандартными математическими операторами (*, *, + и - соответственно). При умножении двух объектов im.matrix выполняется матричное умножение, в остальных случаях — умножение на число.

matrix представляет собой список или кортеж из 20 или 25 элементов. Если передано 20 элементов, список дополняется значениями (0, 0, 0, 0, 1) до квадратной матрицы 5x5, готовой к матричному умножению.

Устарело, начиная с версии 7.4.0: Используйте класс Matrix.

im.matrix.brightness(b)

Возвращает im.matrix, изменяющую яркость изображения.

b

Величина изменения яркости изображения. Должна быть числом от -1 до 1, где -1 даёт максимально тёмное (чёрное) изображение, а 1 — максимально яркое (белое).

Устарело, начиная с версии 7.4.0: Используйте BrightnessMatrix(b) со свойством трансформации matrixcolor.

im.matrix.colorize(black_color, white_color)

Возвращает im.matrix, раскрашивающую чёрно-белое изображение в заданные цвета. black_color и white_color задают цвета в формате Ren'Py — строками или кортежами значений компонентов (0–255).

# Окрашивает чёрные участки в красный цвет, а белые — в синий.
image logo colored = im.MatrixColor(
    "bwlogo.png",
    im.matrix.colorize("#f00", "#00f"))

Устарело, начиная с версии 7.4.0: Используйте ColorizeMatrix(black_color, white_color) со свойством трансформации matrixcolor.

im.matrix.contrast(c)

Возвращает im.matrix, изменяющую контрастность изображения. Параметр c должен быть строго больше 0.0: значения между 0.0 и 1.0 снижают контрастность, а значения больше 1.0 — увеличивают.

Устарело, начиная с версии 7.4.0: Используйте ContrastMatrix(c) со свойством трансформации matrixcolor.

im.matrix.desaturate()

Возвращает im.matrix, полностью обесцвечивающую изображение (делающую его полутоновым). Эквивалентно вызову im.matrix.saturation(0).

Устарело, начиная с версии 7.4.0: Используйте SaturationMatrix(0) со свойством трансформации matrixcolor.

im.matrix.hue(h)

Возвращает im.matrix, сдвигающую цветовой тон (hue) на h градусов с сохранением яркости.

Устарело, начиная с версии 7.4.0: Используйте HueMatrix(h) со свойством трансформации matrixcolor.

im.matrix.identity()

Возвращает единичную матрицу, оставляющую цвет и прозрачность без изменений.

Устарело, начиная с версии 7.4.0: Используйте IdentityMatrix() со свойством трансформации matrixcolor.

im.matrix.invert()

Возвращает im.matrix, инвертирующую красный, зелёный и синий каналы изображения без изменения альфа-канала.

Устарело, начиная с версии 7.4.0: Используйте InvertMatrix(1.0) со свойством трансформации matrixcolor.

im.matrix.opacity(o)

Возвращает im.matrix, регулирующую непрозрачность изображения. Значение o, равное 0.0, соответствует полной прозрачности, а 1.0 — исходной непрозрачности.

Устарело, начиная с версии 7.4.0: Используйте OpacityMatrix(o) со свойством трансформации matrixcolor.

im.matrix.saturation(level, desat=(0.2126, 0.7152, 0.0722))

Возвращает im.matrix, изменяющую насыщенность изображения. Альфа-канал остаётся без изменений.

level

Коэффициент насыщенности результирующего изображения. Значение 1.0 оставляет изображение без изменений, а 0.0 делает его полностью чёрно-белым.

desat

Кортеж из трёх чисел, определяющий весовые коэффициенты красного, зелёного и синего каналов при расчёте яркости для обесцвеченного изображения. По умолчанию используются константы яркости стандарта телевещания NTSC. Поскольку человеческий глаз наиболее чувствителен к зелёному цвету, доля зелёного канала превышает доли двух других.

Устарело, начиная с версии 7.4.0: Используйте SaturationMatrix(value, desat) со свойством трансформации matrixcolor.

im.matrix.tint(r, g, b)

Возвращает im.matrix, тонирующую изображение без изменения альфа-канала. Числа r, g и b должны находиться в диапазоне от 0 до 1 и задавать множители для соответствующих каналов цвета (например, если r равно 0.5, а исходное значение красного канала было 100, то в результате оно станет 50).

Устарело, начиная с версии 7.4.0: Используйте TintMatrix(Color((r, g, b))) со свойством трансформации matrixcolor.
